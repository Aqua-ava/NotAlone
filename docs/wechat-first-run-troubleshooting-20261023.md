# 微信首次接入：当前入口与历史记录

当前操作从[现行微信同步](../architecture/current/wechat-sync.md)的「连接账号 → 选择联系人 → 确认并开始同步」进入，开发启动见[新环境指南](guides/new-environment-hot-start.md)，外置 CLI 配置见[桌面说明](../desktop/README.md#外置微信工具)。账号检测、工具准备、会话名单访问和正文同步授权是不同步骤；检测成功不证明完整历史或图片已可读。

权限或连接失败先按[权限与启动指南](guides/macos-app-permissions-and-errors.md)核对实际开发进程、固定错误及本次读取范围，不直接复用旧包、初始化脚本或权限重置操作。

[2026-10-23 首次接入完整记录](history/wechat-first-run-troubleshooting-20261023.md)保留当时的安装缺失、临时终端权限、wxkey 初始化、26／27 密钥覆盖、降级状态和实际账号检测结果。临时权限关闭后的持续读取当时未复验；一键式接入是当时提出的目标，不能据此声称当前已实现。原记录的授权只属于那次操作，不构成继续读取或初始化授权。
