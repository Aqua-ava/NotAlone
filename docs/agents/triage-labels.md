# Triage 标签

| Canonical role | 本仓库使用的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待评估和分类 |
| `needs-info` | `needs-info` | 等待补充必要信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可由 Agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要用户判断或人工操作 |
| `wontfix` | `wontfix` | 已决定不处理 |

当 skill 提到 canonical role 时，使用表中对应的本仓库标签。
