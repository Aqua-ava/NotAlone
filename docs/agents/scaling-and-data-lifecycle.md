# 数据增长与资料生命周期检查

修改回复输入、累计列表、来源核验、级联删除、桌面资料失效或启动诊断时使用本文件。目标是在长期积累后保持工作量有界，并保留来源、联系人隔离和删除保证。

## 回复输入与来源核验

- 核验一条资料时按稳定身份与版本定向读取；同一数据库事务内的集合复核只建立一次索引。跨事务或请求重新核验来源及修订，不能把旧缓存当作当前资格。
- 冻结模型输入前，先过滤合法范围，再按相关性选择，并落实各类资料的数量及文字预算。排序使用真实采纳方式，包含人工与自动记忆的混合夹具。
- 验证正式生成入口送到合成模型端的实际请求；只测试排序辅助函数，不能证明正式路径已接线。增加无关长期资料后，输入仍受预算限制，当前明确要求和来源编号保持有效。
- 用相同的10／100／更多条合成资料对比查询次数；单条核验和批量核验应避免逐项重建全量集合。记录测试替身，不能把空数据库替身耗时称为SQLite或App性能。

完成条件：实际模型请求有界；删除、修正和来源失效仍拒绝旧输入；增长测试没有出现平方级重复核验。

## 累计列表与历史详情

- 从SQL查询到HTTP、桌面桥和React使用同一分页合同；页面默认读取有界摘要，历史版本、决定及依据按需读取。
- 使用稳定排序及绑定范围的游标。翻页期间资料修订、联系人、连接或显示范围变化时，撤下旧页并重新读取；旧游标不能混入新快照。
- 数组及响应字节上限是运输保护，不是分页方案。测试累计记录超过运输单页上限时，仍能逐页查看和操作。
- 过滤条件、排序和游标必须共同得到SQL索引支持。仅加`LIMIT`不保证扫描有界；覆盖“大量已采纳、少量待确认”等不均匀状态，验证查询计划和实际扫描量。
- 轮询只用于有界状态或当前页；无变化时优先比较修订号。渲染仅覆盖已载入页面，折叠详情不能提前读取全部历史。
- 页外对象的修改按稳定ID和预期版本复验，不能靠重读第一页判断对象是否存在。
- 展开的历史详情跟随每份新的权威列表快照撤下并复验，保留当前历史游标并拒绝旧回执。头版本号或分页修订未变，不代表来源守卫与读取资格未变；折叠状态不提前读取历史。

完成条件：大数据量下每次读取及渲染有界；跨页无遗漏或重复；范围变化、删除中和迟到回包均不能恢复旧正文。

## 删除影响与桌面撤下

- 级联删除沿真实依赖传播；先建立索引，再沿尚未访问的关系推进。同运行副本仅处理受影响位置及其后续输入。
- 本人资料可能连接多个联系人。减少扫描时仍须保留这些真实依赖，不能简单把全部查询限制为被删联系人的ID。
- 优化前后比较相同依赖图的完整删除集合，覆盖显式继续、引用发言、准备副本、循环依赖、早期内容和独立内容；再运行真实SQLite删除集成。
- 桌面来源删除、联系人删除和历史清空统一经过 `DesktopDataLifecycle` 撤下资料。新增资料视图时，在同一模块登记其撤下动作，并覆盖在途请求取消和迟到成功回包。
- 控制器继续拥有自己的操作代次、取消和范围校验。协调模块只负责一致的撤下及复验次序，不代替后台权威核验，也不把失败或未知结果当成功。

完成条件：优化前后删除集合一致；独立资料仍保留；同范围来源变化无需等待联系人切换即可撤下旧内容。

## 索引与迁移

- 用有索引的派生字段保持跨页排序，沿用原有日期精度和未知规则；不能把全局时间线退化为每页各自排序。
- 排序投影必须复用实际展示来源的领域规则，不能直接拿原始引文的最晚日期代替。旧资料补建分批执行，支持取消并明确显示准备状态；按ID查看详情和修改不得等待整个目录补建。
- 持久派生值不能把临时守卫、连接或授权状态写成永久缺失。覆盖“暂时不可读→恢复”的路径；正文仍在每次读取时复验实时资格。已缓存的错误派生值需有后续迁移或明确重建路径。
- 检查维护索引的写入成本：复制K条引文或批量删除时，触发器不能每条都重扫K条旧引用。验证新增版本、切换当前版本和删除闭包三条路径。
- 新迁移先完成隔离测试，再加入运行注册表。开发热更新会应用已注册迁移；一旦应用，保留该版本SQL及校验和，后续修正追加版本。
- 升级验证既覆盖新建库，也覆盖上一版结构到新版的真实迁移；校验和不一致时先恢复原定义，不能修改业务库账本或重建资料来掩盖问题。
- 新增迁移时同步更新当前结构基线，并逐项核对预期DDL差异；历史升级夹具保留其原版本结构，不能一起改成最新版本而丢失升级覆盖。

完成条件：跨页顺序与旧展示一致；派生索引维护无平方增长；已应用版本可原地升级且完整性检查通过。

## 启动诊断

- 在固定本机位置保存有界结构化诊断，包含失败阶段、白名单原因和时间；成功就绪后清除，失败退出后保留。
- 诊断字段从明确枚举生成；异常正文、堆栈、配置路径、凭据和业务正文不进入诊断文件或用户文案。
- 测试正式启动路径的配置失败、数据库失败、成功重试及资源清理；同时验证异常内的合成敏感字符串不会写入文件。
- 具体阶段和安全文件合同沿用[权限与启动错误记录](../guides/macos-app-permissions-and-errors.md)，不在本文件另存一套错误码。

完成条件：失败原因可按阶段定位；临时进程资源已清理；诊断不泄露敏感内容。

## 验证与报告

先使用小规模合成数据重现，再以同一工作负载比较修复前后。优先记录查询次数、访问次数、实际输入大小和单页数量；耗时注明机器、运行次数及是否包含SQLite、模型和界面。按[工程工作流](engineering.md)执行最小相关检查，涉及界面时另外完成实际操作，未覆盖的范围明确列出。

测试夹具要覆盖正式流程前置读取的合法响应，不能让未知路由返回另一种对象。等待合成请求闸门的测试设置超时，失败时报告缺失请求；避免全套测试一直等不到不会发生的回调。
