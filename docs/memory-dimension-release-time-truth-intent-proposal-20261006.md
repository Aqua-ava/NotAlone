## 通过口径

每个维度分别报告 `cases`、通过数、假事数、记错人数、一般错误数、语义标注覆盖和
`summarize().meets_gate`。只有同时满足以下条件，才产生“可考虑放行”的证据：

- 用例数至少 15；
- 假事 0、记错人 0、一般错误不超过 1；
- 语义标注覆盖和失败形态单独报告，不把未标注用例当作语义证明；
- 维度键可由现有结构化字段确定性推导。

达标签仍只是必要条件；评测完成后，每个维度还要由用户逐类批准，才能修改放行台账
和 `DEFAULT_DIMENSION_RELEASE`。任何维度未达标签时，生产继续全部待确认。
