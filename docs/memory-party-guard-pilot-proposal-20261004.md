# 主张人物核验的匿名有限对照提案

状态：待用户决定。当前只批准本机准备，新模型调用授权为0。本文不恢复任何已关闭试验的预算，不修改产品默认路径。

## 要检验的问题

[上一轮](memory-source-pragmatics-pilot-result-20261003.md)独立来源三标签只判对4/12，错误auto仍为4，且额外降级4项正确转述。本机捕获重放确认程序按返回值运行，没有确定性字段丢失。新的假设是：显式区分“这条主张讲的是谁”，再用窄规则检查第三人错标，能减少错误自动放行，同时保护正确本人状态与转述。

这不是知识状态漏提修复。“本人不知道朋友报酬”此前在E首包没有候选；本试验E／R调用为0，提供该句候选只能测试核验能力。

## 唯一方案与比较边界

对照臂为完整原产品V。试验臂保留原V全文及候选11键投影，包括E的三个语用标签；追加临时`described_party`与`party_evidence`。补充指令明确本次六键输出取代原提示的输出字段限制，其余原核验要求继续适用。四条新对照原话及参考答案不进入补充静态提示。

人物指候选事件、状态、属性的直接承担者、体验者或参与者，区别于关系资料`subject`、消息sender和提及对象：`owner`仅用户，`contact`仅联系人，`both`仅用户与联系人共同参与，`third_party`直接承担者全为第三人，`mixed`至少一位第三人与用户／联系人至少一方共同参与，`unclear`无法确定。第三人属于哪一方的亲友仍由原正文及`subject`表示，不新增业务actor字段。

唯一新增编译规则：raw为`supported`、人物为`third_party`、原E同时为`assertion/asserted`时，编译为`uncertain`＋`pragmatics`。其他raw verdict／issues保持，不把`mixed/unclear`或第三人计划一律降级，不升级任何候选。临时人物与定位证据不进入记忆；出口仍为原四键，继续原`ExtractionFlow.run`及`can_auto_adopt`。

每项六键严格完整。supported必须有合法人物值和非空人物证据；non-supported允许人物null和空人物证据。所有非空人物证据继续检查原candidate来源、target及原话逐字范围；这些机械检查不能证明人物语义或证据充分性。非法索引、缺键、额外字段或混合非法返回整包失败，无原V回退。先保存允许的公开raw投影，再解析；不读取或保存内部思考。

上轮source方案从未采用。本轮从完整原产品V重新建立同期对照；相对上轮同时变化了输入可见性、输出和比较规则。相对同期原V也测试提示、结构要求与guard的联合效果，不能把收益单因归给人物问题。

## 逐阶段过门与失败关闭

原话／候选参考在调用前独审并冻结，不按返回改答案。每阶段收齐计划位置后，先独审全部允许的原始V输出及人物证据，冻结审计，再揭编译／Flow完整结果；这是顺序隔离，已知对照不能称盲测。人物标签正确率与人物证据语义充分性分别统计。null、非法、运行失败及未运行均保留固定机会分母，不删除成分母更小的正确率。原V没有人物字段，不给它虚造人物分数。

阶段1须两臂等量完整可评价、无运行／结构失败。新臂人物与充分证据均12/12；负例4/4必须编译`uncertain/pragmatics`并pending；正例8/8 raw及compiled均`supported`、issues为空、引用完整，auto4与pending4保护。新臂坏auto为0且严格小于同期原V；若同期原V坏auto为0，仅表示本轮没有可比收益，关闭阶段2，不继续寻找有利样本。

正例保护核对完整后置候选：正文、原14字段、Flow Fact风险、`PragmaticDecision`风险与去向分别匹配。正确`report/reported`的语用决定带`pragmatic:report/reported`并pending，Flow Fact本身未必已写这些标记；只有调用既有`prepare_for_adoption`才会并入Fact，评测不借此新增业务操作。原V若正确接受，同候选新臂必须与其结果逐值等价；若原V误判，则同时记录该损失，新臂仍须达到冻结正确支持参考，不得借基线错误降低标准。仍pending但Flow新增`semantic:pragmatics`也算损失。

仅阶段1全过才准阶段2。阶段2两臂无运行／结构失败；新臂人物及充分证据8/8，负例2/2为`uncertain/pragmatics/pending`，正例6/6完整保护（auto4／pending2），新臂坏auto0。同期原V本阶段若坏auto0，不单独宣称该阶段改善；总体收益须依赖阶段1严格减少及全部正例保护。全部输出包含额外、重复、误拒、证据缺陷、不必要降级、整包合法损失及原14／最终风险差异，全量报告。

每阶段内不因中途语义失败选择性停止或补位；按照固定顺序完成该阶段，确定性预检、凭据、预算、数据范围或执行基础设施错误则立即停止。已预约失败占预算，保留首请求／返回或失败原因；不重试公开invoke、不调提示、不增加臂。阶段1判败时通常8已运行／16未运行，余16关闭；若基础设施提前停，逐位置记录实际已运行与全部未运行。阶段2判败也关闭余量。两臂共40候选机会保留，阶段1一次失败涉及3机会、阶段2涉及1机会；未运行阶段标未运行，不当模型错误或有效通过。

## 这次决定覆盖什么

只批准上述私有匿名联合对照与独立24次V上限，效果和逐条原话验收由Agent负责。通过也不授权开发真实样本、实际同批、最终留出、产品切换或业务写入；这些仍须另有具体范围和证据。实际必需6/12及可选2/6保持未修复状态。

本机反例仍成立：人物错判contact可继续坏auto；mixed／unclear不受窄guard保护；合法引用可能只是被提及对象；严格结构可能整包丢正确候选。本试验要衡量这些判断，不能仅凭本机绿灯声称语义准确。所有旧预算关闭，不读取actual／private heldout、不写业务记忆／水位／旧五条、不改默认、不发布或远端Git。
