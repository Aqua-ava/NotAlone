## 唯一变量与原接缝

E仍使用原模型、思考参数、语义系统提示、14字段Fact、UUID窗口及来源规则。只把工具结果从facts数组改为groups数组，追加组织协议；每个target恰好一组，可为空。组ID只组织输出，不充当证据，不新加“该组ID必须在fact来源”的门；相连多来源事实允许只放一个组，其他组为空。完整合法结果按原target顺序摊平成原ExtractionPayload。

遗漏、重复、未知／context-only组ID、非法组结构或多个结果工具整体失败；组内坏fact仍沿原逐条解析和拒绝，不补ID、不猜来源、不回退flat结果。原V、Flow、语用、采纳及60候选预算不变，不叠加短编号、subject说明、时间提示或R。窗口内事实与上下文的source／target／quote门均保持。

两臂共同先按键过滤隐藏思考字段，再把公开content／tool_calls与白名单用量／元数据交给原E／V消费；保留14字段及未知公开extra键，不靠过滤普通非法字段掩盖结构失败。匿名sentinel和公开结果等值重放先核验；不会把隐藏对象直接透传称为隐私过滤。公开I/O只在仓库外保留，不保存内部思考。

模型仍为现有ECNU的ecnu-max，thinking enabled、未指定effort、temperature=0、60秒超时及SDK重试2；不采用官方服务或更换回复模型。现有构造入口实际使用ChatDeepSeek。Context7不可用，已对照 [ChatDeepSeek官方源码](https://raw.githubusercontent.com/langchain-ai/langchain/master/libs/partners/deepseek/langchain_deepseek/chat_models.py)及其[父类bind_tools源码](https://raw.githubusercontent.com/langchain-ai/langchain/master/libs/partners/openai/langchain_openai/chat_models/base.py)，再核现装deepseek 1.1.0／langchain 1.3.15／core 1.5.5／openai 1.5.1的方法签名；原dict schema和具名tool_choice入口保持，不增strict等参数。读取官方接口文档不代表调用官方模型。文档和离线构造只证明接口，服务兼容仍待匿名实测。

## 评分与门

联网前独立冻结Gold、原正确主张保护集合和逐轴评分规则；新输出先按原话审全部raw，再揭V及去向。Gold／原标签不能按输出改，Agent参考不等于用户确认。正文、主体、语用、时间、引用充分性、误拒、坏auto、空提取与运行失败分别记录。逐字quote真实不等于意思正确，不强制每个无关来源都复制全文。

保护单位为每个case×repeat完整契约正确且最终保留的主张机会，包含原准确extra；分组允许完整等价拆分／合并，不要求候选数量或逐字形式相同。旧开发9条来源候选覆盖11个必需主张机会及1个准确extra；不能用新候选数大于9宣称改善。fresh原配置先盲审Eraw，再链接V、引用和去向确定保护集合，不依group输出修改；其正确raw被V误拒或随失败损失仍单列，不改Gold负例或丢分母。错误减少按同次窗口复现的错误主张／错误轴计，不用拆分改变错误率分母；运行失败造成少输出不算收益。

- 匿名：完整覆盖两条明确必需主张，全部输出契约正确，0确定／歧义坏auto，原Flow与组协议完成。组覆盖不证明主张覆盖，也不强制每个target有事实。
- 开发：必需严格覆盖不低于原11/18与本次原配置；原及本次原配置的正确主张机会含extra全部保留；0确定／歧义坏auto，运行／结构失败不劣于原及本次原配置。至少严格覆盖增加，或复现错误主张／错误轴相对原及本次原配置减少；不能用正例损失换错误减少。
- 实际：严格必需覆盖较原6/12与本次原配置提高，原及本次正确主张含extra保留，可选覆盖不低于原2/6与本次原配置；0确定／歧义坏auto，运行／结构失败不劣于两基线。固定候选或局部内容出现不代替自然复测。
- 留出：分组严格覆盖不低于本次原配置，正确主张不丢，0确定／歧义坏auto，失败不劣；全部额外输出及禁止主张审计。通过也须完整相关检查、两轴审阅和原用户需求逐项完成审计，才判断生产改动与目标完成。

任阶段判败就关闭这条配置，不进入下一阶段、不修改冻结协议补跑。判败后若需要改变方案、调用或范围，按工作流处理新决定；剩余额度不是许可。当前仍是准备，未消费后续预算、未批准生产。
