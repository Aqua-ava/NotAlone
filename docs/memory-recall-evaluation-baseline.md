# 记忆召回第一期评测基线

日期：2026-09-17。范围：票 05，标定词法召回阈值并固化常量，不修改门槛规则。

## 运行条件

- 确定性离线评测：不连接数据库、不调用模型、不需要模型凭据。
- 命令：`conda run -n NotAlone python -m unittest tests.unit.retrieval.test_recall_evaluation`。
- runner 装配真实评分器与真实回复上下文组装；用例全部为合成中文内容，仓库中不含真实聊天或联系人资料。

## 阈值标定

对同一组 109 条用例扫描阈值（其余常量不变），观察七维度门槛：

| 阈值 | 直述 | 改写 | 排序 | 其他 |
| --- | --- | --- | --- | --- |
| 0.10 | 1.00 | 0.93 | 1.00 | 全部通过 |
| 0.15 | 1.00 | 0.93 | 1.00 | 全部通过 |
| 0.20 | 0.93 | 0.67 | 0.00 | 排序与改写显著退化 |
| 0.25 | 0.80 | 0.33 | 0.00 | 多维度退化 |
| 0.30 | 0.73 | 0.27 | 0.00 | 多维度退化 |

结论：0.15 是保持全部门槛的最高值。降到 0.10 在本组用例上没有增益，只会放宽无关资料进入的门槛，因此保留 0.15；上调到 0.20 及以上会直接破坏排序与改写维度。预算与 query 上限沿用 ADR-028 常量：预算维度用例按 5/600 与 3/240 的前缀规则编码，当前没有证据支持调整。

## 证据边界

- 本基线只说明词法召回在这组合成用例上达标，不代表真实聊天分布的召回质量；真实聊天不进入仓库，也不参与该评测。
- 同义表达漏检规模由改写维度持续度量；只有后续评测持续显示词法不足时，才按 ADR-005 第 5 节评估向量补充。
- 用例或常量变化后必须重新运行并更新本文件。
