# 真实表达离线保真报告

入口只读取合成案例、受控输出与明确标注，不构造模型、不加载业务配置、不访问数据库。报告本身含原输出，只应存放合成数据；不要把私人资料或报告正文写入普通日志。

```bash
conda activate NotAlone
PYTHONPATH=backend/src python -m notalone.reply.fidelity_evaluation \
  --dataset backend/tests/fixtures/fidelity/synthetic-v1.json \
  --run backend/tests/fixtures/fidelity/controlled-v1.json \
  --output /private/tmp/notalone-fidelity-report.json
```

`synthetic-v1` 有16例：4例开发回归与12例独立保留场景，覆盖意图、事实/经历、情绪、承诺、动机、旧资料时效、联系人表达、样本冲突、无历史、整组一致性及故障。成对前文只用于说明不同意图不可替换；原型的无依据开场白只在开发集。模型输入白名单不含标签、预期答案、禁止项或划分；本入口完全没有模型调用。

受控夹具故意注入14个错误输出、1个超时、1个缺失。逐例保留确定性结构/引用检查、原输出、正耗时与调用计数。语义维度只能来自显式标注，必须注明标注者及依据；自然度、关系适配与用户相似度在本夹具均为 `unknown`。缺失的成本为未知；已执行超时计入耗时与调用数。硬性意图或无依据内容失败单独计数，不用自然度平均分抵消。

这轮实际离线结果：分母16，契约失败2，显式合成标注14，保真失败14，未审阅2；已知受控调用记录小计15、耗时1640ms，缺失成本1例，总调用数及总耗时为未知。报告分别呈现开发/保留分母及五个语义维度的通过、失败、未知、未审阅与有效分母。调用记录描述输入夹具，CLI未调用任何模型。没有真实语义审阅、自然度或“像本人”的证据，报告始终注明 `quality_verified: false`。提示调整使用过的保留例不能再称未见数据；真实模型评测须另定数据范围、配置和调用预算。
