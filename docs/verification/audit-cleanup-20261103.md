## 有界关系资料与工具

L1 沿用 0.15 词法阈值，联系人最多 5 条／600 字符，本人最多 3 条／240 字符；未确认参考的兼容接口独立最多 3 条／300 字符，当前正常读取器不启用该轨。查询使用真实请求和近期消息，空请求不会拿工作区说明模板召回资料。

独立复审发现并修复两处边界：Skill 失效降级时将已保留正文及原编号重新放入实际请求，正文读取额度继续累计；初始加载省略失效派生资料，而已冻结／已读资料发生纠错或来源更新时仍严格失败。旧无投影身份沿原完整正文合同核验，不迁移保存内容。文档复验也改为一次调用内按发布集合批量核验；每一项目录／正文投影继续分别比较。固定合成负载中，1 场景加画像的逐项复验 574 次 SQL／30.1 ms，改为 288 次／18.0 ms；15 场景加画像由 46,752 次／2,654.3 ms 改为 2,937 次／128.7 ms。缓存只活在这次批量调用中，同事务后续修改来源后再次复核仍失败；不把事务对象当作长期资格缓存。耗时是合成单次结果。相同容量用例含准备的总时间从 32.53 秒降为 5.11 秒。该容量验证复用正常 90 秒执行期限、1,048,576 上下文容量和 65,536 安全余量，环回替身的输出预留仍为 512；三个实际请求输入上界约为 7,689／13,339／18,989。数据只证明有限容量与程序行为，不证明真实模型质量。
