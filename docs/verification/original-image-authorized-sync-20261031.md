# 授权会话原图同步实施记录

日期：2026-10-31。决定：[ADR-137](../../architecture/adr/137-original-image-authorized-sync.md)。

## 实现范围

- 已接受的历史／增量消息页、启动和合法读取开启会唤醒原图协调器；不依赖记忆任务。
- 消费当前有效授权绑定，串行处理图片；普通同步复用合法原图，缺失尝试持久去重，清除状态不自动恢复。
- 只保存原图文件，数据库保存来源、关联、质量和状态；缩略图、未知质量和无法取得的资源只留消息／尝试记录。
- 原生协议绑定账号、会话、固定目标、分片、表实例和完整消息身份；消息—资源关联及原图 HD 元数据、内容摘要、长度、尺寸均须吻合。
- 只读本机资源，不注入或修改微信进程，不自动探钥、不读取缩略图或临时目录，也不请求远端图片地址。
- 流、受管文件、预览和来源删除沿既有持有者与删除服务处理；取消／关闭等待在途资源退出。
