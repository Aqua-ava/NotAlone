# 本机回复资料与独立模型并发验收（2026-11-03）

依据：[ADR-162](../../architecture/adr/162-local-reply-context-and-independent-model-lanes.md)。工作起点为 `901558303ddee81208ab7cd090819f55148f60ce`，本次在 `codex/local-reply-independent-permits` 独立工作树完成，未改动主工作区的其他未提交任务。

## 实现与边界

- 回复按 `owner_id + contact_id` 读取持久接纳的本机消息、正式记忆与完整发布资料；不装配微信来源恢复器，不启动同步或记忆处理。后台采集和写入保持原活守卫。
- 出站、保存、旧候选继续及讨论恢复复核实际消息版本、知识版本和完整发布成员及其递归依据。无关新增记忆和新发布不使在途输入失效；真实纠错、删除、隔离、来源围栏和换图继续阻断。Skill 失效降级也遵循同一精确依赖。
- 一个 DSH 宿主、共享 provider 和统一出站台账，前台固定 1 路，后台沿用 N 路（默认 3）。两类不借槽；未知调用保留所属类别许可，全局暂停、退出和持久化失败保护保持。
- 无数据库结构迁移、真实资料修改或新增外部读取授权。新请求不能指定任意历史文档版本；既有失证围栏不自动恢复。

## 开发 App 实测

只运行 `pnpm run dev --user-data-dir <独立合成目录>`，启动后用同一目录的 `dev:status` 核对实际开发实例。使用已有合成网络保护器，将正式供应商发送转到本机环回，其他出站拒绝；没有使用真实密钥、私人聊天或执行微信消息发送。

Computer Use 实际操作：

1. 管理页可见两名合成联系人及各一条已保存消息，明确显示同步总开关关闭。
2. 选择合成甲并打开输入小窗。微信识别服务不可用时，明确确认本次联系人并创建助手会话。
3. 输入“帮我回应下周一见面，轻松简短一点。”，点击“帮我表达”。界面出现“候选已保存”及可编辑候选“周一见！到时候轻松聊聊。”。
4. 展开依据，实际显示“聊天原文 对方：合成甲已经确认下周一见面，喜欢轻松简短的回应。”，证明使用了本机保存消息。
5. 开发源码热重启曾要求重试停读，通过界面正常重试后恢复；未强制杀 App。最终通过正常退出关闭自有实例，确认后端握手和锁均已清除，`dev:status` 为 stopped，再关闭合成供应商并清理其自有目录。原工作区实例未被终止。随后核验 Git 未跟踪且无进程引用，清理本工作树开发缓存约 3.8 MiB；合成供应商报告零错误并清除自有目录。

App 实测验证本机资料生成与依据显示；后台保持在途时的并发、快照纠错及删除边界由自动集成测试证明。没有验收真实供应商质量、真实微信同步或发布包。

## 全量验证及剩余限制

全量后台与桌面测试均使用 600 秒上限。后台结果为 1689 项：1619 通过、70 失败，约 398 秒；桌面为 1224 项：1206 通过、17 失败、1 跳过，约 286 秒。两套全量均退出 1，不能宣称全绿。每套各有两个长挂测试，在修改前代码定向复现相同挂点后，仅对本轮已核验 PID、父进程和路径的测试子进程发送 SIGTERM，使其余结果正常结算；其他工作树的同名进程未动。

本次合同变化涉及的旧错误码、quarantine fixture 和空 publication 断言均已适配，分别由 155 项和 15 项定向复验通过；未重复整套全量。其他失败按以下证据分类：

- 从固定基线提取独立源码快照、复用锁定依赖定向复现。7 个后台代表文件 49 项中 25 通过、24 失败，复现 strict 输出、typed 裁决删除／迁移、切换目录／结构／版本及空库断言；另 17 项复现图片自动 profile、旧记忆候选／状态／文档迁移等失败。
- `sqlite-shared-model` 基线同样因旧夹具缺 `ctx.plugin` 失败后不退出；记忆提取的阶段提交用例在基线 20 秒内同样不结束。未扩展修改这些生产路径。
- 两个桌面恢复文件在基线均复现 15 秒挂点；相关表达偏好、本人页面、SQLite 版本和同步优先级失败也在基线复现。桌面生产源码没有本次改动。
- 原图相关用例报 `media_validator_unavailable`，本工作树没有构建该原生媒体验证器，属于该项验证的环境缺口；不据此推断原图产品行为可用。

桌面默认测试入口起初因既有 `workspace-draft-sqlite-handoff.test.mjs` 未登记而拒绝运行；本次只将它登记到符合其 Chromium 前置条件的 headless 分类，没有把浏览器测试塞入默认 Node 套件。
