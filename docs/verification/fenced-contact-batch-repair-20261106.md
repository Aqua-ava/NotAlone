## 4. 剩余 3 位围栏的解释

- 原因码全部为 `history_recertify_suppression_unmapped`（界面文案“删除或清空保护无法映射到新来源”），联系人的读取保持停止，围栏保留。
- 数据侧证据：三位分别有 131、8、7 条 `history_source_terminal`（撤回/终态）记录；旧来源终态无法映射到重新读取的来源，后端按 ADR-144 的保护拒绝激活。这属于设计内的跳过，不是程序错误，也不属于本次可自动修复的范围，需要单独人工处理。
- 其中一位在更早的小批里已留下相同失败终态；全量批次在接纳阶段被后端直接拒绝，因此数据库只新增了 2 行失败认证记录，但界面跳过计数为 3。三者与剩余围栏数一致。
- 失败码分布中未出现未知类型，未触发“连续同类失败整体停下”。
