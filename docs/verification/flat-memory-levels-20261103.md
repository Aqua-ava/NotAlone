# 分层记忆平铺浏览验证

日期：2026-11-03。

## 变更与数据范围

- 顶部用「对方」「我」切换资料对象，以 L1 具体记忆、L2 主题资料、L3 长期概览三个按钮切换整页内容，默认展示对方 L1。
- 人物切换采用左侧无外框文字页签，选中态使用蓝色下划线；层级按钮、标题、正文和卡片沿用 App 的蓝色、米白色及现有 `--panel-*` 变量。
- 所选层的所有记忆或文档直接平铺正文，不再逐层或逐条展开。来源、依据和历史版本继续按需查看；处理状态移到记忆之后，默认收起。
- 切层保留未提交编辑；切换人物或联系人、资格失效、读取失败及决定提交时继续撤下受影响正文，迟到结果不得恢复旧资料。
- 仅调整展示和读取生命周期，不新增数据迁移、模型调用用途或发送能力。本人 L2/L3 沿用当前联系人页不得读取全局本人文档的限制，并直接显示范围说明。

## Computer Use 实测

实际进入「记忆」并选择原有已确认联系人：默认 L1，无需展开即显示正式记忆与候选区域；点击 L2 后只显示主题资料，点击 L3 后只显示长期概览；切换「我」保留所选层，并显示本人范围说明。检查实际排版、三按钮选中状态和处理状态默认收起。

上述实机操作覆盖平铺交互，最终蓝色配色与左侧人物页签的视觉复验使用合成预览；未覆盖该最终样式的实机画面。

当前所选联系人没有可展示的 L1，L2/L3 为待核验状态，所以实际 App 覆盖切层、人物切换及空／不可用状态；有正文的卡片、编辑和来源／依据操作由合成页面测试覆盖。未主动变更真实资料、同步授权或处理状态，未发送微信消息。私人姓名、正文及截图未保存到仓库。
