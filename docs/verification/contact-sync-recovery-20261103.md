# 联系人同步与聊天刷新验证

日期：2026-11-03。

## 问题与修复

- 已确认联系人的读取总开关和逐人授权均有效，聊天页面仍保留旧消息。联系人默认加入时，生产服务已在同一事务建立绑定、核验和读取授权；运行中补选同样具备资格，用户暂停或撤销不因添加联系人而恢复。
- 联系人聊天控制器原先忽略事件流连接与断流，后台历史补齐也不产生新来信事件。现在连接后核对最近聊天，断流后重新订阅，每 5 秒只读当前已加载联系人的最近 20 条，合并保留较早分页与滚动位置。联系人、连接或来源失效及控制器释放会停止旧范围读取。
- 原生守卫瞬时超时可能抢先完成释放，布尔守卫检查或接受事务随后把它统一报为不可重试的来源失证。现在保留原始安全错误码；仅在正常使用基线、无真实来源失证、用户未取消且持久资格仍允许元数据重验时恢复退避重试。不清除围栏，不重新授权。
