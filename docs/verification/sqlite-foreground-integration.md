# SQLite 前台定位接线核验

SQLite 宿主原未提供 `/api/sync/foreground/observe`，桌面观察请求因此得到 503。接线复用既有 `ForegroundLocator`、原生单帧探针及 SQLite 联系人授权；只读取微信前台窗口顶部名称和严格只读 CLI 会话元数据，不读取聊天正文。请求不接受客户端指定联系人或采集参数。授权或身份变更先排空观察；观察前后复核账号、绑定和读取开关，失效后不返回联系人。

通道元数据支持档明确不认证当前前台登录账号，因此仅 `foreground_confirmation` 桌面绑定可自动确认；仅凭 `channel_metadata` 的绑定保留名称提示并要求用户选择。会话名单中群聊名称缺失时不能证明唯一，也不自动确认。这个限制意味着现有仅有渠道证明的绑定不会自动切换；需要后续提供可信的桌面账号核验和绑定建立路径，不能把接线当成该能力已完成。

DSH 声明和安装均为 `0.2.1-rc.2`，Cordis 为 `4.0.5`；核对 `backend-ts/package.json`、`pnpm-lock.yaml`、安装包与官方参考源码 `687f282e8625c6b8d11ff58211a90524be2e4317` 的 Cordis primer 中 `inject`、`apply`、`ctx.effect` 约定。本改动沿用已有 `sqlite-host-plugin` 的插件与退出生命周期，不调用未公开 DSH API。未证明 npm 制品与参考源码逐字一致。

合成测试覆盖宿主认证、同步关闭、唯一绑定、同名群聊、名单缺项和授权变更。只读本机名单联调确认账号元数据、会话列表和已保存绑定的适配可以工作；原生画面到真实 App 的完整自动识别尚未验收。
