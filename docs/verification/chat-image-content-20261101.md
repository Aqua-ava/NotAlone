# 聊天图片取消原图证明门槛验收（2026-11-01）

按 ADR-140 将图片是否可查看与原图身份分开：已授权、稳定消息精确匹配、资源唯一关联、实际字节完整并成功解码即可保存。新回执使用 `wechat-message-image-content-v1`，保存质量为 `unknown`，不伪造原图证明。兼容读取已有原图回执与副本。

## 实现与边界

- 本机主图不依赖 XML 的原图 MD5、HD 长度或大图 URL；仅有同一消息合法关联的缩略图也可保存。多个冲突资源、错消息、错来源及不可解码文件仍失败。
- WXGF 解码修复有界头部内的伪 Annex B 起点，随后仍须合法 VPS／SPS／PPS／VCL 顺序和完整单帧解码。不会任意扫描文件寻找可拼接图像。
- 原生读取先检查 4000 万像素预算；过大合成 PNG 的失败路径分配量由约 160 MB 降至约 228 KB，继续返回资源限制错误。
- 图片实际长度、源与输出 SHA-256、受管文件路径、读取授权及删除路径保留。取消原图升级按钮，正常保存及展示不再要求原图质量。
- 自动重试键升级为 `image_sync_v5_`，旧失败可再尝试一轮；已有可查看副本、手动清除、删除排除和来源隔离不自动恢复。仅声明新内容合同的固定组件参与自动处理，避免热更新期间由旧组件消耗重试机会。
- 未新增 OCR、关系记忆、模型调用、微信下载或外部发送。
