# 引用回复同步与历史补齐验收（2026-11-01）

本次仅实现 ADR-139：既有授权私聊中的一对一引用回复及旧占位补齐。不改变其他富消息、记忆算法、模型任务或发送能力。界面和代码中同时存在其他任务的图片改动，本提交按文件／hunk 拆分，不包含该部分。

## 实现边界

- 固定 CLI 的 `quote-read` 只接受精确类型 `244813135921`（49/57）、`selected-quote-v1` 同意及账号、会话、分片、表、local/server ID、时间的完整匹配。本人状态 2、联系人状态 4 单独认证；未知状态不扩大普通文字支持档。
- XML、解压量和协议响应均有上限；不返回或持久化完整 XML。引用非文字仅保存类型及身份，不读取媒体载荷。
- `history_quote` 保存回复、被引快照／作者／类型及关联；`history_quote_attempt` 按稳定来源、解析版本、载体修订／状态去重。基础消息、不可变捕获和文字检查点不因补齐改写。
- 原目标只通过同 owner/contact/binding 的已认证 server alias 关联；缺失时保留未关联，后到可关联。删除原目标先登记排除，后续解析也不能恢复快照；载体删除清除扩展。
- 候选查找允许重启后的旧守卫元数据；实际读取和保存仍须活守卫。normal-use 引用只复用普通同步已验证的固定目标及相同完整支持报告；无守卫时等待普通同步建立。普通页内唤醒在真实读取结束后继续，关停可取消等待。
- 桌面分别展示引用作者、被引内容和本次回复，支持未知／失效／失败状态；两处现有 reader 共用严格解析器。
