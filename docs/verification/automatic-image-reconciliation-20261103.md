# 授权范围内自动补查全部图片验收（2026-11-03）

实现依据：[ADR-156](../../architecture/adr/156-automatic-image-reconciliation.md)。用户要求既补查全部已授权联系人的存量图片，也在后续运行时自动处理。

## 实现与边界

- 同一图片队列遍历全部有效授权联系人，按消息身份、当前绑定及读取授权筛选旧未知角色、缺副本和已确认缩略图。已知主图及原图不重复读取，不使用尺寸猜分类。
- 未知角色、缺副本及失败沿持久回执按 1 分钟、5 分钟、30 分钟、6 小时、24 小时退避。来源准备失败也记录明确的失败回执，不接受来源证明、不建立执行租约、不产生文件；按联系人退避，避免一批图片反复核验同一不可用来源。正常来源恢复后继续处理。
- 补查主图成功后沿正常发布及删除链更新；旧未知副本只在新缩略图与原内容 SHA-256 相同时补缩略图分类，其他无改善或失败保留旧副本。
- 自动请求在接受短事务中复验入队时媒体世代和清除状态，覆盖来源准备期间清除的竞态；撤权、来源及联系人删除继续沿既有闭环清除失败回执、文件和请求资格。
- `NOTALONE_IMAGE_PROCESSING` 默认继承后台模式，可单独设为自动。正式宿主通过已有 profile 的 appReady、读取开启和历史页回调唤醒；停读与退出沿既有资源排空。状态接口仅增加模式、安全计数及固定失败码。
