# 单联系人历史记忆手动启动验收（2026-11-01）

状态：实现、相关自动检查及隔离热更新 App 验收完成。

## 入口与范围

顶部选择联系人后，在记忆页「历史聊天」区域点击「处理历史聊天」。主进度卡继续只读，启动成功后立即重新读取当前联系人的进度。未选择联系人时按钮禁用。

认证 `POST /api/memory-processing/contacts/:contactId/history` 仅接受 UUID `request_key`。主进程出站前复验当前联系人、选择修订与连接代次；后端在写事务中核对 owner、联系人、授权、来源与删除状态，只冻结点击时该联系人已保存、尚未成功且未被其他轮次领取的合法文字。包含启用边界前首次为增量的旧文字，不改变自动增量边界；运行中新到文字留待后续。

每轮沿正常提取、核验、采纳与 L2/L3 链运行，保持 20 条提取小批及既有模型预算校验。历史请求使用独立幂等键命名空间；同键重放只返回原轮次，不重新领取或调用模型。不同键并发、暂停、受阻、待裁决与未知回执不被新初始化绕过。空范围不创建新轮次，保留已有结果；没有贡献关系的其他联系人旧失败不阻断本联系人。
