## 问题与可检验假设

原ecnu-max六窗两次捕获共17条候选，9条完整正确；原Flow保留15条，其中6条有契约缺陷，确定坏auto为0。逐轴独审区分6条明确正文／主体／限定错误和2条正文或发生期歧义；后两条另有确定的来源覆盖缺陷，不能把它们统计成没有契约问题的纯歧义。原话、逐索引矩阵及Gold保持不变。

旧ecnu-plus试探同时更换E和V：开发必需完整保留5/18，低于原11/18；实际7/12高于原6/12，但提取超时与开发退步使它不能发布。其V截短UUID和超时损失来自plus自己提取的候选，未证明它在原max固定候选上的效果。旧配置没有测试“原max捕获候选＋原plus核验器”。

因此只检验一个尚未分离的变量：在候选、窗口和核验协议相同的情况下，plus核验是否能减少错误保留，同时完整保留原9条正确候选。这是假设，不宣称不同模型更准，也不将旧plus的局部收益当作本次因果证据。
