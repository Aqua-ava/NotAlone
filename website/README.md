# NotAlone 官网

用于介绍产品和演示交互的单页静态官网，使用原生 HTML、CSS 和 JavaScript，无构建依赖。当前产品合同从[现行架构](../architecture/README.md)进入；官网演示不代表后台能力已接通。

## 本地预览

在仓库根目录执行：

```bash
python3 -m http.server 4174 --bind 127.0.0.1 --directory website
```

访问 http://127.0.0.1:4174/ 。

## 页面内容

- 水彩拼贴首屏、帮我回复与帮我改写演示。
- 可编辑候选、依据展开及复制功能。
- 单张技术架构图，点击模块显示职责。
- 产品理念与 GitHub 入口。

## 数据边界

演示只使用预设合成数据，不调用模型、不读取微信、不持久化输入。主动点击复制时写入剪贴板；剪贴板不可用时提示用户手动复制。最终发送始终由用户完成。

## 验证

JavaScript 语法检查使用 `node --check website/app.js`。涉及交互的改动须在浏览器检查回复／改写切换、编辑复制和架构节点说明；语法检查不能代替这些交互验证。
