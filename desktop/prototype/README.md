# 管理后台与输入小窗原型

> 阶段：prototype。双界面职责已确认；具体小窗布局待选择。所有资料与操作都是合成演示。

## 要回答的问题

用户确认的产品形态是两个独立界面：

- 管理后台：完整页面，负责联系人与会话绑定、单联系人历史导入、关系记忆、后台同步和基础配置。
- 输入小窗：类似输入法候选窗口，用于输入意思、改写或按方向回复、选择与编辑候选、复制后收起。

旧原型把小窗放在模拟微信旁边，并将后台做成弹窗，未表达上述形态。
本轮移除模拟聊天界面与弹窗外壳；后台和小窗有各自独立的预览入口。
旧版本保留在本分支提交 `628fd67`，只作为被否定方案的记录。

输入小窗在同一路由通过 `variant=A/B/C` 比较三套结构：

- A：横向候选栏，联系人、单行输入、三个横排候选；完整编辑与依据按需展开。
- B：纵向候选窗，窄窗口内竖排展示完整候选，选中后原位编辑。
- C：单行工具条，默认只显示一行输入和候选数量，候选与编辑在弹层中展开。

## 启动与预览

在本工作树根目录执行一条命令，无第三方依赖：

```bash
node desktop/prototype/start.mjs
```

- [独立管理后台](http://127.0.0.1:4176/prototype/notalone-windows/?surface=manager)
- [输入小窗 A · 横向候选栏](http://127.0.0.1:4176/prototype/notalone-windows/?surface=ime&variant=A)
- [输入小窗 B · 纵向候选窗](http://127.0.0.1:4176/prototype/notalone-windows/?surface=ime&variant=B)
- [输入小窗 C · 单行工具条](http://127.0.0.1:4176/prototype/notalone-windows/?surface=ime&variant=C)

管理后台与小窗中的链接会另开页面。底部原型切换器只在小窗预览出现，箭头切换并首尾循环；
键盘左右箭头也可切换，编辑框获得焦点时不拦截方向键。无参数入口默认打开后台，
旧的 `?variant=C` 链接仍映射到输入小窗。

端口占用时可设置 `NOTALONE_PROTOTYPE_PORT`；服务只监听 `127.0.0.1`，
拒绝以 `NODE_ENV=production` 启动。已验证的打开方式是上述本地 HTTP 地址；
直接打开 `file://` 文件没有通过浏览器验证。

## 体验路径

1. 在后台切换五个管理页面，体验合成导入、配置、记忆修正和范围确认。
2. 另开输入小窗，输入草稿、生成示意候选、选择候选、编辑与展开依据。
3. 使用“复制”或“复制并收起”；后者隐藏小窗，点击“模拟唤起”后保留本次内容。
4. 切换“回复”，先明确回复方向，再生成示意候选。
5. 展开左下角“原型 · 合成演示”，切换合成会话，查看首次确认、新消息、后台关闭和退出场景。
6. “首次确认”清空联系人绑定与读取范围，默认不授权；本次手动确认联系人不扩大后台读取范围。
7. 新消息提示用户主动更新上下文，草稿与候选保持；候选依据仍指向生成时的快照。

左下角原型操作与底部布局切换器是审阅工具，不属于产品小窗。单页内的预览切换保留同一份
内存状态；另开的页面各自使用独立合成状态，未连接跨窗口通信。

## 已确认的边界

后续正式版本使用 Electron + React，首版先 Mac 微信。后台是独立管理窗口；日常操作
通过快捷键呼出可拖动的小窗，隐藏后台不影响小窗。小窗与后台关闭只隐藏；明确退出应用
停止后台读取。当前 HTML 只验证布局和模拟状态，不代表 Electron 双窗口宿主已经实现。

每次回复必须对应已确认联系人。唯一的已验证会话绑定允许自动定位；不确定时要求选择。
同一联系人保留本次草稿与候选，联系人变化时清空。首版由用户输入或粘贴草稿，关系背景默认关闭；
一次性的语气要求不转成长久偏好。候选可编辑、带依据，最终由用户亲自粘贴与发送。
未提交草稿不跨运行保存；后台读取只覆盖用户主动确认的范围。

## 数据与能力边界

全部联系人、消息、来源、记忆与候选均为合成样例。默认场景演示已确认绑定与三个预置候选；
自定义输入的“生成”只演示原文、分句和紧凑排版，不能用于评价模型改写质量。

资料仅存在浏览器内存中，不使用持久存储，不向模型或后端发送请求，不读取或写入真实剪贴板。
“复制”只写入可检查的内存字段；导入、修正、删除、绑定、同步与退出均为页面状态模拟。
没有真实微信、数据库、模型、操作系统输入法、全局快捷键、实际置顶或系统权限接线。
两份页面能单独打开，不能据此宣称跨窗口运行或桌面集成可用。

浏览器人工检查：

- 后台独立页面与 A / B / C 小窗渲染；C 到 A 循环、编辑时方向键不切布局。
- A 生成与候选修改、复制并收起、重新唤起保留编辑；B 选中后原位编辑；C 展开列表与仅复制保持显示。
- 回复方向必填；首次联系人与读取范围无预选，未确认联系人不能生成，本次确认不扩大后台范围。
- 新消息不覆盖草稿和候选；主动刷新后旧候选依据仍保留生成时快照。
- 模拟关闭后台时小窗仍显示、模拟后台读取保持；同步总开关关闭后停读。
- 后台样例导入必须选择单一联系人，确认后记录对应归属。

语法检查与人工交互检查只证明此原型页面行为。按原型流程未增加产品回归测试，
未验证后端、真实剪贴板、跨窗口通信或桌面宿主。截图与工作流交接文件保存在仓库外本地工作产物中。
