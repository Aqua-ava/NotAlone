# 见面时说错话、出糗或尴尬的化解

来源候选：G25、T02、T06。

**适用：**约会或线下互动中出现小失误、说错名字、打翻饮料、忘记细节或一句话让场面尴尬。核心是判断影响后用合适分量回应。

**边界：**若言语涉及羞辱、歧视、隐私或实际伤害，使用明确道歉与修复，不用自嘲带过；若用户感到不安全，优先离开。

**信息不全时：**优先使用用户本轮表达的目的、已提供的原话和当前可用的背景。缺少会改变候选的关键事实时，只问一个必要问题；否则写条件清楚的候选，不补造经历、情绪、约定或对方动机。

## 处理步骤

1. 停一下辨别是谁受影响、影响多大；看对方表情和回应，别为了赶快化解而替对方说“没关系”。

2. 小失误可以简短承认，用一句贴合现场的自嘲或轻松补位；笑点放在自己身上，不拿对方弱点开玩笑。

3. 若对方被冒犯，直接点明自己说错了什么、承认影响并道歉；不加“我只是开玩笑”来撤销责任。

4. 给对方回应空间，再按反馈继续、换话题或结束见面；不反复解释以求对方马上安慰。

## 按实际反馈选择下一步

- 对方也笑了：接一句轻松话后回到原话题，不反复复盘小失误。
- 对方沉默或表示介意：停下玩笑，认真听对方说哪里不舒服。
- 对方明确要求结束或拉开距离：确认听到并停止靠近，不把尴尬当作继续调情的机会。

## 完成条件

回应力度与实际影响相称；若造成伤害，先负责修复，不以幽默掩盖。候选保持可编辑，由用户选择、改写后自行决定是否使用。

**案例指针：**只有在需要比较本场景的常见与困难情形、或用户明确要求演练时，才读取 `references/cases.md`；普通单次回复依本文件步骤处理。
