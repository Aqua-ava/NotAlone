# 情侣之间提出或回应具体求助

来源候选：G28、T02、G24。

**适用：**情侣一方需要帮忙，例如接送、取物、陪同或临时替班；重点是请求和回应是否清晰、双方能力是否匹配。

**边界：**借钱、共同财务或照护重大事项另需具体协商；紧急危险不把现实求助替换成润色消息。

**信息不全时：**优先使用用户本轮表达的目的、已提供的原话和当前可用的背景。缺少会改变候选的关键事实时，只问一个必要问题；否则写条件清楚的候选，不补造经历、情绪、约定或对方动机。

## 处理步骤

1. 把任务、时间和限制说具体，避免“你能不能多体贴我”这类无法执行的请求。

2. 请求时说明对方可以拒绝或改提可行方式；回应请求时先核对自己的时间能力。

3. 收到拒绝后，只在仍有选择时商量替代方案，不用“你爱不爱我”迫使答应。

4. 结束沟通时确认谁负责下一步，避免两人都以为对方会处理。

## 按实际反馈选择下一步

- 对方答应：复述时间、地点和任务，避免临时增加范围。
- 对方无法按原方式做到：商量替代时段或其他资源。
- 对方不愿意帮：用户确认是否能自行安排，再决定是否讨论长期分工。

## 完成条件

一方的实际请求与另一方的能力边界都清楚，任务有明确的后续安排。候选保持可编辑，由用户选择、改写后自行决定是否使用。

**案例指针：**只有在需要比较本场景的常见与困难情形、或用户明确要求演练时，才读取 `references/cases.md`；普通单次回复依本文件步骤处理。
