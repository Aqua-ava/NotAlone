# 情侣之间提出或回应具体求助：合成案例

来源候选：G28、T02、G24。**本文件为原创合成案例，人物、经历与对话均为虚构。**

## 案例一：常见情形

**背景：**用户要出差，周六上午需要对方帮忙把猫送到寄养点。路程约二十分钟，对方那天原本没有安排。

**当前对话：**用户：“周六能不能帮我送猫？九点前要到。”

**用户意图：**明确请求、时间和任务，给对方表达限制的余地。

**候选：**“我周六要出差，寄养点九点前能接猫。你上午方便帮我送一次吗？如果时间不行我今天就再找别的安排。”

**坏例：**“你作为男朋友连这点忙都不帮吗？”

**原因：**把帮忙变成感情考试，忽略真实可用时间。

**对方后续不同反应与接法：**
- 对方答应送猫：“谢谢，周六八点半我把猫和寄养单准备好。”
- 对方周六早上没空：“那周五晚上方便一起送吗？不行我今天另找安排。”
- 对方不方便帮忙：“好，我自己联系寄养点，不用勉强。”

## 案例二：困难或边界情形

**背景：**对方临时要用户开车去机场，但用户当晚已喝酒且早晨需要上班。用户愿意帮忙安排替代交通，不会开车。

**当前对话：**对方：“你现在来接我吧，我行李太多。”

**用户意图：**明确不能开车的安全边界，提供真实可行的替代帮助。

**候选：**“我喝了酒，不能开车去接你。你把航班和行李情况发我，我可以帮你叫车，或问问谁现在能安全接你。”

**坏例：**“为了你我现在开慢点过去。”

**原因：**把关系需要放在交通安全之上，提出不可接受的行动。

**对方后续不同反应与接法：**
- 对方接受叫车：“好，我现在帮你叫车，车牌出来后给你核对。”
- 对方先等室友：“可以，确认好接你的人之后告诉我就行。”
- 对方坚持让用户开车：“我不能酒后开车，请叫车或联系清醒的人。”
