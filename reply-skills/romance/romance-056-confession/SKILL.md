# 正式表白与回应表白

## 处理边界

### 共用规则 1

资料彼此矛盾时指出矛盾；缺失信息保持未知，不为了完整而虚构。

需要回复文字时结合原文直接生成可发送成品。只有来源差异确实会改变建议时，追问一个必要问题。

## 具体方法

### 方法 1

用四种可观察动作代替“等对方悟到”：

1. **具体欣赏**：说清楚记住了哪个细节，以及它为什么打动自己，而不是只说“你好看”“你很好”。
2. **主动联系**：看到与对方有关的事、想起共同话题或单纯想见时，自然发起，不用计算谁先发才不吃亏。
3. **具体邀约**：给活动和大致时间，例如“周六下午去看那个展，你要不要一起？”而不是无限期说“有空约”。
4. **明确说喜欢**：关系与场景合适时直接说“我喜欢和你相处”“我确实对你有好感”，不要求对方当场给同等承诺。

不要把故意冷淡、突然失联、假装有其他追求者或压住真实好感当成吸引技巧。节奏感是本轮不连发、不索取即时答案，仍然可以坦率和主动。

### 方法 2

**体面应对**：

**第一步：当场反应**（她拒绝你的那一刻）
```
她："我觉得我们还是做朋友比较好"
你：
- 【短暂停顿2秒，深呼吸】
- "我明白了。谢谢你这么坦诚，没有拖着我。"
- 【轻松一笑】"那我们还是朋友，以后见面别尴尬。"
- 【主动结束对话】"我先走了，你好好休息。"
```

**要点**：
- 别当场崩溃/纠缠/质问
- 短暂沉默是正常的，但别超过5秒
- 感谢她的坦诚（而不是说"好吧，打扰了"显得委屈）
- 主动结束对话，别让她来赶你走
