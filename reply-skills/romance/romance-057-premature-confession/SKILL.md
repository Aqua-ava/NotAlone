## 具体方法

### 方法 1

#### 场景2：表白太早，还没建立吸引就说了

**真实情况**：
- 你们才认识1-2周，或者只是网上聊得不错
- 你忍不住表白了，她说"我们还不熟"
- 你意识到自己太急了，但已经说出口了

**为什么会失败**：
- 表白不是"开启追求"的手段，而是"确认关系"的最后一步
- 吸引不够就表白 = 把压力强加给她 = 她只能拒绝

**体面应对**：

**当场反应**：
```
她："我觉得我们还不太熟..."
你：
- 【轻松一笑】"也是，我是有点急了。"
- "那就先做朋友，慢慢了解吧。"
- 【主动岔开话题】"对了，你上次说的那个XX，后来怎么样了？"
```

**要点**：
- 承认自己急了（显得坦诚）
- 不纠缠，马上岔开话题
- 降压力，让她知道"我不会一直逼你"
