# 过早表白后的沟通补救：合成案例

来源候选：D24。**本文件为原创合成案例，人物、经历与对话均为虚构。**

## 案例一：常见情形

**背景：**用户认识对方一周，只在线上聊过几次。昨晚他突然发“我确定你就是我要结婚的人”，今天意识到这既不真实也让对方压力大；他实际只想继续认识。

**当前对话：**对方：“你是不是太快了？我们都还没见过。”

**用户意图：**承认夸大表达，澄清想慢慢认识，允许对方拒绝继续。

**候选：**“你说得对，我昨晚说得太满了，我们确实还不熟。我实际想表达的是愿意继续认识你，不是要你现在回应什么；如果你觉得不舒服，我也尊重。”

**坏例：**“我说结婚只是证明我认真，你别想太多。”

**原因：**把对方的不适说成想多，继续要求其接受用户解释。

**对方后续不同反应与接法：**
- 对方愿意继续认识：“谢谢你愿意继续聊，我们先按普通见面相处，不急着谈以后。”
- 对方需要空间：“好，我先不联系你。你准备好再说。”
- 对方拒绝继续：“我听到了，昨晚那句话不该给你压力，我尊重你的决定。”

## 案例二：困难或边界情形

**背景：**用户表白被拒后，情绪激动说“我会等你一辈子”。第二天他觉得这句话会让对方背负压力，实际希望结束追求。

**当前对话：**对方：“你昨天说要等我，是什么意思？”

**用户意图：**收回不真实的永恒承诺，同时确认已听到拒绝并准备停止推进。

**候选：**“昨天我说会等一辈子是情绪化的表达，不应该给你这个压力。我听到你不想发展了，会尊重这个决定，也不继续追求。”

**坏例：**“既然你拒绝我，那我以后都不再相信爱情了。”

**原因：**把自己的痛苦交给对方负责，带有情绪施压。

**对方后续不同反应与接法：**
- 对方接受用户的说明：“谢谢你听我说清，我会按这个决定停止追求。”
- 对方只想工作往来：“明白，之后我们只沟通工作需要。”
- 对方没有继续回应：“用户不追着索要告别，按自己的安排生活。”
