# 暧昧已久时问清彼此的关系意愿

来源候选：E12、C08、G14。

**适用：**持续约会或亲密相处一段时间，用户已不满足于猜测，希望确认双方是否愿意朝恋爱关系发展。

**边界：**刚认识时第一次表达好感用表白场景；确认排他细节用承诺约定；对方信息矛盾时只澄清影响当前的一点。

**信息不全时：**优先使用用户本轮表达的目的、已提供的原话和当前可用的背景。缺少会改变候选的关键事实时，只问一个必要问题；否则写条件清楚的候选，不补造经历、情绪、约定或对方动机。

## 处理步骤

1. 选一个双方可以完整谈话的时机，确定用户最需要知道的是是否想发展，而非一次谈完所有未来安排。

2. 说明用户对当前相处的真实体验和想要的方向，避免用“你到底把我当什么”逼供。

3. 提出一个开放但明确的问题，让对方能说愿意、不确定或只想维持现状。

4. 听完答案后复述理解，再说明用户自己的下一步；不把含糊承诺当成正式关系。

## 按实际反馈选择下一步

- 双方愿意发展：转到排他性、称呼等具体约定，但逐项协商。
- 对方不确定：询问是否有合适的再谈时间，同时决定用户愿意等多久。
- 对方只想维持暧昧或拒绝交往：用户可决定继续现状或收回亲密投入。

## 完成条件

双方对是否发展关系有可引用的明确表达；下一步由用户结合实际答案决定。候选保持可编辑，由用户选择、改写后自行决定是否使用。

**案例指针：**只有在需要比较本场景的常见与困难情形、或用户明确要求演练时，才读取 `references/cases.md`；普通单次回复依本文件步骤处理。
