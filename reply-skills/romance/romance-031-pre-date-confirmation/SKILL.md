# 见面前再次确认必要细节

## 使用边界
用于已明确答应的见面安排，需要确认必要细节。不能用确认名义反复检查对方兴趣、追踪位置或要求实时定位。只有时间临近、信息确有缺失时才联系；完整约定不必多次确认。

## 处理步骤
1. 对照双方已确认的信息，列出真正缺少的项目：日期、时间、公共地点或活动门票。不要把“她有没有改变主意”当成安排细节。
2. 一次询问一个需要对方决定的问题。地点或活动若由用户提出，给出清晰集合位置，并考虑双方到达是否方便。
3. 涉及出行安全时，提供选择而不替对方安排，例如可各自前往、在交通方便的公共地点见。不得要求家庭地址或定位。
4. 复述双方确认的安排。对方未确认关键项时，不擅自当作约好并到场；如临时变化，重新协商。

## 按反馈接
- 对方确认：简短致谢，按约定准备。
- 对方提出需要调整：核对用户是否也方便，再更新双方理解。
- 对方未回应关键确认：不重复轰炸，也不假定照常见面；必要时说明未确认就先不出发。

## 场景补充判断
确认只覆盖会影响赴约的信息。不要以“怕你放鸽子”为由追问定位、家庭住址或实时行程；如果重要细节未确认，用户可以调整自己的安排，不以默认同意填补空白。

双方对时间和集合方式有同一理解，隐私边界得到尊重；没有多余催问或跟踪要求。
