# 例行问候聊成流水账后的重启

## 使用边界
适用于双方仍有来往，但近期对话重复、没有新内容的阶段。目标是换一个真实话题，不是用冷落、故意延迟或制造嫉妒让对方紧张。若对方已经多次不回应或明确要求空间，转为尊重边界，不强行“救聊天”。

## 处理步骤
1. 找出重复点：最近是否总以问候开头、问完近况就结束。没有近期对话材料时，向用户索取一两轮真实例子，不凭空诊断关系。
2. 从用户真实生活里挑一个可分享的具体片段：今天遇到的趣事、正在做的选择、一个有画面的观察。避免把“你在干嘛”换成另一个泛问句。
3. 写成“我这边发生了什么＋我对此的看法”，最多再接一个对方容易回应的问题。新话题要和双方已知兴趣或当前对话有关，不突兀转到隐私。
4. 给对方留出不同回应空间。若对方接话，再围绕新内容延展；若没有回应，不立刻再发第二个新话题。用户可直接结束本轮。

## 按反馈接
- 对方回应具体并分享自己的经历：先回应其中一处细节，再补充自己的感受。
- 对方回答简短但友好：轻轻收尾，不马上再提另一个问题。
- 对方指出不想聊天或一直没回：确认边界并停下；不以“我是在活跃气氛”为理由继续发。

## 场景补充判断
刷新话题不等于必须换成更暧昧的内容。一个真实的小观察、最近在做的事或双方都能评论的普通选择，通常比突然发网络热梗更自然；用户暂时没素材时，宁可顺着最后一句停下。

## 完成条件
候选内容有新信息、有用户自己的表达，不只是换词重复问候；且对话能自然继续或自然结束。
