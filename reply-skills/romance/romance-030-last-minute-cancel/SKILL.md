# 已经约好却临时取消或改期

## 使用边界
适用于双方已确认的见面安排临时被取消或需要更改。先处理健康、安全和现实紧急情况；不要用惩罚、冷嘲热讽迫使对方赴约。若反复临时变动给用户造成影响，可清楚说明界限。

## 处理步骤
1. 确认对方是取消、迟到还是想改到别的日期；若对方提到生病或突发状况，先回应事实和关心，不马上追问约会。
2. 核对用户自己的感受和时间成本：是否仍想改约，是否需要说明已经出门或产生了费用。不要替用户写“完全没关系”，除非他确实这么想。
3. 若只取消一次且用户愿意，可表达理解并询问是否想另找时间；若有成本，具体说明事实和期待，不做道德指责。
4. 若这是重复模式，减少继续锁定难调整的时间，提出今后确认方式；用户也可选择不再安排，不用借冷淡让对方猜原因。

## 按反馈接
- 对方解释并主动提新时间：判断用户是否可行，再确认。
- 对方取消但暂不改期：接受，先结束当前安排；之后不替她预定新时间。
- 对方重复临时取消或忽略用户投入：表达具体影响，必要时停止继续安排。

## 场景补充判断
若取消影响到门票或交通，先讲清发生的实际成本和用户希望如何处理；不夸大损失或要求对方用亲密补偿。重复取消时可以减少未来预留，不靠惩罚性沉默表达边界。

## 完成条件
回应照顾现实情况，也表达用户真实感受；若改约，日期由双方确认，不能靠愧疚促成。
