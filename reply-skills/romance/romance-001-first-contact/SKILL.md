# 初次开聊：承接共同经历或已知兴趣

## 处理边界

### 共用规则 1

资料彼此矛盾时指出矛盾；缺失信息保持未知，不为了完整而虚构。

需要回复文字时结合原文直接生成可发送成品。只有来源差异确实会改变建议时，追问一个必要问题。

## 具体方法

### 方法 1

**优质开场的构成：**
1. **具体观察**——提及对方资料中的一个具体细节，让对方知道你认真看过
2. **轻松猜想**——提出一个有趣的猜测，给对方纠正或接梗的空间
3. **顺势邀请**——留一个轻松、有趣又容易回应的入口

**思路：观察 → 发挥 → 邀请**

### 方法 2

### 2. 现场取材：从共同注意力开始

先用正在发生的事开口：场地、食物、活动、天气、共同朋友或对方刚说过的细节。这比背“75 个话题”更自然。

```text
观察 + 一点自己的感受 + 容易接的小问题

“这家店的歌单比我想的复古，刚那首我差点跟着唱。你是为菜来的，还是为氛围来的？”
```

**效果**：具体、低压力，对方容易接。
**代价**：只问不分享会变成采访；过度评论陌生人则可能显得冒犯。
