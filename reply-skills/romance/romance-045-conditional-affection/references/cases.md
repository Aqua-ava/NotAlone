# 回应“达到某条件才考虑在一起”：合成案例

来源候选：C17。**本文件为原创合成案例，人物、经历与对话均为虚构。**

## 案例一：常见情形

**背景：**用户在健身，不是为了恋爱改变外形。对方聊到两人是否要进一步了解时说，如果用户能瘦十斤才认真考虑。用户不确定这是不是玩笑。

**当前对话：**对方：“你瘦十斤我就考虑跟你在一起。”

**用户意图：**先问清这是否是对方的认真条件，同时表达不接受以体重作为交往资格。

**候选：**“你是认真把体重当成考虑交往的条件吗？我可以聊生活习惯，但不会为了获得关系资格承诺一个体重数字。”

**坏例：**“好，我一个月一定瘦十斤，你别反悔。”

**原因：**用尚未决定的身体目标交换承诺，会把用户推入不真实保证。

**对方后续不同反应与接法：**
- 对方解释只是在开玩笑：“如果只是玩笑我知道了，不过体重不会成为我争取关系的目标。”
- 对方坚持体重门槛：“我不会为获得交往资格承诺减重，我们可能想要的关系不同。”
- 对方继续嘲笑身材：“别拿我的身体开玩笑。我先结束这次谈话。”

## 案例二：困难或边界情形

**背景：**用户约会几次后，听到对方说只有升到某收入才适合公开交往。用户愿意谈经济规划，但不愿把未来不确定的收入保证给对方。

**当前对话：**对方：“等你年薪达到四十万，我就公开承认我们在一起。”

**用户意图：**澄清对方担心的真实内容，并拒绝把未能保证的收入承诺当成交换。

**候选：**“你是在担心我们能不能共同承担生活开支，还是把这个收入数当作必须达到的条件？我可以讨论预算，但不能保证未来收入。”

**坏例：**“没问题，我一定做到。”

**原因：**把无法保证的未来承诺写成确定事实。

**对方后续不同反应与接法：**
- 对方愿谈实际预算：“可以，我们按现在的收入和支出讨论，不保证未来数字。”
- 对方坚持收入门槛：“我理解这是你的条件，但我不会承诺无法保证的收入。”
- 对方继续贬低用户：“我不接受这样谈话，今天先到这里。”
