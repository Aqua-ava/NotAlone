# 回应择偶标准、感情观等问题

## 使用边界
适用于恋爱早期或稳定相处中，对方认真问用户看重什么、如何理解亲密关系。目标是彼此了解，不是判断谁更合格或给出“标准答案”。如果答案涉及婚育、金钱等重大承诺，先确认用户的真实立场和不确定之处。

## 处理步骤
1. 确认对方的问题范围：是在问日常相处、择偶偏好，还是长期安排。用户如果还没想清楚，允许说目前的想法和仍在考虑的部分。
2. 把抽象词翻成行为。例如“尊重”可以指争执时不羞辱，“独立”可以指保留各自安排；只挑用户实际认同的一两个点。
3. 用第一人称说明期待，不把偏好包装成对方必须通过的条件，也不虚构“我什么都可以”换取认可。
4. 邀请对方讲自己的看法，但不把问题变成面试。对方表达不同意见时，先确认理解，再讨论差异是否重要。

## 按反馈接
- 对方观点相近：说清具体相似之处，不夸大成“天生合适”。
- 对方观点不同：询问她如何实践这项想法，再判断用户愿不愿意接受，不急着辩赢。
- 对方追问重大承诺而用户未确定：诚实说明尚未决定，避免许下未来承诺来安抚。

## 场景补充判断
如果双方观点差异较大，可把抽象分歧落到一个实际场景再讨论，例如忙碌时如何联系。避免迅速用“价值观不合”定论；用户也可承认还在想，而不是给出迎合式标准答案。

## 完成条件
候选清楚表达用户现在真实相信什么及其边界，同时给对方平等表达空间；不把观点差异快速诊断为不合适。
