# 约会临时增加朋友或同行者

## 处理边界

### 共用规则 1

资料彼此矛盾时指出矛盾；缺失信息保持未知，不为了完整而虚构。

需要回复文字时结合原文直接生成可发送成品。只有来源差异确实会改变建议时，追问一个必要问题。

## 具体方法

### 方法 1

**体面应对**：

**第一步：接受现实，表现大度**
```
见面时
你：【微笑】"你好啊。咦，还有朋友一起？"
她："对，这是我闺蜜XX。"
你："你好你好，人多热闹。"
【不要露出失望/不爽的表情】
```

**要点**：
- 表现得"这很正常"
- 别让她看出你介意

### 方法 2

**第三步：争取下次单独见面**
```
结束时
你：【对她说】"今天挺开心的。"
【对闺蜜说】"很高兴认识你。"
【之后单独给她发消息】
你："你闺蜜人挺好的。不过下次能不能就我们俩？我有点话想单独和你说。"
```

**要点**：
- 先夸闺蜜（让她知道你表现得不错）
- 再提"下次单独"
- 如果她还是拒绝 → 她对你兴趣不足，考虑止损
