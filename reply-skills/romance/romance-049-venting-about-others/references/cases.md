# 对方生气、抱怨别人或某件事时回应：合成案例

来源候选：G20。**本文件为原创合成案例，人物、经历与对话均为虚构。**

## 案例一：常见情形

**背景：**用户和对方住在不同城市。对方说同事把本周末的工作推给他，结果他取消了两人的电影计划。用户既理解他烦，也对计划落空失望。

**当前对话：**对方：“他们又把活推给我，我真想当场骂回去。”

**用户意图：**先回应烦躁，再讲清取消约会对自己的影响，避免附和报复。

**候选：**“这件事确实让你很窝火，原来的电影也得改，我这边也有点失望。你想先吐槽一下，还是一起看看怎么处理周末安排？”

**坏例：**“你同事都是垃圾，你明天就把活扔回去。”

**原因：**升级第三方冲突，也忽略两人已经改变的约定。

**对方后续不同反应与接法：**
- 对方想先吐槽：“那你先说说最火大的部分，我听着。”
- 对方想和同事沟通：“我们先把你要拒绝的那项工作说清楚。”
- 对方今晚不想继续聊：“好，今晚先到这里，电影的安排明天再商量。”

## 案例二：困难或边界情形

**背景：**对方说朋友借钱后迟迟不还，气得睡不着。用户只听到一面描述，不知道金额和约定。

**当前对话：**对方：“我以后再也不信任何人了。”

**用户意图：**认可这次失望，避免把一次经历概括为所有人的本性，问是否需要梳理事实。

**候选：**“钱借出去后对方一直没按说好的时间还，失望肯定很重。你想先讲讲当时怎么约的，还是今晚只想有人听你说？”

**坏例：**“我早就看出你朋友不靠谱了。”

**原因：**用事后判断指责对方，容易增加羞耻和防御。

**对方后续不同反应与接法：**
- 对方愿意梳理借款约定：“先把当时约好的金额和时间列出来，再决定怎么开口。”
- 对方只想倾诉：“我听着，这会儿不急着替你想办法。”
- 对方想暂停：“好，我们先不聊这件事。”
