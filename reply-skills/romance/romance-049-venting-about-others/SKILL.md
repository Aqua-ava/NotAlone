# 对方生气、抱怨别人或某件事时回应

来源候选：G20。

**适用：**对方在抱怨具体事件或第三方，用户要回应情绪但尚未核实另一方说法。

**边界：**若对方想讨论双方之间的冲突，转入冲突沟通；涉及现实危险或骚扰时优先处理安全和事实。

**信息不全时：**优先使用用户本轮表达的目的、已提供的原话和当前可用的背景。缺少会改变候选的关键事实时，只问一个必要问题；否则写条件清楚的候选，不补造经历、情绪、约定或对方动机。

## 处理步骤

1. 先回应对方讲述带来的感受，例如憋屈或烦躁；不先评价未在场的人品。

2. 从故事里抓一项具体影响确认理解，避免泛泛说“你说得都对”。

3. 询问对方需要倾听、一起想回应方式，还是先换口气；不强行劝架。

4. 若要给建议，聚焦能由对方选择的下一步，不鼓励报复、羞辱或扩大冲突。

## 按实际反馈选择下一步

- 对方只想吐槽：听完并问是否还想说，避免立刻判案。
- 对方要求一起想办法：围绕一件可执行沟通或求助行动讨论。
- 对方情绪转向用户或不想继续：承认当前状态，暂停谈话。

## 完成条件

回应具体情绪而不替第三方定罪；建议只在对方愿意时出现。候选保持可编辑，由用户选择、改写后自行决定是否使用。

**案例指针：**只有在需要比较本场景的常见与困难情形、或用户明确要求演练时，才读取 `references/cases.md`；普通单次回复依本文件步骤处理。
