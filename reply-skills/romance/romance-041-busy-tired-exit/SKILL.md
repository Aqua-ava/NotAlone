# 对方说忙、困或想休息时收住

来源候选：C03、C16。

**适用：**对方直接说忙、疲惫、困倦或想独处。用户想回复同时不施加继续聊天的压力。

**边界：**若有重要约定需确认，只保留必要的行程安排问题；长期失衡需要单独沟通，而非在对方睡前突然处理。

**信息不全时：**优先使用用户本轮表达的目的、已提供的原话和当前可用的背景。缺少会改变候选的关键事实时，只问一个必要问题；否则写条件清楚的候选，不补造经历、情绪、约定或对方动机。

## 处理步骤

1. 直接回应对方当前状态，避免把忙累解释为不在乎或故意冷淡。

2. 判断是否有必须今天确认的一件事情；若没有，就让本轮自然结束。

3. 若确需后续联系，可给一个可调整时间窗口，不要求承诺立刻回复。

4. 候选保持简短，删掉“我等你”“你忙完必须找我”等情绪负担。

## 按实际反馈选择下一步

- 对方说明何时方便：确认或保留该时间，之后按约联系。
- 对方只说现在累：让其休息，本轮停止追问。
- 对方多次取消重要沟通：改在彼此有精力时讨论时间安排，不当场逼谈。

## 完成条件

对方可以安心结束当前对话，用户也没有被要求压下必要需求或承诺未来。候选保持可编辑，由用户选择、改写后自行决定是否使用。

**案例指针：**只有在需要比较本场景的常见与困难情形、或用户明确要求演练时，才读取 `references/cases.md`；普通单次回复依本文件步骤处理。
