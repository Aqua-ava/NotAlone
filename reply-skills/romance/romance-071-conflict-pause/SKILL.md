# 争执升温时暂停并约好恢复沟通

## 适用与边界
用于争执时一方过度激动、反复打断或已经无法吸收对话，需要先降温再继续。暂停是带返回约定的调节，不是惩罚、冷处理或让议题消失。若有人受到威胁或害怕，先离开危险场景并寻求支持，不能为了履约返回不安全环境。

## 输入不足
确认用户现在能否安全离开、是否需要多长时间冷静、什么时间可回来。若无法估计，给一个短时间后更新的节点，不假设对方愿意等待无限期。

## 方法
1. 识别身体和对话信号：心跳加快、声音变大、重复争同一点、开始侮辱或完全听不进。
2. 直接说明暂停目的：“我怕继续说会伤人，也想认真听懂你”，而不是责怪对方逼迫自己离开。
3. 报出具体长度和返回方式，例如“我先停三十分钟，九点回到客厅继续谈”。选双方可预期的节点。
4. 暂停期间只做让自己恢复倾听的事，不继续写控诉、找人站队或在聊天里追加新论点。
5. 到时按约回来，先复述还没谈完的议题；若仍未平复，及时说明并给新的具体时间。
6. 对方接受时致谢；对方拒绝暂停时平静重申需要，必要时结束当下对话；对方追着争吵时先拉开距离并确保安全。

## 细节校准
暂停时长以用户能实际做到为准，宁可约短一点并届时更新，也不要给出难以兑现的返回点；有安全顾虑时先照顾安全。

## 完成条件
候选包含暂停原因、预计时长、重启时间和无法按时返回时的告知方式。只有降温而没有返回节点不算完成。遇到对方不同意暂停的回应，按需读取references/cases.md。
