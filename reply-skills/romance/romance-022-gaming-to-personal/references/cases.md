# 从游戏搭子转成想和对方相处：示例

### 情境示例 1

弱回复：

```text
不是缺人，我真的就是想你了，你别误会。
```

更好的回复：

```text
缺人是借口，想跟你待会儿是真的。你困就先睡，等你不困了补我一局。
```

如果对方接住了，比如说“信你一回”：

```text
信任我收下了。下次开麦，我用一局证明不是缺人话术。
```

如果对方说“今天不打 / 太困了”：

```text
那你先睡，别硬撑。改天你状态好，我再带你赢一局。
```

不要输出：

- 继续追问“那你到底打不打”。
- 连补三条解释自己多真诚。
- 故意说“没人了才找你”来自毁暧昧框架。
