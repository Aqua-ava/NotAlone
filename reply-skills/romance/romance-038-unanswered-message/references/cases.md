# 一条消息迟迟没有回复：合成案例

来源候选：E10、G21。**本文件为原创合成案例，人物、经历与对话均为虚构。**

## 案例一：常见情形

**背景：**用户昨晚发给刚认识的对方一条消息，问他推荐的面包店周末是否要排队。过去两人聊得自然，眼下没有必须当天决定的安排。

**当前对话：**用户：“你说的那家面包店，周末早上是不是人很多？”消息发出十小时仍未回复。

**用户意图：**避免焦虑下连发，先等待；若第二天仍想继续，再轻量跟进。

**候选：**若用户明天仍想联系，可用：“我周末可能去试试你说的那家店，谢啦。”当前先不追加内容。

**坏例：**“你为什么不回？昨天不是聊得挺好吗？”

**原因：**把一次延迟升级成关系质问，可能让尚未形成的互动承担过多压力。

**对方后续不同反应与接法：**
- 对方回答面包店排队：“谢谢，那我周末十点前去看看。”
- 对方解释最近忙：“了解，你先忙，周末我自己安排。”
- 第二天仍没回应：“用户不追问，也不把一次未回当成关系结论。”

## 案例二：困难或边界情形

**背景：**用户和对方已约好今晚八点看演出，六点要确认票务取票方式。对方还没回上条关于集合位置的问题，用户只需要及时确认路线。

**当前对话：**用户：“我们在哪个出口碰面比较方便？”

**用户意图：**补充一次只含必要行程安排信息，避免把行程确认写成情绪抱怨。

**候选：**“取票要在七点半前换好。我打算七点二十在东门口等，你方便的话回我一下；不方便我们电话确认也行。”

**坏例：**“你再不回这次就别见了，我看你根本不在乎。”

**原因：**把可解决的时间确认转成关系惩罚，妨碍用户完成安排。

**对方后续不同反应与接法：**
- 对方确认东门集合：“好，七点二十东门见，我会提前换票。”
- 对方提出改天：“可以，今晚先不买票，我们再挑都方便的时间。”
- 票务截止仍没回应：“用户按票务规则处理自己的安排，不追加情绪追问。”
