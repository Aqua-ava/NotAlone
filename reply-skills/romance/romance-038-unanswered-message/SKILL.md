# 一条消息迟迟没有回复

来源候选：E10、G21。

**适用：**一条消息在用户预期的时间内仍未得到回应，且没有证据说明关系已经整体变冷。重点是回应当前这条消息，不做长期关系判断。

**边界：**跨多轮持续冷淡看趋势处理；约定事项临近且需要确认时，直接补发必要安排信息，不把其写成情感试探。

**信息不全时：**优先使用用户本轮表达的目的、已提供的原话和当前可用的背景。缺少会改变候选的关键事实时，只问一个必要问题；否则写条件清楚的候选，不补造经历、情绪、约定或对方动机。

## 处理步骤

1. 核对消息发出时间、内容是否有明确问题，以及是否存在时间敏感的安排；若没有重要事项，默认先给对方处理时间。

2. 区分“没有回”与“明确拒绝”：不从在线状态、已读或单次延迟推断动机。

3. 确有需要时，最多补充一条轻量且带具体信息的内容；删掉责备、连问和要求即时解释的部分。

4. 补充后停止继续追加，等实际回应；如果用户想联系只是为了缓解自己的焦虑，先写下说法，再决定是否使用。

## 按实际反馈选择下一步

- 对方正常回复：接回原话题即可，不追问为什么晚回。
- 对方说明忙或忘记：回应事实，按用户目标继续或改约。
- 仍无回复：不再补发第二条；如果是约定事项临近，可另发纯安排确认。

## 完成条件

候选至多推进一次必要沟通，保留对方的回应空间；没有足够证据时不解释沉默。候选保持可编辑，由用户选择、改写后自行决定是否使用。

**案例指针：**只有在需要比较本场景的常见与困难情形、或用户明确要求演练时，才读取 `references/cases.md`；普通单次回复依本文件步骤处理。
