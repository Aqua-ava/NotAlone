# 对方主要在需要帮助时才联系：合成案例

来源候选：C12、G15。**本文件为原创合成案例，人物、经历与对话均为虚构。**

## 案例一：常见情形

**背景：**用户与对方认识半年。对方最近两次请用户帮忙改简历和搬电脑，平时很少主动约见。用户愿意改一小部分，但也想有普通约会。

**当前对话：**对方：“这周能不能再帮我看一下简历？我投出去前想让你过一遍。”

**用户意图：**答应自己能做到的部分，同时把双向相处的愿望说出来。

**候选：**“我周三可以帮你看一遍重点。也想找个时间不只聊简历，周末一起吃个饭怎么样？”

**坏例：**“我帮你这么多，你是不是应该跟我在一起？”

**原因：**把援助变成索取感情的交易，否定对方自由选择。

**对方后续不同反应与接法：**
- 对方答应吃饭：“好，那周六我来订位，简历我今晚帮你看一遍。”
- 对方只想谈简历：“我能帮你看重点，关系方面我们之后找时间再聊。”
- 对方拒绝普通相处：“这次简历我就不接了，希望你投递顺利。”

## 案例二：困难或边界情形

**背景：**对方常在深夜发来请她帮忙联系工作机会，白天却多次推掉两人的约定。用户不想冷战，也不希望每次都利用人脉。

**当前对话：**对方：“你不是认识那家公司的HR吗？能不能帮我打听下？”

**用户意图：**据实说明可以或不愿帮的范围，并谈到持续缺少普通相处的事实。

**候选：**“这次我可以把公开招聘页面发你，但不方便替你私下托人。还有，我们几次约饭都没成，我也希望两个人能认真留点相处时间。”

**坏例：**“你这人只有用得到我才出现。”

**原因：**把模式概括成人格指责，容易转成争吵，无法得到安排。

**对方后续不同反应与接法：**
- 对方同意周六相处：“好，周六见面时我们也聊聊彼此最近的生活。”
- 对方继续要求托人：“这次我只能把公开招聘信息发你，私下托人我不方便。”
- 对方因边界生气：“我理解你着急，但这个要求我做不到。”
