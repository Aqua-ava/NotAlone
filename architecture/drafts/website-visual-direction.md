# 官网视觉方向草案

> 状态：草案。本文记录官网调研形成的视觉语言，不代表已实现页面或最终品牌系统。

NotAlone 官网采用“冷灰产品展台”方向：以 Claude 的安静文字宣言和产品展示布局为骨架，以 Teenage Engineering 的大型产品物件与工业目录感建立页面节奏，以 Kimi K3 的工程线、节点、测量和实验材料作为独特视觉资产。Physical Intelligence 只提供浅色、安静、留白充足的背景参考；Google DeepMind、Special Projects、Bureau Cool 的媒体轮播、作品集拼贴和实验型导航不纳入方向。

主色暂定为冷灰、黑、深蓝；不使用高饱和渐变。深蓝承担结构、状态和选中标记。回复工作台材质仍未决定，保留三条原型分支：工业面板、纸张/手稿、外部工业面板与内部纸张混合。

官网叙事从巨大产品名 `NotAlone` 开始，随后以整屏章节展示“确认联系人 → 形成关系语境 → 明确表达方向 → 生成可编辑候选 → 用户亲自发送”。页面展示目标产品愿景时必须标注开发状态，不能把架构草案当作已实现能力。
