# 现行隐私、模型调用与删除

本文保存已采纳的数据处理边界，不证明对应功能或真实渠道已验收。身份与数据契约见[领域规格](domain-data.md)，业务步骤见[核心流程](core-flows.md)。仅在核对旧实现或阶段结论时阅读[历史实施记录](../history/privacy-implementation-notes.md)；撤回新规则等暂缓目标见文末。

## 本机存储与模型凭据

- 聊天、截图、语音、关系资料、任务产物及备份均为敏感资料。桌面后台与业务资料位于本机，使用受控 SQLite；实例身份、事务与迁移按 [ADR-109](../adr/109-controlled-sqlite-storage-foundation.md)。云端工程已取消，不建设云端业务库、对象存储、设备认证服务或模型密钥代理。本机保存不代表外部模型调用完全离线。
- 模型使用用户自己的 API Key，沿受控配置路径保存，与业务资料隔离，不进入聊天、追踪、日志或诊断。不能据文档宣称本机库和缓存已加密；加密尚未落实时按明文存储假设向用户说明。
- 普通结构更新按 [ADR-066](../adr/066-in-place-schema-updates-and-database-reuse.md)沿用原本机库和资料位置，不自动创建备份或复制资料。更新及分批切换每项业务只有一个执行和写入责任方；回退先停止并核对在途任务及结构兼容，不做请求级自动双实现兜底，不用旧库覆盖新增资料、用户修正或删除决定。
- 历史 App 管理快照继续受来源、过程、关系资料和助手会话的删除约束；核验完整归属后清理，未知、损坏、未完成或清理失败时不得宣告删除成功。停止创建新快照不授权丢弃已有副本；外置原库、用户另存文件和供应商副本按各自归属处理。
- 重装沿用留存资料；彻底删除须明确范围并二次确认。异常诊断脱敏且不自动上传。独立分发、工具准备、框架迁移和规格采纳均不自动授权真实资料迁移、外部连接或删除操作。[ADR-101](../adr/101-local-app-first-use-lifecycle.md)

## 联系人、读取授权与停读

### 确认范围与首用

- 每次处理映射到已确认联系人，联系人范围按 `owner_id + contact_id` 隔离。用户明确确认单个会话或当前微信账号的全部私聊范围；默认仅所选会话，列表不预选，主动全选仅作用于当前未绑定列表。按 [ADR-089](../adr/089-all-private-wechat-sync-scope.md)，明确开启全部私聊后可按稳定身份纳入当前及以后新增私聊，不能按昵称或正文猜测合并。
- 全部私聊范围按账号持久化；切回仅所选只停止自动纳入，停止读取仍由总开关控制。撤销或删除会话保留必要排除，刷新、重启及重复开启全部私聊不能恢复。具体后台可用范围须按已认证能力展示；[ADR-110](../adr/110-selected-sqlite-contact-read-grants.md)的新 SQLite 逐人实施阶段不等于取消产品的明确全部私聊分支，字段能表达该范围也不证明它已实现。
- 首次连接按 [ADR-142](../adr/142-first-connection-contact-selection.md)先确认账号，再搜索、多选联系人，最后明确确认读取所选会话本机可读历史及后续消息并开启同步。候选账号只来自工具配置，不证明前台登录账号或正文可读。账号确认前说明名单访问；确认后仅取必要元数据、丢弃夹带摘要，不授予正文读取或开启同步。搜索词不持久化或外发。
- 最终授权复验来源、稳定身份与名单代次；绑定失败或连接换代不能开启同步。后续添加保留总开关状态，响应丢失及重启恢复不重放授权。身份、绑定、核验证据与读取授权分别保存；取消立即撤销旧资格，普通重选不解除清空排除。首次绑定须说明范围、屏幕录制权限用途、停止入口、恢复行为和最终由用户发送的边界。
- 手动当前文字仅在明确选择已有联系人后处理，生成前不发模型请求，也不静默保存为长期记忆或规范消息。明确生成后的文字与表达方向属于助手讨论及候选依据，随会话删除；已有联系人手动表达不要求开启同步。手动确认只声明本次归属，不建立联系人、外部会话、读取或发送权限。历史文件导入是已采纳的单联系人目标合同，当前 SQLite 正常入口尚未开放；现行历史由授权微信同步取得。文件导入目标仍须独立预览、确认联系人归属、登记来源并提供删除路径，混有多位联系人的资料拆分或拒绝。

### 后台同步与前台定位控制

- 仅有效授权范围内的 active 绑定可在应用运行且同步总开关开启时，由 CLI 按稳定外部会话标识只读正文；不要求微信前台，全局 session 流只提供变化触发元数据，不保存全量导出。关闭同步、退出或撤销后停读；绑定失效时停止该绑定读取。后台状态与前台定位状态分别显示。
- 每个授权私聊首次进入范围时同步本机可读文字历史，再转增量；两者共享去重、来源和删除边界。重开或恢复时按可靠位置补齐仍有效范围内的缺口，暂时失败有界退避；恢复中或本机无记录不能标为完整。按 [ADR-025](../adr/025-cli-background-sync-gap-backfill.md)、[ADR-100](../adr/100-authorized-private-history-sync.md)及当前[来源合同](../adr/113-sqlite-private-history-source-contract.md)核验实际支持范围。
- 前台定位仅在微信前台、会话可见且窗口唯一时，在本机内存分析该窗口布局，再仅 OCR 顶部会话名称。原始视觉帧默认不保存或上传，不读取聊天正文、左侧选中行、其他联系人列表或头像指纹，也不读取其他 App。定位暂停或失败不阻塞已有合法绑定的后台同步；CLI 不可用时不退回 OCR 正文。[ADR-049](../adr/049-automatic-foreground-window-layout.md)、[ADR-052](../adr/052-header-ocr-foreground-locator.md)
- 名称匹配按 [ADR-132](../adr/132-existing-contact-name-matching.md)关联当前配置账号的已有稳定联系人，不创建或合并身份、不写人工核验事实、不恢复读取授权。该启发式不能独立证明前台登录账号，也不能严格排除缺名群同名；实际歧义或质量失败需用户选择，界面明示对象与匹配来源。生成仍由用户主动发起，最终消息由用户选择、修改并亲自发送，发送不得成为产品 Tool 或后台能力。
- 工具首次准备不授予正文权限。初始化前说明影响，必要的一次性系统授权由用户亲自完成；App 不接收或保存管理员密码，保留原微信安装包，不保存全量导出文件。工具准备不自动赋予后台安装、提权、重签或重启微信的能力。

### 来源变化与重新认证

- 同账号来源变化后的重新关联须由用户明确核对当前来源，旧授权、正文来源围栏、删除屏障和排除记录不恢复；已有资料按来源代次保留。[ADR-130](../adr/130-explicit-wechat-source-reconfirmation.md)
- 来源重新认证须有当前有效读取授权和用户明确选择。旧失证正文及实际派生结果保留但不自动恢复使用资格，新代次在全部来源验证完成前不可用于模型。不得用清空、移除围栏或新身份绕过删除排除、清空边界及撤回终态；无法可靠延续保护时继续停读。认证本身不触发模型、媒体提取或历史记忆初始化。[ADR-144](../adr/144-preserved-history-source-recertification.md)
- 已采纳的开发者批量重新认证（ADR-173）已在开发模式实现并验收（2026-11-06），入口仅开发者调试区可见、不进入打包版，且不改变本段要求：一次确认的范围限于确认弹窗列明的全部当前被围栏且在有效读取范围内的联系人，每位仍由后端独立复验账号、来源、读取授权与删除代次，不恢复旧证据或旧授权。见 [ADR-173](../adr/173-developer-batch-source-recertification.md)及[验收记录](../../docs/verification/fenced-contact-batch-repair-20261106.md)。
- 旧读取器的来源键仅按 [ADR-161](../adr/161-proved-legacy-source-suppression-mapping.md)的有界证明映射（另见该 ADR 2026-11-06 的窄覆盖补充：旧代次撤回记录仅当当前代次在同一分片、同一物理表实例、同一本地键位置独立记录为撤回时才可映射，未覆盖仍须证明，且不凭正文、时间或昵称猜测）：同一账号、联系人、会话及所选物理表须由独立读取器核验，证明保留在认证审计；不据正文、时间、昵称或别名建立映射，不宣称失证前后连续。已完成认证且审计有效的证明，才可扩展同一物理出现的跨代次删除与未来排除；不恢复旧证据或读取资格。删除冻结全部已证明副本及派生结果，连同尚未捕获的等价键保留排除，重试不依赖原种子仍存在；证明随联系人或账号删除。

## 允许的数据流

各流程只使用本次声明的最小必要资料，不默认向模型发送整个历史、其他联系人资料、未选择的原始截图或无关账户信息。新模型、外部 OCR、存储或连接器必须事先记录数据、用途、接收方、保留期与删除行为，既有同步授权不自动覆盖新增用途。

| 场景 | 允许范围与约束 |
| --- | --- |
| 本地文字导入 | 明确来源和联系人归属并提供删除入口；用户提交的原始 JSON 仅供来源复核和可追踪重解析，不进入回复检索，不默认发给模型，随来源删除。 |
| 用户提交的 OCR／转写 | 仅用户主动提交的截图、语音及原始引用，说明本机或供应商处理方式；这与自动前台名称定位、图文记忆输入分别授权。 |
| 图文记忆提取 | 同一联系人聊天文字与实际图片共同进入模型，限已确认范围和已配置接收方，保留图片所属消息、文件版本及删除依赖；结果为待采纳候选并保留证据。记忆正文与检索表示仍为文字。[ADR-153](../adr/153-joint-text-image-memory-input.md) |
| 来源语义核验 | 同一已授权提取窗口的必要原消息与候选，使用既有供应商和模型，至多一次有界调用；不检索新范围、不改写事实，保留无正文台账与独立含正文追踪。 |
| 回复与表达建议 | 本次输入、有界近期消息、相关且有效的已采纳资料、适用偏好，以及当前可用 Skill 的名称与简介目录、模型按需加载的正文和资源；每包固定一个修订，未加载的正文不随目录发送，输入预算不扩大。记录实际上下文，建议不冒充用户已确认立场，新消息只提示、不自动生成。[ADR-079](../adr/079-unified-expression-workspace.md)、[ADR-136](../adr/136-multi-skill-reply-composition.md) |
| 本人事实与明确偏好概览 | 复用同 owner 的无正文清单、真实 SELF 原版本和来源 ID；不复制联系人原话、姓名或定位文字，每项来源回到已确认原范围核对。本人资料不成为自动读取另一关系原话的入口。 |
| 记忆提取完整追踪 | 实际来源映射、窗口、模型请求／返回、程序处理和写入结果；默认独立保存，遵守下方[追踪边界](#记忆提取追踪的正文与删除边界)，不扩大读取或外发。 |
| Skill 发现与使用 | 仅授权根内的核验包与允许静态资源；发现不发送聊天或联系人资料，网络获取须另行授权。安全和删除按下方 [Skill 边界](#回复-skill-指令安全)。 |
| 经验提案（已采纳目标，当前未开放） | 正常 SQLite 宿主尚未开放学习入口；目标要求默认关闭、单独确认学习用途。同一联系人有界助手任务、编辑／选择、可靠后续观察与有效教学策略，每批最多 8 份／24000 字符，采用独立模型许可、租约与有限重试；清洗策略和私人依据分开，未审核不运行。实际来源与偏好依赖参与代次复验和删除。[ADR-048](../adr/048-memory-skill-evolution-lifecycle.md)、[ADR-162](../adr/162-local-reply-context-and-independent-model-lanes.md) |
| 对照审核与发布（已采纳目标，当前未开放） | 正常 SQLite 宿主尚未开放审核发布入口；目标要求明确审核输入、同一冻结上下文、旧策略或无 Skill 基线及隔离草稿，不临时发布；范围和替代关系双确认后原子发布。来源、导航及偏好全部进入删除证明，学习产物无独立留存例外。 |

### 受管图片与联系人头像

- 授权范围内的聊天图片须核验消息来源、唯一资源关联和完整实际解码，再保存为应用受管副本；只保存标准图或高清图，缩略图太小看不清，不保存（资源端口关闭句柄并以仅缩略图失败，聊天保持占位），已保存图片不再分原图等级。只对来源已核准且明确缺钥的图片，通过外置 wxkey 在当前账号范围准备并内存复用密钥，不调用 bootstrap、不注入或修改微信进程、不驱动远端下载。最小来源元数据、消息 ID 与每联系人水位保持。[ADR-138](../adr/138-chat-image-original-extraction-and-placeholder.md)、[ADR-140](../adr/140-source-verified-viewable-chat-images.md)、[ADR-170](../adr/170-no-thumbnail-storage-and-no-original-classification.md)
- 受管文件（图片、运行副本）的身份只核对 inode、创建时间、属主及父目录，不含系统设备号，避免重启或重新挂载后误判已存文件失效；旧记录中的设备号忽略。依据见 [ADR-168](../adr/168-managed-file-identity-without-device.md)。
- 图片保存、补查和记忆调度分离：取图任务本身不调用记忆、OCR 或外部模型；记忆任务按图文输入合同独立处理。全部有效授权联系人中没有可查看已保存图片的消息（缺副本、仅缩略图、取失败）由串行任务补查，使用持久退避（1 分钟至 24 小时），重复唤醒和重启不重置。读取与发布均复验授权和来源；“全部”不扩大同步范围。已保存的图片不再复查，失败前可查看副本保留，关闭同步、退出、撤权或删除停任务，已清除图片不恢复。[ADR-156](../adr/156-automatic-image-reconciliation.md)、[ADR-170](../adr/170-no-thumbnail-storage-and-no-original-classification.md)
- 联系人列表头像仅为可见的已确认联系人，按稳定绑定查询微信 contact 表单行并核验账号、授权及来源代次。总开关关闭或撤销时停止新读取并取消在途请求；仅向 `wx.qlogo.cn`／`thirdwx.qlogo.cn` 的 HTTPS 原地址请求，禁止重定向，不携带聊天、姓名或模型凭据。位图有界解码为缩略图，只驻本机内存；页面卸载、范围切换或联系人删除时释放，不进入记忆、模型或业务库。

## 模型适配器约束

所有模型请求通过独立适配边界 `ModelGateway`，不散落于导入、检索或 UI。它只接收隔离范围内已裁剪的上下文，不自行查询全量历史；区分表达建议、回复、提取、核验和 OCR／转写等用途。发送前校验字段白名单与预算；越权、超预算、未声明字段或供应商政策未知时拒绝调用。供应商地域、保留期、训练使用和删除机制必须明确且满足要求，不能把连接成功当作数据政策或质量确认。

用户按 [ADR-146](../adr/146-editable-deepseek-endpoint.md)明确填写兼容接收方 Base URL 与对应新 API Key，原子保存并受控重启后生效；保存不调用模型，不把旧密钥自动转给新地址。OpenCode Go 的模型环境、独立容量及同套餐核验路由按 [ADR-147](../adr/147-opencode-go-model-configuration.md)，沿用相同数据准入。

按 [ADR-162](../adr/162-local-reply-context-and-independent-model-lanes.md)，回复独立许可只隔离排队容量，不分裂供应商、台账或数据保护。已接纳且仍有效的本机资料可在微信不可读时使用；来源删除、隔离、真实冲突及本轮实际依赖变化仍在出站和保存时复核，后台来源资格不放松。取消或执行者断线不证明已发送调用结算；未知结果保留所属类别许可及原恢复保护。

### 普通日志与强制出站台账

- 每次对外发送产生不可关闭的 `outbound_ledger` 记录，包含必要内部范围／来源／条目／请求标识，供应商、模型、用途、请求时间、用量、响应结果，以及保留期与供应商删除能力。内部标识仍属私密范围资料，不等于匿名。
- 普通运行日志仅保留内容无关的引用、状态与错误，并定义留存期限和清除任务；普通日志和最小台账均不得复制聊天、候选、记忆正文或来源文件名。含正文追踪独立管理，不写入日志、台账、控制台或自动诊断上传。
- 单份来源／资料删除保留 [ADR-031](../adr/031-source-deletion-retains-minimal-ledger.md)允许的最小无正文调用记录；整联系人或账户删除按 [ADR-094](../adr/094-ledger-erasure-by-deletion-scope.md)清除对应台账及可恢复副本。不能把记录改名或藏入删除凭证、日志、缓存继续保留，也不能把防自动恢复的同步排除标记扩张为整条调用记录。
- 本机删除不证明供应商副本已清除；界面须说明独立删除路径、保留期与剩余限制，台账只支持核对曾经发生的调用。

## 回复 Skill 指令安全

当前正常路径只读取用户授权根中的外部原包，SQLite 保存不可变修订的身份、定位及内容摘要，不复制正文或建立文件历史库。原目录始终只读，不因包失去数据库引用、停用、来源撤销或目录消失而删除用户文件。[ADR-129](../adr/129-controlled-dsh-reply-skill-discovery.md)与[当前删除接入](../../backend-ts/src/skills/sqlite/README.md#删除接入边界)限定这些责任。

- Skill 包是待验证的不可信指令，仅在宿主已配置并授权根中发现；新包及既有未知项完整技术核验后默认启用，记录 `default`，不冒充用户确认。用户停用、来源撤销及删除不因刷新恢复，重新启用复验当前内容。[ADR-129](../adr/129-controlled-dsh-reply-skill-discovery.md)、[ADR-135](../adr/135-default-enabled-localized-skill-library.md)
- 业务身份与物理定位分开。按 [ADR-157](../adr/157-portable-skill-directory-identity.md)，目录复制或设备标记变化仅在授权根内、完整安全快照及正文／全部资源双摘要与最新历史修订一致时恢复定位并建立新修订；保持包身份、启停及来历，旧修订、运行锚点和迟到结果不复活。停用项不因迁移读取正文或启用，来源撤销不能靠相同文件恢复；没有基线、内容不符或真实冲突仍不可用。
- 技术核验覆盖格式、大小、路径、资源类型、内容摘要及读取期间身份，拒绝路径遍历、符号链接和硬链接逃逸。`SKILL.md`、references 与允许的静态 assets 绑定不可变版本；scripts 不进入可运行版本，`allowed-tools` 等能力声明不进入模型目录。
- Skill 正文不能注册或授权 Tool、MCP、Shell、文件写入、外部网络或聊天发送；应用的 Tool 注册表与确定性权限规则决定可执行范围。候选回复 Agent 无自行搜索、下载、写入、启用、删除或发布 Skill 的权限，未来网络安装必须是独立用户操作。
- DSH 受控 provider 仅暴露当前 owner/contact 可用的虚拟路径；只读工具只能读取本轮版本清单内的正文和静态资源，不读取任意文件、外部 URL 或其他范围。目录、Tool 结果和摘要绑定本轮 `owner_id + contact_id`、实际包修订及目录快照；目录中包集合或 head 修订变化使旧目录身份失效，名称在同 owner 内唯一，旧运行状态不能恢复失效版本。当前快照按[受控 provider](../../backend-ts/src/skills/sqlite/provider.ts)核验，不将旧 `skill_library_revision` 标量当作现行数据字段。
- 当前删除按所有权区分：账户删除清理包／修订元数据、定位和摘要；联系人或单份来源删除不清除同 owner 独立的外部原包。实际调用输入、追踪、Tool 结果、摘要及运行恢复副本由持有它们的业务域按真实依赖清理，不能以包域不保存正文为由遗漏；原包不得登记为受管文件删除目标。

### 尚未开放的学习与受管发布目标

正常 SQLite 宿主尚未开放学习、审核发布、版本回滚、删除包、导出或试用入口。以下保留已确认的[学习发布合同](skill-library.md#6-已采纳的学习审核与发布目标)，不授权删除外部原包，也不表示普通目录核验已实现审核发布：

- 明确停用方法或整个 Skill 的范围政策，默认不保存反馈原话或候选正文；执行投影绑定实际允许正文，在提交、继续和恢复时复验。政策变化保留合法历史与用户编辑，来源删除擦除应用持有的受影响策略、使用和恢复副本，撤销无正文决定不能复活已删策略。
- 应用受管发布内容按不可变版本保存；删除清理其全部版本正文、资源、可编辑副本、隐藏发布历史、暂存、来源定位、目录缓存、Tool 结果和摘要，并登记可重试清理。失败不能重新发现并复活；历史请求仅保留内部标识、名称、简述、摘要、删除时间与凭证组成的最小记录，不保留可恢复正文或资源。原 [ADR-096](../adr/096-directory-backed-reply-skills.md)的受管目录目标不得套用于当前外部只读原包。
- 若旧任务已留下应用持有的学习、审核、发布或恢复副本，其来源删除责任继续适用；当前入口未开放不构成留存例外。

## DSH 迁移的数据边界

精简 DSH 与 TS 业务共用本机后台进程，Electron 独立；业务模块仍负责联系人隔离、权限、来源、事务、输入预算、出站台账及提交前复验。采用框架不扩大工具或外部发送权限。[ADR-102](../adr/102-dsh-typescript-backend-migration.md)

候选回复助手会话按 [ADR-106](../adr/106-persistent-assistant-conversations.md)在稳定本机目录保存可恢复 DSH 记录，业务数据库是用户可见讨论、候选、修改及来源的主记录。运行记录可与业务材料重合，必须绑定可靠的 owner、联系人及业务会话；不加载会话日志上传、遥测或无关工具，必要模型调用仍遵守最小出站。

空闲 12 小时只改变默认续用，旧会话保留到用户删除。释放运行实例或退出 App 不等于删除文件；重启核对权限、来源和业务提交状态，中断轮不自动重复模型请求，不恢复未提交候选或已删除内容。后台任务按业务状态恢复，不因助手持久化增加长期执行日志。

删除覆盖有关 DSH 日志、分叉、派生索引、缓存和应用管理的恢复副本，保留无关讨论与无正文占位。NotAlone 自行协调关闭、清除和失效，清理失败不得报告删除成功或继续使用未清理记录。修正、失效或删除后，在恢复及出站前排除不合格材料，必要时从有效业务记录重建；只追加更正提示不能代替清理被删正文。

## 记忆提取追踪的正文与删除边界

按 [ADR-037](../adr/037-complete-memory-extraction-trace.md)，所有提取默认独立保存含正文完整追踪，保留至手动删除或来源删除；阶段与查询契约见[追踪规格](memory-extraction-trace.md)。这允许核验正文在受控追踪中留存，不扩大模型准入、范围、原始视觉帧处理或自动采纳权限。

来源依赖覆盖实际原始记录、全部窗口消息和参与判断的旧记忆，不能缩为候选直接引用。删除任一实际来源时，清除受影响整份追踪的正文、原始请求／响应、解释、缓存和可恢复副本，并复核不可检索；多来源权威消息与记忆仍按其独立规则处理。联系人和账户清除包括全部相应追踪及最小台账。

追踪不含凭据，不进入普通日志、控制台、Git、公开评测或自动外部上传。记录失败停止本批后续处理和水位推进，保留已提交结果并暴露失败、部分写入及不可观察的历史载荷缺口；不能用合成工程或文档宣称真实模型和原生渠道均验收完成。

### 删除范围与完成条件

| 用户选择 | 必须清理或保留的范围 |
| --- | --- |
| 单一来源／资料 | 清除来源引用、仅由其支持的消息和资料、受影响候选、证明、追踪、检索、缓存、任务与恢复产物；其他有效来源仍支持的消息不误删。仅保留最小无正文调用记录。 |
| 单条关系资料 | 清理实际依赖它的派生正文、检索、回复及恢复副本；独立合法原始消息不因资料删除而误删。 |
| 助手会话 | 清理讨论、候选、编辑版本、携入及运行副本；独立原始聊天和关系资料按各自来源规则保留。 |
| 整个联系人 | 清除其全部来源、消息、关系资料、回复、会话绑定、运行副本和调用记录，连同本范围投影、抑制和证明；稳定渠道身份仅保留阻止自动恢复所需的墓碑／排除。无关联系人保持。 |
| 整个账户资料 | 清除该 owner 的全部相应资料、调用记录及可恢复副本，不影响其他用户。 |
| 受管图片 | 随来源／联系人删除一并清除消息引用和完整性记录；仅清除图片时保留消息及清除状态，后续同步和补查不自动恢复文件。 |
| Skill 相关资料 | 按上方只读原包与应用持有副本边界清理；当前包目录保留，实际输入和恢复副本按依赖删除。受管学习发布目标另行核验，不用历史请求或 checkpoint 恢复已删副本。 |

- 删除建模为可重试、幂等的后台任务，逐存储面确认结果并处理并发、晚到写入和部分失败，失败原因可查看。`deleted` 仅在确定性复核“不可查询、检索或恢复”后成立；请求、执行中和失败分别记录，只改状态不算完成。操作日志只含存储键、条目 ID 等非正文标识。
- 联系人删除确认须核对对象与选择代次，先封禁该对象读写资格再清理闭包；说明本机范围，微信原件及外部模型副本不随本机删除。任务不随联系人离开目录丢失，后台列表包含全部未完成任务，不被较新的完成记录挤掉。回执丢失不推断成功，已知任务只重试原任务，未知任务只能由用户明确重放原确认的旧联系人 ID。重连先核对固定 owner，仅同本人恢复内存中未确认意图，不同本人不公开旧姓名或任务，也不自动重放删除。用户确认一次后，删除由本机在后台自动推进：已有任务编号的未完成任务，在同一本人连接内按原任务有限次退避自动续跑，重启或重连后每个连接对每个任务自动续跑一次；等待清理期间名单随后端封禁尽早移除该联系人，完成后不留任务面板。单次删除请求只等待运输层时限；清理或压缩未结束时按原任务编号轮询权威终态，请求超时不被当作失败或结果未知，只有发现窗口也读不到原任务时才标记结果未知。仅结果未知、受阻或自动续跑后仍未完成的任务才显示状态并提供明确重试；未取得回执的删除意图和换本人后的任务仍不自动重放。成功撤下姓名及联系人标识；仅重新读取名单并明确新建，且旧绑定全部撤销、旧联系人均已删除，才可在稳定身份墓碑上建立新联系人 ID；不恢复旧资料或授权，旧删除重试不作用于新对象。
- 联系人删除在范围事务内封禁对象后，名单服务即可只读重建：目录、已保存绑定与同步状态可读，但被删联系人及其绑定不再出现；重建的名单读者只查询活跃联系人，不进入该删除操作的闭包，封禁前已有的名单读者仍在清理前关闭。账户删除、尚未封禁或已缺失联系人的任务，以及任何身份写入和可能把已删联系人重新列为候选的名单预览，仍保持关闭到对应删除完成。该提前可用不改变压缩与全库校验须在结案前完成的保证；压缩期间存储 Worker 同步执行，名单读取按维护预算排队。
- 结案前必须完成 SQLite 压缩（checkpoint、VACUUM 与全库校验）并把结果记入 `sqlite_pages_wal` 核验。压缩在存储 Worker 内同步执行且无法中途打断，使用独立于普通动作的维护预算（不低于 10 分钟并随库体积增长），期间运行状态保持可用、不被误判断连；压缩中断或超时时任务停在清理态，不记完成，重启后沿原任务幂等重试并补齐核验，已清除的范围数据不因失败恢复。
- 导错联系人先删除错误来源，再重新确认和导入，不能直接迁移私密资料归属。重新导入已删文件须重新预览、确认并创建新来源，不恢复旧 UUID、依据或证明。删除完成只保留不含联系人名称、来源文件名、文件哈希或聊天内容的最小删除凭证；必要同步抑制按下节独立处理。
- 外部模型／存储副本、用户另存文件及外置原库分别说明独立删除路径和限制。应用管理的完整快照、暂存及恢复副本全部核验归属并清理，未清完不能报告整体成功。

### 来源依赖、纠错与失效

修正关系资料保留修正时间与原来源关联，不要求长期保存用户已要求删除的正文。删除／重试的进度、失败原因和结果须可见，不能静默失败。多个有效来源对同一规范消息互为替代，正文必需消息之间则是合取依赖；保留内容须在删来源前由用户明确另存为独立手动资料，不能在删除过程中把自动提取改名为手录以逃避依赖。

- 失效或过期记忆及依赖它们的正文不得用于新生成；仍有合法来源的历史表达可以回看，真实来源／记忆删除则物理擦除受影响回复、编辑版本、携入和恢复副本。依据变化提示不复制正文或改写原快照，旧幂等键、中断重试和迟到结果不能复活内容。[ADR-080](../adr/080-unified-memory-list-and-retired-exclusion.md)
- 证明须覆盖完整参与窗口及活动来源，而非只有候选直接引用；背景来源删除也使旧证明失效，多来源消息仍存不能借另一来源恢复旧证明。候选拒绝或删除清除依据，复核残留定位；来源标识、摘要及标签虽无正文仍属私密资料，不进入普通日志或公开上传。[ADR-046](../adr/046-source-bound-dimension-evidence.md)
- 正文必需消息依赖独立于证明保存：任一必需消息失去全部活动来源时，收集全部状态的资料及版本，清理引用回复与运行租约，再擦除正文、解释、备选、索引并核残留。人工确认不切断依赖；独立手录、无关范围及仍有有效来源的消息保留。仅背景消息删除使证明失效，不扩大为无正文依赖资料的删除；旧合同记录按其实际来源合同核验。[ADR-063](../adr/063-bounded-runtime-evidence-and-source-dependencies.md)
- 纠错的完整参与窗口和来源代次进入原删除事务；排队删除即撤下旧比较和批准，执行时清除纠错正文、候选证明、追踪和恢复副本。仅为仍有效规范消息防止旧错误复活保留无正文 `erased_guard`，最后有效依据删除后移除。已退役升级留下的比较、提取结果与裁决同属敏感副本，在原事务清理，不依赖下一次 GET；算法身份仅含有限非秘密配置，不含正文、密钥、任意环境变量或带凭据端点。
- 受管学习、审核与发布目标中的输入、对照、正文、资源、方法、操作摘要，以及跨联系人准备和实际使用副本，须按完整来源、导航与偏好依赖进入删除锁和事务物理清除；已有应用持有的旧副本同样承担该责任，不扩展到外部只读原包。新增学习用途不自动获得出站许可，未审核草稿不能运行。
- 已退役主动收藏样本及其独立留存例外按 [ADR-082](../adr/082-retire-explicit-style-samples.md)清理旧样本和来源依赖，撤销受影响冻结输入、携入及恢复资格。独立合法聊天、记忆与长期偏好不因退役误删。

### 自动同步的删除抑制

删除排队及直接来源／观察删除在既有范围锁事务内，按规范消息已有稳定身份登记最小无正文抑制，防止后台用新捕获 UUID 恢复已删内容。标识仍属私密范围数据，不含正文、昵称或文件哈希；只阻止新自动消息及来源引用，不影响其他有效来源支持的规范消息。原始处理收据、提取意图和消息通知使用同一过滤结果，整页过滤仍按实际 CLI 页推进游标。

普通重启、总开关重开、后台重试或一般重绑不解除抑制；重新预览确认文件导入只建立独立新来源，也不解除后续自动读取抑制。本规则不新增永久消息封禁或“恢复已删历史”能力。未知稳定身份不作语义猜测、不引入正文哈希，升级不能回填已经丢失的历史删除身份。

跨来源代次只沿已完成的有界映射传递抑制，不授予读取或旧证据复用资格。联系人／账户整体删除清理本范围抑制，全部私聊撤销排除继续生效；不能用新身份绕过旧清空边界。受管备份仍受清理及恢复门禁约束，抑制表不能撤销用户持有的外部旧副本。

### 概览、准备输入与恢复副本

- 联系人／本人概览的无正文清单也属于删除范围。底层记忆、候选、人工决定、来源、消息、来源引用、观察或实际追踪依赖变化时，在原事务撤下投影并记录真实集合修订，不改变资料采纳或授权。来源进入 `delete_requested` 即失效，清理失败也不能从旧清单恢复；重试及已提交但 Worker 回执未保存的重建都须重新核验来源。
- 本人手录根沿真实合法版本链核验，其后混入的聊天依据仍受来源删除约束；owner 引用不能豁免聊天依赖。本人概览来源定位文字为空，仅留真实范围与引用 ID；旧未知证明不能靠后续人工决定或另一来源恢复。修订及清单失效随原事务提交或回滚，旧投影和中断回执不恢复正文。
- 概览投影不保存 HTTP 正文、原话、模型摘要或另一份恢复正文；数据库约束拒绝在投影、记忆依赖或引用层追加正文。HTTP 禁用缓存，客户端按范围和操作代次撤下旧内容。
- 回复导航和检索保存生成时的无正文回执，实际证据正文只保留合法底层快照。准备阶段尚无回复请求时也在输入 CAS 固定完整参与依赖；来源排队删除在同一事务擦除有关固定 JSON、输入及恢复副本，最终写入在同一 owner 锁事务复验。导航依赖即使未作为候选引用也进入删除链；只供删除追踪的隐藏依赖不冒充模型依据，回执不替代 `basis_changes` 或原来源证明。
- 概览或补查失败不扩大读取权限或预算。联系人原话补查与本人资料预算独立，旧快照、失败重试、同库恢复和迟到输出不得恢复应删正文。记忆调度的待处理输入、合并窗口和执行资格随来源复验，旧事件、截止时间和迟到结果不能重建被删来源的处理资格。

## 检索记录与度量

检索记录只保存引用标识、排序分数和检索器版本，不复制正文，不作为长期关系资料。默认持久化并设置保留期（原规格以 30 天为例，实际值按配置核验），到期后台清理；随 `reply_request` 删除级联，用户可查看并主动删除。

评估检索时记录空结果率、降级率、候选拒绝率与引用纠错率，采集点为检索／生成的返回及接受／拒绝动作。持续超阈值且有实际反馈才评估 embedding 或向量检索；引入前明确计算位置、发送字段和供应商，向量按文本相同隔离键、留存和删除语义处理，并单独评审数据影响。

## 暂缓目标与尚未决定

- [ADR-128](../adr/128-deduplicated-wechat-message-storage.md)的撤回新展示及使用规则仍暂缓，不能当作已启用行为。目标为可靠撤回前已保存正文可查看但不进入新回复、检索或记忆，仅由其支持的记忆失去资格；未取得正文只保留无正文占位，旧回复不因撤回自动改写。微信端删除或短暂不可见不自动删除 NotAlone 消息，缺失不猜作撤回。暂缓期间继续现有来源资格保护；去重已采纳，但不证明每位用户资料已迁移或完整实机已验收。
- [ADR-092](../adr/092-defer-time-calendar-web-tools.md)下，时间、日历和公开网络搜索不属于当前接入要求。未来时间结果由确定性代码提供，日历须独立授权且只读，公开搜索不默认携带聊天、联系人身份或关系资料；须分别明确接收方、用途、范围与出站类别，不授予聊天发送能力。
- 本机库／缓存加密、凭据存储和本机备份的具体方案，以及各供应商地域、训练使用、保留与删除 SLA，仍须明确。现有 API 接入不替代这些结论；云端工程和多设备同步不列为当前待办。
- 外部聊天渠道连接器是否及何时接入另行决定，必须独立授权，不改变最终由用户亲自发送的产品边界。

## 最小验证清单

按改动范围选用以下合成或隔离验证；未执行的真实渠道、模型质量和桌面行为分别报告，不能用文档或历史通过替代。

- 隔离：A 的请求不可取得 B 的消息、记忆或 Skill；本人概览不成为读取其他关系原话的入口，字段白名单、预算及未知供应商政策拒绝有效。
- 授权与采集：首次列表不预选、不保存夹带摘要；撤权、关闭和退出停读，旧响应及重启不重放授权；前台仅名称 OCR，定位失败不变为正文 OCR，已有合法后台同步不被前台状态阻断。
- 回复出站：只发送本次实际声明的有界资料，建议不冒充已确认立场，范围或修订失效拒绝旧结果；不存在自动聊天发送。时间、日历、网络 Tool 的当前不接入边界保持。
- Skill：授权根内新包完整核验后默认启用并保留 `default` 来历；用户停用、来源撤销和删除不因刷新恢复。合法定位迁移只生成新修订，恶意正文不能增权、越界读取或恢复旧版本；应用持有副本清理失败不复活，外部原目录保持只读。
- 删除：单来源与多来源分别验证，涵盖规范消息、候选、确认资料、受管媒体、证明、导航、准备输入、追踪、运行副本、备份及索引；只改 `deleted` 状态必须失败，晚到写入、重试和同库恢复不重建内容。
- 删除范围：单来源只保留最小无正文台账，整联系人／账户清除对应台账；旧联系人删除重试不影响重新添加的新 ID。明确显示外部副本限制，未知供应商政策不能描述为外部删除完成。
- 删除可读性：联系人封禁后名单只读可读且被删对象及其绑定不可见，重建的名单读者不阻塞删除闭包；账户删除、身份写入与名单预览仍关闭；跨重启保持同一区分，压缩期间不宣称读取可用。
- 防恢复：再次文件导入产生新确认和来源，自动历史／增量读取仍遵守稳定身份抑制；跨代次证明覆盖全部等价键，未知身份不猜测，图片清除不被补查恢复。
- 追踪与日志：仅作背景的来源删除也清除受影响完整追踪；记录失败停批且不推进水位、部分写入可查；普通日志、最小台账及诊断无正文和凭据。
- 留存与界面：加密未落地时明确“未加密”；落地后验证静态加密及密钥轮换／吊销。损坏导入、空／模糊检索、后台任务与删除失败均有用户可见结果。
