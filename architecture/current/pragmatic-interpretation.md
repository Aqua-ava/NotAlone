# 记忆候选的原意与不确定性

正常记忆处理按[领域与数据契约](domain-data.md#候选采纳与人工保护)执行：结构合格、独立来源支持且仍有效的候选，经过适用的条件、事件与版本检查后进入自动裁决。依据为 ADR-200 及 ADR-200；语用、置信度、风险字段用于描述，不单独增加人工确认门，也不设置统一重复次数门槛。

- 核验须支持主张正文、`self/contact/shared` 主体及原话限定；计划、可能性、条件、转述、玩笑不能被改写成已发生的确定事实或长期偏好。
- 未知第三人不因窗口中只有两位发送者就归给联系人；机构提及、一次建议或本次回复策略也不能变成身份、人格或长期偏好。
- 来源支持说明“资料支持这项表述”，不认证现实真相。日期、有效期、事件顺序与不确定性按[资料分类与时间](domain-data.md#资料分类与时间)及 ADR-081 保留；当前时间不能证明计划已完成或临时状态仍持续。
- 未解决矛盾与关系未知保留待定；失败如实记录，旧人工决定、删除和来源资格不被新标签绕过。候选状态和写入权限由业务代码控制，模型不能扩大联系人范围、执行步骤或外部发送能力。

显式旧语用字段、三门流程、固定窗口和旧框架接线已移至历史协议（本机 `architecture/history/pragmatic-interpretation.md`）。仅核对对应历史评测或审批回放时读取；历史成绩与当时验收范围保持原意。
