# 现行语用解释与记忆候选边界

> 状态：已采纳的记忆提取约束；当前最小代码纵切已实现，完整界面展示仍按本文边界推进。
> 日期：2026-09-09

## 1. 目标

关系记忆提取不能只把消息改写成一句“事实”。同一句话可能是事实、计划、假设、转述、玩笑、讽刺或夸张。语用解释模块先描述消息在当前语境中的表达状态，再由确定性规则决定它能否成为记忆候选以及能否自动采纳。

```text
同一联系人有限消息窗口
  -> 模型结构化语用解释
  -> 来源、范围和字段确定性校验
  -> 语用记忆边界判断
  -> memory_candidate / pending / 不生成长期记忆
```

该模块不判断“贷款是否真的发生”这类现实世界事实，也不代替用户确认关系资料。

## 2. 输入窗口

- 输入必须属于一个已经确定的 `owner_id + contact_id` 范围。
- 首次历史提取按目标消息分批；每次模型调用最多处理 20 条目标消息，并补充目标前后各最多 20 条同一联系人的上下文消息。
- 上下文消息只能帮助理解语气、指代和前后关系；模型产出的每条候选必须至少引用一条目标消息。
- 不把完整聊天历史、其他联系人或未授权媒体内容交给模型。媒体占位文本不能被解释成媒体正文。
- 导入和增量任务仍由 Worker 负责批次、重试和水位；语用解释只处理当前窗口。

## 3. 结构化解释结果

模型通过现有注入式 `BaseChatModel` 返回结构化对象。结果至少包含：

| 字段 | 作用 |
| --- | --- |
| `text` | 不改变原意的标准化主张文本；保留否定和必要的归属。 |
| `speech_act` | `assertion`、`plan`、`question`、`request`、`report`、`correction` 或 `unknown`。 |
| `assertion_status` | `asserted`、`hypothetical`、`conditional`、`reported` 或 `unknown`。 |
| `figurative_type` | `literal`、`joke`、`sarcasm`、`hyperbole` 或 `unknown`。 |
| `subject` | 主体是 `self`、`contact` 或 `shared`。 |
| `source_message_ids` | 输入窗口中的证据消息 ID；至少一条且不能越界。 |
| `confidence` | 对本次解释和证据匹配程度的运行置信度，不等于现实真相概率。 |
| `risk_flags` | 转账、借款、健康等已有风险标签。 |
| `alternatives` | 只有存在歧义时列出少量其他解释，不展示模型内部思考过程。 |
| `interpretation_reason` | 一句面向用户的简短判断依据。 |

模型不能自由增加记忆状态、联系人范围、任务步骤或写库动作。`memory_action` 由下面的确定性规则计算，而不是由模型决定。

## 4. 记忆分流规则

| 语用结果 | 分流 |
| --- | --- |
| `assertion + asserted + literal`，没有歧义且证据合法 | 进入既有置信度/风险门槛；满足门槛才可 `auto`，否则 `pending`。 |
| 计划、意图、假设、条件、转述、纠正或 `unknown` | 只生成 `pending` 候选；不能自动进入已确认记忆。 |
| 纯问题 | 不生成长期记忆。 |
| 玩笑、讽刺、夸张 | 默认不生成长期记忆。 |
| 来源越界、字段非法、没有目标消息证据或模型调用失败 | 安全失败，不生成候选。 |

因此，“我准备贷款 30 万加仓”最多形成带 `pragmatic:plan` 阻塞标记的待确认近期状态；“我已经贷款 30 万”也只有在模型识别为确定、字面、证据充分且通过既有风险门槛后，才可能进入自动采纳路径。语用解释不会把任何一句话直接升级为现实事实。

当前最小纵切把语用阻塞原因复制到已有 `risk_flags`，并把 `subject` 持久化到
`memory_candidate`，以便人工确认时仍能区分 owner 与联系人记忆；结构化的备选解释
和短理由目前由提取运行结果携带，完整记忆管理界面展示属于后续工作。

## 5. 故障和隐私

- 模型调用没有返回结构化结果时，整个批次报告失败，不猜测且不推进水位；单条候选的字段无法解析、证据不在窗口或没有目标消息引用时，只拒绝该条候选，其他合法候选仍可继续处理。
- 模型调用仍通过既有出站台账记录；模型供应商、留存和删除约束沿用 `privacy-deletion.md` 与 ADR-024。
- 语用解释不允许读取其他联系人、执行 Tool、修改记忆或发送外部消息。

## 6. 验证边界

最小本地验证使用合成消息和 fake model，覆盖确定事实、计划、假设、转述、玩笑、讽刺、夸张、问题、纠正、歧义、来源越界和模型失败。它证明结构化字段、上下文边界和确定性分流行为；不等于真实中文模型在用户私聊上的准确率。真实效果需要另行建立约 30 条匿名化、人工标注的评测集，并重点统计错误确认率、证据精度和拒答率。
