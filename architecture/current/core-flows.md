# 现行核心流程

本页说明产品闭环并按任务定位详细合同。当前技术入口为 Electron／React 桌面、官方 DSH profile 装配的 TypeScript 后台及受控本机 SQLite；设计要求、实际接线和验收分别核验，不从文档存在推断功能可用。

## 1. 导入与关系资料采纳

```text
确认真实联系人与同步／导入范围
  → 可靠保存消息和来源
  → 同一联系人图文参与有界记忆处理
  → 来源核验、确定性裁决与可撤销自动采纳
  → 分阶段整理主题及长期背景
  → 回复按需使用仍有效的本机资料
```

联系人建立、首次历史和增量读取见[微信同步](wechat-sync.md)；资料对象及同联系人隔离见[数据契约](domain-data.md)。一次导入只能属于一位已确认联系人，混有多人必须拆分或拒绝，导入不能创建身份或授予微信读取权限。

默认采纳不以语用、置信度或风险标签制造额外人工待办。来源、人工修正、真实矛盾待定、时间限定、图文证据和删除仍须核验；内容拒绝与技术故障分开处理。完整流程与历史／增量及 L1/L2/L3 调度的唯一详细入口是[记忆处理](memory-processing.md)。

### 1.2 本人概览读取与底层管理

本人概览只返回合法本人资料及其可追溯标识；原关系的原话与定位信息不得通过 owner 范围旁路读取。查看、修正和删除仍沿对应资料身份，概览读取不调用模型或创建偏好；对象和范围见[数据契约](domain-data.md)。

### 1.3 旧资料升级退役

不再保留独立旧资料升级或重跑入口。既有记忆不会因入口退役而删除；日常更新由合法历史／增量处理承担，旧任务不再领取，残留比较和工作副本仍进入删除闭包。依据：[ADR-070](../adr/070-automatic-memory-maintenance.md)。

## 2. Mac 微信增量同步与前台定位

后台在 App 运行、同步开启且授权有效时读取正文；前台只用唯一微信窗口的名称区域定位已有联系人。两条路径独立，OCR 不作为后台同步门禁；微信暂时不可用也不阻断合法本机回复资料。

同步范围、首次连接、历史与变化页恢复、图片／引用、来源认证以及名称匹配的完整合同见[微信同步与前台定位](wechat-sync.md)。其中默认仅所选会话，明确全部私聊授权才允许自动纳入稳定身份；产品范围与本轮 SQLite 已开放能力分开。

## 3. 候选回复生成

用户明确选择或通过有效前台匹配确定联系人，进入同一工作区：“帮我表达”组织本次想法，“帮我想想”提供尚未采纳的建议。点击后固定输入、来源和精确依赖，有界生成 1–3 组候选；新消息、切换与回看不自动生成。

本机资料资格、上下文与模型预算、工具边界、持久助手会话、历史继续和候选依据见[回复生成](reply-generation.md)。Skill 发现、组合、版本、启停及受管副本边界统一见 [Skill Library](skill-library.md)。

## 4. 候选编辑与表达偏好

候选可编辑、回看保存版本及复制，最终由用户亲自发送；复制和“未观察到发送”都不能证明发送结果。候选选择、一次性要求和普通修改不静默成为长期偏好，主动表达样本收藏已退役。明确携入和长期偏好管理见[回复生成](reply-generation.md#候选展示编辑与发送)。

## 5. 删除与修正

联系人详情通过「⋯ → 删除联系人」具名确认；先封禁对象读写资格，再沿依赖闭包清理，最后独立复核。联系人从列表消失、请求返回或操作中断都不代表删除已完成；回执丢失沿原对象和任务恢复，不误作用于重新加入的新联系人。

来源、单条资料、联系人及账户的删除范围，多来源与合取依赖，媒体／运行记录／备份／外部原件，以及修正与另存手动资料的区别，统一以[隐私与删除](privacy-deletion.md)和[数据契约](domain-data.md)为准。

## 6. 后台任务边界

同步、记忆处理、删除和候选生成有各自的范围与控制意图。任务及步骤由确定性代码创建和推进，模型只提供受控语义结果，不能取得数据权限或决定提交成功。

历史／增量分类、阶段触发阈值、五种处理状态、暂停与安全恢复、内容拒绝、Worker 以及前后台独立模型许可见[记忆处理与后台调度](memory-processing.md)。来源与删除保护始终优先；新事件、重启或另一条队列不恢复撤销或未知调用资格。

## 启动、状态与验证

普通结构更新沿用同一本机库，核对身份和真实迁移历史；仅缺版本时在认证停读、生成结算与连接排空后原地补齐。已就绪则直接复用；新安装按受控生命周期初始化空库。异常历史或未完成更新保留现场，不因连接失败另建替代库，也不在普通启动中自动备份或复制资料。详细生命周期与副本责任见[隐私规格](privacy-deletion.md)。

当前源码导航见[后台入口](../../backend-ts/src/README.md)，开发和桌面验收执行[工程工作流](../../docs/agents/engineering.md)。各详细规格分别列出当前接线、尚未开放目标和验证入口；阶段进度、旧协议及固定实现记录见[历史目录](../history/README.md)，不列为正常开发必读。
