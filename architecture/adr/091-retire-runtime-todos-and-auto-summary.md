# ADR-091：不增加运行计划和自动过程摘要

> 状态：已采纳（2026-10-21）。用户在逐项复审 Q06 时明确选择沿用当前设计，不增加运行计划和自动过程摘要。

ADR-009 要求始终注册 TodoListMiddleware，并使用 SummarizationMiddleware 压缩单次运行消息；这些要求后来被其他文档沿用，但当前生产装配没有接入。此次取消这两项强制要求，保留现有受控模型与工具循环、输入预算检查以及长讨论显式新开的规则，避免为有限回复任务增加计划展示与摘要生命周期。

## 决定与保留边界

- 候选回复不增加 `TodoListMiddleware`、`write_todos` 或对应的模型计划／步骤进度界面。已有加载、生成、失败状态，以及确定性后台任务步骤不受影响；不把取消模型计划理解为删除业务进度。
- 候选回复不增加 `SummarizationMiddleware` 或自动过程摘要，不通过压缩较早工具／运行消息绕过输入预算。保留现有逐轮输入、输出预留及调用预算检查；无法容纳时按现有路径停止、提示或要求用户显式新开，不提交超限生成。
- 持续助手讨论继续按 ADR-042／045 不自动摘要、不静默截断。既有资料的有界选择、检索结果预算与未纳入上下文的低相关材料处理不等于截断用户讨论，按现行规则保持。
- ADR-090 的受控补查循环继续有效，工具调用不以先列任务计划为前提。范围、来源、删除、Skill 版本和输出校验不变。
- 不删除关系记忆、L2／L3 资料、业务历史或来源追踪；本决定只针对候选回复运行时的计划和过程摘要。未来若长任务确有需求，需单独复审，不作为本次未完成事项自动补入。

## 替代范围与验证限制

替代 ADR-009 第 4 节对 Todo／摘要中间件的强制接入、相关 UI 和测试要求，以及第 6 节把其视为当前必需能力的理由。ADR-010 和 ADR-042 中“单次运行机制继续有效”的引用不再包含这两项要求；保留框架选择、Skill、运行预算、产品讨论边界和来源删除规则。同步修订 Agent 草案与现行流程；时间、日历、网络工具的 Q07 仍待单独确认。

[生产装配](../../backend/src/notalone/reply/adapters/langchain_runtime.py)使用 ScenarioArguments、Skills 与 InputBudget 中间件，未接入上述 Todo／摘要能力；[输入预算](../../backend/src/notalone/reply/adapters/input_budget_middleware.py)继续约束模型调用。本次仅统一文档，未改代码、运行配置、业务数据或历史验收结果，未运行新的模型或桌面验收。
