# ADR-180：图片输入有界恢复、单项隔离与运行退休

已合并入[ADR-197：聊天图片取得与记忆图片输入现行合并决定](../197-chat-image-and-memory-image-input-consolidated.md)（2026-11-18）：聊天图片的取得、保存、补查与记忆图片输入约束已收拢到该 ADR。下文保留为历史决定与原因，现行条款以该 ADR 为准。

状态：已合并（ADR-197）。原记录：已采纳（2026-11-11）。来自图片可靠性整改中用户确认的六项决策。实现、合成验证与真实验收分别记录，不以此决定宣称真实模型或桌面已通过。

本决定补充[ADR-179](179-memory-image-input-normalization.md)，局部修订[ADR-149](149-content-rejection-is-not-failure.md)中技术故障停止整批的图片输入情形；内容拒绝与技术故障仍分别记录。[ADR-162](../162-local-reply-context-and-independent-model-lanes.md)的真实未知／孤儿保护、联系人隔离、来源与人工决定门槛继续有效。

## 决定

1. 图片模型调用明确返回终端传输失败时，区分“上游是否处理／费用未知”与“本地执行者或回执未知”。仅图片提取／来源核验、未取消、官方适配器明确返回的终端 `TRANSPORT`，以及严格符合首响应前原生证据的官方终态 `TIMEOUT`，可按 `terminal_failure=transport` 单独结算失败。TIMEOUT必须同时满足：实际fetch已开始、当前请求经原生undici request:create观察且绑定到该调用、尚未观察任何响应头或HTTP状态；不能仅凭异常码或自定义fetch推断。`dispatch`仍保持 `authorized_unconfirmed`，不冒称HTTP响应、未发送或费用为零。已经收到HTTP响应头／状态、非原生或缺少请求身份的超时、取消、预约／结算ACK丢失、缺少终态和真实未知均不进入此图片降级，继续遵守原响应／未知保护。
2. 失败窗口先保留来源与调用账本，再释放已知终态占用；新窗口使用独立请求身份和稳定槽位。按图片数二分直至单张；单张再使用一次更小版本。原图不超过1024时也须实际缩小，无法产生不同更小版本时不发送相同载荷。每次E/V物理发送分别记账，原任务预算不重置。
3. 降级树始终基于冻结目标的种类、顺序和原上下文，不因局部准备失败重新编号。恢复跳过已持久释放的父窗，复用已知成功子窗；局部坏图留在原叶隔离。子窗只携带自己的目标及合法文字上下文，未实际附带的图片如实记录未观察，不能用文字占位冒充图片。
4. 文件局部不可读、不能解码或单图降级仍失败时，以 `media_model_input_unavailable` 保存来源绑定的隔离事实；保留原 `file_id/sha256`，该项不计成功，其他目标继续。文件读取失败后必须再次复验授权、来源和冻结版本；真实删除／换图／撤销仍按原失效合同停止。连续三次同类隔离持久暂停，图片成功处理或用户显式重试重置计数。
5. 隔离状态与稍后重试可在产品查看。重试仅恢复有当前来源证明的隔离项，保留原成功步骤和已确认事实，使用控制版本与幂等操作身份，继续遵守总开关、待确认候选、未知账本与活动租约门槛。旧轮隔离在后续轮次出现后仍有有界恢复入口。重试新增的本人贡献按原事件身份增量交接，不被旧成功结果遮蔽。
6. L1任务可在全部目标成功或有合法单项隔离证明后完成，成功数与隔离数分别展示；适用L2/L3可继续。失败／退休且已释放占用的运行不再算 `contact_busy`；待确认、在途、未知或未释放占位仍阻断。联系人范围代次或本人反馈版本永久失配、不能继续的暂停轮经产品恢复逻辑退休，先核对完整调用链与关联后续任务均无未决调用或占位，保留原成功历史及删除依赖。后续队列仅在单次同步扫描中按运行复用释放核验，不跨读取保留资格；实际领取继续复验。
7. 图片就绪沿现有同联系人唤醒进入后续有界准入，不扩张已冻结运行。自动调度未运行时，汇总如实展示尚未纳入数量；已成功项不重复提取。manual运行时的单联系人收尾仍持久登记后续需求，但只有正式启动调度后才唤醒后续Worker，不能由一次手动请求隐式派发全owner的L2/L3。没有历史归因证据时，不把旧暂停推定为总开关暂停，也不自动解除有效用户暂停。
8. 每次调用与逐图元数据进入现有统一诊断日志：原／发送字节、图片ID、格式尺寸、张数、请求UTF-8字节、失败枚举与耗时。没有正文、base64、凭据或原始cause。正式图片／来源／联系人删除清除隔离、重试、完整追踪和逐图诊断；排空旧调用后清理，失败保持删除受阻可恢复。

## 取舍

降级可能增加模型调用；每次失败仍计预算，发送事实或费用未知如实保留。隔离使其他资料和后续整理能够推进，但不表示模型已经看过失败图片，也不保证缩放后小字质量。显式重试不扩展读取范围，不新增普通单联系人运行入口，不改变最终消息由用户亲自发送的边界。
