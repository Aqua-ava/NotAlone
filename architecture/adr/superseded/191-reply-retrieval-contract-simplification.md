# ADR-191：收敛回复检索合同并退役未使用适配

已合并入[ADR-195：回复检索现行合并决定](../195-reply-retrieval-consolidated.md)（2026-11-18）：回复侧记忆与历史检索的现行约束已收拢到该 ADR。下文保留为历史决定与原因，现行条款以该 ADR 为准。

状态：已合并（ADR-195）。原记录：已采纳，2026-11-17。用户要求清理后台调度与回复检索中的冗余状态、无用途兼容层和重复编排。

正式回复已经只消费共享检索的排名与按需核验结果，但旧综合选择器仍维护另一套词法评分、数组入口和待确认候选预算，部分兼容分支只有合成夹具使用。继续保留会让未来装配意外退回整池核验，也使测试测到与正常入口不同的路径。因此只维护当前正式消费合同，历史材料兼容单独保留。

## 决定与替代范围

- 正式回复读者必须提供记忆头部列表、逐条物化和文档读取；不按可选能力退回整池读取。记忆领域同样删除仅供旧验收使用的整池 `read` 与 `includeUnconfirmed` 开关，按精确身份物化并复验，验收复用 `list/open`。待确认候选的管理、来源检查与历史冻结材料复验各走实际领域入口，不重新开放枚举或注入。记忆与文档领域读者继续只承担各自职责，组合层明确装配所需能力。
- 文档预算与已排名记忆选择分别处理。正式记忆必须使用共享检索返回的精确身份／版本及顺序，联系人最多五条、本人最多三条，额度由同一处定义；失效条目继续跳过并补位，不能截断正文。删除旧字词覆盖率回退不影响缺少向量时的 BM25 降级。
- 退役未开放的待确认候选选择／注入适配接口及其三条／三百字符、0.15 旧词法预算，不为该接口继续维护第二套回复选择链。局部替代 [ADR-035](035-pending-candidate-unconfirmed-reply-reference.md) 的独立检索入口与预算实现要求、[ADR-028](028-lexical-memory-recall-phase-1.md) 的残留回复词法选择条款，以及 [ADR-067](../067-layered-scenario-and-profile-context.md)／[ADR-182](182-reply-memory-hybrid-retrieval.md)／[ADR-190](190-tencent-style-local-hybrid-retrieval.md) 中继续保留该轨的条款。待确认资料的管理、采纳、否决与删除不变；若以后开放新的生成入口，须另行明确合同，不能把未确认资料当作已确认事实。
- 文本回填与向量领取结果都只用必填 `scanMore` 表达本轮扫描是否还有后续页，不同时返回调度未使用的精确剩余数。文本回填合并排队与旧分词身份，最多多探测一项，不处理探测项或额外统计全池。`retrieval.pending` 继续提供诊断计数；当前批次或游标结束与稍后新待办是不同事实，不能把 `scanMore: false` 当作全局永久完成。

## 保留与验收

不迁移、删除或改写已有业务资料。历史 `memory_candidate` 材料继续沿原快照、来源、时间、否决和删除合同读取及复验；旧 v1 冻结历史身份集合继续约束同一检索，不补造范围或恢复已删正文。BM25／向量／RRF、联系人隔离、实际输入、未知调用、持有者排空与迟到 CAS 保护保持。

测试应经过正式按需读取与检索入口，覆盖排名、独立额度、失效补位、文档容量、历史范围和删除；索引领取对照比较同一合成 SQLite 负载的逐页身份、继续信号与查询数。合成供应商、向量替身和源码审查分别报告，不能代替真实模型质量或微信端到端验收。
