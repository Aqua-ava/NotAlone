# ADR-074：当前对话自动判断并加载回复 Skill

> 状态：已采纳（2026-10-19）；用户明确要求按原设计自动判断并加载，只展示本次实际策略，不再手动选择。
> 修订范围：局部修订 ADR-010 的产品手选入口和 ADR-043 的方向探索加载路径。单版本、受控只读、联系人隔离及明确场景权限继续有效。

原方向探索仅按手动填写的场景字符串匹配策略，缺少场景时固定为无 Skill。它没有实现 ADR-010 的目录发现与按需加载体验，又将内部的 Skill 选择暴露为用户任务。

方向探索从当前 owner/contact 及明确授权范围发现精简目录。先固定本次对话和输入并建立合法任务，再让模型根据对话、主动目的、纠正及本次要求选择零或一个版本；仅选择后读取该版本正文，再执行方向探索。空目录不增加选择调用，无匹配使用通用流程。两次调用分别接受预算、超时、前台宿主和出站台账约束，不增加业务 Tool 循环。

实际选择（包括无 Skill）固定到探索任务；重试、确认及后续候选使用同一选择。来源删除、版本或目录变化、取消与输入失效持续复验。自动选择不能伪装成用户亲自指定。

回复区取消手动场景和策略选择，只显示当前结果实际使用的名称、版本或通用流程，运行前只说明会自动匹配。Skill 库管理和旧显式 API 继续供管理、历史兼容及内部版本固定使用。

模型识别沟通任务只决定受控目录内的相关性，不构成发布范围或方法权限。skill_scene 仍是用户明确声明的精确范围，不能根据对话猜测或静默写入；没有这项声明时不加载场景限定的发布方法。owner/contact 隔离、来源删除、停用政策、人工意愿确认与手动发送保持。

实现与实际验证记录见[本次规格](../../.scratch/automatic-reply-skill/spec.md)。本决定不代表真实模型语义质量或真实微信渠道已验收。
