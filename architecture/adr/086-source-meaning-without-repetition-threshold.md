# ADR-086：按来源含义采纳记忆，不设统一重复次数门槛

> 状态：已采纳（2026-10-21）。用户在逐项复审 Q02 时选择“按现在的设计来”。

早期 ADR-002 的“重复才信”容易被理解为所有事实都必须多次出现才能采纳，与当前默认直接提取和自动维护不一致。此次明确沿用现行设计：不增加统一重复次数门槛，按来源表达的含义与适用范围处理，继续执行 ADR-085 的来源核验和自动裁决规则。

- 单次明确表达的事实、长期偏好或习惯可以进入提取及采纳流程，不必等第二次出现；这不表示每句话都值得记住，也不免除结构、来源、条件、事件、版本及人工保护检查。
- 保留原话中的主体、否定、时间、条件及不确定性。一次性情绪、暂时状态和本次回复要求不能静默升级为长期偏好；缺少明确期限时不自行补出起止日期，时间处理继续按 ADR-081。
- 重复出现可以提供更多来源，但次数本身不能证明长期性、真实性或支持范围，不能把模糊暗示自动变成确定的人格、动机或长期特征。
- 例如“我昨天搬到杭州了”可以作为单次有据事件；“我一直不吃香菜”可以作为明确偏好；“今天不想聊天”和“这次回复冷淡一点”分别保留当次状态和本次要求，不推导长期性格或表达风格。示例用于说明边界，不代表真实模型验收结果。

本决定替代 ADR-002 的“重复才信”作为默认采纳机制的表述及旧现行规格中“所有事实必须重复”的宽泛解释，闭合 ADR-085 留待单独确认的 Q02。显式冻结评测和历史协议不变，不重解释旧资料，不改变来源删除和人工纠错保护。

实现依据：[默认提取提示](../../backend/src/notalone/memory_extraction/direct_adapter.py)要求提取有据事实、明确偏好并保留限定；[自动采纳](../../backend/src/notalone/memory_extraction/adoption.py)没有统一重复次数门。此次仅统一文档，不修改代码、运行配置或业务数据，不据此宣称真实模型总能正确区分长期与临时表达。
