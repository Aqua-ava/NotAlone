# ADR-107：统一记忆处理入口与安全自动恢复

> 状态：已采纳，产品行为已确认；实现规格见下文。
> 决策日期：2026-10-27
> 实现状态：统一入口、固定轮次、跨阶段衔接、暂停／继续、启动恢复、存量保守接入与旧入口退役已进入正式宿主和桌面桥；工程与隔离合成 App 验收完成，真实模型质量及私人资料迁移仍不在本轮验收范围。
> 局部修订：ADR-041 的重启不扫描旧队列及依据新资料自动重排受阻轮次的规则，以及 ADR-034／103 在记忆处理范围内仅显式恢复的限制。其他任务的恢复规则保持。

## 背景与取舍

记忆页同时展示提取、主题与画像、旧失败等任务，使同一联系人同时出现失败、完成和停止，用户还需分别恢复内部步骤。用户确认以统一的记忆处理过程管理这些工作，并选择在重启后自动恢复安全的未完成处理，减少逐任务操作。

这与 ADR-041 为限制启动触发范围而不扫描旧队列的取舍不同。新的范围控制依靠明确的处理归属、持久手动暂停、来源与授权复验、累计预算及调用回执；启动本身不提供新的资料授权。

## 已确认决定

1. 每位联系人只有一个面向用户的记忆处理入口；本人记忆按本人范围单独管理，不能混入当前联系人进度。显示与操作统一，通过一个继续／暂停入口协调内部阶段。
2. 流程覆盖已保存聊天的记忆提取、核验保存、主题整理和长期画像更新。消息同步和 Skill 学习保持各自入口与授权。
3. 本轮资料的全部阶段处理结束，才可显示整体完成。某阶段受阻时，已有记忆或画像可用作为补充说明，不能用局部完成覆盖整体受阻。
4. 符合条件的新聊天保存后自动排队，各阶段自动衔接。用户手动暂停时保留已完成结果并暂停剩余处理；新消息和 App 重启均不解除暂停，只有用户明确继续才恢复。
5. 证据不足等明确不合格候选逐条拒绝，其他合法候选继续；所有内容已按规则检查且后续阶段结束后，本轮仍可完成。明确拒绝与无法完成核验分开：协议、来源或证据合同异常不得伪装成正常拒绝以绕过检查。
6. 系统能确认可安全重试的临时故障沿有界策略自动重试，期间仍属于处理过程；耗尽重试或需要人工处理时转为受阻。未知模型调用先核对回执，不盲重发；重启、新通知或切换界面不刷新累计预算。
7. App 启动后可检查已有的、未手动暂停的未完成记忆处理。只有归属、授权、来源、版本、预算和调用回执均允许安全恢复时才自动续跑；保留原进度、成功步骤和合法回执。手动暂停、需要人工修复及尚不能安全恢复的状态继续保留。
8. 内部任务、批次和领域步骤继续作为真实执行记录，保留联系人隔离、来源删除、人工修正、租约与迟到结果保护。统一入口不合并不同单位的进度，也不改变其他业务任务或同步读取范围。
9. 每轮固定处理范围，先完成当前轮次，运行中新到的资料进入后续轮次并自动衔接；新增资料不会持续扩大当前轮次的总数，也不会冲掉已有进度。
10. 某位联系人的记忆处理受阻后，保留已完成结果；新增聊天仍可按原授权同步保存和排队，但该联系人的后续记忆更新等待阻碍解决。新消息不自动解除受阻，也不围绕同一错误不断创建新失败任务。其他联系人仍按各自授权、处理条件和预算正常推进；解决问题后从统一入口继续。
11. 主状态固定为等待处理、处理中、已完成、已暂停、处理受阻。提取记忆、整理主题、更新画像及自动重试作为处理中的阶段说明，不再逐任务并排展示主状态。
12. 主界面只展示当前阶段及可可靠统计的实际处理量；不能可靠计数时只显示阶段。聊天条数、记忆条数和步骤数分别计，不相加，也不按权重拼成整个流程的百分比。
13. 主界面只保留当前统一状态；旧的完成、停止和失败记录放入默认收起的处理历史。任务编号和技术错误码放入详情；当前受阻的主卡显示中文原因与下一步操作。内部任务记录继续保留，不能因不在主界面展示而删除真实执行证据。
14. 只根据当前有效工作及范围内的控制意图聚合状态，优先级为已暂停、处理受阻、处理中、等待处理、已完成。手动暂停优先显示，原有阻碍保留在说明中；历史失败不影响新的当前状态。
15. 受阻时显示中文原因和查看原因入口；只有具备安全恢复条件时才提供继续处理。配置或程序问题需要先修复时，明确说明待解决事项，不提供没有安全执行资格的恢复动作。操作执行时仍复验实时资格，不能仅依赖上一次页面结果。
16. 从未有可处理资料时显示等待处理，并说明暂无待处理资料；已有轮次全部完成且没有待处理资料时显示已完成。已有轮次完成而下一轮资料仍在等待时，当前整体状态按等待处理呈现。
17. 暂时无法读取状态时，显示状态暂不可用和刷新入口，先不展示未经确认的业务状态。状态读取异常不增加第六种记忆处理状态，不改写真实进度；切换范围仍须清除上一范围的展示和动作资格。

## 统一状态与呈现

| 主状态 | 含义与说明 |
| --- | --- |
| 等待处理 | 有资料尚待执行或满足处理条件；从未有可处理资料时说明暂无待处理资料。 |
| 处理中 | 当前有效轮次正在推进，提取、核验、主题、画像及有限自动重试作为阶段说明。 |
| 已完成 | 已有轮次全部阶段结束，且没有后续待处理资料。 |
| 已暂停 | 用户持续暂停该范围的记忆处理，保留结果与原有阻碍，直到明确继续。 |
| 处理受阻 | 当前工作存在不能安全继续的阻碍，保留结果并说明原因及可执行动作。 |

状态读取异常是上述业务状态之外的读取结果，不把它作为处理失败落库。统计不足时不编造进度；历史任务记录保留在默认收起的处理历史中。

## 实现与验收边界

本轮讨论形成领域术语和产品决定，已发布[统一记忆处理生命周期规格](../../.scratch/unified-memory-processing/spec.md)。正式宿主与桌面桥现已接入范围隔离、固定轮次、跨阶段衔接、手动暂停持久化、启动安全恢复、存量任务保守接纳、受阻隔离、真实计数、历史折叠与读取失败处理；内部来源、版本、预算和回执守卫保持。工程结果不替代真实模型质量或私人资料迁移验收。

验收入口已由用户确认：正式宿主的认证 HTTP、隔离数据库及真实 Worker；生产具名桥接与真实记忆页面；热更新开发 App 中的隔离合成资料桌面验收。测试替身仅用于明确的供应商或确定性时序边界；本轮实现按这三层完成合成验收，不据此宣称真实供应商语义质量、真实微信资料或发布包已通过。
