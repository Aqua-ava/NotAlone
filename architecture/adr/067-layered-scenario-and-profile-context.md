# ADR-067：场景文档与长期画像的分层加载

> 状态：已采纳的目标决定，待实现。2026-10-17 用户确认 Q1–Q10；已明确校验后自动生效、两类纠错、失败回退及范围控制，完整工程方案待整体核对。
> 局部修订：ADR-011 的普通资料不固定加载规则、ADR-028 的第一期仅由 L1 词法基线提供记忆正文的阶段边界。保留原有 L1 评分、独立预算、来源与删除校验；不新增逐条记忆的常驻标记。

当前主题目录只分组并引用记忆，长期概览仅保存无正文依赖清单，回复仍读取真实底层记忆。用户希望同时获得自动维护的主题资料与简短长期背景，并明确选择 L3 背景、L2 目录及按需正文，与 L1 动态检索组合使用。选择新增可追溯的生成资料层，代价是更多模型调用、输入容量及版本／删除管理；收益是跨条目背景可以先被组织，较长资料仍按需读取。

## 决定

1. **L2 与 L3 分别承担主题背景和精简长期背景。**L2 按持续主题记录事实、经历及时间变化；L3 归纳有依据的稳定事实、明确偏好及重要关系背景。两层只使用已采纳且来源有效的记忆及合法手动资料；待确认候选保留原未确认参考轨，不进入两层。ADR-048 的不自动开展深入性格、动机推断及不把一次性策略写成长偏好规则保持。
2. **资料 scope 始终隔离。**联系人按 `owner_id + contact_id`，本人按 `owner_id` 独立整理和读取。本人只使用合法本人记忆，不因生成画像去跨联系人查询聊天；底层本人资料原有的联系人来源依赖继续有效。
3. **关系语境开启后加载有限 L3 背景与 L2 目录。**有合法可用版本时，当前联系人和本人的简短 L3 作为系统上下文中的背景资料；L2 只先提供有界目录，正文通过独立只读工具按本次授权 scope 和版本读取。系统消息中的资料区不授予指令、Tool 或来源权限，也不改变用户当前意图。
4. **保留 L1 动态检索。**原中文词法评分、阈值和联系人／本人／未确认参考的独立预算继续使用。L2/L3 新设预算并计入完整请求容量，目录不成为过滤 L1 候选的唯一入口；本决定不启用 BM25、向量或新的语义检索。
5. **派生正文不写入现有无正文概览表。**新增生成资料对象保存明确版本及实际输入依赖，并继续追溯到底层记忆和来源；不能只以旧摘要证明新摘要。读取、生成前后与提交时均复验来源、scope、版本及删除状态，来源删除覆盖正文、旧版本、任务产物、缓存和实际回复副本。

该决定选择受预算限制的短背景预加载与长文档按需读取，承认固定背景可能与本次话题无直接关系，需要评估输入成本和对回复的影响。没有选择固定加载全部 L1 或全部场景正文，也没有取消词法基线；具体预算和质量门槛在实现规格中以评测固化。

完整流程、工程建议及整体核对点见[联合设计草案](../drafts/layered-relationship-memory.md)。本决定不授权运行真实资料整理、执行迁移或外部模型调用，也不证明端到端能力已可用。
