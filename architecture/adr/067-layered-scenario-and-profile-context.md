# ADR-067：场景文档与长期画像的分层加载

> 2026-11-17 局部修订：[ADR-191](superseded/191-reply-retrieval-contract-simplification.md)退役无正常入口的旧词法选择及待确认候选注入适配；本文 L2／L3 分层、读取预算、来源和删除合同保持。历史未确认材料仍按原资格回看，不恢复新的注入入口。

> 2026-11-14 局部替代：见 [ADR-185](superseded/185-on-demand-reply-memory-and-history-search.md)。初始 L1 预注入由按需搜索替代；L2/L3 分层与读取预算保留。

> 后续修订：[ADR-070](070-automatic-memory-maintenance.md) 将正常记忆维护改为默认逐项核验后自动处理；原评测结论不变，旧资料升级功能退役。

> 状态：已采纳的目标决定，按正式任务分步实现。2026-10-17 用户确认 Q1–Q10 并整体确认联合方案定稿；已明确校验后自动生效、两类纠错、失败回退及范围控制。
> 局部修订：ADR-011 的普通资料不固定加载规则、ADR-028 的第一期仅由 L1 词法基线提供记忆正文的阶段边界。保留原有 L1 评分、独立预算、来源与删除校验；不新增逐条记忆的常驻标记。

当前主题目录只分组并引用记忆，长期概览仅保存无正文依赖清单，回复仍读取真实底层记忆。用户希望同时获得自动维护的主题资料与简短长期背景，并明确选择 L3 背景、L2 目录及按需正文，与 L1 动态检索组合使用。选择新增可追溯的生成资料层，代价是更多模型调用、输入容量及版本／删除管理；收益是跨条目背景可以先被组织，较长资料仍按需读取。

## 决定

1. **L2 与 L3 分别承担主题背景和精简长期背景。**L2 按持续主题记录事实、经历及时间变化；L3 归纳有依据的稳定事实、明确偏好及重要关系背景。两层只使用已采纳且来源有效的记忆及合法手动资料；待确认候选保留原未确认参考轨，不进入两层。ADR-048 的不自动开展深入性格、动机推断及不把一次性策略写成长偏好规则保持。
2. **资料 scope 始终隔离。**联系人按 `owner_id + contact_id`，本人按 `owner_id` 独立整理和读取。本人只使用合法本人记忆，不因生成画像去跨联系人查询聊天；底层本人资料原有的联系人来源依赖继续有效。
3. **关系语境开启后加载有限 L3 背景与 L2 目录。**有合法可用版本时，当前联系人和本人的简短 L3 作为系统上下文中的背景资料；L2 只先提供有界目录，正文通过独立只读工具按本次授权 scope 和版本读取。系统消息中的资料区不授予指令、Tool 或来源权限，也不改变用户当前意图。
4. **保留 L1 动态检索。**原中文词法评分、阈值和联系人／本人／未确认参考的独立预算继续使用。L2/L3 新设预算并计入完整请求容量，目录不成为过滤 L1 候选的唯一入口；本决定不启用 BM25、向量或新的语义检索。
5. **派生正文不写入现有无正文概览表。**新增生成资料对象保存明确版本及实际输入依赖，并继续追溯到底层记忆和来源；不能只以旧摘要证明新摘要。读取、生成前后与提交时均复验来源、scope、版本及删除状态，来源删除覆盖正文、旧版本、任务产物、缓存和实际回复副本。

该决定选择受预算限制的短背景预加载与长文档按需读取，承认固定背景可能与本次话题无直接关系，需要评估输入成本和对回复的影响。没有选择固定加载全部 L1 或全部场景正文，也没有取消词法基线；具体预算和质量门槛在实现规格中以评测固化。

完整流程、工程方向及整体确认记录见[联合设计方案](../drafts/archive/layered-relationship-memory.md)。本决定不授权运行真实资料整理、执行迁移或外部模型调用，也不证明端到端能力已可用。

后续执行以[正式规格](../../.scratch/layered-relationship-memory/spec.md)为行为和验收入口；[11项粒度及依赖](../../.scratch/layered-relationship-memory/ticket-proposal.md)已获用户认可并逐张发布，真实执行状态见[任务索引](../../.scratch/layered-relationship-memory/planning.md)；任务状态不替代真实模型质量与自动使用资格。

2026-10-18 修订：个人 L2/L3 的有据推断边界已由 [ADR-072](072-personal-memory-insights-without-action-guidance.md) 局部替代；此前一概禁止性格/动机推断的表述保留为历史，不再约束新个人画像合同。行动指导仍排除。

## 2026-11-03 实现预算补充

回复装配恢复 L1 原词法阈值及联系人／本人独立预算；查询来自本次真实请求和近期消息，不以工作区说明模板召回。当前生产读取器不启用未确认候选；保留的候选读取接口沿 ADR-035 独立最多 3 条／300 字符。

L2 初始只给标题、提示和段落数量，目录合计最多 12 项／1,600 字符；正文限本轮冻结目录材料编号，由 `read_relationship_document` 按段读取。每轮最多成功读取 2 次，每次最多 3 个完整段落／1,800 字符。L3 每份最多 8 条完整陈述，实际加载的长期背景合计不超过 1,200 字符。超长完整条目不截半句，不以缩略正文冒充已读全文；所有内容继续计入供应商完整请求预算。

这些上限经过合成容量验证，尚不构成真实模型回复质量标定。旧已保存的无投影资料身份继续按原完整正文复验；新目录、背景与正文分别追踪实际版本、来源和输入材料。删除、纠错、取消及 Skill 降级不能把未进入实际请求的正文标成模型依据。具体结果和限制见[清理验证](../../docs/verification/audit-cleanup-20261103.md)。
