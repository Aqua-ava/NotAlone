# ADR-096：目录保存回复 Skill，数据库只管理业务状态

> 状态：已采纳（2026-10-21）。用户明确要求迁出现有五个 Skill，并采用新增、修改后自动发现及按需加载的目录工作方式。
> 后续细化：[ADR-098](098-skill-business-state-only.md)将描述、资源索引和质量警告统一放入无正文文件清单，并删除旧内容兼容结构；其余约束保持。
> 局部替代：ADR-010、ADR-019 及 Skill Library 规格中正文和资源字节存入 PostgreSQL、只能逐次选择本地包导入的约定。保留既有范围、审核、方法停用、预算、删除和人工发送要求。

此前把正文、资源和管理状态一起入库，便于事务内发布，却使查看、编辑和增加 Skill 必须依赖导入/导出。现在选择可维护、可迁移的标准目录包作为已发布内容的权威来源；数据库保存身份、版本/哈希、受控内容定位、启停、适用范围、来源依赖和运行关联；描述、警告和资源索引按 ADR-098 保存在文件清单中，不再新增已发布正文或资源字节。

经审核发布的方法标题和指令同属运行内容，以不可变版本目录的 `methods.json` 索引及独立方法文件保存，只读取本轮允许的方法；数据库只留方法身份、顺序、延续映射与政策。待审草稿、审核对照及其删除依赖仍是业务状态，不作为运行时正文的备用来源。

- 本机根目录由 `NOTALONE_SKILLS_DIR` 配置，默认 `~/.notalone/skills`；可编辑包位于 `<根>/<owner_id>/<name>/SKILL.md`，辅助资源保留 `references/`、`assets/`。按 owner 隔离，不把真实用户安装包提交到仓库。
- 用户把独立包放入自己的管理目录即为明确安装操作；管理刷新和每轮运行前自动发现新增、修改或移除。完整校验通过后注册内容版本，未变化不重复发布；不因扫描恢复停用、删除或来源失效的内容。
- 目录发现只向模型提供名称、描述和受控路径；选中后按需读取该版本正文与资源。导入大小限制与整轮模型预算沿 ADR-093，仍每轮零或一个 Skill，无脚本、网络或外部聊天发送能力。
- 发布生成隐藏的不可变文件快照，数据库事务只发布快照定位及业务元数据；在途生成固定本轮版本，目录变化使旧 revision 失效。合法历史回滚保留，不能用回滚恢复删除内容。暂存或事务失败遗留文件不能被扫描为已安装 Skill。
- 自动学习继续先形成业务草稿，经用户同输入审核和范围确认后才写正式文件；编辑带审核来源的工作副本不能自动消除其来源、扩大适用范围或绕过方法停用，无法可靠继承时拒绝运行并等待审核。
- 旧库迁移先完整落盘、核对正文和所有资源，再清空对应数据库字节；可恢复重试，迁移失败保留原数据。兼容窗口中的旧包只供迁移读取，不再产生新数据库正文。
- 删除和来源撤销同时覆盖工作副本、不可变历史、暂存、运行缓存及恢复副本。数据库先撤销资格并登记可重试文件清理，清理失败不能让目录重发现恢复内容；文件清理完成后才认定相关磁盘副本已擦除。

这是存储与发现方式的调整，不更换回复框架，不把用户放入目录的指令升级为执行权限。实现和真实本机迁移证据分别记录于[本次规格](../../.scratch/directory-reply-skills/spec.md)。

参考：[Codex 本地 Skill 发现](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills)、[Agent Skills 目录规范](https://agentskills.io/specification)。
