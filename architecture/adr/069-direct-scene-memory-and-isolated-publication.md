# ADR-069：按场景直接生成记忆与逐项发布

> 后续修订：[ADR-070](070-automatic-memory-maintenance.md) 将正常记忆维护改为默认逐项核验后自动处理；原评测结论不变，旧资料升级功能退役。

> 状态：已采纳（2026-10-18）；用户确认四层流程、多条合并及逐项隔离，工程和真实质量分开验收。

## 背景

ADR-051 的分句编译减少自由正文，但孤立前缀等协议错误会阻断整批，并不保证记忆完整性。用户明确要求参考腾讯 Agent Memory 的完整记忆生成流程，保留本产品的来源和隐私边界。

## 决定

默认 L1 改成一次模型调用按场景生成完整记忆，再逐项校验、独立来源核验和采纳。不使用 prefix 标签编译；历史显式 bounded 运行和冻结评测保留旧协议，不能混用。来源核验的单条格式错误按失败条目记录，不拖垮同次其他合法项。

相似记忆在有界召回后由模型决定新增、更新、并存或合并。多条合并正文必须重新核验，并原子写入新候选和失效旧自动版本。人工资料不自动替换；旧正文、父版本与全部来源仍可追溯，删除覆盖多父依赖。不同类别、时效或事件阶段不强行压缩成同一条。

L2 按持续主题、L3 按有据背景条目整理，逐项隔离结构、纠错及忠实度失败。同一批仍只进行一次提案和一次核验，不扩大调用预算。发布前重验输入版本；整批输出不可解析、输入变化、期限或预算不足时停止。质量资格不因工程实现自动获批。

本决策替代 ADR-051 的默认提取入口和整批标签失败策略，局部修订 ADR-024 的默认正文来源及 ADR-067 的逐项整理发布方式。联系人隔离、来源删除、人工修正及手动发送保持。

参考版本、具体 Seam、适配差异及验收见[正式规格](../../.scratch/tencent-memory-alignment/spec.md)。本轮不引入向量召回、不生成回复指令、不推断性格动机、不迁移真实记忆。

完整生成及合并的正文增加 `requires_all_sources` 生命周期标记：待确认候选和已采纳记忆均依赖全部声明来源，删除任一来源清除派生正文，不按旧 ANY 记录缩减来源后继续保留。此标记不把旧 v3 核验升级为 v4 证明，不扩大自动采纳资格；原证据合同仍按实际版本校验。
