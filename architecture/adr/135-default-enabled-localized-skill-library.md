# ADR-135：Skill 默认启用与中文场景管理

> 2026-11-03 后续局部修订：[ADR-157](157-portable-skill-directory-identity.md) 允许最新内容完整一致的物理定位自动恢复，保留默认启用来历及用户明确停用；来源失效和内容不符不能借迁移恢复。

> 状态：已采纳（2026-10-31），依据用户要求“Skill 默认全开启”、中文适配、标签筛选和单个滑动启停开关。
> 局部修订 [ADR-129](129-controlled-dsh-reply-skill-discovery.md) 的逐包明确启用要求；目录授权、技术核验、来源撤销、读取预算和人工发送边界保留。

## 决定

管理刷新及每轮回复前仍只发现宿主已配置并授权根中的合法直接子目录。新发现和既有未知启停项目在完整技术核验成功后默认启用，来历记录为 `default`，不标为用户操作或用户确认。失败项目保持不可用，来源资格失效与目录身份冲突不经扫描恢复。用户明确停用记录为 `user_action`，刷新、更新和重启均保留该决定；重新启用继续核验当前内容。

默认开启表示可被按需选择，实际使用继续遵守当前回复运行流程、版本校验和输入预算。它不授权网络下载、任意目录读取、自动学习发布、聊天资料出站或外部发送。

管理页以中文场景标题展示本套恋爱 Skill，使用已有目录的中文分类作为筛选标签；协议 `name`、目录名和已保存的包身份保持稳定。卡片之间保留清晰间距，启停合并为一个可通过键盘操作的滑动开关。默认状态由后台真实状态投影，不由页面推测。未知或核验失败状态须可辨认，连接失效或在途操作期间禁止重复操作。

正文及示例的中文适配保留原来源、许可和内容对应关系，翻译明确标注，不把译文冒充上游逐字摘录。中文呈现不更改技能作用、联系人范围和删除路径。

## 数据与验收

启停来历通过追加迁移支持 `default`，不修改已发布迁移；已有明确启停选择不覆盖。默认启用与用户停用都必须经过当前修订检查，状态稳定时不重复推进修订。

验证应覆盖未知项和新增项默认启用、停用后刷新与重开保留、无效与失效来源不可用、中文标题/标签/开关交互及真实热更新 App。模型效果、微信识别和消息发送不属于本次管理页验证。
