# ADR-051：原文分句结构提取与确定性候选编译

> 状态：默认提取入口与整批标签失败策略已由 [ADR-069](069-direct-scene-memory-and-isolated-publication.md) 替代；显式历史协议与冻结评测仍保留。以下保留 2026-10-14 的原始决定及原因。

自由生成14槽候选即使多次补提示，仍会增加不存在的日期、关系或额外计划。保留一次模型
提取，改为让模型标注由程序编号的原文分句，再编译原14槽交既有来源核验与采纳流程。
这是对ADR-026第一版提取协议的替换；ADR-033的V只降不升、ADR-036默认空放行表及
ADR-047的来源证明合同不变。新编译器不生成 semantic_basis 或自动放行依据。

程序保证原文定位、目标分句覆盖、无重复编号、依赖存在与有界、字段组合及受支持期间的
日期运算。模型不能提供自由正文、替代解释、理由、日期或任意风险文字。候选正文使用
原作者标注的引句和必要原文上下文，代价是摘要不如自由改写简练，但不会擅自扩写故事。
同一消息的未知第三人同类资料保留在一个原文记录中，不发明已解析的实体身份。

模型仍负责事实类型、重要性、资料归属与指代依赖判断；程序不能由分句覆盖证明所有
重要事实都正确保留，也不能由编号合法证明语义支持。非事实省略必须有受控类型并保存
原始标注。无法解析的时间保留null并降级，结构损坏沿既有可见失败流程处理，不静默
丢弃条目或新增修复调用。范围外的连续前缀和过深依赖当前可明确失败，不能猜测补全。

合并话题/条件前件时传播依赖、敏感性、最低置信度和未知标记。不按问答邻接自动增添来源；明确以第三人指代
开头、又无外部依赖的引句保持未知。该有界检查不能发现所有中文指代缺口，V仍须核验
完整候选。相对日期只接受受支持的完整期间，否定或未支持修饰保持未知；窗口时间
未知不能借当前墙钟推算。日期槽表示检索期间，不把期间边界写成实际事件发生时刻。

新 adapter 用于CLI、后台Worker和带优先级的服务入口；旧 adapter 保留供历史协议评测。
模型原始标注、输入分句/位置与编译结果经原可删除追踪保存；沿完整窗口原来源删除链，
不迁移业务库、不回填旧数据、不处理私人聊天，不增加模型轮次或供应商。

验证包括真实运行时、原文编译器的错误回归、同一失败返回的离线重放，以及原公开六窗
的两场固定真实调用（每场六次），不重试到通过。已知六例不等于独立泛化/维度放行或App验收。

2026-10-14续接修订：生产协议使用grounded-v2命名对象字段，每个目标分句由程序预先
建立必填字段，模型不再填写自由的数组编号。动态schema提供窗口内依赖枚举；本地编译器
独立复验精确字段集与引用，不能把schema发送成功等同于供应商强制遵守。
对于受支持的句首第三人指代，保存事实且声明已消歧时，必须提供先前非裸指代的依据；
否则模型必须明确标为未知，矛盾的“已消歧但无依据”输出整窗拒绝。不根据邻接推定身份，
不允许用后面的回答、另一个裸指代或未决前文自证。这个有界规则只检查定位结构，来源
是否真支持人物关联仍依赖语义核验，不能生成自动放行证明。v1编译器仅保留旧证据回放。
新协议以同一公开六窗另跑一场、零重试，结果另记，不覆盖前两场失败。

2026-10-17后继E2标签指导修复：按[原07的有限提示修复](../../.scratch/memory-extraction-accuracy/e2-stable-fact-guidance-spec-20261017.md)，
仅未来E2请求把既有event明确为普通事实标签，含已完成动作及没有短期期间的对话方稳定身份、职业、专业。
沿用wire名称与schema，不由程序将state提升为event；明确期间、当前知情／决策、第三方归属及否定未知边界保持。
模式专属提示由Runtime和评测合同共用，原基底与v3/v4提示字节保持；不借观察日推资料开始日，不认证永久有效。
这是旧标签指导的局部语义修订，未切换默认版本、重解释旧候选或增加来源信用；须另冻实际新提示，SDK给定标签不证明模型质量。

v2还包含有界的完成问答规则：模型把明确完成短答标成state/momentary_state时，仅在
短答为首分句、没有合并前件、显式依赖唯一先前异方首分句，并且完整问答匹配受支持动作
语法时，按已完成event编译，解释中注明程序依据。到达类还要求受支持的地点后缀；
截止时间、抽象状态（极限/崩溃边缘）、将来、否定、条件和其他超出语法的内容不据此改类。
这项有限语义规则修订了v1完全由模型决定类别的方式，但不新增事实、不猜来源、不增加
模型调用，也不替代V或提供自动采纳证明；不能泛称中文完成语义解析。

2026-10-17后继E2字段语义修复：仅命名v2入口显式启用私有编译策略，复用实际分句、成员和
依赖；完整condition／prefix＋plan产生式增加“的话”“你要是”及外层时间条件的有限许可，
不修改模型原标签或补来源。已有相容字段仅按完整来源降低确定性，日历单独计算指定星期、
同周范围、完整下月和明确钟点；否定只在已完整解析的条件／主句节点内解释作用域。
原观察state／临时request日期保持，UNKNOWN只清本片完整接管且有具体不可靠见证的旧period；
期间未明风险在最终期间后派生，其他风险、采纳门和原完成／指代guard不变。原模型draft与
最终编译结果仍沿既有追踪保存，不新增调用或proof。v1／v3／v4及旧封存保持；这是原07允许
范围的后继实现修复，离线编译与SDK控制不代表真实模型质量或全部公开缺口已经解决。
