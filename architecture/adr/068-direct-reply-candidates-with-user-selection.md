# ADR-068：生成候选后由用户选择，不追加模型复核

> 状态：已采纳。2026-10-18 用户选择检索后直接生成候选，由本人选择、编辑和发送。
> 修订范围：替代主线收敛记录中的生成后模型复核；ADR-009／012 的确定性输出检查及 ADR-067 的分层资料加载边界继续有效。

生产曾在生成后追加一次模型复核，检查意图、事实、承诺等语义；最近有限诊断中，复核输出的 JSON、字符覆盖和来源路径频繁不合法，使检查环节阻止候选展示。用户选择取消这次模型调用，由自己判断候选表达，减少等待与误拒。复核失败记录保留，不能改写为真实回复质量通过。

候选回复生产入口不再装配 `ReplyConstraintReview`。草稿改写、回应消息、主动联系、继续生成与恢复均沿同一装配；检索及按需只读 Tool 循环之后，直接将通过结构、引用和当前来源检查的候选保存并展示。资料和 Skill 仍为生成提供背景与表达约束，当前用户意图优先，最终消息始终由用户手动发送。

保留联系人隔离、模型前后来源与版本复验、输出结构及引用 ID 检查、删除与取消后的迟到结果拒绝、预算、超时和真实出站台账。生成过程可能为读取资料调用模型多轮，取消的是生成结束后的独立语义复核，不承诺任何生成都只有一次调用。

记忆入库及 L2/L3 整理的核验、离线质量评测与自动使用资格保持原边界。新回复合同明确 `post_generation_review=disabled` 并包含生产接线身份，旧流程资格不得自动复用；候选不新增“语义已核验”或“保证正确”状态。旧复核实现仅供显式离线诊断与历史证据重放，产品入口不提供重新开启开关。本次不迁移或删除既有资料、不新增真实模型调用。
