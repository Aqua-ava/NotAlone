# ADR-054：前台采集上下文变化后的可靠绑定恢复

> 状态：已采纳；修复版实机仍待验证
> 决策日期：2026-10-15
> 局部修订：ADR-050／052／053 对所有失败一律保持人工确认门的规则；联系人质量、唯一绑定及其余人工门保持。

正式包缩放实测取得`minimal_region_layout_changed`，新鲜高质量读名恢复后仍被旧人工门阻断。用户明确选择窗口变化后的可靠绑定自动恢复；低分、重名和匹配失败仍要求选择。当前变化帧继续拒绝并撤销生成资格，旧资料与草稿保留；只有新的完整、高置信度、唯一且已确认的有效绑定观察才能重新授予资格，不复用变化前的姓名或资格。

仅将三个明确采集上下文错误视作可恢复：`automatic_capture_context_changed`、`automatic_capture_window_metadata_changed`、`automatic_capture_dimensions_changed`。新版顶部观察的采图后／OCR后上下文检查统一使用第一个错误，不增加采集。旧`minimal_region_layout_changed`还可能包含旧裁剪诊断的名称复读不一致，含义不足以证明只是窗口变化，继续进入人工门；不根据这个旧码盲目放行。保持原四／八秒技术退避及单轮在途；首次、改名、重名、低分、不完整、未知布局、权限／超时／传输等其他失败照旧进入人工门。若人工门已由其他原因开启，后续窗口变化绝不能将它清除。

代价是仅窗口变化后不再逐次要求用户确认，但下一轮仍须独立取得完整身份资格。助手如实显示等待重新识别，恢复时只跟随新观察指向的已有绑定；解绑、删除、代际、范围变化和晚结果保护保持。无需新增权限、帧数、持久化或外部连接；原失败场次保留，合成回归不替代修复包实机验收。
