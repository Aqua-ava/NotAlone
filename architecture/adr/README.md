# 架构决策目录

仅在查找具体决策、核验来源或复审取舍时使用本目录。当前开发先从[架构阅读入口](../README.md)定位现行规格；这里的标题与编号不表示全部条款仍有效，也不证明实现或验收完成。

阅读 ADR 时先看顶部替代范围，再读取与任务有关的条款。部分替代的 ADR 保留原路径及历史正文，仍有效的约束由现行规格承接。

同号 ADR-074 有两份，引用时附标题与完整链接，不能只凭编号判断。
