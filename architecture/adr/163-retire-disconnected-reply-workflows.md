# ADR-163：退役未接入 SQLite 的旧回复流程

状态：已采纳（2026-11-03）；用户授权清理审查发现。实现与验收状态分别记录。

## 背景

ADR-079 保留旧三类输入和方向探索合同供历史与内部兼容使用。SQLite 产品入口现已使用助手讨论和候选接口，旧探索、确认方向后生成、旧会话连续修改的客户端没有对应的正常后端路由；新界面也不再调用这些入口。继续保存其 IPC、状态机和专属测试，会让维护者误以为仍存在另一条可用产品链路。

## 决定

- 局部替代 ADR-079 中继续维护旧探索与旧连续修改运行入口的兼容条款。删除仅服务这些入口的桌面 IPC、preload 方法、客户端、界面、状态及专属测试。
- 当前 SQLite 助手讨论、候选生成与编辑、用户明确续用讨论、新开讨论、联系人隔离、草稿恢复、任务停止、来源失效与删除仍沿现有合同。旧协议的“连续修改”不等同于当前讨论的明确续用。
- 不通过本次代码清理删除、迁移或重写已保存业务资料。仍被正常路径使用的读取兼容、失效处理和恢复设施继续保留；不能因为同处旧控制器就整文件删除。
- 删除无生产引用的历史记忆处理面板、仅测试挂载的后台任务面板，以及未被当前 SQLite 调度接入的旧提取流水线与专属自测。实际历史处理、后台任务和 SQLite 调度能力保持。

## 取舍

选择一个有实际后端支持的产品流程，放弃在当前桌面端保留已断开的旧协议。需要研究历史实现时使用 Git 固定版本；历史测试通过不能作为当前产品能力证据。该决定不改变来源、删除、模型预算或用户亲自发送的边界。

实现及合成验证见[2026-11-03 清理记录](../../docs/verification/audit-cleanup-20261103.md)，实际桌面与全量测试的限制分别说明。
