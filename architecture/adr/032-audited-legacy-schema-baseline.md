# ADR-032：审计基线与实际迁移账本分开

> 状态：已采纳
> 决策日期：2026-10-01

用户批准对没有迁移账本、结构接近 035 的本机旧库进行受控接管。结构相近不能证明历史 SQL 连续执行，重放 003/021 等转换又可能破坏资料，因此接管保存独立的审计基线：固定前缀文件摘要、现存结构与全 owner 来源契约核验、实际约束补齐摘要，以及受限备份恢复凭证；不补写历史成功记录。唯一支持的差异是经审计的旧来源类型约束，其他差异拒绝。

后续受管迁移验证该前缀不可变，实际账本只从 036 起保存真实执行记录；接管补齐与基线、后续每个 SQL 与其记录分别原子提交。该基线只描述接管时的结构和资料契约，不证明过去的数据完整性，不改变用户确认的身份、同步范围、暂停或人工发送边界。操作说明和真实验收以 [数据库迁移说明](../../database/README.md)及任务记录为准。
