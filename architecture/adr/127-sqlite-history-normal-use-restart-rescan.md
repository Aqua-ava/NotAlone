# ADR-127：SQLite 私聊历史正常重启后从头重扫

状态：已采纳；原生历史／增量、App 持久化和重启去重已实机验证；正式运行后的新增来信验收待完成。日期：2026-10-30。

仅当微信账号、数据库文件及来源分片／表实例身份都经明确能力报告 `continuity='same-source-instances-normal-use-v1'` 核验为完全一致时，应用正常重启才可恢复读取；每次恢复都从当前固定来源完整重扫，不沿用重启前的不透明游标，并以已认证本地身份幂等对齐消息。历史删除或排除对应的本地出现键必须在重扫中继续受抑制；检测到任何身份或来源变化、报告缺项或无法核验时，持久停止读取。用户接受无法识别保留相同账号、文件和表实例标识的原地回滚，因此该情形不在连续性保证内；此限制不构成恢复证明，原生路径已实机验证但 App 集成验收仍在进行。

来源目录身份不包含随 SQLite 旁车增减变化的条目计数。目录写事件仅触发选定数据库名单及实例复核；等待被系统信号中断时重试，不将 `EINTR` 当作来源变化。两个核验之间瞬时出现后消失且未被读取的新路径，不构成可观测的恢复证明。
