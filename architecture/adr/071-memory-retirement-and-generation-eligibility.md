# ADR-071：区分错误纠正与状态变化的历史生成资格

> 后续局部替代（2026-10-20）：[ADR-082](082-retire-explicit-style-samples.md)取消主动收藏表达样本及其使用、独立留存和关联生命周期要求；下文涉及样本的内容仅保留为历史。其他决定及原验收范围不因此改变。

> 状态：已采纳。2026-10-18 用户明确确认；实现与验收见[任务](../../.scratch/memory-history-eligibility/issues/01-history-generation-eligibility.md)。
> 后续修订：2026-10-20 的 [ADR-080](080-unified-memory-list-and-retired-exclusion.md) 取消状态变化旧版的生成例外；全部失效记忆只供查看。下文保留原决策经过。
> 局部修订：ADR-048 及现行规格中“修正后旧版可作历史参考”的宽泛许可；ADR-028 的当前事实检索继续保持，明确变化的历史例外须额外满足本决定。

`invalidated` 只说明旧版退出当前资料，不能证明它过去正确。此前错误纠正与状态变化共用旧版失效状态，导致历史导航、旧候选及派生资料可能再次把错误作为背景传给模型。

保留版本链，增加明确的退役原因。用户的“纠正错误”记录为 `error_correction`，“记录变化”记录为 `state_changed`；历史存量和无法确定原因的自动失效记录为 `unknown`。只有明确的状态变化、来源仍合法且按历史标注读取的旧版可以进入生成。错误与未知旧版仅供用户审计，不能用于事实、历史背景或表达参考。修改记录时间与事实变化时间分别表达，不以当前时间补造过去有效期。

资格检查覆盖初始检索、补查、概览、L2/L3、助手讨论、续写、恢复和表达样本，并在生成前后及写入时复验。既有候选保持可回看，显示错误或未知依据已禁用，要求重新生成；不会借候选正文重新携入错误。纠错防重复提取与真实删除的清理规则保持，原始聊天不因记忆纠错被静默删除。

选择先禁用原因不明的历史，会减少历史召回，但避免把旧错误包装成“过去的事实”。以后如需恢复，须有明确分类与依据，不能自动根据版本链推断。本决定不授权读取、修改业务数据库或真实模型调用。
