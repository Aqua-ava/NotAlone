# ADR-188：想法、语气和要求统一为主输入

状态：已采纳（2026-11-14）。实现与验收分别核验。

用户指出语气和具体要求都能直接写在“有什么想说的”主输入中，独立设置重复并增加填写负担，明确要求删除界面及相关无用代码。

主输入统一承载想法、方向、草稿、语气和一次性要求。保留“帮我表达”和“帮我想想”两个动作及空输入建议；模型须区分表达意图与写作约束，不能把“简短一点”等要求当成待发送正文，也不能将其自动变成长久偏好或联系人事实。

本决定局部替代 [ADR-079](079-unified-expression-workspace.md) 的独立本次设置，以及 [ADR-187](187-retire-workspace-recent-chat.md) 中保留语气和本次要求的条款。清理两套界面、专用状态与样式、语气枚举、设置校验、专用提示拼接和新请求中的 `tone`／`instruction` 字段；新请求拒绝已退役字段，避免静默忽略用户要求。请求指纹仍冻结实际输入，重试不得改用后来编辑的主输入。

已保存的原输入、要求和候选依据按原快照只读回看，必要的历史读取分类不因入口移除而删除。本次不迁移或删除业务资料，不扩大聊天读取、外部模型、长期采纳或发送授权；联系人隔离、来源复验、删除、输入预算和用户亲自发送继续适用。
