# ADR-144：保留旧资料的来源重新认证

状态：已采纳（2026-11-01）；实现、自动检查及真实大范围验收已完成，证据见[来源重新认证验收](../../docs/verification/source-recertification-20261101.md)。用户明确选择保留旧资料并实现重新认证流程。

部分修订（2026-11-07）：[ADR-175](175-clean-superseded-binding-copies.md)覆盖本决定“旧消息、原始来源……保留”中**没有任何派生引用的旧消息与原始来源**这一部分——修复通过后，被取代绑定下这些副本按统一删除范围清理；被记忆、候选回复、整理条目等引用的消息及其来源、必要来源审计、终态抑制、排除项和围栏历史仍按本决定保留。本决定其余条款不变。

持久来源围栏不能进入正常续证，正式微信渠道的明确重读也尚未接入跨批次守卫；清空聊天会删除资料，却不能恢复读取。决定新增独立、明确确认的来源重新认证入口，为同一稳定账号和会话建立新的来源认证代次，不把失证前后的来源称为连续。

- 入口只作用于用户明确指定、仍在当前有效读取范围内的稳定会话。账号、绑定、来源、选择、读取开关或删除代次变化时必须重新核验；不通过昵称合并联系人，不恢复已撤销授权或删除排除项。
- 当前来源必须通过正式支持档、准确账号和会话身份、分片及表实例核验，并由正常 snapshot guard 持续保护完整遍历。新资料在完整验证完成前不对检索、记忆或生成开放；启用必须原子完成，失败或中断保持停读。
- 独立认证允许旧已认证清单是当前受支持完整目标的精确子集：物理来源代次相同，旧明确记录的检查文件集合与当前完全相同，旧分片及表实例全部保留。仅在没有清空边界、来源删除排除或全局删除围栏，且旧终态能够精确保护时适用；旧检查文件清单缺失仍仅允许完全相同的目标。预检目标与实际认证目标必须精确一致，从空游标完整遍历；不拼接目标，也不放宽普通续证的 `partitionGrowth` 或旧检查点交接要求。
- 旧消息、原始来源、记忆、助手结果及必要来源审计保留。旧失证来源及实际依赖它的派生结果保持不可用，不用新捕获替换旧执行证据。新认证资料具有独立身份，不能借相同本地键或服务端别名静默接回旧资料。
- 来源删除排除、清空边界、撤回和消失终态抑制继续生效。删除某条来源时，同一可信账号、联系人、会话及物理出现的跨认证代次副本与派生结果必须一并清理；删除计划冻结后不依赖种子仍存在。不同物理出现不通过正文、时间或服务端别名猜测等同。未能可靠映射这些保护时不恢复读取；恢复过程不触发历史记忆初始化、关系资料整理或媒体提取。
- 保存认证操作、旧围栏和新资格的无正文审计，以及认证失败的具体阶段、时间和原因。响应丢失后只读操作状态；同一请求键幂等，不重复建立认证代次。无法确认守卫失证或释放已持久化时，先关闭存储使资料失能，再排空渠道。
- 提交只完成持久接纳并短时返回，完整读取归应用内后台操作生命周期管理；状态查询按原请求键精确定位，不启动渠道。精确取消必须处理早于接纳到达的意图，不能误停其他请求；页面切换停止本页面发起的认证，读取总开关、退出、撤销和删除继续停读。守卫关闭及收尾确认之前仍为处理中且保留围栏，最终原子启用后才公开稳定的完成状态，不能先报告完成再因本次清理翻成失败。

本决定补充 ADR-113 的独立恢复能力，保留其实际来源、不可改写证据和联系人隔离合同；ADR-127／133 的正常续证不因此放宽。ADR-130 仍只处理账号来源重新关联，不授予正文读取资格；本入口另行验证当前已有授权。直接删除围栏、清空资料解锁或在缺证时自动恢复均未采纳。

旧、新正式读取器对所选物理来源使用不同代次标识时，另按 [ADR-161](161-proved-legacy-source-suppression-mapping.md)验证有界抑制映射及跨代次删除闭包；不放宽本决定的普通来源认证规则。
