# ADR-144：保留旧资料的来源重新认证

状态：已采纳（2026-11-01）；实现和验收尚在进行。用户明确选择保留旧资料并实现重新认证流程。

持久来源围栏不能进入正常续证，正式微信渠道的明确重读也尚未接入跨批次守卫；清空聊天会删除资料，却不能恢复读取。决定新增独立、明确确认的来源重新认证入口，为同一稳定账号和会话建立新的来源认证代次，不把失证前后的来源称为连续。

- 入口只作用于用户明确指定、仍在当前有效读取范围内的稳定会话。账号、绑定、来源、选择、读取开关或删除代次变化时必须重新核验；不通过昵称合并联系人，不恢复已撤销授权或删除排除项。
- 当前来源必须通过正式支持档、准确账号和会话身份、分片及表实例核验，并由正常 snapshot guard 持续保护完整遍历。新资料在完整验证完成前不对检索、记忆或生成开放；启用必须原子完成，失败或中断保持停读。
- 旧消息、原始来源、记忆、助手结果及必要来源审计保留。旧失证来源及实际依赖它的派生结果保持不可用，不用新捕获替换旧执行证据。新认证资料具有独立身份，不能借相同本地键或服务端别名静默接回旧资料。
- 来源删除排除、清空边界、撤回和消失终态抑制继续生效。未能可靠映射这些保护时不恢复读取；恢复过程不触发历史记忆初始化、关系资料整理或媒体提取。
- 保存认证操作、旧围栏和新资格的无正文审计，以及后续失败的具体阶段、时间和原因。响应丢失后只读操作状态；同一请求键幂等，不重复建立认证代次。

本决定补充 ADR-113 的独立恢复能力，保留其实际来源、不可改写证据和联系人隔离合同；ADR-127／133 的正常续证不因此放宽。ADR-130 仍只处理账号来源重新关联，不授予正文读取资格；本入口另行验证当前已有授权。直接删除围栏、清空资料解锁或在缺证时自动恢复均未采纳。
