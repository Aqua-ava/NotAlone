# ADR-046：维度依据绑定当前来源，第四门采用合取

> 状态：已采纳；DTO、存储与隔离迁移已通过相关验证，两轴评审待收口；生产四类依据和质量资格分别报告。
> 决策日期：2026-10-13。用户明确批准可空、带版本的候选 JSONB 与相关维度 AND 门，只批准隔离测试库迁移。
> 局部修订：ADR-036 的单键优先判定。原语用、0.7、风险、默认空放行表及逐类批准要求不变。

> 后续局部修订：[ADR-047](047-bounded-source-semantic-proof.md)已获批准，增加同一次V的有界可空提案及版本二语义依据，实施／隔离验证进行中。下文版本1实现与已验边界保留；新合同不代表真实模型质量、业务迁移或维度放行已通过。

ADR-036 只从语用与日期取一个优先键。候选可能同时依赖主体、指代、保真、媒体与转述，单键会遮蔽未获验证的其他维度；候选表也无法保存、回读和删除这些依据。原03明确要求补运行字段，用户本轮批准如下边界。

`memory_candidate.dimension_evidence` 使用可空、带版本的 JSONB；旧候选保持 NULL，表示未知，不回填、不重新提取或采纳。版本1记录同 owner/contact 的完整参与窗口、活动来源引用、消息类型和文字表示、带时区的来源时间、字符区间及摘要，另含候选共有字段摘要和三个受控语用标签的快照。既有原资料指纹和引用载荷只进入最终摘要，缺失即未知，不复制载荷、不读源文件，也不以数据库指纹一致认证外部文件真实性。片段不复制正文。持久候选没有独立语用字段，读取时只能保留既有快照，不能由正文或旧候选反推标签。

四类可空依据表达候选与来源的逐字对齐、指代提及及目标、媒体类型与已有文字／占位表示、直接说话人及被转述主体的关系。结构存在不代表语义正确；V 的通用 `supported` 不能替代唯一指代或转述依据。现有生产装配只从受控窗口、完整逐字核验和实际媒体元数据取可证明部分，指代和转述保持未知；不得以人工合成锚点的门测试宣称生产四类均可用。

第四门要求相关集合全部有当前有效依据，且每项分别在已批准放行表中。当前集合采用保守超集：固定主体、语用、保真、指代和转述，日期或近期状态加入时间；不能确认纯文字表示时加入媒体。这个5至7项集合不宣称是完整的语义相关性分类器；缺依据不能证明某维度无关。来源失效、范围不符、完整窗口或正文摘要变化、任一语用标签改变、歧义和过期均保守失败。来源重新匹配不恢复旧证明。

候选读取 API 可查看和导出无正文依据及当前来源校验状态，该状态不能表示质量认证或用户批准。自动确认前，存储事务在同联系人锁下复核活动来源和完整窗口；保存后依据丢失或变化时保留待确认，不使旧记忆失效。候选依据的来源删除清除覆盖全部窗口依赖，包含只作为上下文的来源；候选拒绝或删除清除依据，删除完成复核检查残留依据。多来源权威消息继续按既有规则保留。已采纳的confirmed／owner记忆当前仍按原source_ids删除；仅作上下文的来源失效是否还须处理相关已采纳资料，另有待评审接缝，不能声称此依赖清除已实现。

056迁移仅增加可空列和版本／范围／形状约束。旧055结构仍可读取 NULL，不能写新依据，适配器明确拒绝而不自行迁移。业务库迁移需另行批准；隔离测试库通过不代表业务升级、App界面或模型质量已验收。质量仍须按原≥15例、假事0、记错人0、一般错误≤1的正式证据达到门槛，再由用户逐类批准。默认空放行表、运维回退的既有三门语义和 E14／V4协议保持。
