# ADR-118：SQLite 场景资料与长期概览的完整发布

状态：已采纳（2026-10-30）。实施09落地；合成存储、隔离桌面与来源删除验证按任务记录，不认证真实模型语义质量或真实微信集成。

## 背景

记忆处理包含提取核验、主题资料与长期概览。如果每篇文档直接当作当前资料、逐篇更新指针，或把部分模型输出、旧概览直接当作本轮结果，会出现跨轮混合文档、依据与版本脱节、来源删除后旧正文继续生成、并发修订被静默覆盖，以及本轮只完成提取就显示整轮完成。

## 决定

- 场景文档与长期画像共用 `memory_document` / `memory_document_version`，以 `kind` 区分，身份与不可变版本分开；正文结构落在 `document_block`（段落／画像条目容器）和 `document_statement`（事实、推断、矛盾），不保存可改写的整篇 Markdown。矛盾保存左右主张、状态与文字，修订产生新文档版，不原地改写旧版。
- 每个陈述的真实依据写入 `document_basis`，指向实际 `execution_input`（`event_id` + `input_no`）；事实基础必须是已采纳且仍合法的记忆版本，旧文档只作可追溯上下文。不能用当前可用材料回填或替换旧证明。
- 发布是独立事实：`document_publication` 表示同一范围的一次成套发布，`publication_member` 保存完整成员集合（每个文档一版），不存 ID 数组、不递归补上次成员；`owner` / `contact` 的 `current_publication_id` 与 `document_revision` 在同一短事务切换。
- 文档输入基线在本任务前置记忆阶段成功后、首个文档步骤冻结输入时捕获 `accepted_memory_revision`、`accepted_document_revision`、`accepted_publication_id` 与 `document_basis_state`。不能在任务创建时提前冻结，也不能事后刷新掩盖并发。零选中记忆同样保存基线；明确不适用记录原因，缺失记录不当作完成。
- 文档步骤输入冻结到精确记忆版本、文档版本、反馈和真实来源（`step_input` 的 memory／document／publication typed 分支），运行后不追加、不重指当前版本；实际执行输入另存 `execution_input` 与 `event_source`，供删除、调用与回看反查。
- 发布前复验同范围记忆／文档修订、当前发布集合、文档依据和实际来源；成员只来自本轮固定贡献或可复验旧集合，本人混合资料按贡献联系人逐项核验资格。完整成员集合、成员摘要、发布指针和范围修订在同一短事务 CAS 提交；冲突使本轮文档结果失效，不覆盖另一轮。
- 冻结后的不兼容并发修订使本轮文档结果失效；需要新固定输入时由用户明确后续轮次重建，不自动刷新原基线或调用模型重算。已验证没有记忆变化的旧集合可用明确 `unchanged_memories` 不适用阶段重新发布同一完整集合，仍推进发布身份与范围修订，从而撤下在途旧快照。
- 只有本轮全部适用阶段结束（成功或明确不适用）且完整发布集合仍可用时，整轮才置为 completed；部分阶段失败保留合法已有资料并明确本轮未完成。页面、检索与回复消费同一次校验过的完整集合，并区分旧集合可用、处理中、冲突和待核验；来源失效后旧集合不得继续作为有效依据。
- 来源删除经05领域清单立即撤销发布资格并清理派生闭包（正文版本、段落陈述、依据、实际输入追踪及本人跨联系人依赖）；待重新核验的内容不用于生成，删除后的晚到发布因资格或代次复验失败被拒绝。记忆的时间事实（`valid_at` / `invalid_at`）在整理、发布与读取时复验：过期、损坏或待核验内容不进入模型或候选回复。
- 迁移13复用受控重建扩展既有执行结构（`processing_run` / `task` / `item` / `step` / `step_input` / `model_operation`），并新增文档、版本、依据、发布集合及范围效果占用；`document_extraction_reuse` 只登记已在真实提取核验中成功且有来源与输入证明的复用，不重发提取模型请求，也不绕过未知调用锁。迁移1–12保持不变。
- 不建立持久 FTS／向量投影或概览缓存，不以文档条数、模型返回或空集合推断完成，也不新增外部消息发送入口。

## 取舍与适用范围

完整发布集合、不可变版本和双写依据校验需要更多关系与短事务复验，但能避免逐篇热更新、跨轮混合和旧概览冒充本轮完成。本决定具体化 SQLite 统一设计的实体54–60与事务边界，保留 ADR-117 的记忆版本与来源删除合同。真实模型质量、真实微信数据、最终产品切换与原生 App 验收不由此 ADR 宣称通过；实际证据与语义质量边界见实施任务09。
