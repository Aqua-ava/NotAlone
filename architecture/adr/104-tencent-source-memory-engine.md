# ADR-104：记忆核心以腾讯 TypeScript 源码复用为主

> 状态：已采纳（2026-10-25）。用户明确允许替换或删除无用的现有记忆模块，要求优先直接复用 TencentDB-Agent-Memory 源码；工程实现和真实质量分别验收。

为减少重复实现和适配偏差，L1 提取、批量冲突裁决、L2 场景维护和 L3 增量画像以腾讯项目的适用源码为基础。固定来源为 `6a4bb55ea54834d8265ce52024d3e3c75db30d38`，将有用模块迁入仓库并保留 MIT 许可、上游路径、摘要及适配差异；产品运行不依赖开发者的上游检出目录。重复的算法或提示构建实现由同一正式入口替换，不维护可自动兜底的两套生成器。

这修订 [ADR-074（腾讯记忆）](074-tencent-reference-python-memory.md) 的“上游仅供阅读、行为对照并自行实现”限制；[ADR-102](102-dsh-typescript-backend-migration.md) 的 DSH／TS 运行方式继续有效。不启动腾讯服务、嵌入整个 MemoryCore 运行时、接入其遥测或新增独立数据库。

## 必须保留的产品适配

- 原始会话的用户和联系人都是人，不能把联系人映射成可忽略的 AI。上游的 AI／用户角色、全局 instruction、分类、输出和文件格式按 NotAlone 领域契约适配；一次性关系要求不升级为助手长期规则。
- PostgreSQL、稳定身份、`owner_id + contact_id` 隔离、原始资料和已有人工修正保持。来源核验、可撤销版本、事务、删除及提交前复验由现有确定性外壳负责，不能以来源编号合法或上游生成成功代替语义支持。
- 模型仍通过现有 DSH、provider、逐物理请求预算及台账；未知请求回执不能盲重放。L2/L3 工具仅操作同范围内存暂存视图，核验后才发布，不获得文件系统、网络或聊天发送能力。
- 上游不适用于本产品的代理工作指令、心理驱动力推测和替用户决策模板不迁入。分类、主体、时间、来源版本、场景文件格式和显式完成协议保留可核对差异。
- 真实验收继续限定用户本轮指定且唯一核验的联系人；费用按已确认范围暂豁免。合成检查、模型质量和实际桌面验收分别报告。

源码和当前切片见[复用说明](../../docs/third-party/tencent-memory-reference.md)及[来源清单](../../backend-ts/src/vendor/tencent-memory/upstream.json)。这项决定不表示旧任务失败、未知回执或真实记忆质量已经解决。
