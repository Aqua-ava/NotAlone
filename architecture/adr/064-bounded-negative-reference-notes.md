# ADR-064：E2有限负向指代说明保持未知

> 状态：已采纳的有限实施边界；本文来访与借钱问答规则尚未实现或验收。
> 决策日期：2026-10-16。局部补充ADR-051的程序固定备选说明；ADR-027允许的字段语义及只降不升边界保持。

生产默认grounded-v2只给空备选或泛称指代未明，完整作者引句仍可能遮蔽人物、裸家位置及借贷方向的具体缺口。我们选择在E2编译E14时，按[精确规格](../../.scratch/memory-extraction-accuracy/bounded-negative-reference-spec-20261016.md)的参数化完整文法及实际作者／来源／候选包装，追加固定中性notes；复用既有借用／请托缺角色分支，并有限覆盖单消息未绑定复数来访及两消息含糊借钱问答。匹配不建立身份、家归属或借贷事实，范围外不干预，原unknown／unsupported不变成positive，不生成semantic_basis或来源信用。

这一选择避免为生产E2增加歧义字段或恢复模型自由解释，代价是只能覆盖公开、封闭的完整表达，不能承诺一般中文消解。每条借贷说明完整携带其实际主引句及已引用原问，保留人物、肯定／否定与未知方向，不新增交付、债务或金额；来访说明只保留来访者及裸家位置未绑定，不认定真实发生或产权。程序不读用例ID、Gold、姓名白名单或关键词命中后补结论，不恢复未列来源。

仅E2专属hook追加alternatives，保留泛称和模型原标签、正文、来源、阶段、日期、风险、置信度及其他E14字段；V后不改候选。旧v1/v3/v4编译行为及提示／schema不变，E2 schema与默认版本保持。[ADR-058](058-controlled-ambiguity-labels.md)／[ADR-059](059-closed-unknown-kinds-and-calendar-month.md)继续是模型显式报码的离线路线，本决定的程序notes不冒称模型选择了其codes；已有V后负向防护与正向来源证明各守原合同。

先核实际纯编译及SDK红灯、参数替换／负向／已明／包装／作者／来源反控，再相关回归、类型与独立两轴审查。本地工程通过不代表模型质量；现行指代至少15窗、假事0、错人0、一般错误≤1和既有140窗实际回归仍需真验，Gold、旧失败、已封存运行及空放行表不改，不回填业务资料或复用关闭预算。
