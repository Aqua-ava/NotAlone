# ADR-184：有来源支持的记忆变化自动更新与合并

状态：已采纳（2026-11-14，用户确认修改 ADR-174 并同步实现）；采纳决定、代码实现与实际验收分别核验。

部分替代 [ADR-174](174-align-tencent-uncertainty-degrade-not-intercept.md) 第 2、4 条中的动作兼容与变化拦截限制，以及 [ADR-081](081-source-grounded-memory-time-and-conditions.md) 中将事件、条件差异一律排除在自动合并之外的限制。来源语义核验、人工保护、时间与版本、联系人隔离及删除合同继续有效。

## 背景与取舍

同一人的想法、计划和状态可以随时间变化。旧规则将 `keep` 与主张变化严格互斥，合并又要求至少两条旧记忆，并对事件／条件差异整体转为待定；有来源支持的正常演化因此可能无法自动落地。动作与变化标记不兼容，只能证明该次裁决不能直接执行，不能单凭原因码断定原始记忆冲突，也不能将模型技术问题转交用户判断。

腾讯参照实现只有 `store / skip / update / merge` 四类自动动作；同一事件的前因后果、不同阶段可以合并，新候选与一条旧记忆也可以合并。本项目采用这些处理语义，并保留自身的来源与人工保护约束。

## 决定

| 产品动作 | 处理含义 |
| --- | --- |
| `store` 新增 | 新信息可独立保存时新增，保留旧记忆。主题相关不等于同一事实，也不要求新信息与全部旧资料完全无关。 |
| `skip` 跳过 | 旧记忆已充分表达且没有新增信息时跳过，记录实际原因。 |
| `update` 更新 | 同一事实有来源支持的纠错、状态或适用条件变化时更新对应自动版本，保留旧版本与变化来历。 |
| `merge` 合并 | 将新候选与 1～8 条同范围旧记忆的互补内容或同一演化过程整理为完整叙述，最终正文另行核验。 |

- 现有内部 `add / noop` 名称及历史 `keep` 可兼容，不因此改写存量记录；新裁决按四种产品动作选择处理方式。既有相关信息可新增保存，有据变化可更新，同一事件不同阶段可合并，不能以额外动作分类代替语义判断。
- `claim_changed`、`condition_changed`、事件标注或有效期差异用于描述与复核变化，本身不构成人工确认门。自动更新或合并必须核验新旧合法来源、对应事实、原话限定及时间关系；变化确实获得支持后才写入，不能为适配动作把变化标记改成假。
- 合并保留仍成立的信息、实际时间顺序与限定。当前版本的结构字段沿用新候选已核验的信息，旧阶段与条件通过有据合并正文、精确父版本和来源保留，不能把旧字段套成新事实。未知时间保持未知，计划或取消不能被写成已发生；较新的保存时间不证明事实更新。条件变化须有后续原话支持，不能从时间流逝或 `condition_changed=true` 自动推导原禁忌已解除。
- 原始来源中的未解决矛盾、主体或关系仍无法核实、人工决定冲突继续保留待定。模型动作／关系不兼容、调用失败或证据协议异常须保留实际原因，不能冒充事实冲突、已采纳或无新增；本决定不新增无限重试，也不采用腾讯实现中“裁决失败直接全部保存”的降级。
- 自动替代只作用于冻结时确切的自动版本，人工录入、确认、修正、否决与删除保护优先。提交时同事务复验范围、来源、父版本与租约；未知回执、来源失效、暂停、删除或预算耗尽仍阻止提交。
- 自动结果标为 `auto`，保留候选、最终正文、实际参与版本和全部必要来源，支持查看、撤销与删除。规则更新不授权重读新范围或自动重新解释全部真实存量；旧策略待定结果按现行策略版本与安全恢复合同重新核验。

## 替代与保留范围

- 替代 ADR-174 第 2 条对新增／并存的过窄关系分类，以及第 4 条将正常有据变化与实际无法解决的关系问题一起转为待确认的口径。自由文本不确定性降级、低把握丢弃、同义重复留痕与原人工决定继续有效。
- 局部替代 ADR-081 的“条件改变不能参与自动更新”及“无事件／条件差异才可合并”限制；其来源时间、事件时间、有效期、未知精度、反证与删除规则继续有效。
- 未知调用恢复、图片关系核验能力、L2／L3 发布与重试预算继续按各自合同执行。本决定不宣称这些能力已补齐。

## 依据与验证边界

参照腾讯官方固定版本的[动作与时间线规则](https://github.com/TencentCloud/TencentDB-Agent-Memory/blob/42d4cde50c5a83182fced8c584f9ddb32a620615/MemoryCore/src/core/prompts/l1-dedup.ts#L34-L47)及[写入行为](https://github.com/TencentCloud/TencentDB-Agent-Memory/blob/42d4cde50c5a83182fced8c584f9ddb32a620615/MemoryCore/src/core/record/l1-writer.ts#L184-L218)。实现须分别覆盖单旧记忆合并、有据状态／条件变化、时间与限定保留、人工保护、来源删除及范围隔离；合成模型通过不代表真实语义质量或整条 App 链路已验收。
