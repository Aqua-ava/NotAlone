# ADR-063：指定任务的有限运行依据与正文来源依赖

> 状态：已采纳；指定任务接线与隔离工程验收已完成，真实模型交付和质量验收另记。决策日期：2026-10-16。
> 局部修订：[ADR-046](046-source-bound-dimension-evidence.md)、[ADR-047](047-bounded-source-semantic-proof.md)、[ADR-060](060-author-arrival-quote-representation.md)的有限作用域、正式任务接线及新记录删除语义；旧合同保留。

单消息作者到家切片不能覆盖跨消息指代、省略和多第三人，保存快照或V的通用supported也不能代签这些关系。按[已批准决定](../../.scratch/memory-accuracy-next/runtime-evidence-completion-decision-20261016.md)，采用指定任务显式启用的有限六类运行依据，而不切换全局默认或承诺通用中文证明。实施与验收边界见[实施规格](../../.scratch/memory-accuracy-next/runtime-evidence-implementation-spec-20261016.md)，字段和封闭产生式以[精确合同](../../.scratch/memory-accuracy-next/runtime-evidence-wire-contract-20261016.md)为准。

指定任务在提取步骤首次领取前持久固定模式及规则版本，恢复和重试沿同一配置，避免全局开关或worker偏好使一次任务混用合同。新模式沿既有grounded-v2和同一次V，严格配对nullable-proof-v3／proof3、SemanticBasis3与DimensionEvidence4；程序独立核完整来源、实际候选包装和逐项能力，主体、时间、转述、指代、保真分别取得依据，媒体只沿实际类型与来源链核定。范围外或唯一性不足保持UNKNOWN，明确矛盾只降不升；保存和确认前重新核对当前来源，不信任旧摘要或valid状态。旧默认、空放行表及原置信度、风险、语用和全部相关项合取门保持。

新evidence4记录将完整窗口的新鲜度与正文成立必需的规范消息分开：前者变化使依据失效，后者按持久source_dependency_mode=all构成一组合取依赖。同一规范消息的多个有效来源引用仍为替代关系；任一必需消息失去全部有效来源，须清除依赖它的正文。选择这一较严格的新记录语义，是因为只清proof仍会留下已确认资料、相关原文及回复副本中的失源内容；反过来，仅删除无关窗口背景不应误删独立成立的正文。清proof不清all，来源重新匹配也不自动恢复旧依据。

普通确认、自动采纳、手动修正版和本人资料回退均继承all与必需来源，不能靠确认或去重切断删除路径。删除须在收缩来源或清依据前收集所有状态下受影响的候选、关系记忆、本人资料及版本，以其身份传播清理回复派生副本和索引，并覆盖已使用本人资料的其他联系人回复及运行租约。独立手动录入、无关资料及仍有有效替代引用的消息保留；旧any、旧NULL及旧证据1–3沿原合同，不回填、重解释或重采纳。这增加依赖传播与兼容成本，换取新资料可追溯且删除后不留失源正文。

只新增前向迁移并在自有隔离库验证；业务库迁移与生产逐类放行仍须另行批准。正式导入至任务、依据保存和删除的工程验证、真实模型依据交付及逐维度质量门分别举证，Mock通过不替代模型质量。实现与全部验收完成前不关闭原任务，也不以本ADR的采纳状态声称功能可用。
