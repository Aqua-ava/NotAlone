# ADR-033：记忆采纳前核验来源语义支持

> 状态：已采纳
> 决策日期：2026-10-02
>
> 补充 ADR-026 第一版的单次模型语用解释，保留 ADR-024／027 的安全门槛与
> ADR-029 的恢复策略。实际实现与模型效果从任务和运行证据核验。

公开复现表明，来源 UUID 合法与确定标签并不能阻止候选正文反转原文否定；现有新旧
记忆写入裁决又不接收原消息。决定在有限提取窗口内增加一次独立、逐候选的来源语义
核验，并确定性核对其返回的证据片段。明确支持继续原有采纳门；证据不足只留 pending，
无支持拒绝，没有核验器不自动采纳。核验只降不升，不改写正文、主体、来源或有效期，
不判断现实真伪，不以第二次模型判断保证正确。

## 取舍与边界

- 继续补提示词仍缺独立反馈；只要求逐字片段又无法区分“是”与“不是”。选择模型语义
  比对加确定性来源片段校验，同时保留严格的逐命题评测，代价是延迟、成本与相关模型误判。
- 每个有可保留候选的窗口至多增加一次有界核验调用，使用现有已配置供应商与模型，
  不检索新范围、不增加工具能力；每次调用有独立无正文台账。
- 片段与核验结果只用于当前运行，不新增永久“事实已证实”状态或核验正文副本；风险与
  原来源沿现有删除路径保存。旧记忆不自动补认证或重新提取。
- 核验器不可用不推进该批水位；非法结构沿既有可见恢复流程处理。缺少注入核验器的
  内部调用只产生未核验候选，不能借兼容默认值自动写入。
- 当前输入尚无原生引用结构时，只能验证所见文本，不宣称获得了未传入的引用语境。
  私人聊天不进入本轮外部模型评测；实测只使用合成资料。
- 严格评分逐条核对全部候选，安全错误与记错人独立计数，显式展示语义标注覆盖。
  不以旧去向达标签替代语义准确率，不放宽门槛或接入维度自动放行。
