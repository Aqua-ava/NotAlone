# ADR-018：Worker 启动命令当前全局串行

> 状态：已采纳  
> 决策日期：2026-08-24

v1 的 `notalone-task-worker` 启动命令只处理指定 `owner_id + contact_id` 范围内最早的一个后台任务，并通过 PostgreSQL 会话级 advisory lock 保证当前系统同一时间只有一个命令 Worker。任务步骤仍使用联系人范围租约、自动重试和租约续期；因此未来放开不同联系人并行时，只需移除命令级全局锁，不改变任务、消息或记忆的数据隔离边界。

## 决策

1. 命令启动前先校验数据库、owner、联系人和模型配置；预检查失败不领取任务。
2. 一次命令连续执行一个任务的 `parse -> normalize -> extract_memory -> index -> verify`，中断后由下一次命令从未完成步骤继续。
3. 模型或网络暂时失败最多自动重试 3 次；成功步骤不重复执行；永久失败返回非零退出码。
4. 长时间模型调用通过 Worker 租约心跳续期，避免有效处理期间租约过期。
5. 命令输出只包含状态、步骤数量和错误分类，不输出聊天正文、模型完整输入输出或联系人标识。

## 与 ADR-015 的关系

ADR-015 保留不同联系人未来并行的任务模型；本 ADR 只规定 v1 启动命令的全局运行限制，不改变 `owner_id + contact_id` 的任务领取和数据隔离语义。
