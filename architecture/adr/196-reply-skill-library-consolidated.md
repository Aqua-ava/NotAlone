# ADR-196：回复 Skill 的发现、启用与按需加载现行合并决定

状态：已采纳（2026-11-18，现行合并）。本文把回复 Skill 的存储、发现、启用、数量与范围的一条替代／修订链收拢为一份现行决定，不新增、放宽或收紧任何产品规则；联系人隔离、来源可验证、删除路径与人工发送边界逐条承接。Skill 的包结构、限制数值、失败边界与管理界面细节以[现行 Skill Library 规格](../current/skill-library.md)为准；实现与验收状态仍以代码、测试为准。

## 决定

1. **存储与发现。** 授权目录中的只读标准包是已发布内容的权威来源；宿主配置并授权目录根，管理接口与模型均不能传入任意根目录。SQLite 保存业务状态与摘要，不复制已发布正文或资源字节，也不从旧 `.versions` 目录猜测审核或启用历史。每次读取以实际完整内容与本轮固定修订共同复验，缓存或选择事件不能代替字节与业务资格复验。
2. **启用与更新。** 技术核验成功即默认启用，用户停用优先且持久；已启用包的合法变化由应用自动发布为新修订；来源撤销、删除、停用与目录身份冲突不被扫描恢复，旧修订永不复活，迁移只能在授权根内凭历史双摘要恢复定位。
3. **范围。** 联系人可用的 Skill 集合由其所在分组绑定与全局可用包求交决定；未分组即不使用 Skill，失败即关闭。
4. **加载。** 唯一运行路径是官方 `@deepseek-ai/dsh-tool-skill` 先提供名称与简介目录，模型按需载入零个或多个修订正文，再按需读取静态资源；没有显式单包预加载，没有按场景字符串、方向确认或模型额外选择调用的旧路径。回复区只展示实际载入的 Skill。
5. **边界。** Skill 只是策略文字与静态素材，不得授予文件系统、脚本、网络、子 Agent、写入或聊天发送能力，不覆盖本次明确要求、联系人事实、来源、隔离、删除或人工发送边界；每轮上限 5 次物理模型请求与 2 份静态资源，输入预算按整轮计算且不静默裁剪；读取失败整体降级为无 Skill 流程。
6. **DSH 查证。** 本组决定沿用锁定的 DSH `0.2.1-rc.2` 官方 profile、`dsh-skill` registry 与 `dsh-tool-skill`；参考源码固定到 `687f282e8625c6b8d11ff58211a90524be2e4317`（[`tool-skill`](https://github.com/deepseek-ai/deepseek-harness/blob/687f282e8625c6b8d11ff58211a90524be2e4317/packages/skill/tool-skill/src/index.ts)），经安装的公开类型核对 `registerProvider`、`snapshot`、`get` 与 `restrict`、`guard`；不增加框架接口，不改 DSH 核心或插件树，不宣称整个制品可复现构建一致。后续再接触 DSH 须按 [DSH 源码查证流程](../../docs/agents/dsh-development.md)重新核对。

## 已失效取舍（不得当作新增要求）

- 数据库保存 Skill 正文或资源字节、隐藏不可变快照与 `manifest.json` 版本根、文件历史回滚、旧库字节迁移流程。
- 仅手动选择本地包导入、放入目录后逐包明确启用才可运行、未知包不读取正文。
- 每次回复最多使用一个 Skill、独立的单次／累计资源额度要求、方向探索中的两次调用选择流程、手动场景或策略选择。
- 显式 `selectedPackageId` 单包预加载及其配套工具可见性与追踪分支。
- 目录身份冲突一律不能经扫描恢复的绝对限制。

这些取舍的原因保留在已归档的原 ADR 中，供追溯，不再约束新实现。

## 验证与限制

本文只合并文档，未改代码、运行配置或业务数据，不新增验收。合成测试、DSH 官方接线、原生读取器、实际开发 App 与真实模型效果分别核验：原 ADR 记录的合成回归（多 Skill 同名资源不串读、修订与来源失效阻断迟到结果、整轮预算与失败降级、旧字段拒绝、既有历史读取、可迁移回归与迁移恢复回归）仍是相应行为的验收线索，但不构成真实模型质量、实际 App 或发布包验收，原生读取器仅覆盖 arm64 macOS 15。
