# ADR-176：核对来源后原地续读，不旋转绑定

状态：已采纳（2026-11-07）。用户确认“元数据一致可直接解除围栏、不全量重读”，并授权覆盖冲突旧条款。原地恢复已通过[任务 02 副本验收](../../docs/verification/sync-simplification-02-copy-replay-20261107.md)；迁移 46 已将三张旧来源表折叠为 `source_proof`，迁移及重启验收见[任务 04 记录](../../docs/verification/sync-simplification-04-copy-replay-20261107.md)；真实库恢复、存量清理及观察期另由用户执行。

重启造成的守卫失效与来源真实变化此前共用围栏，显式修复又建立新绑定并完整重读，累积重复副本。决定让绑定持续表示联系人与稳定会话的关系，来源核对独立表达读取资格；正常重启和显式处理使用同一条受控恢复流程。

## 核对与恢复

- 当前读取授权、账号键、会话键与物理来源代次必须相同。分片、物理表实例及文件身份按现行读取器合同核对；固定快照描述符变化、正常 WAL/SHM 旁车变化不构成来源变化。仅允许已有物理实例完整保留且读取器独立证明的表增长；当前读取器尚不能证明新物理文件加入，文件集合变化仍停读。精确判据及反例见[基线](../../docs/verification/sync-simplification-01-baseline-20261107.md)。
- 有效元数据基线相同的围栏可以恢复原范围，不撤销、新建绑定或读取授权，不增加认证代次、不复制旧正文。通过正常读取器逐表定点核对最多八个已存锚点；账号、会话、代次、表或文件实例不符，锚点缺失或不符均保持或建立待确认状态。
- 读取器暂不可用、微信未运行或来源暂不可核验时停读并有界重试，不把不可用错误码单独作为来源变化写入围栏；后续仍需完整元数据核对，不能接纳失败页。账号、会话、代次或物理实例明确不符仍停读待确认。
- 已接受的持久检查点优先复用；没有可用检查点时，只由本机存储生成各物理表已存最大 localId 与锚点清单，由受信任读取器签发持久恢复证明。第一页从各表水位之后读取，新表从零开始；不在业务层拼接不透明游标。页接纳前保存恢复点，硬中断后可继续。
- 核对结果、围栏解除和运行内守卫接纳在同一受控事务完成；读者、授权或删除代次在途中变化即拒绝。锚点正文仅用于本机内存比较，不另存正文，不进入普通日志或外部模型。原有有界围栏诊断继续保留。
- 持久模型为每个 `owner_id + contact_id` 一行 `source_proof`，状态仅 `ok` / `needs_confirmation`，保留账号、会话、来源代次、目标摘要与最近核对时间。迁移把已有围栏保留为待确认，只有能与当前有效绑定核对的旧范围才为 `ok`；原生快照守卫留在进程内，不再把运行租约作为跨重启读取资格。迁移不伪造最近核对时间，`checked_at` 初始为空；后续实际核对才更新。Worker 把易失守卫变更与 SQL 事务一起提交或丢弃；进程重开不会恢复守卫。

## 替代范围与保留项

本决定覆盖 ADR-144 中“已围栏不得正常续证”“重新认证必须新绑定与全量重读”“相同元数据仍不得恢复原资料资格”的条款；ADR-173 的逐位操作改用同一原地恢复，不再建立认证代次，其开发入口范围限制保留至任务 06 删除入口。ADR-175 不再由新的原地恢复登记副本清理，已有清理请求和存量离线清理继续有效。

账号、会话或来源真正变化仍需用户明确核对，不把未知来源当成连续。撤销授权、联系人/会话排除、清空边界、撤回与消失终态均不恢复；一次恢复只属于一位联系人。ADR-161 已证明的历史跨代次删除闭包及旧认证审计继续用于存量副本，不因未来停止换绑定而提前删除。派生结果与被引用旧消息保留，存量清理完成前不得删去对应账本和保护。

## 结构与删除

迁移 46 删除 `history_continuity_fence`、`history_continuity_scope`、`history_guard_lease`，不改写历史迁移的校验和。旧围栏优先保留为 `needs_confirmation`；范围缺失、身份未核验或目标形状无效也保守待确认。合法已保存资料的资格只依赖持久来源事实及现有身份、删除约束；取消读取授权停止新外部读取，不能抹掉合法本机资料。

未完成删除任务中的旧三类目标按联系人合并为精确 `source_proof` 目标，提高计划修订并重新收集；损坏或跨范围定位使整次迁移回滚。整联系人或账号删除同时清除证明与易失守卫，即使该守卫尚未对应证明行。清空、来源排除和跨代次抑制继续按原合同保留。

## 取舍

元数据和有限锚点不能证明任意位置从未被同身份改写；接受用户确认的前提，并以有界锚点拒绝可观察的不一致。缺少新恢复能力的旧读取器明确停读，不暗中回退到全量复制。结构升级后旧代码必须拒绝新库；回滚使用升级前独立备份，不能覆盖升级后的新增资料或删除决定。
