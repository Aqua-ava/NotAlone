# ADR-048：记忆演进与自动 Skill 的受控生命周期

> 状态：已采纳的目标约束，待实现；不表示代码或质量验收已经完成。
> 决策日期：2026-10-14。
> 局部修订：领域与核心流程对无有效期状态的解释、ADR-010 的 Skill 仅本地导入生命周期，以及 ADR-042 中不增加自动经验提炼的阶段范围。保留既有框架、联系人隔离、质量门槛、删除和人工发送。

用户已确认记忆与 Skill 的 8 个完整功能，并要求先形成正式规格和任务、搁置 DSH。选择让现有业务模块持有可追溯的记忆版本、概览、学习草稿、用户审核与范围政策，AI 只产生有界提案，回复运行时只读取批准后可用的策略。

## 决定与原因

1. **历史状态不等于当前事实。**保留历史来源与时间，区分当前已核实和当前未知；无结束时间不能单独证明临时状态一直成立。此项细化当前“无有效期视为长期有效”的解释，不给全部事实套统一失效天数，也不把过去正确的资料当作错误删除。
2. **更新与纠错保留人工决定。**同一旧证据上的错误含义不能通过改写重生。新依据可提出待确认结果，自动更新继续遵守 ADR-024、ADR-033、ADR-036、ADR-046、ADR-047 的门槛；默认维度放行和实际质量未因本决定改变。
3. **概览是可追溯投影。**联系人变化与本人资料可形成长期概览，底层来源和修订仍是权威；概览不等同于 ADR-011 的主题目录，不自主推断性格或动机。深入分析仍由用户明确触发，完整新增分析产品不在本规格。
4. **自动学习与用户发布分开。**授权材料可自动产生新建、更新、合并草稿；集中审核后才发布或替代不可变版本。此项扩展 ADR-010 和现行 Skill 库的“v1 只导入本地包、无 SkillDraft”，本地包的原有路径继续有效。回复 Agent、SkillsMiddleware 和学习模型均不得直接调用发布或管理接口。
5. **范围由系统建议、用户确认。**通用方法与联系人/场景相关做法分别判断，清洗身份不等于证明通用。私人审核依据与发布策略分开；当前意图优先，Skill 内容不能扩大 Tool 或读取权限。
6. **反馈作用于明确的最小对象与范围。**明确停用即时生效；普通修改先作用于当前回复，长期修订走草稿审核。方法身份与范围政策独立于正文版本，更新、合并和回滚不能绕过用户停用；无法可靠排除指定方法时在该范围回退通用回复。候选提交、继续、重试与恢复也复验相关政策，防止读取后才发生的停用被迟到结果绕过。
7. **来源删除高于复现和回滚。**自动学习产物完整继承参与资料的删除依赖，清除草稿、对照、发布策略中受影响内容和恢复副本；未授予学习产物 ADR-044 的主动样本独立留存例外。需要重建时只用仍有效材料重新提案和审核，不能把其他来源存在当成保留旧生成内容的证明。
8. **审核等待属于业务状态。**生成任务结束后草稿仍在权威库待审核；重启从业务状态恢复，批准前重验来源、范围及版本，不依赖长时间暂停的 Agent 或 checkpoint 保存用户决定。复用 ADR-007 的任务租约、步骤与幂等。

代价是增加草稿、来源依赖、范围政策和版本冲突处理；收益是自动发现经验与长期生效之间有可查看、可撤销的用户控制，且基座可以继续替换而不接管业务事实。

## 保留的阶段边界

- DSH 搁置，ADR-006/009/010 的现行回复运行时保持；本决定没有要求或完成运行时比较。
- ADR-042 的助手讨论不自动摘要、不静默截断仍有效；只扩展独立经验提案流程，不把讨论直接变成长记忆或表达样本。
- ADR-028 的生产词法检索保持。语义补充先独立评估，启用另需合格证据及决定，不能沿用既有失败实验当作放行。
- ADR-047 的旧资料不自动回填、重解释或重采纳保持。升级功能提供明确范围、差异和确认的独立流程，不授权现在执行任何业务资料升级。
- 真实资料、模型调用、业务库迁移、App 验收、远端发布和部署不由规格或任务发布自动授权。
