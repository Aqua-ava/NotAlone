# ADR-197：聊天图片取得与记忆图片输入现行合并决定

状态：已采纳（2026-11-18，现行合并）。本文把聊天图片的取得、保存、补查，以及记忆处理中图片输入的替代／修订链收拢为一份现行决定，不新增、放宽或收紧任何产品规则；联系人隔离、来源可验证、删除路径与人工发送边界逐条承接。图片状态表、补查退避与关联细节以[现行微信同步规格](../current/wechat-sync.md#图片引用与消息状态)、图文记忆规则以[现行记忆处理规格](../current/memory-processing.md)为准；实现与验收状态仍以代码、测试为准。

合并并归档的原 ADR：[137](superseded/137-original-image-authorized-sync.md)、[138](superseded/138-chat-image-original-extraction-and-placeholder.md)、[140](superseded/140-source-verified-viewable-chat-images.md)、[153](superseded/153-joint-text-image-memory-input.md)、[154](superseded/154-source-grounded-image-versions.md)、[155](superseded/155-image-variant-display-and-thumbnail-refresh.md)、[156](superseded/156-automatic-image-reconciliation.md)、[169](superseded/169-memory-uses-confirmed-non-thumbnail-images.md)、[170](superseded/170-no-thumbnail-storage-and-no-original-classification.md)、[171](superseded/171-image-pick-standard-over-high-definition.md)、[179](superseded/179-memory-image-input-normalization.md)、[180](superseded/180-memory-image-recovery-isolation-and-run-retirement.md)。正文保留为历史依据，不再单独作为现行要求。

仍作为现行决定、未并入本文的相关 ADR：[ADR-125](125-image-video-byte-decoding-and-validation.md)（单条媒体字节转换与实际解码验证）、[ADR-126](126-managed-voice-local-silk-conversion.md)（语音）、[ADR-172](172-jpeg-trailing-bytes-and-wxgf-alpha-frames.md)（JPEG 尾随字节与 WXGF 双帧透明度）、[ADR-149](149-content-rejection-is-not-failure.md)（内容拒绝不等于失败）、[ADR-162](162-local-reply-context-and-independent-model-lanes.md)（前后台独立模型车道与未知调用保护）。

## 决定

1. **取得范围。** 图片只在用户已确认、同步总开关开启且账号与来源仍有效的联系人范围内取得；只读取本机已存在资源，不驱动微信下载、不切换或点击微信、不扩大读取范围，也不因展示图片而触发 OCR、视觉理解或记忆调用。
2. **保存资格。** 同账号、同联系人、同消息及唯一资源关联核验、完整读取与实际解码通过后，保存标准图或高清图为应用受管副本，不保存缩略图，不区分原图等级，聊天不显示版本标签；文件存在而核验失败时按真实原因失败，不退缩略图掩盖；字节转换与解码细节见 [ADR-125](125-image-video-byte-decoding-and-validation.md) 与 [ADR-172](172-jpeg-trailing-bytes-and-wxgf-alpha-frames.md)。
3. **密钥与外置工具。** 仅在明确缺少图片密钥且图片已唯一关联本机资源时调用既有外置取钥工具，受时间、输出与同一账号／数据根核验限制；密钥只在后台宿主内存中复用并经独立管道传递。
4. **补查。** 未保存且本机资源尚未就绪的图片按持久退避自动补查，其他确定性失败仅在打开聊天时额外补查一次；已保存与已清除的结果不重取、不恢复；关闭同步、退出、撤权与删除即停止。
5. **展示与删除。** 同一消息泡内显示图片或占位；预览复用受管文件、资格校验与删除撤销 ACK；来源、联系人、账号删除清除受管副本、关联、隔离与追踪，受管文件身份不含系统设备号（沿 [ADR-168](168-managed-file-identity-without-device.md)）。
6. **记忆图文输入。** 记忆处理把同联系人、同窗口内的聊天文字与当前可查看的已保存图片一起带入模型，图片以规范化发送版本入模，来源引用仍指向原始受管副本；缩略图、未取图、已清除或来源失效的图片不进入模型且如实标注未就绪；记忆正文仍为文字，输入预算、暂停、未知调用保护继续适用。
7. **失败隔离。** 图片相关模型调用的传输失败、降级、单图隔离与恢复按上表 180 行执行；隔离项不计成功，不能用文字占位冒充模型已观察图片。

## 已失效取舍（不得当作新增要求）

- 只保存可证明为原图的图片，原图补提（`original_upgrade`）、原图证明门槛、`wechat-cdn-big-hd-exact-content-v4` 作为保存条件。
- 缩略图保存、缩略图 60 秒复查、`original`／`thumbnail`／`unknown` 分类与 `image_quality_evidence`、聊天版本标签。
- 标准图与高清图并存时要求内容一致、否则整条失败；文件存在却核验失败时退到缩略图。
- “每张图片只自动尝试一次”的阶段性补查规则（已由 2026-11-16 规则替代）。
- “记忆输入统一为文字”的限制；技术故障一律停止整批的图片输入处理；先强制 PNG 再缩放的附件适配。

## 验证与限制

本文只合并文档，未改代码、运行配置、业务数据或原生制品，不新增验收。原 ADR 记录的合成回归（缩略图不保存、标准图优先与重复资源记录、持久退避与重启保持、图文提取与删除闭包、规范化与降级树、隔离与重试）仍是相应行为的线索；真实微信图片取得、WXGF 取钥、真实模型对图片的理解质量、实际 App 与发布包验收仍须分别核验，不据此宣称完成。
