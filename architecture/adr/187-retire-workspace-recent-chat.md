# ADR-187：退役表达工作区最近聊天区块及专用读取链

状态：已采纳（2026-11-14）。实现与验收分别核验。

用户明确要求移除“最近聊天 · 查看／补充”整块区域及相关无用代码。工作区保留想法输入、表达／建议动作、语气和本次要求，生成自动参考获准资料，实际引用随候选展示。

本决定局部替代 [ADR-079](079-unified-expression-workspace.md) 和 [ADR-165](165-remove-message-exclusion.md) 中最近聊天查看／刷新、关系背景开关及补充聊天输入的界面要求。清理两套工作区中的区块、专属状态、样式、媒体面板，以及候选列表额外读取近期聊天的服务、存储动作和响应投影；其他入口仍使用的消息提醒、历史管理、媒体桥和生成上下文保留。

正常工作区生成仍使用空补充输入与自动关系背景。后台输入字段继续服务实际材料装配、原请求指纹、旧输入恢复和历史回看，不改写已保存请求或扩大其原输入范围。联系人隔离、授权、来源复验、删除、预算、候选依据和用户亲自发送的边界继续有效；本次无需迁移或删除业务资料。
