# ADR-072：个人主题与画像允许有据推断，排除行动指导

状态：已接受；2026-10-18 用户明确修订。参考腾讯个人记忆的主题与画像表达，在现有 Python 管线内实现，不引入腾讯运行时。人物资料可以保留有场景依据的隐含特征、动机及演变；与之对应的代价是必须区分直接事实和模型推断，不能用来源存在替代语义核验。

L2 持续主题包含基础信息、核心特征、明确偏好、隐性信号、叙事、演变和矛盾；L3 跨场景归纳基本信息、长期偏好、生活背景、兴趣、洞察和演变。条目显式标记事实、偏好、推断或矛盾；推断写明依据与不确定性，矛盾不强行合成确定结论。直接引用仍绑定有效 L1 版本，L2/旧画像只是组织上下文。

排除腾讯 L3 的沟通策略、决策逻辑及 Agent 行动指导。禁止通过换标题把“应该如何回复、安慰、替对方决策”等建议伪装成人物资料。策略 Skill 后续单独设计。当前用户意图与手动发送边界不由画像替代。

本决定局部替代 ADR-048、067、069 中对个人 L2/L3 一概禁止性格/动机推断的条款；旧决定保留为历史。来源、隔离、人工修正、递归删除、失败隔离与不把推断当事实的约束不变。旧无分类条目按历史事实展示，新合同仅在实际生成、核验和读取均贯通后算实现。

### 实际预算映射

生产个人整理每批最多覆盖 20 条新增 L1；为持续重写旧主题，单次递归来源上下文最多 120 条 L1，输入 JSON 上限 128000 字符（含来源及元数据）。单次最多 15 个主题、40 个段落；每主题正文最多 1500 字，L3 最多 16 条且正文合计 2000 字。新增覆盖与历史上下文使用不同限额；达到输入上限会明确失败或继续下批，不声称全部输入已成功整理。默认受控测试预算保持小批；以上是正式 verified_items 装配配置。
