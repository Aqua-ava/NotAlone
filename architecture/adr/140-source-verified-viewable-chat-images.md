# ADR-140：聊天图片取消原图证明门槛

> 记忆图片范围修订（2026-11-05）：[ADR-169](169-memory-uses-confirmed-non-thumbnail-images.md)规定记忆只带入确认不是缩略图的图片（原图或来源依据为标准图）；缩略图和来源未确认的图片不进入模型，聊天保存与预览规则不变。

> 自动补查修订（2026-11-03）：[ADR-156](156-automatic-image-reconciliation.md)将旧未知版本、缺副本及普通失败纳入当前有效授权范围内的持续自动补查，替代下文旧失败只补一轮及已有未知副本不自动重取的条款；已有主图／原图保留、来源复验和已清除图片不恢复的规则保持。

> 缩略图复查修订（2026-11-03）：[ADR-155](155-image-variant-display-and-thumbnail-refresh.md)允许已保存缩略图在有效同步范围内有界复查，取得合法主图后更新副本；下文“已有可查看副本不自动重新获取”不再适用于已确认缩略图。已清除图片不自动恢复及其余授权、来源和停读边界保持。

> 分类补充（2026-11-02）：[ADR-154](154-source-grounded-image-versions.md)按已核验资源来源记录原图、缩略图或未知版本并保留依据；分类不影响可查看图片的保存资格。

> 图文输入修订（2026-11-02）：[ADR-153](153-joint-text-image-memory-input.md)。图片展示不单独触发模型的边界保持；记忆任务将实际图片与聊天文字共同带入模型，不受本文当时未接入记忆的实施范围限制。

> 状态：已采纳（2026-11-01）。用户明确要求删除原图证明门槛，并人工核对了同一消息的本机 WXGF 解码预览。[实现与正常 App 验收](../../docs/verification/chat-image-content-20261101.md) 已记录。
> 局部替代：ADR-137、ADR-138 中只有原图资格成立才保存、只读取非缩略图内容，以及缺 HD 长度／大图地址或 XML MD5 不匹配即拒绝保存的条款。账号、联系人、来源、停读、受管文件及删除边界继续有效。

微信的可查看本机副本可能只有普通图地址，或采用 WXGF 转换表示，无法满足消息中另一版本的原图长度和 MD5。原图身份不等于图片是否可读；将两者合并为导入门槛会阻断合法消息图片。

已授权图片在稳定消息身份、唯一资源关联、完整读取和实际解码均通过时保存并显示。新副本不认证原图身份；质量信息不影响可查看图片的成功状态，不再提供原图升级操作。优先取得同一消息的本机图片版本；仅有合法关联缩略图时也允许保存和显示，不根据尺寸或文件名冒充原图。仍不驱动微信下载，不读取其他消息或扩大授权。

WXGF 转换在验证来源后直接执行，完整解码与大小、像素、帧数限制继续生效。传输和受管文件仍核验实际字节长度与 SHA-256；它们用于验证读取及保存完整性，不与 XML 原图 MD5／HD 长度比较。窄客户端仅接受明确声明新图片内容合同的固定组件，旧原图证明回执保留兼容读取。

旧失败按新版持久幂等键补处理一轮；已有可查看副本和已清除图片不自动重新获取。正常运行、同步总开关、当前账号、读取授权及来源守卫仍决定是否允许处理。来源或联系人删除继续清除副本、引用与派生结果。图片展示不自动进入 OCR、关系记忆或外部模型调用。
