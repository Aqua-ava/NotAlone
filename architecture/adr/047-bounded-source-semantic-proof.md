# ADR-047：同次来源核验的有界提案与版本二语义依据

> 状态：已采纳；实施与隔离验证进行中，未取得真实模型质量或维度放行资格。
> 决策日期：2026-10-13。用户明确批准D1–D3实施及隔离验证；业务库迁移、旧数据回填和任何维度自动放行不在批准范围。
> 局部修订：ADR-046的版本1单一存储合同与生产指代／转述未知状态；ADR-033的一次V、同来源、只降不升及不认证现实真伪保持。

版本1的逐字对齐和可空锚点不能证明非字面表达的完整角色、产权、受益人、阶段与条件。我们采用[完整D1–D3合同](../../.scratch/unfinished-work/goal-memory-dimension-proof-interface-decision-20261013.md)，将模型在同一次V中提出的有界字符位置，交给无I/O的服务端模块独立解析完整来源和候选。模型提案与服务端语义依据分开；未知归属保持未知，不让通用supported、模板、昵称或摘要代签关系。该合同的批准前v3冻结摘要为`55a3be6f3aa9122922d786008716b8f31f18cf02ddf4de30fe43c22d11cd9291`，相关文档历史用于追溯合同，不充当运行证据。

V保留明确的`legacy-v4`入口。新`nullable-proof-v1`入口保留原四槽及引用的必填、类型和覆盖合同，仅增加可缺或为null的proof；非法proof停止整批，不能丢弃后继续认可supported。proof只含受限规则及Unicode码点位置，不增加模型上下文、供应商、重试阶段或可信身份字段。模型原四槽评分视图和程序降级原因分别保留，程序只能降级。

服务端只在单目标、单来源、无额外上下文且完整受控作者／文字／活动来源链成立时，解析批准的参数化词元和完整产生式。来源与候选各自建立角色、原子命题及否定、距离、程度、条件、时间关系，再比较规范图；实现不读取case ID或Gold，不保存完整句许可表。第三方“她／他”的产权或受益人必须有来源全文明确指称句；无此句不能因出借施事、请托者或模板认定唯一，也不能把未知归属伪装成已证错误。范围外表达保持UNKNOWN。有限候选负向语法可以核明确的方向／角色差异、阶段改变及来源不支持的新增接受／义务／执行节点；该诊断图不能成为持久正例或新模型规则。

`dimension_evidence.version=2`保留原十键，唯一新增必填可空的`semantic_basis`。非null值按D3固定形状保存无正文的完整关系及来源／候选定位，quantity、degree、condition和time使用各自严格条目及交叉引用。未知键／版本、布尔或浮点位置、超限、断链或错kind均拒绝。保存与自动确认前从当前完整实际文本重新执行同版本规则及三锚复核；hash存在、此前valid或source_bound状态不能替代重解析。查看／导出与来源、候选删除复查继续覆盖新字段。

新增前向迁移扩展版本约束，056和历史迁移不改写。旧055只读NULL并拒新依据，056只写版本1；新约束仅在隔离测试库验证，业务库另行批准。旧NULL／版本1不回填、不重解释或重采纳。第四门继续对保守相关集合逐项核有效依据和逐类批准；版本二只增加时间相关性，不删除原固定项或媒体项，无依据时继续pending。默认放行表、语用、0.7和风险门保持。

此有限合同不能代替原指代跨消息／省略／多第三方验收、核心命题同批与留出，或每类至少15例的真实模型质量门。实施先验证同次V解析→实际producer→隔离保存／回读／导出／删除，再独立报告真实质量。只有质量达标并获用户逐类批准，才能改变放行表；本ADR不授予任何维度放行资格。
