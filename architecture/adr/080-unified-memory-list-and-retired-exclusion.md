# ADR-080：统一记忆列表与失效记忆禁用

> 后续局部替代（2026-10-20）：[ADR-082](082-retire-explicit-style-samples.md)取消主动收藏表达样本及其使用、独立留存和关联生命周期要求；下文涉及样本的内容仅保留为历史。其他决定及原验收范围不因此改变。

> 状态：已采纳。2026-10-20 用户明确要求。
> 局部替代 ADR-071 中允许 `state_changed` 旧版作为历史背景参与生成的例外，以及独立版本历史展示；保留退役原因、来源、版本链及真实删除约束。

记忆自动新增、更新和合并后，用户只需在同一列表查看记住了什么。独立的版本历史模块重复展示资料，也容易让用户误以为仍需手动管理迭代。

管理列表同时展示当前与仍有合法来源的失效记忆。失效或超过 `invalid_at` 的条目正文加中划线，明确标记“不再引用”；它们不能经历史检索、概览、L2/L3、旧候选、助手讨论、续写、恢复或表达样本重新进入生成。修改原因不再赋予任何旧版生成例外。有效条目的“可用于回复”只表示资格，实际使用哪些依据仍由每次回复的引用展示。

保留底层版本及来源，继续支持追溯和删除，不迁移或物理清除真实记忆。管理读取独立于检索资格，仍按 owner/contact 和合法来源过滤；用户已删除或来源已删除的正文不得重新展示。人工确认资料保护和自动记忆迭代机制保持。

代价是无法再把已被替换的记忆直接作为历史背景引用；用户如需使用其中事实，应核对后保存为当前有效资料。验收须分别覆盖统一列表划线、作用域隔离、来源删除和生成前后的资格检查。
