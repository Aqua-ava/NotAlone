# ADR-074：参考腾讯源码自行实现自动记忆

> 状态：已采纳（2026-10-18）；实现与验收状态按任务记录，不由本文推断。

用户明确要求参考 TencentDB-Agent-Memory 本地 e9a8293 源码，在 NotAlone 现有 Python 后端自行实现，禁止接入腾讯服务、嵌入 MemoryCore 或增加 Node sidecar。

## 修订范围

- 修订 ADR-069/070 的处理算法：L1 使用词法和本地语义混合召回，以统一候选池作批量新增、跳过、更新、合并裁决，允许跨类别和多目标；替代旧的同类别/同主题字符相似度筛选。
- L2 参考上游受限 read/write/edit 工具维护 Markdown 场景的方式；工具只改变同范围暂存文档，最终转为现有带来源版本的事务发布。
- L3 参考旧画像加变化场景的增量更新，场景无变化时跳过；后台调度和恢复由现有持久任务承担。
- 上游源码仅用于阅读和行为对照，Python 产品实现不依赖上游目录。

## 有意保留的适配差异

1. 联系人和本人身份、已授权输入及 owner/contact 隔离保持。
2. 独立来源核验、人工修正保护、可撤销版本、事务写入和来源删除保留；模型裁决失败不按上游默认新增而绕过保护。
3. L2/L3 工具无文件系统、shell、网络或消息发送权限；只访问显式提供的资料视图，文档工具本身不发布。
4. 每次模型网络请求受同一持久预算、截止时间和输入版本检查，不以一次逻辑提案掩盖多次请求。
5. 中文语义向量由固定公开模型离线计算。模型准备显式执行，运行时不下载或外发 embedding；缺模型需明确诊断。
6. 保持系统生成/auto身份，不冒充用户确认；质量验收与工程测试分开报告。

## 主分支整合边界

2026-10-19 整合时从重复的 ADR-072 调整为 ADR-074。个人主题与画像继续遵循 [ADR-072](072-personal-memory-insights-without-action-guidance.md) 的有据推断、分类及不确定性合同，前台观察继续遵循 ADR-073。工具维护不扩大资料范围或执行权限；保留个人输入和正文限额，使用既有工具流程的逐请求计费与有界调用预算。自动提取失败保留可恢复的任务与追踪，不重新制造确认待办。分支旧验收为历史证据，整合结果以本次验证另行核对。
