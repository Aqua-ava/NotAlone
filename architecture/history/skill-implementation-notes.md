## 已审核更新、合并与版本历史

更新和合并沿同一对照审核，目标须精确匹配当前版本；同次合并只处理用户明确确认且适用范围相同的集合，展示旧正文、范围、替代对象和方法延续。历史读取再次校验范围与完整发布来历，可读取仍合法的非当前／停用历史。回滚核当前版本和库修订的双重预期，原操作键不能覆盖后续决定；只切换当前版本，保留用户停用，也不恢复合并中的其他目标。canonical067只保存无正文动作及复合范围外键。

已明确本人或精确场景范围的版本可供同Owner其他已确认联系人更新；父发布在原取材联系人范围递归核验，私有祖先不因此成为其他联系人的独立目标。学习模型只见本联系人的普通材料、清洗策略及合法版本锚点，完整私密来历留在删除依赖；去身份不会自动取得广范围资格。来源排队删除后拒绝加载、预览、导出与回滚；删除事务擦除受影响正文及恢复副本，独立合法旧包仍可显式恢复为当前，但保持停用。方法政策的实际执行与祖先停用继承仍待13组合验证。

### 清理前第 115–127 行

管理接口必须执行用户权限、Owner 归属、同名规则、完整校验和原子发布。模型、Reply Runtime 和 Skill 运行适配器（当前 SkillsMiddleware，目标 DSH 适配器）均不能调用管理接口。

### 4.2 运行接口

SkillPort 是 Reply Runtime 使用的框架无关只读接口：

- catalog(scope) 返回当前 Owner、联系人范围和 skill_library_revision 下的目录元数据；
- load_version(scope, version_id) 返回一个当前可用且不可变的 Skill 正文；
- 受控资源读取能力按相同 scope、version_id 和相对路径返回 references 或允许的 assets。

每个运行接口都必须重新校验 Owner、联系人范围、启用状态、当前版本和目录修订。资源读取不能退化为任意文件读取。

SkillsMiddleware 是当前待替换的运行时 Adapter，不是 Skill Library 的领域接口。迁移后的 DSH 适配器同样只把 SkillPort 的受控视图转换为模型可见的目录和按需读取能力，领域规则保持普通 TS 模块；正常自动回复可组合零个或多个当前可用版本，每个包固定一个不可变修订，运行前和提交前逐包复验范围、来源与目录修订。

### 清理前第 133–139 行

1. 管理刷新和每轮回复前的检查自动发现授权根内的新包，登记目录名与身份；新包及既有未知项按 ADR-135 在完整核验成功后默认启用。用户无需手动添加或填写路径。
2. 默认启用或用户重新启用之前，技术校验器检查目录结构、frontmatter、名称、描述、大小、编码、路径、符号链接、资源类型和内容哈希。
3. 技术校验器检查内容是否包含越权工具、外部发送、网络下载、联系人隐私或把一次性规则写成长期偏好的指令。
4. SKILL.md 和全部辅助资源通过校验后，原子准备不可变文件快照，再由数据库事务发布目录项、内容定位、版本与文件清单哈希；数据库不新增正文或资源字节。未提交快照不进入运行目录。
5. 按 ADR-135，完整核验通过后新包及既有未知项可默认启用，来历为 default；用户操作为 user_action。质量问题可以产生警告，结构或安全失败不得发布，用户明确停用不因刷新或重启恢复。

任何文件失败都不能发布半成品。自动发现不重复登记同一目录；已启用包内的合法修改由应用自动核验形成新修订，相同内容不重复发布；停用包的自动刷新不读正文，重新启用时核验最新内容。非法、消失或带审核来源且未经再次审核的变更不可运行，不静默回退成编辑前版本。扫描保留停用与删除决定，不能把来源撤销的工作副本当作新发现的有效包恢复。

## 7. 数据与删除

Skill Library 的权威数据归属于 Owner，使用 Owner 级 revision：

| 对象 | 作用 |
| --- | --- |
| skill_library | 保存 Owner 级目录修订。 |
| reply_skill | 保存稳定名称、归属和 active / disabled / deleted 状态。当前通过来源与技术核验的全局 Skill 仅对所属 Owner 可用。 |
| reply_skill_version | 保存不可变文件版本的受控路径、版本、来源定位、内容与清单哈希，不保存已发布正文。 |
| manifest.json（文件） | 保存版本描述、质量警告和资源清单；不含正文，资源内容仍按需读取。 |
| reply_request | 按项保存实际使用的 Skill 版本、准确名称、选择原因、目录修订和使用结果。 |

目录文件是已发布 Skill 正文和资源的权威来源；SQLite 事务管理身份、范围、启停、版本／哈希、受控文件定位、审核来源依赖、使用与删除状态。待审核业务草稿与对照不因此自动发布。受管文件与数据库状态在同一删除生命周期中核验；失败时保留未完成状态并支持重试。

已发布方法的标题和指令同样属于运行内容，保存在隐藏版本目录的独立方法文件，由无正文的 `methods.json` 索引，只读取本轮允许的方法；方法身份、顺序、延续映射和停用政策保留在数据库。运行时不从待审策略或审核对照回退读取正文。

删除必须覆盖工作目录、不可变版本、暂存、资源索引、目录缓存、运行状态、Skill Tool 结果和包含旧正文的摘要；数据库撤销资格并记录可重试文件清理，完成后只保留不含正文和可恢复来源定位的最小删除凭证。
