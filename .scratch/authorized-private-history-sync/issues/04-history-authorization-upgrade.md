# 历史同步授权版本与旧授权升级

Triage: ready-for-agent
State: open
Type: task
Blocked by: 03

按 [spec](../spec.md) 与 [ADR-100](../../../architecture/adr/100-authorized-private-history-sync.md)，引入明确的“历史同步授权版本”状态，替代只靠现有同步范围推断历史读取资格。三条入口都要触发首次历史同步：新用户首连确认、仅所选会话确认、全部私聊模式下新发现的会话。老授权不能静默解释为包含历史，必须有一次明确确认。

## 验收

- [ ] 新用户首次连接确认同时授予全部私聊范围、后台同步开启与历史同步资格，并为现有私聊创建历史覆盖任务（含 ADR-095 合并授权）。
- [ ] 仅所选会话逐项授权的绑定同样创建历史覆盖任务；全部私聊模式下上线后新发现的会话首次纳入时也先读既有历史再转增量。
- [ ] 老授权在下一次进入相关设置或启动时看到一次性明确确认；拒绝不改变总开关和绑定、不创建历史任务、增量同步继续；接受后与新用户行为一致，不再出现分支。
- [ ] 重复确认、响应丢失、后端重启和并发刷新不重复创建任务、不重置检查点、不恢复已撤销或排除的会话。
- [ ] 桌面确认界面文案明确说明读取范围扩大；控制器与视图测试覆盖接受、拒绝与重复确认。
