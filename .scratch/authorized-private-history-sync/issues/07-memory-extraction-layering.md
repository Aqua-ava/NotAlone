# 关系资料处理与消息历史分层

Triage: ready-for-agent
State: open
Type: task
Blocked by: 03

按 [spec](../spec.md) 与 [ADR-100](../../../architecture/adr/100-authorized-private-history-sync.md)，历史消息入库后即可作为关系提取的合法来源，但提取是独立、异步、可恢复的派生任务，不阻塞历史同步或首次使用，也不在首次入库时无界批量执行。界面分别表达“消息历史覆盖”和“关系资料处理”。

## 验收

- [ ] 历史消息入库不等待关系提取；提取任务独立排队、限流、可恢复，积压或失败不改变消息覆盖状态。
- [ ] 历史消息作为提取来源时保留来源引用；来源删除、绑定撤销或联系人删除后，相应提取失效且不可再检索。
- [ ] 首次历史入库不触发无界批量提取；提取按现有队列约束推进。
- [ ] 界面分别显示消息历史覆盖与关系资料处理，不合并成“记忆已同步”一类状态。
- [ ] 队列、失效与界面状态的测试覆盖。
