# 单绑定会话历史同步引擎与消息覆盖状态

Triage: ready-for-agent
State: open
Type: task
Blocked by: 02

按 [spec](../spec.md) 与 [ADR-100](../../../architecture/adr/100-authorized-private-history-sync.md)，为一个已授权绑定建立首次完整历史同步：从本机可读最早点分页读到启动时固定的水位线，再无缝转入增量。覆盖状态按 `owner_id + contact_id + binding_id` 独立持久化，至少区分尚未开始、同步中、完整、不完整（含原因）。历史正文只进现有消息与来源链路，状态输出只含元数据。

## 验收

- [ ] 首次同步后该绑定本机可读历史全部可检索；重复运行不重复写入，已有 cursor、文件导入来源和重叠历史不阻断读取。
- [ ] 历史读取期间插入的新消息进入同一去重与来源链；历史追平水位且无更早页面后无缝转增量，无断档、无重复推进。
- [ ] 每页消息与检查点在同一成功边界提交；中途退出或重启从已提交检查点续读，不重复也不跳过。
- [ ] 总开关关闭、绑定撤销后停止新增读取并保留已提交检查点；读取不占用单一全局无界事务。
- [ ] 空结果、本机历史删除、缺消息表、CLI 异常输出分别形成不完整或失败状态，不能标记完整，也不能用空结果冒充完成。
- [ ] 状态接口按绑定输出覆盖状态、原因、计数与时间等元数据，不含正文；真实 PostgreSQL 与 scripted CLI 的合成集成测试通过。
