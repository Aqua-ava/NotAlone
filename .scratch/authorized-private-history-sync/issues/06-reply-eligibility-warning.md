# 回复资格与历史覆盖不完整警告

Triage: ready-for-agent
State: open
Type: task
Blocked by: 03, 05

按 [spec](../spec.md) 与 [ADR-100](../../../architecture/adr/100-authorized-private-history-sync.md)，当前联系人历史未追平时不得静默生成回复。门禁必须在后端生成入口执行，不能只靠桌面禁用按钮；明确进入“不完整”状态后允许用户基于已同步部分继续，但请求前与请求证据都要保留警告。

## 验收

- [ ] 当前联系人历史处于尚未开始或同步中时，默认阻止新候选生成。
- [ ] 覆盖状态为明确“不完整”后，用户可选择基于已同步部分继续；生成前必须展示历史覆盖不完整，界面对话与请求证据都保留该警告，不声称完整语境。
- [ ] 用户不选择继续时不生成；警告的消失只由覆盖状态变化驱动，不能靠关闭界面绕过。
- [ ] 后端生成入口执行门禁，桌面提示与禁用状态同步；绕过桌面直接调用也不能静默生成。
- [ ] 控制器、视图与接口测试覆盖阻止、明确继续与状态恢复三种路径。
