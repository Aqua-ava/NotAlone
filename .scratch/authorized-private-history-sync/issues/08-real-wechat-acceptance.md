按 [spec](../spec.md) 与 [ADR-100](../../../architecture/adr/100-authorized-private-history-sync.md)，用真实开发 App 和微信做只读验收。真实全历史规模、重启恢复和 24 个既有自定义账号会话的兼容结果必须单独记录，不能由合成测试替代；验收不向外部联系人发送消息。

## 验收

- [ ] 使用 `npm run dev` 的真实 App 与微信，仅按用户已确认的私聊范围读取；不发送任何外部消息。
- [ ] 记录真实全历史规模下首次同步的耗时、存储增量、分页推进与断点恢复结果。
- [ ] 记录退出重启、总开关关闭与绑定撤销后的停止行为及检查点恢复。
- [ ] 24 个既有自定义账号会话从失败转为可读，记录修复前后的命令输出与覆盖状态。
- [ ] 验证来源删除与联系人删除后历史不可重新检索或恢复。
- [ ] 验收结果写入本票 Comments 与 Answer，并注明未覆盖项与剩余风险。
