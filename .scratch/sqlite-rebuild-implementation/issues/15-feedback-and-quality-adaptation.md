## 交付行为

既有有限纠错保护和诊断功能改接新SQLite模型，准确关联被纠正的资料版本、适用输入窗口及来源删除路径。只在隔离测试实例执行可信固定合成案例评估，保留冻结案例、预算、运行状态、实际调用和审阅结果；不建设生产私聊评测平台。

## 验收条件

- [ ] 通过既有正常纠错入口记录针对精确记忆版本或文档版本／条目的真实反馈，严格核验用户、本人／联系人范围及目标，不把纠错扩成全局文本黑名单或新的正确事实。
- [ ] 纠错保护只对明确的固定材料窗口生效，记录真实来源、准确版本与保护修订；窗口／目标失效时复验或退役，后续模型提交复验当前保护，不无限扩大适用范围。
- [ ] 更改或撤销保护具有真实操作与幂等结果，不回拨来源代次，不解除删除排除，也不能恢复已删正文；页面可区分生效、撤销、冲突及来源失效。
- [ ] 诊断案例在执行前冻结输入和预期结果；冻结后改输入必须建立新案例身份，不能原地覆盖已执行案例或用后来的材料伪造旧结果。
- [ ] 案例、一次明确运行、单案例尝试和模型调用分别有真实身份、状态和关系；失败、unknown、未审阅与已完成区分，不以模型调用返回或分数存在冒充已评估。
- [ ] 可执行评估只接受隔离test实例内已验证的固定合成案例；调用前核验可信fixture身份、修订、摘要、核验方法及版本，并与受信登记的规范输入逐字节一致，不能信任调用方自行设置synthetic标签。
- [ ] 纯合成案例无真实业务来源；真实案例可按既有能力保存待审记录但不得作为本轮可执行评估输入，也不得按正文相似改标合成，不能自动复制生产聊天或联系人资料到诊断库。
- [ ] 真实案例及纠错窗口的完整敏感来源经05反查清理，覆盖输入正文、预期输出、尝试、实际追踪及本人跨联系人依赖；删除来源后停止使用并拒绝晚到结果，不能把诊断一概视作无敏感数据。
- [ ] 每个诊断运行固定调用次数、总token与截止预算；预留、发送、实耗及释放同账本状态一致，unknown不因超时释放预留，迟到实耗可结算但不能重新授予业务写入资格。
- [ ] 使用现有模型配置及最小合成输入，实际调用／回执与诊断attempt关联准确；重试不覆盖原调用事实，重复请求不刷新预算，未知请求不盲发，不新增模型设置或真实资料出站用途。
- [ ] 正常诊断／纠错反馈界面或既有公开状态入口能回看当前运行与案例结果、阻碍、预算耗尽和未覆盖范围；不新增生产评测平台，也不让诊断结果未经明确业务流程修改正式记忆／文档。
- [ ] 隔离正常入口覆盖可信合成正常评估、伪造标签、fixture字节改变、冻结后修改、预算耗尽及未知回执，验证拒绝时没有隐式模型发送或生产写入。
- [ ] 使用隔离敏感合成资料检验真实来源形状的删除及晚到回调：无关联系人不受影响，含其贡献的本人／纠错／case闭包全部失效，原有冻结与运行事实不被伪造为完成。

## 验证与证据

复用现有纠错保护、诊断和质量案例的最高业务入口，改接真实SQLite存储及05删除协调；运行环境与案例门禁必须真实执行，只对模型供应商及确定性时序做明确替换。先最小fixture／冻结／预算反例，再相关纠错、文档、诊断及删除模块，并观察既有界面或公开状态反馈。

依据为两份父规格及统一设计的有限反馈、固定case、真实来源、quality run／attempt、调用与预算合同。记录受信合成案例核验、实际请求数、预算结算、删除不可检索、资源收尾及未覆盖项，不提交可识别夹具、正文或凭据。真实模型质量、真实私聊评估和产品整体效果不由合成分数代签。

## 范围与执行门禁

- 本轮仅发布任务，不启动实现。`ready-for-agent`表示任务信息可供后续处理，执行仍须用户另行明确下达实现指令；本任务不授权读取私人资料、调用模型或切换／清理真实业务库。
- 适用[实施索引公共约定](../planning.md)和两份父规格；数据库实体、键、状态及事务以[唯一统一设计](../../sqlite-database-rebuild/greenfield-design.md)为准，不采用早期讨论稿的并行结构。新增敏感资料及本人跨联系人依赖均接入[05来源删除与清理](05-source-deletion-and-cleanup.md)，不能只靠隐藏或移除单条引用声称已删除。
- 后续开发只用 `pnpm run dev`，先执行 `dev:status`核验并复用实例；不得擅自打包、运行旧包、修改发布门禁、推送或创建远端分支／PR。
- App首次使用继续搁置；组件安装、新模型设置、干净机器和发布、微信迁移／恢复实验均不属于本任务。不新增模型或凭据入口，沿现有配置核验用途与最小文本出站授权。
- 合成结果与真实模型、真实微信、产品集成分别记账。当前未核验的真实账号／联系人读取范围不可读取；不发送外部消息，不把开发验证能力加入产品工具。
