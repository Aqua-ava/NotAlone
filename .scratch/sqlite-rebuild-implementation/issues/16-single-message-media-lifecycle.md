## 交付行为

用户明确选定已确认联系人下的一条图片、视频或语音消息后，通过正常业务接口和页面保存、查看提取状态或单独清除媒体；文件归应用独立管理，清除媒体保留聊天占位。此票交付真实文件登记、写入、发布和删除协调，不只建表；实际图片／视频适配器由17承接，语音适配器由18承接，未接线类型明确不可用。

数据与事务遵循[统一数据库设计](../../sqlite-database-rebuild/greenfield-design.md)的 `message_media`、`media_extraction_attempt`、`media_file` 及统一删除账本；读取和代次遵循[同步与记忆规则](../../sync-memory-behavior/spec.md)。通过明确的合成消息和类型适配器可独立验证本票，不要求真实微信先通过。

## 验收条件

- [ ] 正常接口和页面只接受明确指定的一条消息；展示待执行、进行中、有限结果、失败、中断和已清除等真实状态，不新增批量提取、打开页面自动提取或后台扫描。
- [ ] 归属完整限定 `owner_id + contact_id + message_id`；三实体按正式键、外键及状态形状落库，不给文字、身份待核验或来源失效的消息建立可执行提取资格，不依昵称、正文、时间或文件名猜归属。
- [ ] 新微信读取须App运行、当前账号／绑定／来源合法、联系人仍勾选且读取总开关开启；读取前、分段期间和发布前复验授权、读取／选择／资料／媒体代次及执行租约，失效立即停读并拒绝晚到提交。
- [ ] 媒体字节不写入消息正文或原始捕获载荷，不做ASR、OCR、媒体理解或模型调用，不上传云端；记录必要资源定位和证明时仍保留敏感资料的删除路径。
- [ ] 每条消息保存独立副本及文件身份，不跨消息或联系人共享文件、路径、硬链接或哈希唯一性；微信缓存和用户外部原文件仅作受控来源，不能直接标为已保存的应用副本。
- [ ] 文件流程先持久登记不可复用的受控定位和清理意图，排他创建后登记实际文件身份，再写入、同步及校验；类型校验通过后才在短事务内发布当前组合并登记不再需要的旧文件清理意图，不在事务内等待外部读取或转换。
- [ ] 复制完整、容器／格式有效和可查看／播放分别有证据；文件存在、字节摘要或类型适配器未完成均不能冒称全部成功。合成校验器替身须明确登记，不能作为真实类型已支持的证明。
- [ ] 只保留当前有效结果仍需的文件组合和尝试记录，不保留每次旧字节；新结果未校验或发布失败时保留仍合法旧结果，有限或未知新结果不得降低已有合法原图／可播放组合，已删除或来源失效的旧结果不适用保留例外。
- [ ] 同一请求键重送只返回同一操作及结果，不新执行；执行互斥、租约接替和过期提交经事务代次核验，不能仅因租约到期、重启或页面重开自动重提。
- [ ] 单独清除同事务推进媒体代次并登记当前、退役、暂存及在途文件目标，保留消息占位；旧请求、旧转换和晚到回调不能恢复文件，只有新的明确操作才创建新尝试。
- [ ] 单来源删除、清空聊天或删除联系人时接入05的同一删除计划，闭包覆盖提取证明中的XML／定位、原始件、派生件、暂存、退役及活动预览／播放引用；复核后才显示完成，不另建媒体删除平台，不删除微信或用户外部原件。
- [ ] 关闭读取总开关不删除仍合法的已存副本，允许查看和播放；取消联系人停止新提取和本地转换并拒绝在途发布。18的本地重转分支须明确与新微信读取资格分开。
- [ ] 空间不足停止本次新增写入并提示用户，只清理本次可安全清理的临时目标，不驱逐其他成功媒体；文件写入、发布或清理窗口故障均有可见失败和可核验恢复状态。
- [ ] 退出或崩溃后未完成提取显示中断，不自动新读微信或重提；只恢复已登记的本地清理，已有合法结果继续可用，持久请求身份不被重新解释为新执行。
- [ ] 本票含接口、页面、真实受管文件和删除流程的正常及反向测试，覆盖跨联系人、关闭开关、取消、并发清除、晚到文件、重复请求、发布失败及活动引用释放，不把基础页面或删除接入推到19。

## 验证与证据

使用隔离SQLite、受管临时目录及有明确归属和完整性证明的合成资源，通过正式业务服务、认证接口、具名桌面桥和页面验证。类型或渠道替身、正常路径差异和未覆盖范围逐项记录；先运行单场景，再运行相关模块，不重复条件未变的有效检查。

复用[媒体运行时与文件发布研究](../../../research/sqlite-ready-media-runtime.md)及[规格定稿验证记录](../../../research/wechat-spec-finalization-validation.md)的限定证据。既有原生12项、生命周期14项及其他合成结果均不是本票产品接线或真实媒体验收；完成时提供实际命令、页面结果、文件／数据库复核、失败场景和自有临时资源清理记录。
