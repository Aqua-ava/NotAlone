## 验证接口

1. HTTP：旧升级接口返回404，不读库或创建任务。
2. Worker：遗留升级步骤不领取；正式新消息记忆任务继续执行。
3. 提取与采纳：使用真实默认协议的合成模型输出，经公开流程自动写入；核验失败、人工保护不自动写入。
4. 整理：隔离数据库中新L1自动建立维护状态、派发有界任务并发布逐项通过的L2/L3；明确停用保持。
5. 来源删除：遗留升级副本和当前记忆依赖按原删除路径清理。
6. 桌面：复用npm run dev实际确认入口移除；真实服务连接与模型质量另行如实报告。
