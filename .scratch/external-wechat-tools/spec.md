# 微信工具只使用本机外置安装

用户已确认：取消 App 附带 wechat-cli／WCDB，只保留调用用户本机外置工具。

## 范围与实现决定

- 删除第三方 CLI／WCDB 的打包参数、检查与搬运入口、包内自动发现及 WCDB 环境注入。
- 删除仅为该分发路径保存的九份许可／来源材料及其复制、校验与测试代码。
- 保留后端只读 CLI 适配器、设置页面与保存路径／环境变量配置；配置优先级保持保存值优先于环境。
- 保留 NotAlone 自研 repository-probe 的构建、签名、搬运、完整性核验与包内发现；共用代码收窄为自研探针用途。
- 当前安装／打包说明同步修改；历史审计和已运行包证据保留，不能把旧验收转给新包。

## 验证边界

复用已有公开打包命令、StartupDiagnostics、loadBackendConfiguration 和 backendEnvironment 接缝：旧第三方参数在创建输出前拒绝；旧 Resources 第三方目录不再自动发现；本机外置路径和库环境保持有效；实际离线检查包只附带自研探针且 Node 启动配置正确。最小相关测试先失败再修复，并进行两轴评审。

## 排除项

不启动真实 App、第三方 CLI、自研探针、微信、模型或数据库；不删除用户本机工具、旧产物或业务资料；不恢复 WCDB 来源获取任务；不推送远端。
