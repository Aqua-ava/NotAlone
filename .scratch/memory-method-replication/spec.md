# 记忆方法复刻与配对实验

日期：2026-10-02。固定比较起点：`739304d42521d86162e204b4f8dfc11e6153bb0c`。

## 用户问题

用户要求先调研公开记忆方法，摘取可复刻的机制，再实际测试是否改善中文关系记忆的含义和准确性。现有正则评分混合了措辞、时间和候选去向，不能直接称语义准确率；现有来源核验也存在漏判与误拒。

## 解决方案

在既有 `MemoryExtractionRuntime.extract(ExtractionWindow)` seam 复刻两种有界机制，执行四臂配对实验：A 现有提取；B 叙事整理后提取；C 现有提取后来源时间精修；D 两者组合。所有路径最终使用相同的现有来源核验、语用解释和自动采纳门。实验不接生产入口、不读数据库、不处理真实聊天、不修改已有记忆。

调研技能已读取，一手资料与本地调研记录已完成；本任务规模是一张可独立验收的实验 ticket，不拆成需另行确认的多会话任务。

## Implementation Decisions

- B 复刻 EverOS／EverAlgo 的“第三人称叙事→原子事实”阶段分工。中间叙事保留原消息 ID 和逐字片段；原始消息仍是第二阶段和核验阶段的权威依据。含糊指代不猜人物；独立事项可拆分，同一主张的数量、否定、条件与期间不可拆丢。中间结果只驻内存，不是来源或永久记忆。
- C 借鉴 Graphiti 的独立时间步骤，但明确是 NotAlone 适配：输入候选及其原有引用的消息和每条消息时间；检查已有与空时间字段，只允许修改 `valid_at/invalid_at`，不改正文、主体或来源。未知粒度留空，不用运行当天或默认一月一日补日期。
- 时间结果逐候选一对一，引用真实逐字来源；明确日期需带时区、结束晚于开始。超预算、缺失、重复、越范围、伪造片段或异常输出为可见失败，不静默回退为成功。未知可留空，冲突加 `semantic:time` 风险；不放宽门槛。
- 两个额外阶段各至多一次结构化模型调用；每批最多 60 个叙事单元／候选。原模型运行时和来源核验器不改写。
- 仅使用项目已经安装的 `bind_tools/invoke` 接口，无新依赖。Context7 不可用，已查 LangChain 官方模型文档并核对当前安装版本（core 1.5.5、langchain 1.3.15、deepseek 1.1.0）。
- 模型实验只使用显式 `NOTALONE_EVALUATION_API_KEY` 与仓库内固定合成用例；CLI 不加载 `.env`、任意外部消息文件或存储。根 Agent 可在子进程中将已授权供应商配置用于合成评测，不输出或保存凭据。
- 输出为仓库外本地合成审计资料，包含首次自然输出、固定输出重放后的核验去向、失败、模型调用／用量／耗时；不得覆盖已有输出目录。记录传输成功与后续验证失败的区别，不保存模型内部思考。

## Testing Decisions

- 已授权的既有提取、来源核验和评测 seam 是测试边界；新阶段通过运行时／Flow 的公开行为测来源隔离、结构失败、时间修复与安全降级。先 red 再 green，使用合成输入及可控模型。
- 新建 24 个独立合成场景：8 个开发、16 个留出验证。冻结消息、消息时间、目标范围和中文语义 gold 后才能调用模型；留出集不得用于调提示词。两次重复，四臂按固定种子交错排序；固定相同模型／温度与核验器，保留首次失败，不按结果补抽。
- 主指标为逐场景完整语义保真：全部必需主张保留、主体和限定正确、无额外无依据主张。允许同义改写、忠实拆分与忠实合并；不能以一条正确掩盖额外错误，也不能因零候选而得满分。
- 语义 gold 明确主体、必需含义、不能丢失的限定和可允许的谨慎去向；时间单独标注 `ignore/must_null/allowed`，绝对区间按现有半开时间约定，不把观察时刻误称实际事件开始日。
- 使用隐藏臂名、模型信息、置信度和核验理由的合成输出逐项复核；生产核验器的 supported 不是评测答案。独立报告覆盖率、无支持自动采纳、时间字段错误、漏提、正确候选误拒、失败率以及调用／token／耗时。旧正则只作次要诊断，不用其百分比代替语义准确率。
- 小样本只报告原始分子分母、配对改善／回退和局限；无提升或代价过高也算有效结果，不包装成成功。
- 最后执行相关类型检查、完整 Python 测试及 Standards／Spec 双轴评审，解决发现项，自动本地中文提交。不 push。

## 方法来源与复刻区别

1. [EverOS 叙事事件与事实阶段](https://github.com/EverMind-AI/EverOS/blob/d2aa9494da062246e665a21e3f045583d81df90f/src/everos/memory/strategies/extract_atomic_facts.py)，[EverAlgo 原子事实规则](https://github.com/EverMind-AI/EverAlgo/blob/7746a87ad5604362d19588c05ee617ed6b746d93/packages/everalgo-user-memory/src/everalgo/user_memory/prompts/en/atomic_fact_from_text.py)。版本分别固定；未证明与 EverOS 锁定发行包完全对应。
2. [Graphiti 时间步骤](https://github.com/getzep/graphiti/blob/3c427640abf909f12f71f963fce15eb514a3c493/graphiti_core/utils/maintenance/edge_operations.py#L576)。上游只读事实＋参考时间且任一日期非空就跳过；本实验加入原文并复核已有字段，因此不称原样复现 Graphiti。
3. [SimpleMem](https://arxiv.org/html/2601.02553v3) 与 [Mem0](https://arxiv.org/html/2504.19413v1) 的独立命题与细节保留作为参考；不新增重复的一轮提示词臂。

提示词用中文自行重述机制，没有复制上游完整提示词或代码，不引入平台。公开论文的 LoCoMo／LongMemEval 分数属于检索后问答，不是本项目提取准确率。

## Out of Scope

生产默认切换、数据库／ADR 变更、模型供应商切换、真实聊天再提取、既有记忆批量改写、图数据库、画像预测、外部聊天发送、部署、远端分支和 PR。只有实验结果才能支持后续采纳决策。
