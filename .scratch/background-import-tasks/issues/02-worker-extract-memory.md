# 02 — Worker 执行记忆提取

**Triage:** ready-for-agent
**State:** open

**What to build:** 提供一次只执行一个可领取步骤的 Worker 入口，使导入任务能够在消息入库后异步执行 `extract_memory`。Worker 需要安全领取、更新进度、处理暂时失败，并支持在崩溃或手动重试后从未完成步骤继续。

**Blocked by:** 01 — 导入任务和固定步骤必须先存在。

- [ ] Worker 一次只领取一个有效租约步骤，统一联系人范围内不能同时执行两个任务。
- [ ] 租约过期后，另一个 Worker 可以接管未完成步骤；正常租约不能被并行接管。
- [ ] `extract_memory` 使用已有的结构化提取、证据校验、自动采纳和出站台账边界。
- [ ] 首次历史导入按有限批次处理全部来源消息；后续只处理水位之后的新增消息。
- [ ] 网络、超时或模型暂时错误最多自动重试 3 次；成功步骤不重做；失败任务可手动复用原任务重试。
- [ ] 记忆提取失败不回滚已经成功入库的消息和来源。
- [ ] Worker 输出当前步骤、处理数量、尝试次数和不含正文的错误分类。
- [ ] fake model 覆盖成功、pending、证据越界、结构错误、重试和租约接管；不调用真实模型。
