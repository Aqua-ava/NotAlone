# 05 单个批次的协议错误让整个联系人任务失败，已成功的批次也迟迟不产出记忆

Triage: needs-triage
State: open

## 现象
联系人 A 提取共 22 批。第 6 批和最后一批各因 `extraction_model_validation_failed` 使任务 `failed`、run 变为 blocked（`contact_failed`），需要用户手动点「继续」。

## 证据
- 第一次失败时已有 100 条提取并核验成功，但 memory=0、candidate=0；第二次失败时已有 420 条成功，仍为 0。裁决阶段只在全部提取完成后才开始。
- 任务只尝试 1 次，没有自动重试；错误码没有区分是模型格式问题还是业务问题（见 issue 04）。
- 每次「继续」只重跑失败批次，已成功批次保留。

## 待查
- 单批协议错误是否应有限自动重试，或只跳过该批而不让整任务失败。
- 前面批次已成功时，是否应先产出可用记忆。
