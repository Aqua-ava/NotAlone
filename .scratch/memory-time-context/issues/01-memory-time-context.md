### 交付行为

- 三类记忆统一携带来源聊天时间范围、当前版本保存时间与原有有效期。旧 PostgreSQL
  行在读取时批量核验同范围活动消息，只取直接引用日期，不改旧行，不新增迁移。
- 提取只汇总真正引用的消息；已进入窗口的未知时间安全传给模型。人工确认、自动采纳、
  修正与本人路径保留时间，各次保存有自己的保存日期。
- 检索、预载消息、历史 Tool、模型请求和依据快照完整传递时间。生成前后核验时间变化；
  历史快照按同范围依据 ID 恢复，旧快照缺字段保持未知，不用当前来源倒填。
- API 与 Swift 展示来源、保存／录入、生效／失效时间，含年份、时区、多日期范围和
  未知／不完整提示；旧客户端与旧快照兼容。

### 数据影响与限制

本轮没有改写真实资料、记忆正文、状态、采纳方法、有效期或绑定；没有重提取私人聊天，
没有调用外部模型或发送微信消息。新的提取与回复在保存时携带元数据；旧数据读取仅投影。
时间信息帮助判断事实语境，不证明事件精确日期或语义必然正确；无失效日也不证明旧状态仍成立。

生产加载器仍排除发送时间缺失的新消息。评审发现直接放入这些消息会破坏既有聊天时间
水位；改成摄入顺序又不能保证旧 UUID 水位无损迁移。已撤回临时入口改动，并在规格中
明确该既有限制。本轮支持已进入窗口的未知值与旧记忆未知来源的展示；生产摄入与持久化
进度协议另行设计，不静默重排或重跑历史。
