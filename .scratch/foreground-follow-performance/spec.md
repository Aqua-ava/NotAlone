# 高频联系人跟随与内容恢复解耦

基线：7afa5b17c81b644507f62ec937848939dbbdf53c。
用户已确认：先可靠识别人，再恢复内容；快速切换优先最后停留者；复用缓存；不因切人反复重启识别。

## 范围
- 仅优化既有开发版，不打包、不发送外部消息，不扩大授权/采图/OCR范围。
- ContactSession.scopeRevision继续保护联系人内容，不能作为全局同步及采集许可的生命周期。
- SyncControl纯展示切人保留同连接的全局状态与在途请求；按钮仍核验当前展示修订。
- Foreground可靠观察内部选择联系人不停止顶部变化源；人工选择、目录不可用、授权变更、关闭及重连仍撤销旧许可。
- 在途收到更新提示时不提交旧身份，最多合并一次串行复查；失败退避与传输结算约束保持。
- 身份先显示，内容异步恢复。复用现有草稿/编辑缓存，权威内容与删除状态仍复验。
- 快速切人使用短且有界的内容恢复合并窗口；取消旧读取且迟到内容不得覆盖当前联系人。

## 验证接口
- ForegroundController + SyncControlController + ContactSession公开状态/操作及真实HTTP合成后端：自动A→B→C许可连续、全局状态不重复请求，B旧观察不提交。
- 同步关闭跨切人仍生效，旧按钮、旧代际、目录失效、绑定变更不得恢复许可。
- ReplySession公开联系人与内容投影：慢B不阻塞C身份、快速途经B不加载完整内容、回A缓存/删除复验。
- NativeHeaderChangeSource既有有限租期、单子进程、失败锁边界保持。
- 启动时同步快照暂不可用（503 sync_status_unavailable）应自动退避重读只读状态；同连接恢复后无需手动刷新即可授予已开启同步的许可。成功、断连或主动刷新撤销旧等待，不重放开关等写操作。
- npm run dev实机核对联系人跟随；报告真实测量范围，不能将一次OCR674ms当作端到端P95或秒识别保证。

## 不做
- 不缓存联系人身份替代正式核验；不缓存已删除正文；不降低名字质量/唯一私聊/已确认绑定校验。
- 不修改原生采集频率或绕过前台门禁；不取消失败退避与单轮执行限制。
