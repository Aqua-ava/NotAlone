# 修复 App 数据授权重复触发与后端生命周期

## Problem Statement

用户明确要求允许 NotAlone 的已绑定会话读取并避免持续弹出系统 AppData 授权框。当前签名及 bundled 动态库完整；Apple 官方说明默认 AppData 授权只在 App 打开期间有效，不能以稳定签名保证跨重启永久免询问。实际进程及代码证明复用后端每轮重复初始化读取，退出后复用实例不受监管；签名脚本也覆盖嵌套 helper 标识。

## Solution

修复已复现的无效重复初始化及复用后端的正常退出停读，签名由内向外逐项执行，纠正权限台账。保持原已确认绑定、总开关配置、scope 隔离和用户手动发送。不修改 TCC，不扩大磁盘或其他 App 权限，不自动代点系统授权。

## Implementation Decisions

- 同一连接的 attach 初始化至多一次；真实失联后仍能恢复，不能用跳过轮询掩盖故障。
- 本地后端连接的运行状态与自有 Process 状态分别处理；关闭 App 时复用的运行时也须走有界正常关闭，避免孤儿读取。
- 关闭协议只用于已认证的回环后端，不能任意杀 PID、关闭其他服务或改变持久化同步偏好。
- 主 App、helper、库保持各自稳定 identifier；打包保留现有二进制依赖与权限说明。
- 系统授权由人类处理；可独立完成代码、合成验证、构建和签名检查，未通过实际允许后的运行验证不得称弹窗永久解决。

## Testing Decisions

在公开接缝以合成后端复现重复初始化／退出停读，先失败再修复；验证同连接幂等、真实断开恢复、复用关闭、未认证关闭拒绝和超时边界。执行相关 Python／Swift 测试与真正 App 构建，核验 helper 完整性及签名；按工作流两轴评审和本地中文提交，不 push。

## Out of Scope

永久授权的新文件选择／bookmark 功能、Full Disk Access、改写系统权限库、扩大联系人读取、自动外部聊天发送、远端部署。默认 AppData 跨重启重新确认由 OS 决定，本轮不承诺永不弹窗。
