## 交付行为

给定本任务新建的合成已采纳记忆、当前正文与预先标注的相关 ID，使用真实词法检索和回复上下文组装，输出按本地记忆身份计分的基线结果及数据版本。无需 Hindsight 即可演示和复验。

## 验收

- [ ] 校准和最终数据按场景分离，先标 gold 后运行；至少 60 条最终中文改写正例，每个主 bank 至少 300 条合成已采纳关系记忆。
- [ ] 包含多相关项、低词面重合、同主题难负例、直述、无关短句、不同 owner/同名联系人和独立预算压力组；主收益组 gold 可容纳于 5 条/600 字符。
- [ ] 真实 Context 完成预算及当前性复验后按本地 ID 计算 Recall@5、Precision@5、无关注入和正例空结果；失败正例不移出分母。
- [ ] 本人记忆单独报告，保持现有路径和 3 条/240 字符预算；不混入联系人主指标。
- [ ] 数据、gold、种子与查询规则可冻结并复现，静态有效期在整轮运行内稳定；可保存逐 query 结果。
- [ ] 在确认的 Context/runner 接缝完成 red → green 与相关回归、类型检查；旧 109 条结果不重命名为 Recall@5。
- [ ] 只处理新建合成资料，不连接业务库，不修改默认产品行为。
