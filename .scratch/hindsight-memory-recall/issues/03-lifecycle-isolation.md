## 交付行为

在实际服务与实验适配器中修正、失效或删除合成资料，证明旧结果无法进入上下文，并单独核查外部索引副本的清除；失败和竞态可重复演示。

## 验收

- [ ] 跨 owner、跨 contact、错误 bank、相同正文不同 ID、缺失映射和陈旧 revision 均不会产生越界依据；同时含能正常选入的有效正例。
- [ ] 回读后及上下文选入后注入删除/修正竞争，最终 validate_current 拒绝旧快照；时间边界独立分组，不污染静态收益组。
- [ ] retain/更新/删除/重建重试幂等；单来源、多来源、整条记忆与联系人 bank 的生命周期符合本地资料支持规则。
- [ ] 对 document、chunk、memory unit、向量、运行缓存与重启后检索核验外部删除；无法证明的备份/介质残留列为限制，不能只凭本地拒绝宣布外部清除。
- [ ] 服务不可用、超时、部分重排未完成和返回异常均显式记失败；不隐式用 A 冒充 B 成功。
- [ ] 双预算、本人本地路径、普通改写未授权参考资料和复验直通保持原有边界。
- [ ] 完成已确认接缝的 red → green、相关回归、类型检查及真实服务生命周期验证；清理仅触及本实验资源。
