# 04 — 正式对照实验与报告

> Triage: ready-for-agent
> State: open
> Blocked by: 01, 03
> 规格：[Hindsight 本机记忆召回对照实验](../spec.md)

## 交付行为

用独立校准集选择并冻结 B 配置，再运行同一最终集上的实际 A/B 对照，输出可复现的中文结果报告，明确服务是否达到已确认门槛以及本机成本。

## 验收

- [ ] 只在校准集选择模型、相关性阈值及候选规则，冻结后运行最终集；不按 B 输出修改最终数据或 gold。
- [ ] 优先使用 02/03 已验证的配置；若服务、模型或切块/候选规则变化，重新通过受影响的 smoke 和生命周期检查后再验收。
- [ ] 主指标为真实最终上下文的宏平均 Recall@5；报告 B−A 是否达到 10 个百分点，无关注入是否增加，范围/状态/重复/预算是否违规。
- [ ] 各臂至少 100 次预热后完整尝试；交替次序固定，计入 HTTP、embedding、rerank、本地复验、上下文选取和当前性校验，报告 P50/P95/最大值与所有失败。
- [ ] P95 按规格分位数计算并核对 ≤1,000 ms；不以 HTTP 内部耗时或快失败代替完整检索表现。
- [ ] 保存逐 query/逐尝试数据、版本摘要、实际命令、硬件/CPU/内存/存储、冷启动和索引更新成本，以及可执行运行与清理说明。
- [ ] 最终结论为达到门槛、未达到门槛或运行前提未满足；未达收益门槛不放宽规则，服务不可运行不伪造结果。
- [ ] 全部相关检查及 Standards/Spec 两轴评审完成；只新增实验能力，不启用生产向量，不读取真实聊天，不宣称提取或微信集成已验证。

## 完成记录

只有真实运行及验收材料齐备才能改 State 为 resolved；未达到收益门槛可形成完整失败结论，但运行前提缺失须保持未完成并如实记录。
