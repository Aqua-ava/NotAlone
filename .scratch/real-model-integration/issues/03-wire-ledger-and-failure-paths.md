# 03 — 台账接线真实调用与失败路径收敛

**What to build:** 真实外部模型调用的完整闭环：每次调用自动写入出站台账，成功、运行失败、校验拒绝三种结果都落账；网络错误、超时、限流与结构化输出解析失败统一映射为既有运行时错误并按既有失败重试语义处理，不产生部分落库候选或悬挂的进行中请求。

**Triage:** ready-for-agent
**State:** resolved
**Blocked by:** 01（模型构造与冒烟）、02（出站台账 port 与持久化）

- [x] 真实调用前后接线台账：成功、运行失败、校验拒绝三种状态分别落账且字段准确
