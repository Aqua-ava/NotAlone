# 持续会话运行时小验证

Triage: ready-for-agent
State: resolved
Type: prototype

## 目标

在不改正式产品代码的前提下，以同一组合成场景比较 DSH 与仓库已安装的 LangChain：多轮上下文、新会话隔离、进程重启恢复、生成取消与替换。只判断运行机制和接入负担，不评价真实模型的表达质量。

## 范围

- 仅本机模拟模型、合成标记和独立临时存储；不读取 `.env`、私人聊天、业务数据库或 DSH 个人目录。
- DSH 使用官方发布运行时，锁定实际可获得版本；默认执行工具和额外日志上传必须关闭。
- LangChain 使用项目锁定版本，实验持久化适配器安装到临时目录，不修改项目依赖。
- Context7 当前不可用，接口以官方文档与实际安装源码核对。
- 若某入口无法启动，保留具体阻塞证据，不把文档能力写成通过；不扩大到桌面集成或框架迁移。

## 交付

实验脚本、运行结果、简短对比结论和复跑命令。原型不是生产实现，不替代 ADR-009 或现有会话草图。
