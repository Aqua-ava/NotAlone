# 群聊前台定位暂停

用户已确认：切到群聊时暂停前台联系人跟随，清除群名并显示“群聊暂不支持”，保留原私聊草稿；切回已确认私聊自动恢复，已授权私聊后台同步继续。

## 实现范围

- 顶部末尾人数括号作为疑似群聊的保守暂停线索，不作为群类型证明，也不剥离数字后匹配私聊；无人数尾缀时，正式前台观察复用有界 CLI 会话元数据识别群聊。同形数字括号私聊标题也可能暂停，此保守限制需记录。
- 群聊不向助手传递名称或身份，不提示用户把群聊确认为联系人，不允许旧资格或手动确认绕过暂停。
- 暂停不是关闭定位总开关；沿用单轮观察和有限调度以发现返回私聊，不增加采集范围、帧数、正文读取、模型调用或发送能力。
- 群聊暂停不新建永久人工确认门；原先低分、重名、未绑定等引发的人工门继续保留。恢复必须依赖新的合格私聊与已有有效绑定。
- 保留私聊内容及既有任务；定位暂停不调用后台同步关闭接口。
- 未知类型、元数据不可用或候选截断不授予私聊资格。低分、不完整标题也不能借群聊检查取得身份。
