## 六个重点窗口的原句与实际分歧

以下为仓库已提交的公开合成句；`T` 是 target，`C` 是辅助 context，索引零起始。它们不是私人聊天或模型输出。

| 窗口 | 最小必要公开输入 | 需要核定的语义边界 |
| --- | --- | --- |
| A05，姐借车 | `0 T contact`：我姐把她的车借给我了。 | 所有者是姐姐，接收者是联系人；不能写联系人拥有车或仍在借用。第三人已发生事件按当前提示候选为 `report/reported/pending`，旧 oracle 是 `auto`。需先决定采用现行语用契约的 Gold，不能去掉转述标签保旧分数。 |
| A06，机场等行李 | `0 C self`：你到机场了吗？ `1 T contact`：到了，正在等行李。 | ①已到机场；②当时正在等行李。合并可忠实，但历史到达和瞬时状态有不同有效期，是否必须拆分需要核定。观察时点是 `2026-09-15T00:01:00+00:00`；原文没有等行李的实际结束时间，不能补航班、到达时刻或已取到行李。 |
| A10，多第三方借钱 | `0 C self`：老李借你钱了吗？ `1 T contact`：借了，小王没借。 | 老李的肯定项和小王的否定项都要保留，二人的角色不能互换。“借你钱”的借入／借出方向有歧义；核定保留原措辞的 `pending`，或明确该合成句希望表达的方向后记录修订原因。不得凭旧 pending 期望宣称方向已经明确。 |
| A15，借书看完 | `0 T contact`：你上次借我的书我看完了，谢谢。 | 确定部分是联系人读完了所指书；书名、借用方向、归还均未确定。可只核定读完主张，借书关系作为可选歧义主张单列；也可要求保留忠实的原关系措辞，但不能擅定出借人或所有者。 |
| B01，报价与条件咨询 | `0 C contact`：你怎么看那家泥塑体验课的报价？ `1 T self`：我觉得两次课90元挺合适，不过报不报名还没决定。 `2 T self`：如果周末有空，我只去问场地是否能借工具。 | ①用户对这一报价的判断；②尚未决定报名；③仅在周末有空时去询问能否借工具。不得升级为长期价格偏好、已报名、一定咨询、已借工具或场地能借。前两项用课程全名需 `[0,1]`；第③项写明与该课场地关联时需核定额外上下文，单独保存原场地措辞可仅 `[2]`。 |
| B02，表弟历史与当前未知 | `0 T contact`：2024年暑假，我表弟曾在社区读书会负责活动主持。 `1 C self`：你表弟现在做什么工作？ `2 T contact`：现在他做什么工作，我不知道。 | ①表弟的2024年暑假经历；②联系人在来源时点不知道表弟当前工作。②是联系人的知识状态，非 V 证据不足，非表弟失业。历史经历不补暑假的具体日期，不变成当前职业；两项语用不同，混合候选不能用单一 assertion 标为已确定第三人事实。 |

A06 的日期规则须明确记录采用的契约：[domain-data](../../architecture/current/domain-data.md)要求瞬时状态的失效不得超过来源当天结束，[E 提示／schema](../../backend/src/notalone/memory_extraction/adapters.py)还给出当日结束边界；[pragmatic-interpretation](../../architecture/current/pragmatic-interpretation.md)仍写“仅当原文明示结束日期或期间时推算失效时间”。这一处文档口径差异没有在本文被修订。来源 UTC 偏移为 `+00:00`，可推算的当天结束上界是 `2026-09-16T00:00:00+00:00`；这是约定的检索有效边界，**不是原文证明的等行李实际结束时刻**。人工须核定采用何种边界口径，不能把尚未选定的 `invalid_at` 当作空值 Gold。
