# CLI 全量增量同步与前台 OCR 定位

> 状态：已确认，进入实现
> 后续修订：首次默认全选由 ADR-030 改为默认不选；关闭窗口永久跳过已由 ADR-025 的有界补齐替代。下文保留原任务的验收背景，新改动以现行 ADR 为准。
> 目标：让用户只在首次批量确认微信私聊后，由 CLI 在 NotAlone 运行期间持续同步；OCR 只负责判断当前微信前台联系人，不再作为后台消息同步的前置条件。

## 用户问题

当前同步把“微信必须保持前台”和“消息读取”绑在一起。用户从微信切到 NotAlone 操作时，微信失去前台，读取立即停止；回到 NotAlone 选择联系人时又会打断前台观察，形成无法完成的往返。当前状态页因此长时间停在“等待微信前台”或“绑定确认”。

## 解决方案

运行时拆成两个互不阻塞的通道：

1. **CLI 全量增量同步**：用户在 App 内打开总开关后，后端只启动一个 `wechat-cli tail --mode sessions --follow --jsonl --strict-read-only` 全局会话事件流。事件流只用于发现哪些会话有变化；正文仍按已确认的外部会话定位标识调用一次性 `tail <talker>`，每个联系人使用独立持久化 cursor。NotAlone 关闭或总开关关闭时停止读取，不创建隐藏 daemon。
2. **前台 OCR 定位**：在 App 运行期间低频观察微信是否在前台，并用顶部 display name、左侧选中会话元数据和既有绑定判断当前前台联系人。该通道只返回状态和待确认候选，不写消息、不驱动 CLI 后台同步；微信不在前台不会影响 CLI 通道。

## 首次批量绑定

- “所有微信人”定义为 CLI `sessions --type-filter private` 能看到的已有一对一会话，不包含群聊、从未出现在 CLI 会话列表中的联系人或仅存在通讯录但没有会话的好友。
- App 提供一个批量预览列表，默认全选，用户可以取消勾选并编辑新联系人展示名；最后点击一次“确认绑定所选会话”。提交前不写绑定，提交后才一次性创建联系人（若未选择既有联系人）和会话绑定。
- 稳定外部会话定位标识是身份依据，展示名只用于显示和默认联系人名。相同定位标识不能绑定到多个联系人；已有绑定只展示为已绑定，不重复创建。
- 批量确认时为新绑定建立 baseline 时间，只读取确认之后的新消息；已有 cursor 的绑定从 cursor 恢复。
- CLI 新出现的会话不自动绑定、不自动创建联系人；它只出现在下一次批量刷新结果中，等待用户确认。

## 实现决策

- 保留现有 `FrontSyncEngine` / `TailLifecycle` 作为人工验证和兼容兜底路径；新的常驻后端主路径使用独立的 CLI 全量同步协调模块，避免让旧的“当前唯一联系人 tail”语义污染后台路径。
- 全局事件流只有一个长进程；联系人正文读取是有界的一次性命令，按变化会话排队并逐个执行。由于事件流不保证覆盖我方发送等变化，队列清空后还要按固定预算对 active 绑定做定期 round-robin 安全对账；全局流不可用时同样退化为有界 round-robin 一次性读取。不启动每联系人 Follow，也不无限重启进程；单个会话失败延后到后续轮次重试，不得占满队列。
- 后台观察来源模式新增 `cli_background`，与旧的 `live`（前台现场）和 `cli_catchup`（切回补读）区分。
- 状态 API 同时返回 CLI 后台状态和前台 OCR 状态；旧字段保留兼容，`active_contact_id` 表示当前 OCR 定位联系人，不再表示后台唯一读取联系人。
- 所有写入继续通过 `owner_id + contact_id`、active 绑定和稳定消息身份校验；只保存文字及来源元数据，不保存截图或原始视觉帧；不提供任何发送能力。

## 测试 Seam

- CLI 适配器：全局 session 事件流命令、cursor、定位标识解析、关闭行为；一次性 tail 的 baseline 参数。
- 后台同步协调模块：全局事件只触发已绑定联系人；每个联系人独立 cursor；一次 baseline 后只读新增；一个全局流而不是 N 个 Follow；事件流失败时有界降级。
- 前台定位模块：OCR/探针不可用只影响前台状态，不阻塞后台同步；未绑定和重名仍要求用户选择。
- HTTP：批量会话预览、一次性批量绑定确认、CLI/前台双通道状态，以及敏感正文不出现在状态响应中。
- App：状态模型能区分“CLI 后台同步”和“当前微信前台”；批量列表默认全选且可取消；人工 Follow 验证仍作为单独兜底入口。

## 不在本次范围

- 不读取微信数据库、密钥或非公开协议。
- 不自动切换窗口、点击微信、滚动会话、输入或发送消息。
- 不自动绑定群聊、未确认的新会话或通讯录中没有 CLI 会话的好友。
- 不把历史会话正文默默补入；不实现媒体正文 OCR、语音转写或跨设备同步。
- 不删除既有前台人工验证路径，待新主路径经过真实用户的脱敏冒烟后再单独决定清理。
