# 05 — 主窗口骨架：联系人列表、同步开关、菜单栏降级

Type: task

**Triage:** ready-for-agent
**State:** open

**What to build:** 用户双击打开带主窗口的 NotAlone 应用：三栏骨架的左栏显示联系人列表与同步状态角标，可以开启/关闭前台增量同步并立即看到状态变化；菜单栏应用降级为轻量状态入口，查询后端状态，不再周期性拉起子进程；主窗口应用负责拉起并监管后端子进程，退出时一并收掉。

**Blocked by:** 01（后端服务骨架与进程内测试接缝）

- [ ] 主窗口应用为独立 Swift Package，位于仓库根目录、与探针包平级；形态为正常窗口应用。
- [ ] 应用自动拉起并监管后端子进程（沿用 conda 环境路径探测经验），退出时收掉；后端不可用时界面给出清晰错误。
- [ ] 左栏联系人列表含展示名称与同步状态角标，保持 owner 范围隔离。
- [ ] 同步开关操作经后端 API 生效，菜单栏与主窗口立即反映状态。
- [ ] 菜单栏应用停止每 3 秒拉起子进程轮询，改为查询后端；保留开关键与状态显示。
- [ ] 屏幕录制权限只需授予主窗口应用，探针作为其子进程运行；探针调试窗口暂时保留在菜单栏应用中。
