# 11 — Skill 库管理与设置页

Type: task

**Triage:** ready-for-agent
**State:** open

**What to build:** 用户在管理页导入、启用、停用、回滚、删除回复 Skill，并预览其内容与辅助资源；设置页管理模型凭据、探针路径与同步参数，并可打开探针调试窗口（OCR 文本与裁剪预览）；出站台账统计概览可供核对。

**Blocked by:** 05（主窗口骨架）

- [ ] Skill 管理共用既有管理端口：完整校验后原子发布、版本不可变、回滚与隐私清理语义不变；拒绝原因在界面可见。
- [ ] Skill 预览只展示版本内容与受控辅助资源，不暴露联系人资料。
- [ ] 凭据配置写入受控配置，界面与错误信息均不回显密钥。
- [ ] 台账概览只含元数据（时间、供应商、模型、联系人范围、用量、结果状态），不含正文；按 owner 隔离。
- [ ] 探针调试窗口经设置页打开；屏幕录制权限模型与既有探针一致。
