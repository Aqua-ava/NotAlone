# 09 — 记忆管理（含 pending 候选确认）

Type: task

**Triage:** ready-for-agent
**State:** open

**What to build:** 用户在管理页查看所选联系人的关系记忆列表（正文、分类、主题、采纳标记与有效期），手动录入、修正与删除记忆；低置信的 pending 候选第一次可以人工处理：确认走与自动采纳相同的落库裁决路径并标 `manual`，丢弃使候选失效并计入删除指纹。

**Blocked by:** 05（主窗口骨架）

- [ ] 记忆列表只返回当前联系人范围内 active、有效期内且仍有有效来源的关系记忆；列表含正文。
- [ ] 手动录入标 `manual`（支持联系人级与 owner 级）；删除记忆后其文本指纹阻止自动复活，手动录入不受限。
- [ ] pending 候选确认后成为 `manual` 记忆；丢弃后候选失效，重复提取不再自动采纳同一文本。
- [ ] 记忆修正产生版本演变语义，与既有写入裁决一致；撤销后检索不可见。
- [ ] 集成测试覆盖确认、丢弃、删除指纹、有效期与 owner 隔离；API 契约测试钉住 JSON 结构。
