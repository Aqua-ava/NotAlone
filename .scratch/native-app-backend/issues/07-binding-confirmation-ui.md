# 07 — 绑定确认界面化

Type: task

**Triage:** ready-for-agent
**State:** open

**What to build:** 首次绑定、重名、改名或证据矛盾时的候选绑定，在主窗口内显示一次性选择列表（display name、外部会话定位标识、最近活动时间），用户选择后写入绑定；菜单栏的两级子菜单确认入口被主窗口入口替代。

**Blocked by:** 05（主窗口骨架）

- [ ] 出现候选绑定时主窗口弹出选择列表，同步在确认前保持暂停，不写入消息。
- [ ] 确认后后续切换自动识别，不再重复确认；已绑定会话经最近会话回退可自动认出。
- [ ] 证据矛盾或无候选时失败关闭，不把消息写入错误联系人。
- [ ] 绑定确认 API 与既有 `confirm-binding` 命令共用同一确认逻辑；绑定只保存展示名与证据摘要（预览为 SHA-256）。
- [ ] 集成测试覆盖首次、重名、改名与失败关闭路径。
