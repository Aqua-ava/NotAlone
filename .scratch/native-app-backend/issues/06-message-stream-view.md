# 06 — 消息流展示与实时更新

Type: task

**Triage:** ready-for-agent
**State:** open

**What to build:** 用户在主窗口中栏看到所选联系人的规范消息流：正文、说话人、时间、媒体占位文本与引用消息按领域定义如实展示；打开联系人加载历史，新消息到达时经事件通道实时更新，不需要手动刷新。

**Blocked by:** 02（事件总线与 SSE 契约）、03（--follow 流式读取与事件驱动同步）、05（主窗口骨架）

- [ ] 消息查询 API 只返回当前联系人范围内 active 来源的规范消息，跨联系人读取被拒绝。
- [ ] 媒体占位文本与引用消息按领域定义渲染：占位不冒充正文，引用目标缺失时显示为未解析引用。
- [ ] 打开联系人时分页加载历史消息；新消息事件到达后消息流实时追加。
- [ ] 契约测试覆盖消息查询 API 的 JSON 结构与范围隔离。
- [ ] 手工冒烟：真实导入数据与前台同步新消息都能在消息流中正确展示。
