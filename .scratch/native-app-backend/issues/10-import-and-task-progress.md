# 10 — 导入与任务进度

Type: task

**Triage:** ready-for-agent
**State:** open

**What to build:** 用户在主窗口完成历史导入：选择 JSONL 文件、预览校验结果、选择或新建联系人后正式导入；导入完成后可一键触发记忆提取任务，任务步骤在后端进程内执行，进度与结果统计经事件通道实时推送；失败显示错误分类并可重试，中断后重新触发从未完成步骤继续。

**Blocked by:** 02（事件总线与 SSE 契约）、05（主窗口骨架）

- [ ] 导入预览与正式导入共用既有命令的同一逻辑：单联系人归属校验、混联系人拒绝、同一事务写入与幂等。
- [ ] 任务触发始终由用户动作发起；不引入定时器或无人值守调度。
- [ ] 任务步骤进度（当前步骤、计数、尝试与重试）经事件实时推送；终态结果统计可在界面查看。
- [ ] 模型或网络暂时失败的重试与租约续期语义不变；中断后重新触发从未完成步骤继续。
- [ ] 既有 `task-worker` 命令保留为兜底恢复工具，与后端进程内执行共用同一任务执行路径。

## Comments
