# 08 — 回复闭环

Type: task

**Triage:** ready-for-agent
**State:** open

**What to build:** 用户在主窗口右栏回复工作区完成候选回复全流程：选中一条联系人消息并填写表达方向，或提交自己的原句与改写要求；系统经已验证会话范围检查后生成候选回复，界面展示生成依据与本次使用的 Skill；候选可编辑、可复制到剪贴板，用户可显式选择一条历史候选继续生成。全程不存在任何外部发送能力。

**Blocked by:** 06（消息流展示与实时更新）、07（绑定确认界面化）

- [ ] 两种输入形态（回复目标消息 + 表达方向、用户原句 + 改写要求）都能生成候选；请求按幂等键处理重放。
- [ ] 生成前必须通过已验证会话范围检查；绑定缺失、未验证或范围不符时拒绝生成并给出原因。
- [ ] Skill 默认自动选择（至多一个），允许用户手动指定一个 active 版本；界面展示本次 Skill 使用摘要与回复上下文依据，材料可移除或补充。
- [ ] 候选可编辑与复制；改写要求与表达方向只约束本次生成，不静默成为长期偏好。
- [ ] 基于历史候选的显式继续可用；系统不自动推断"最近未发送候选"。
- [ ] 回复 API 与既有测试共用同一应用层候选回复流程；集成测试覆盖两种输入形态、范围校验与幂等。
