## Acceptance criteria

## 验证与交付

使用公开桌面操作、后端 HTTP 和隔离 PostgreSQL，模型及消息输入使用合成适配器；安全和竞态在应用入口验证。优先复用前五票测试，新增组合场景用于暴露真实集成缺口；缺少原生窗口授权时先完成合成检查，保留原生项未完成。完成后按工作流进行 Standards/Spec 两轴评审、本地提交，并在本票写 Answer；没有证据不改为 resolved。

真实 App 仅由主 Agent 在另行约定的有限窗口通过项目入口执行；普通验证不启动 App、不读取微信、不调用外部模型。
