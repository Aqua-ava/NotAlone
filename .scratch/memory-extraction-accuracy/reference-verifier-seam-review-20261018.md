# 指代质量续轮：核验接缝排除与示例教学假设

上一轮已改变源码并形成真实反证，属于有效进展；任务07仍未达标。续轮先依据当前代码与封存输出定位，不重跑旧配置。

## 已核事实

- `verification_adapters.py`的`_verification_text`已发送category、topic、主体、时间和语用标签；不是序列化漏发这些字段。真实错误输出对应的V仍为supported，见[上轮分组结果](reference-agent-contract-result-20261018.md)。
- 同函数有意不发送候选自写的confidence、risk_flags、alternatives及interpretation_reason；既有`test_candidate_self_assessment_is_not_exposed_as_source_evidence`通过。不能把防自证隔离误当接口缺陷，也不能令候选自己的解释充当来源证据。
- `flow.py`的UNCERTAIN路径只增加语义风险并保留原字段，UNSUPPORTED路径移除候选；两项既有行为测试通过。现有V接口不返回修订标签。仅增强V会拒绝或降级，但不能把错误分类纠成正确分类；不能据此承诺一般错误≤1。
- 本次核对共3项单例通过，零供应商调用、零业务/桌面数据、无生产代码修改。

## 下一条可证伪路径

按原spec第5条允许“提示词与示例”，采用此前未使用的成对微例教学；不是增加模型重试或更改安全门。样例分别区分第三人职业与本人参与、亲属互动与普通完成背景、消息维护与持续交付、事项未明与事项明确但尚未决策。样例须独立审核，不复写主集或诊断输入，不以其作后继评测分数。

接入假设：抽象规则已经送达却仍选错标签，成对示例能让模型更稳定地选择受控字段；若相同模型配置的独立完整主集仍一般错误>1，则本次教学干预未达到目标，不能以某个旧错修好或程序测试绿替代。

拟只将教学文本纳入E2 system提示，实际请求仍仅有当前window的source_units/target/schema；样例不得成为候选正文、来源ID、dependency或目标消息。旧v3/v4、编译器和采纳门保持。只检查教学接线与来源隔离不证明语义，真实收益必须另冻新场；本文件未登记或开启新模型预算。
