# 02 — 本机真实聊天找错一轮

**What to build:** 在用户本机上，对已确认联系人跑一轮真实提取评测（默认只读；是否写入待确认候选由用户当场决定）。只输出聚合统计与判错分类（去向、标签错误类型），不输出消息原文、命题文本或联系人标识。用户抽查判定结果；发现的真实错误经去标识改写成合成用例，经用户过目后加入评测集，供后续维度票使用。

**Triage:** ready-for-human
**State:** open
**Blocked by:** 01（评测骨架）

- [ ] 仅在本机运行；不产生包含真实内容的仓库文件
- [ ] 输出聚合统计与判错分类，不含原文、命题或联系人标识
- [ ] 用户抽查确认判错分类
- [ ] 去标识改写的新用例经用户过目后入库并标注来源为"真实找错"
