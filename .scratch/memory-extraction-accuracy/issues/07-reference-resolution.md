# 07 — 指代消解维度评测与修复

**What to build:** 把"他/她/那个/这件事指谁、指什么"测全：跨消息指代、省略主语、多个第三方同时出现、指代含糊时应保守。至少 15 条合成用例。重点保证含糊指代不会被写成确定事实（宁可不采纳，也不能猜错）。发现判错按允许手段修复，并保证全部既有用例回归通过。

**Triage:** ready-for-agent

**Blocked by:** 01（评测骨架）；02 的产出用例可并入

- [ ] 指代含糊的候选不得进入自动采纳
- [ ] 修复只用允许手段；全量既有用例回归通过
- [ ] 新增与修复对应用例入库
