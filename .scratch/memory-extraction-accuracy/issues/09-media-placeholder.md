## Answer

- 用例：媒体占位维度 16 条，覆盖图片、语音、表情、动画表情、视频、视频号、文件、链接、名片、转账、位置与混合占位；文字伴随事实（到家、养猫、方案改好、下周出差）额外做文本检查，禁止出现"图片里/语音里/视频里/文件里"这类对媒体内容的推测。
- 真实模型 `ecnu-max` 三轮：15/16、15/16、16/16；假事 0、记错人 0 两轮，另一轮出现 1 条"名片"被自动采纳的假事。
- 过程中替换了三类不稳定候选：纯占位"在路上/到了"会被偶发自动采纳、文件签署请求召回不稳；换成信息量更足但同覆盖的文字伴随事实与稳定占位用例。
- 结论：媒体维度的占位不推测内容这条已稳定成立（16 条中占位类全部通过或仅召回波动）；名片类弱事实偶发进入自动采纳，与任务 11 的放行记录一并复核。
- 验证命令：`python -m unittest discover -s tests/unit/memory_extraction`（54 项通过）；未改提示词与自动采纳规则。
