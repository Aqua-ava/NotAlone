**What to build:** 把媒体占位测全：图片、语音、视频、文件、表情、动画表情等占位文本只能推断"发送行为偏好"（如"他不爱发语音"），不得推断或复述媒体内容。至少 15 条合成用例。重点保证占位不会变成正文事实。发现判错按允许手段修复，并保证全部既有用例回归通过。

**Triage:** ready-for-agent

**Blocked by:** 01（评测骨架）；02 的产出用例可并入

- [ ] 媒体占位不得被推断为正文事实；允许的发送行为偏好可以生成候选
- [ ] 修复只用允许手段；全量既有用例回归通过
