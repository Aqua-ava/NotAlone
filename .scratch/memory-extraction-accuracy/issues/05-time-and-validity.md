# 05 — 时间与时效维度评测与修复

**What to build:** 把时间状态测全：已发生事实、未来计划、已取消的安排、条件式承诺、有时效的近期状态（出差中、感冒中）、明确的时间修正。至少 15 条合成用例。重点保证"取消的不会记成要去""过期的不会一直有效"。发现判错按允许手段修复，并保证全部既有用例回归通过。

**Triage:** ready-for-agent
**State:** open
**Blocked by:** 01（评测骨架）；02 的产出用例可并入

- [ ] 该维度达标签：至少 15 条中假事 0、记错人 0、一般错误 ≤1
- [ ] 覆盖已发生、未来计划、已取消、条件承诺、有时效状态、时间修正
- [ ] 有效期字段在需要时被正确填写（存在性检查，不校验具体时刻）
- [ ] 修复只用允许手段；全量既有用例回归通过
- [ ] 新增与修复对应用例入库
