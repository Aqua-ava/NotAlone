## 语义干预与边界

仅增加显式V提示档`reference-retention-v1`：在原legacy-v4提示后复用既有作者引句规则，再说明编译器已有的完整周／周末半开检索期间约定。来源时区自然日为锚，周从周一开始；本周／这周和下周各取完整一周，本周末／这周末／周末及下周末取对应周六零点到下周一零点。边界不是现实事件准确起止或持续执行的声明，不改变事件阶段。

人物、归属、否定、数量、语用、来源链仍逐项核验；未知只能原样保留，不能为通过而消歧。多个未消歧期间、否定或取消改期及修饰期间不得套用整周约定。新提示不包含原16答案；E保持`reference-kind-teaching-v1`，E/V schema、原Gold及审查规则不变；V档自身不改编译器，当前联合冻结另包含下述有限理由补全。默认与既有公开作者引句V提示字节保持不变。

同时给记录器既有拒绝路径添加固定枚举失败码，用于区分外层JSON／编码、嵌套JSON／非对象、序列化与内部失败。只保留固定代码，不保存异常文本、类型、正文或片段；仍摘要留证、立即硬停并保留unknown，不补发、不重试，不能反推旧场失败原因。

## 独立程序理由修复

A05旧场仍是一般错误：程序已在alternatives保留物品所有者未知，却未在interpretation_reason说明出借、接收及完成依据。联合冻结在V档之外增加独立E2编译说明，不称V单项干预。

只复用已有单消息／唯一target及source／作者一致／完整原句匹配门禁与有限出借文法。仅肯定已完成且物品所有者未知时，按原文角色和完成词跨度动态追加说明，并保留原未知所有权提示。它解释原话而不认证现实、唯一身份或产权，不扩语法、不构造正向proof；其他13字段、模型标签、V和pending去向保持。

否定、未来、已明确所有者、多消息、残缺引句、错作者或来源、顶班受益人分支均不套用。固定A05标签、参数变体及SDK保存回归只能验证程序，不能回填旧场分数或替代新的模型验收。
