## 问题与范围

已有真实失败表明：来源中的产权代词未唯一确定，E返回无歧义标签且V返回supported时，即使候选完整引用原话，理想采纳门仍可能auto。引用保留字面并没有消除内部角色歧义；不能用编译器替模型补身份或改写旧返回。

在本次V已提供的输入文本上，复用既有借用及请托完整产生式，只识别其明确缺失的产权／受益人身份。它不是可信来源证明，不要求补造source快照，也不给来源、指代或任何维度正向信用。原metadata为unknown仍保持原值。函数不读取文件、业务库、case ID、Gold、昵称或供应商。

防护只处理单消息、单实际target、候选只引该消息，且正文精确等于实际sender对应的“用户／联系人原话：”完整包装。原消息全文及候选均沿既有4096码点上限。借用沿原我姐／我哥、她／他、车／书／雨伞、已完成或带既有时间的否定语法；请托沿原self作者及亲属／同事、周末／明天／后天顶班语法。复用解析结果中的缺失property_owner／beneficiary，不另造最近人物推断或新的正向语法。

原有显式身份成立、非完整引句、错外层作者、多消息、额外context／观察前缀／尾句、其他谓词或范围外文本均不干预。未命中不等于程序认定supported，也不证明候选安全；继续原V、来源、语用及采纳规则。更广泛指代及范围外歧义仍须靠原07完整质量验收。
