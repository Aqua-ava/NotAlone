# E2条件场景检索期间与计划语气词的有限补全

Triage: ready-for-agent

归属[原07](issues/07-reference-resolution.md)允许的字段语义及时间解析修复，续接[首片有限策略](bounded-e2-semantics-spec-20261016.md)。首片及三项审查修复的工程验证不代表真实模型质量；对原固定140／138个必需主张的必要六字段扫描，136项有给定标签见证，仍缺天气TC-only及句尾“吧”两项日期表达。数学见证不签完整正文、来源或去向；不改Gold或旧成绩。

## 明确增加的两项有限行为

1. **完整天气条件的场景检索期间。** 同一实际目标消息的两个相邻完整MAIN成员，模型已标condition或prefix＋plan，满足首片完整来源／文法约束；条件为`IF + TC + WEATHER + ，`，主句为`[SUBJ] + 就 + EVENT + S`，没有外层T0或主句TA。IF沿原五类条件连词，WEATHER仅下雨／降雨／不下雨／不降雨／天晴，SUBJ／EVENT／S沿原闭集。TC只允许今天／明天／后天／本周／这周／下周／本周末／这周末／周末／下周末／下个月／下月这些完整单容器。由同消息aware锚点计算该完整**条件场景的检索期间**，条件性仍保留；这不证明天气成立、行动实施或行动的精确发生时间。
2. **完整计划的句末语气词。** 首片完整时间动作框架已经具有唯一TP与EVENT，且实际kind为plan／hypothesis时，额外允许结尾恰为`吧`或`吧。`。原语气词和标点仍逐字留在MAIN与最终正文，只让既有日历解析识别完整期间；不改变原断言状态或把邀约当承诺，不给state、request或condition前件新增语气归一化。重复语气、完成／疑问标记、额外尾句、其他标点及未列词法继续范围外。

第一项是对首片“TC-only一律不计算”的**明确有限例外**；其他TC-only仍UNKNOWN。尤其完工截止条件、无“就”的主句、任一必要成员未被实际编译、不同消息、缺锚点、条件与主句有额外未解析时间均不获此例外。有TA或T0仍沿首片现行作用域规则，不能用天气TC覆盖明确TA或消除真正冲突。

第二项只增加完整末尾词法许可，不能先截取一个可匹配短串再忽略剩余字。`了吧／吧吧／吗／TP吧但缺EVENT`等反控不得藉由不透明PLACE／OBJECT吞入尾部取得许可。原来未接管的观察型日期与范围外旧期间，不因本片UNKNOWN获得新的清除权限。

## 不变项与验证

继续使用既有compile_labels／实际SourceUnits、成员及依赖／同一次renderer，不新增公开DTO、profile、规则DSL、模型字段或调用。仅本E2的最终期间及原grounded:unresolved_period派生标记可随这两项变化；正文、来源、类别、主体、其他语用、敏感性、置信度及其他风险保持。条件例外须先确认完整来源与plan，再计算场景期间；不得凭时间词命中给任意条件或动作填日期，不产生typed依据或放宽自动采纳。

正控至少覆盖非Gold的不同EVENT／PLACE／作者、不同容器与跨月年锚点、condition／prefix两种合法前件；反控分别只改变WEATHER、连接词“就”、TC截止归属、显式TA、锚点、作者／消息边界、终端语气及额外尾句。实际SDK控制核原draft→最终compile→candidate_raw及同一次V；模型响应只给旧标签，不代签真实分类质量。
