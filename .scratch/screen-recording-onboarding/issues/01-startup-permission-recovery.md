# 启动时引导屏幕录制授权并支持恢复

Triage: ready-for-agent
State: resolved

## 问题与范围

用户在正式 App 小窗看到缺少屏幕录制权限，但启动时没有用途提示或授权入口。当前正式观察只静默预检，无法完成授权闭环。

本任务在 App 启动时只读检查当前包内探针权限；缺权限显示一次用途提示，由用户点击后调用系统授权，再提供系统设置及重新检测入口。配置页和小窗保留恢复按钮，暂不授权不阻断后台文字同步或人工选择联系人。用户亲自决定系统授权，不改 TCC 数据库、不自动接受系统授权。

## 验收与测试边界

- 正式原生 CLI 的独立权限入口：check 不申请、不采图；request 仅明确操作后申请；未知参数拒绝。
- 可信宿主具名 IPC：启动只检查及一次提示、用户点击才申请、重复操作互斥、拒绝后能进入固定系统设置、重新检测、退出时拒绝晚结果。
- 生产页面：缺权限有授权和重新检测按钮，说明只用于本机微信名称识别；权限就绪后状态更新。
- 当前签名包由 Computer Use 操作验证真实启动提示与恢复入口；真正系统授权由用户完成。单元／合成测试不证明系统已授权或自动联系人识别成功。

不修改已有联系人绑定、总开关、正文范围、模型调用或自动发送能力；不清空现有草稿，不重置系统权限。
