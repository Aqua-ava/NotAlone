# 前台联系人变化触发识别

用户已确认正式 App 名称识别准确、提示稳定，仍认为切换后的等待过长；已授权选择流程并推进。当前正常轮次结束后固定等 2 秒，真实旧场两次采集间隔约 2.5 秒，不能将其称为用户切换延迟。

采用 `ask-matt → grill-with-docs → implement/TDD → code-review`。联系人身份与 OCR 正确性已有边界，先做最小原生能力验证，再决定事件来源；不重做联系人、草稿或生成验收。

## 目标与边界

- 变化提示到达后优先触发现有新观察，取消空等；原有单轮在途、认证 HTTP、质量与唯一已有绑定核验保留。
- 切回微信与微信内切换会话分开验证，AX 注册成功不等于联系人切换时会发事件。
- 不读取聊天正文、AX 联系人文本或其他 App 内容；帧仅端侧内存，OCR 仍仅顶部名称。
- 同一连接只有一个事件来源。事件仅提示变化，不能携带或自行确认联系人身份；失焦、停用、断连、退出与旧代际丢弃仍有效。
- 保留有限周期复验以维持现有五秒名称时效；不能通过刷新旧时间戳伪造新观察。
- 若需持续标题区域画面比较，明确修订 ADR-050 与 ADR-053 的采集/调度约定，并实测资源开销。未核验前不宣称低耗或亚秒响应。

## 当前已确定与待核验

- 已确定：NSWorkspace 前台激活通知只解决回到微信，不能代替微信内部切换事件。
- 待实机核验：现有权限下 AX 是否可用、当前微信是否发出标题/选择/焦点事件，以及它们是否覆盖连续切换。
- 第一动作：受限 `test:app` 执行 90 秒仅元数据通知诊断，主 Agent 独占一轮、最多启动 1 次；不弹权限申请、不保存身份。若 AX 不可用，选择现有录屏权限下的标题区域变化检测，不把缺失通知当成功。

2026-10-15 [实际可视核验](visual-acceptance-20261015.md)已完成两场：当前进程权限和七类注册均通过，但用户实际聊天切换没有可用提示，第二场只有窗口移动／活动窗口事件，未证明标题或选中项通知覆盖。当前注册方式不接入正式调度；上述待核验项保留为历史准备范围，后续转向顶部区域变化检测的方案收束，不扩大为“所有微信均无通知”的结论。

## 验证接口

沿用已有 `/api/sync/foreground/observe` 与正式 ForegroundController 的公共状态/联系人接口，验证事件可以提前触发、在途仅合并一次、迟到结果不能覆盖新代际、真实失败保留退避、停止后零新观察。原生通知适配器只用合成信号/图像验证纯处理；真实通知覆盖率与端到端延迟必须来自有限实际场次。

## 可视化人工验收入口（2026-10-15 用户决定）

用户明确要求先做看得见的程序，由用户切换微信会话并自行验收。扩展现有独立诊断为非激活悬浮窗，经既有 `test:app` 单实例门禁运行，最长90秒，可提前关闭；不接入产品识别调度。

- 分别显示微信内部界面通知和进出微信的前台变化；辅助功能准入、可注册类别、最新通知、计数和相对时间实时可见。前台变化不能当作内部会话切换证据。
- 提供“这次切换有提示／无提示”按钮和即时反馈，人工反馈只记录用户观察，不由近期任意通知推导切换覆盖率。通知相对时间不是切换到显示的端到端延迟。
- 没有辅助功能权限、微信实例不唯一或注册失败时明确提示未验证；不弹权限申请、不读取AX文本、不截图／OCR、不读CLI／业务库、不调用模型或发送消息。
- 窗口不主动抢焦点；关闭或到期后注销监听、退出并由门禁回收自有进程。只保留固定类别、计数和布尔摘要。
- 自动回归复用诊断事件与人工反馈到可视状态／匿名摘要的公开边界，核验分类分离、未知输入、记录有界、关闭后停止和反馈不冒充证明。实际通知支持和人工体验由本入口另行记录，不能因程序构建通过勾选原01票。

## 顶部局部变化来源的实施决定（2026-10-15）

按 [ADR-057](../../architecture/adr/057-header-change-triggered-foreground-observation.md) 局部修订 ADR-050／053：辅助源初始化另用一张整窗内存布局帧，随后仅以4Hz上限采顶部窗口区域，不OCR，不输出图／摘要／坐标／名称。独立单窗过滤器忽略sourceRect，改用显示器仅包含目标窗口过滤器；首版拒绝非原点显示器、跨屏／离屏和未知布局。每源最长60秒、最多240次局部比较；同连接一源，停止确认退出后才允许替代。失败／提前暂停在连续许可内锁住，不能每轮观察重复初始化；正常到期仅在新鲜观察仍允许时续租。

宿主由SyncControlController已确认enabled状态及有效连接／范围门控，关闭开始或状态未知即停。变化只取消正常2秒空等，单轮在途最多合并一次；真实失败保留4／8秒退避，暂停／旧代际／停止清pending。周期复验、五秒名称时效及原认证HTTP和身份门保持。纯顶部像素、坐标拒绝、固定枚举子进程和公共控制器／认证HTTP用合成数据验证；实际窗口裁剪、额外帧数、资源和端到端延迟仍须同版正式包实机，不以编译或合成耗时勾验收。
