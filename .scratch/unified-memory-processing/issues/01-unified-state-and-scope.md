## 验收条件

- [x] 当前状态、阶段、单单位可靠计数、后续等待信息、动作资格与历史采用明确的范围合同；当前状态不依赖历史首屏是否截断。
- [x] 五态、优先级、空资料、读失败及旧失败不覆盖当前状态可经认证 HTTP 与真实页面验证。
- [x] 本人读取不宽查全部联系人任务，不要求选中联系人；另一 owner 和跨联系人读取拒绝。
- [x] 历史默认折叠且可分页，原始错误码与编号只在详情；迟到结果受联系人、选择代次和连接代次保护。

- [x] 必要元数据骨架明确轮次身份、可信任务归属和控制代次；只读查询不制造执行事实或伪造安全操作资格。
- [x] 真实页面测试必须保留原重复入口的覆盖，不把后台任务入口整体替换为空而掩盖问题。
- [x] 认证 HTTP＋隔离库验证真实投影和无写副作用；生产桥接页面验证单卡、范围、历史及读取错误；开发 App 用合成资料核对实际呈现。
