- [x] 仅依据可信归属、来源、意图及回执映射存量工作；不能把旧“已停止”推断为手动持续暂停或自动可恢复。

- [x] 新本人入口不再受旧 owner 宽查／反向恢复联系人合同影响；旧合同的兼容调用在调用方切换后退役。本人隔离已在 01 落实、旧执行门禁已在 02 落实，本票不承担补上此前缺失的隔离或暂停保护。
- [x] 复验全部状态、轮次、暂停、受阻、启动、来源删除、晚结果、历史和连接错误的组合，特别是重启恢复当前轮次后自动衔接后续资料；主界面只有一个当前入口。
- [x] 通过已确认三层验收记录整体验证与真实限制；旧规格与旧验收仍保持历史属性，不执行真实私人资料迁移、模型试跑、打包或远端操作。
- [x] 可信旧任务的接入只建立管理元数据和原回执关联，不搬迁或重写私人聊天正文，不修改已删除或已撤销决定。
- [x] 旧入口退役必须保留非记忆业务任务的合法功能；所有尚存内部执行路径继续遵守统一门禁。
