## 01：一个真实状态入口，联系人与本人分开

交付范围：建立统一管理的查询 Interface 及必要的范围控制元数据骨架，明确轮次身份、可信任务归属和控制代次的稳定合同，复用内部真实执行记录形成权威状态；实际记忆页经生产桥接读取同一合同，去除两套主入口并排展示。该票只交付查询与呈现，操作能力由 02 接入，不伪造尚不存在的安全动作。

- 当前状态、阶段、单单位可靠计数、后续等待信息、动作资格与历史采用明确的范围合同；当前状态不依赖历史首屏是否截断。
- 五态、优先级、空资料、读失败及旧失败不覆盖当前状态可经认证 HTTP 与真实页面验证。
- 本人读取不宽查全部联系人任务，不要求选中联系人；另一 owner 和跨联系人读取拒绝。
- 历史默认折叠且可分页，原始错误码与编号只在详情；迟到结果受联系人、选择代次和连接代次保护。
- 为后续显式控制提供稳定合同，不从旧 cancelled／failed／paused 猜测用户持续暂停；不能证明存量归属时保守说明。

独立验收：认证 HTTP＋隔离库验证真实投影和无写副作用；生产桥接页面验证单卡、范围、历史及读取错误；开发 App 用合成资料核对实际呈现。

## 02：一次暂停与继续控制整个范围

Blocked by: 01

交付范围：范围级暂停／继续从页面到持久控制意图、执行资格和原领域恢复动作完整生效。它控制该范围现有合法工作，不另行解决自动接纳新轮次的问题。

- 接纳暂停与推进控制代次在受控事务内完成，后续领取、模型出站和业务提交复验资格；所有能推进提取、主题或画像的旧执行入口也必须遵守同一门禁，不能等到 06 才防绕过。消息同步、来源删除等独立能力不受误限。
- 暂停保留已完成结果与原有阻碍；新增通知和重新读取不解除暂停，也不改写同步或 Skill 设置。
- 继续仅使用仍合法的阶段、原来源与回执；动作版本过期、重复请求和并发操作不重复建工作或覆盖新意图。
- 取消在途本地执行并有界排空；失去资格的晚结果不提交，已发生调用仍按原回执结算，不宣称供应商已停止计费。
- 受阻只有安全可恢复时才提供继续动作；本人操作不能定位并恢复联系人任务。

独立验收：通过相同认证 HTTP 和实际页面点击，覆盖领取前、模型在途、阶段切换、重复继续、旧版本响应及另一范围不受影响；新控制意图可在测试宿主重建后保持，启动自动恢复由 05 验证。

## 03：固定一轮资料，完整处理到画像

Blocked by: 02

交付范围：在统一继续或已接纳工作的执行路径中形成一轮固定目标，贯穿提取、核验保存、必要索引、主题和画像；使用相同状态入口展示整轮进展及合法完成结果。严格限定一轮，不扩展至新增资料的自动连续调度、启动恢复或存量接入；向 04／05 提供稳定的轮次、后续等待集合、恢复资格和预算合同。

- 本轮目标、来源与版本持久固定，新增资料记录为后续等待，不能追加本轮总数；保存合法已完成目标和阶段回执。
- 各阶段在预算与领域守卫内自动衔接，只有全部必要阶段完成或确定性无需执行，才能结束本轮。
- 不合格候选逐条拒绝、零新增及无需画像变更可正常完成，不伪造调用或结果；协议、来源及证据合同异常保持受阻。
- 主题已成功而画像失败时保留主题，恢复只补仍合法的画像阶段；删除、人工修正和版本变化使旧晚结果失效。
- 本人和联系人均沿各自合法输入推进，复用既有去重、来源隔离及模型回执，不改变抽取、关系判定或画像算法。

独立验收：用正式宿主、隔离库和供应商边界的合成结果驱动一次完整轮次，并经生产桥接页面观察阶段与完成；覆盖无结果、部分成功和受阻等分支。

## 04：新资料自动接续，受阻只阻止当前联系人

Blocked by: 03

交付范围：接上原已授权的新资料通知与调度入口，使轮次持续自动推进，同时把手动暂停和受阻落实为范围屏障。

- 合格新资料在原授权、来源和处理条件内自动进入后续待处理集合；运行中新资料不改变当前轮次。
- 当前轮次结束后自动接纳下一轮，通知重放、同消息多来源和并发通知不重复目标、工作或用量。
- 受阻范围继续保存和排队，不因新资料清除阻碍、刷新失败预算或形成失败任务风暴。
- 安全临时故障有限重试，耗尽后受阻；明确拒绝与系统／协议异常分类保持，不能放宽核验。
- 其他范围在原全局执行排他、前台优先和预算下可继续推进，不承诺或引入额外并发。

独立验收：经真实入队／通知和认证读取入口，观察固定轮次、自动接续、同一受阻范围与另一范围的状态；页面显示本轮可靠数量和后续等待信息。

## 05：重启后安全恢复未完成工作

Blocked by: 03

交付范围：为采用新生命周期记录的工作接入启动时安全恢复；该触发入口与 04 的新增资料通知入口独立，二者共用 03 形成的轮次执行与资格合同。

- 启动后只恢复原授权下、未手动暂停且来源、版本、预算和回执允许的未完成工作，无须打开记忆页。
- 正常退出、异常退出和重启保持明确暂停及受阻原因；无可信资格的工作不自动执行。
- pending／unknown 模型调用先核对原回执，不能盲目重发；成功阶段和已用额度保持。
- 当前固定轮次在重启后按资格安全续跑，后续等待集合准确持久保留，不重新接纳已完成目标；重复启动或恢复不会多执行。后续轮次的自动接纳由 04 负责，重启与自动接续组合在 06 验收，避免引入隐性依赖。
- 页面打开、读取、刷新和历史展开保持只读，不承担启动恢复职责。

独立验收：正式宿主与隔离库跨进程重建，核对成功阶段复用、暂停不解除、未知回执不重发及累计预算；开发 App 合成场景验证重开后的真实状态。

## 06：存量任务安全接入并完成旧入口收口

Blocked by: 04、05

交付范围：把存量工作的可信证据接入统一管理，并在全部调用方切换后收敛旧的宽范围和逐任务主入口；完成整份规格的用户可见闭环验收。

- 仅依据可信归属、来源、意图及回执映射存量工作；不能把旧“已停止”推断为手动持续暂停或自动可恢复。
- 有可信证据的旧未完成工作可从统一入口合法继续；无法证明安全的保留历史、说明阻碍，不刷新预算或猜测数据范围。
- 新本人入口不再受旧 owner 宽查／反向恢复联系人合同影响；旧合同的兼容调用在调用方切换后退役。本人隔离已在 01 落实、旧执行门禁已在 02 落实，本票不承担补上此前缺失的隔离或暂停保护。
- 复验全部状态、轮次、暂停、受阻、启动、来源删除、晚结果、历史和连接错误的组合，特别是重启恢复当前轮次后自动衔接后续资料；主界面只有一个当前入口。
- 通过已确认三层验收记录整体验证与真实限制；旧规格与旧验收仍保持历史属性，不执行真实私人资料迁移、模型试跑、打包或远端操作。

独立验收：隔离旧格式合成资料在受控结构升级后，通过统一公开入口展示与恢复，再在实际热更新 App 验证完整路径及资源收尾。
