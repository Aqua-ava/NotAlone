# 06 验证记录

状态：resolved。基线 `41ed6a92`；工作分支 `codex/memory-lifecycle-06`。

## 实现边界

- 迁移 127 只保存旧任务接入决定、原任务身份与一次性继续要求；不复制聊天正文，不改写旧结果或累计预算。
- 正式宿主在模型运行时和发布握手前接入缺少统一 scope 的旧工作。可信导入要求原导入确认、处理计划及非空来源目标；观察要求原计划、有效绑定目标；L2/L3 要求有效 job、设置代次及非空 manifest。
- 多个候选、无计划、空目标、旧 job 暂停或证据不完整只建立 `unresolved` 阻碍，不执行、不提供继续。旧 cancelled 仅保留历史，不推断为持续暂停。
- 唯一可信旧任务默认 blocked，必须用户显式继续；继续复用原任务和控制代次，不重新解析私有正文、不刷新预算。未明确继续的轮次不参与启动自动恢复。
- 启动恢复当前轮后由正常 Worker 自动完成并接纳后续轮次；已 queued 或 `verifying/running` 且有 pending 步骤的合法任务都会返回唤醒身份。
- 旧 `/memory-processing`、`/resume` 与 owner 宽查入口返回 404；通用任务面仍列出真实记忆任务，但不再提供第二套 stop/recover 动作。非记忆任务动作保持。
