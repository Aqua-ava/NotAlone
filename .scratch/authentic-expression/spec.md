# 真实表达与关系感知第一版

Triage: ready-for-agent

规格状态：第一版范围与测试接缝已确认，2026-10-11 发布；尚未实现，拆票提案待确认。

## Problem Statement（用户问题）

候选可能语气自然却新增用户未表达的事实、情绪、经历或承诺。既有原型出现“好久没联系”“突然想到你”等无依据前提，引用 ID 合法也未能证明正文被支持。只用采用率、结构化成功率或词面禁用表不能验证真实表达。

## Solution（解决方案）

第一版落实当前意图优先与无依据扩写约束，提供用户主动保存、可查看删除、联系人隔离的低权重表达样本，并建立独立的合成语料及可审阅输出评测。生成可以比历史表达更自然或更理想，但不替用户塑造人格、改变立场或承诺关系结果。

## User Stories（用户故事）

1. 作为用户，我希望当前草稿与明确意图优先于历史习惯、旧记忆或 Skill，以便表达本次真实意愿。
2. 作为用户，我希望没有依据时不替我增加经历、情绪、称呼、共享记忆或承诺。
3. 作为用户，我希望旧资料仅被当作过去的证据，不自动推出现在仍然如此。
4. 作为用户，我希望系统可改善措辞、幽默和表达结构，但不将“理想回复”解释为取悦对方或提高回复率。
5. 作为用户，我希望联系人心理、动机与沉默的原因保留不确定性，不被保存为事实。
6. 作为用户，我希望明确选择最终文字作为表达样本，而不是复制或选择候选后自动被学习。
7. 作为用户，我希望查看并删除表达样本，其他联系人不能使用该样本。
8. 作为用户，我希望样本只影响说法，不把样本里的事实、情绪或一次性状态当成本次事实。
9. 作为用户，我希望本次要求与样本冲突时以本次为准，没有样本也能使用回复功能。
10. 作为用户，我希望看到质量评测的失败例与剩余风险，不把结构化成功或合成回归当作模型质量保证。
11. 作为用户，我希望多条候选作为整体不产生新的承诺或矛盾，而不只逐句检查表面措辞。

## Implementation Decisions（实现决定）

### 保真边界

- 当前明确意图和用户原句优先；历史表达、联系人资料、Skill 只在不冲突时提供依据或表达参考。用户允许探索措辞不等于允许增加事实、情绪或长期目标。
- 区分有来源事实、用户本次声明、条件性建议与未知；候选及其解释都要遵守该边界。旧事实不自动成为现状，联系间隔不能从“没有读到消息”推出。
- 来源引用存在只证明引用合法，不证明语义蕴含。结构、范围、来源存活及明确输入契约由确定性程序校验；不声称规则能自动识别所有语义编造。
- 对模型输入和输出契约落实保真要求，已检测的越权范围、失效来源或无效结构拒绝返回为有效结果；语义保真通过下述独立逐例评价暴露缺陷。不能仅靠拉黑旧实验词句或预置完美合成响应宣称解决问题。
- 暂不加入第二个模型自动审查、自动重写或无限重试；是否值得增加有界语义复核，需要独立比较延迟、成本与误判的证据。

### 主动保存的表达样本

- 沿用既有“用户主动保存最终文字”的产品方向；提供明确保存、查看、删除操作，属于 owner/contact，记录手动保存来源及必要的候选/消息引用。不能从选择、复制、同步事件自动保存。
- 保存样本是用户确认文字可以作为表达参考，不是系统证明已发送。没有正向发送观察时发送状态仍为未知，不要求扩大微信读取来证明。
- 仅在该联系人范围作为低权重风格参考，按现有样本数量和输入预算选取；不参加方向探索，不覆盖本次明确要求，不写成关系记忆或人格画像。
- 用户手工输入可作为手动来源；从候选/消息衍生的样本保留真实来源依赖，不通过复制重新标记成无来源手动输入来逃避删除。
- 删除样本或依赖来源后，清理相关派生上下文、缓存与恢复副本，不能继续召回；源消息仍有效时，删除样本本身不删除独立聊天资料。使用记录需能说明本次选取了哪些样本。
- 当前代码未发现完整样本保存链路，不能把现行架构中的保存流程当作已实现；本规格要求在公开入口完成生命周期。

### 评测协议

- 新建合成场景及逐例审阅表，明确当前意图、可用事实、未知项、允许变化和不可新增内容；预期答案与场景标签不发给生成模型。
- 覆盖意图保真、事实/经历、情绪、承诺、动机推断、时效、联系人专属表达、样本冲突、无历史和多条表达一致性。包括同句不同前文的成对对照及无依据开场白的独立变体。
- 旧原型失败例只作开发/回归集；独立保留集不得用于改提示后又作为未见数据宣称通过。记录数据版本、开发/保留划分、提示与模型配置、输入范围、输出、耗时和调用次数；失败/超时不删除、不按零成本处理。
- 每例分别记录意图是否保持、是否存在无依据事实/承诺/心理归因、表达自然度和关系适配；硬性保真失败不能被平均自然度分抵消。输出分母、缺失项、失败例和审阅依据，不只给总分。
- 硬边界目标为保留集无已发现的越权或无依据事实/承诺；通过有限样本不等于普遍安全。自然度和用户相似度没有用户审阅证据时写未验证，不擅自给“像本人”的结论。
- 首轮只准备语料、评分规则与离线评测入口，用受控合成响应检查评测流程。真实模型对照需另定模型配置、合成数据范围和调用预算后执行，本规格不授权新的外部调用。

## Testing Decisions（测试决定）

用户已确认公共页面操作 → 后端 HTTP → 隔离 PostgreSQL，使用合成联系人、消息与可控模型；在应用入口验证范围和删除，在输出评价入口逐例审阅语义。公开保存样本→查看→生成参考→删除→重试恢复的路径使用真实业务存储。

确定性测试覆盖本次意图与样本冲突、跨联系人样本拒绝、手动保存而非复制触发、发送状态未知、样本/来源删除与生成并发、无样本退回正常流程及有界输入。脚本响应只能证明数据和控制契约，不能证明真实模型遵守意图。

评测程序使用故意含错误的合成输出验证失败可见、分母与字段完整、报告不把未知当通过；不写一组只镜像实现的全绿测试。模型语义、自然度及长期影响分开报告。沿用现有风险提醒，不在本轮新造未成年人或危机场景专项策略。

## Out of Scope（排除项）

热梗资料包/外部趋势 Tool、自动风格学习、自动人格推断、自进化、长期依赖或后悔研究、第二模型自动复核、自动发送、OCR、多模态识别、外部模型评测调用、真实资料导入、未经授权的数据收集。原草图这些研究议题继续保留，不因本规格发布标为完成。
