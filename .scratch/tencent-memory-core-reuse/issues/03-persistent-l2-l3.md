## 实现记录

实际 L2 SDK 现在明确接收旧主题，并要求重整全文及显式 replaces；生产服务逐项拒绝命中旧主题却未替换的提案，避免遗漏字段后静默拼接。历史不支持场景上下文的合成适配器保留兼容，不作为新流程证据。

L3 读取同范围、同设置周期、未撤回且完整底层 manifest 仍有效的已有画像；外发只保留正文、时间限定和必要引用。输入携带变化主题版本，输出替换一份逻辑画像。全部 L2 版本与整理合同不变时复用已有画像，跳过模型。来源失效或纠错保护不允许旧画像回流。

验证：4 个新增 HTTP→隔离 PostgreSQL 用例通过，覆盖旧画像更新、无变化零 L3 调用、隐含来源删除、遗漏替换协议。原完整画像模块 23 例中 2 个纠错物理删除断言失败；在 HEAD 旧实现同样复现，未将它们算作通过或扩展修复。独立 Standards / Spec 复核无新阻塞。真实模型质量与完整预览由 04 继续。
