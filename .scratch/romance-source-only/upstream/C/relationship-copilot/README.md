# relationship-copilot

恋爱/暧昧关系的**一站式入口**：读聊天 → 后台判阶段 → 像朋友拿着聊天记录现场拆一样，先给能直接发的一句，再解释为什么，再教下一步怎么升级。

## 它编排了什么

| 步骤 | 调用的模块 | 产出 |
|---|---|---|
| 判阶段 | `relationship-stage-assessor` | 后台得到分数评级、证据、反证、风险；前台说 0/10/20/30/40/50 分、friend zone、减分信号、下头 |
| 卡点推进 | `references/human-progression-playbook.md` | 朋友框架/工具人位/陪聊/过度推进的原味诊断和升级打法 |
| 给话术 | `tong-jincheng-perspective` | 可直接发送的一句 + 具体依据 + 对方不同反应的接法 |

## 怎么触发

```
> 帮我看看这段聊天，我们到哪一步了，下一句该怎么回
> 他最近有点冷淡，我该怎么说
> 这条怎么回不尴尬
> 景辰怎么看
```

贴上聊天/截图，标一下谁是你、谁是对方，说一句要啥。默认不会先甩理论表，会先给能发的消息，再用你给的具体话解释判断。

## 输出档位

- **快速档（默认）**：可直接发送 1 条 + 2-3 条具体依据 + 下一步升级动作。
- **完整档**：阶段判定 + 证据 + 反证 + 缺失数据 + 主推话术 + 接法，但仍然少用表格。
- 随时切换：「只判阶段」「给我三条候选」「景辰怎么看」「别用童锦程口吻」「按我的语气改」。

## 唯一底线

成功推进是核心，不做温吞分析。底线只拦截违法、胁迫、明确拒绝后继续施压、羞辱打压、查岗控制；除此之外，情绪杠杆、抽离、性张力、朋友框架都可以直给。

## 诚实边界

- **判阶段** = 研究蒸馏（概率框架），默认转成人话。
- **话术** = 童锦程视角的策略内核（街头智慧，**非研究背书、非本人**），默认转成正常微信语气。
