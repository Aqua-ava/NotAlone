# 显式v4的事项指称未知与归属说明

Triage: ready-for-agent
State: resolved

## 问题与目标

[原21当前v4基线](../grounded-evaluation/reference21-complete-v4-result-20261016.md)中，A04已显式选择`other_unresolved`，但程序只能渲染泛称“其他未决解释”，不能表达冻结参考要求的“所指事项无法由本窗识别”。A01的原作者引句完整保留第三人资料，却被V无据拒绝；A05同时存在E漏标物品归属／代词未知及V非法位置提案。旧输出、正式审核和关闭不重算，A05没有正式审核，不能事后补签。

本切片只补一个显式v4歧义表示，并澄清v4模型可见的既有归属原则。证明适用性收束另写设计，不在本片实施；非法proof仍严格停止，不扩展借车或任意引句证明。

## 实现决定

1. 仅`grounded-v4`新增封闭码`matter_reference`，含义是原句所指事项在本窗口无法唯一识别。它不同于人物身份、物品／地点归属、借贷方向、时制和阶段未知；不能用`other_unresolved`替代应明确选择的事项指称未知。
2. 模型必须显式选择该码并置`unresolved=true`。程序不按关键词、case ID、Gold或句式补码，不生成事项内容、类型、具体人物或秘密正文。明确事项不应额外标未知；该语义选择仍须独立来源审核。
3. 固定解释为“所引原句中的事项指称在本窗口无法唯一识别；保留未知，不补事项内容或类型。”，完整附带实际原引句与既有依赖。沿现有固定顺序、码并集、8400字符单条预算、最低置信度与风险传播；超限整窗失败，不截断。原七码及编译语义保持，新版最多八码／九条说明。
4. 只追加显式v4 E指导：逐项区分出借施事、接收者、物品所有者和代词指称；施事／接收角色或亲属性别不证明唯一所有者或代词身份。没有来源唯一指称时按实际未知显式选全已有`object_ownership`、`entity_identity`等码；角色明确不因此变成未知，不能机械见借用就补码。
5. V作者包装原则的精确候选文案及后继显式接入记录在设计中。现有V提示是所有模式共享，未经单独确定接入边界前不改其字节。保留原四槽独立来源判断、一次V、只降不升、nullable/proof2、可信链和全部停止规则。
6. v2／v3提示、schema、编译、生产默认、来源参考／Gold、阈值、默认空放行表和旧记录不变。新增码旧版拒绝。将来真实评测必须重新冻结实际v4提示／schema／源码，不把旧固定21／140合同或本地绿灯当作质量收益。
