## 验收条件

- [ ] 前置及其传递依赖均通过后，才在正常开发入口启用官方持久化装配，稳定业务目录不会被宿主退出清理。
- [ ] 零 HTTP 准备和正式出站按同一真实派生请求计量，包含恢复历史、工具结果、系统提示及控制字段，不能用空会话预检低估预算。
- [ ] 接近预算提醒，硬上限保留回看并要求显式新开；不自动摘要、静默截断或改变模型配置、输出契约及总调用预算。
- [ ] 完整公开接口与桌面矩阵覆盖切联系人、生成中回看／新开、旧 scope 和连接回执、同键并发及单写者。
- [ ] 正常开发小窗实际完成连续生成、退出后恢复、历史回看／继续及新开提示；删除验证使用隔离合成资料，最终消息仍由用户亲自发送。
- [ ] 同材料对照记录应用准备、复验、保存及模型阶段，统计查询、物理调用和输入量，并报告完整墙钟时间，不把局部计时当总时延。
- [ ] 合成验证与正常配置下的有界真实模型效果分别报告；真实调用遵守既有授权范围及问题预算，不扩大样本追求有利结果。
- [ ] 相关模块、类型检查、有限时全量和 Standards／Spec 审查通过，清理测试自有实例与临时副本，并记录实现状态及未验收项。
- [ ] 不打包、不推送远端、不发外部聊天消息，不自动转换或迁移真实历史资料。
