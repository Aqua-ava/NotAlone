# 02 — 统一回复与改写输入

Type: task
State: open
Triage: ready-for-agent

**What to build:** 在已验证联系人范围内建立一个统一 Reply 入口，同时支持“针对目标消息按表达方向回复”和“使用用户原句进行改写与润色”。两种输入都经过 Context、Runtime 和 Store，返回已保存、带依据、可编辑但不会自动发送的候选。

**Blocked by:** 01 — 外层流程验证联系人与会话范围。

**Status:** ready-for-agent

- [ ] 目标消息加用户确认表达方向可以生成候选，并保留目标消息与方向的请求语义。
- [ ] 用户原句加可选的一次性改写要求可以生成候选，并默认保留原意、进行基础润色。
- [ ] 两种输入共享同一个 Reply 入口和联系人范围校验，不接受昵称或窗口标题替代已验证范围。
- [ ] 一次性改写要求只影响当前请求，不写入 Memory、长期偏好或 Skill；普通改写不默认检索长期关系资料。
- [ ] 候选在 Store 成功保存并通过依据、引用和范围校验后才返回，系统没有外部发送能力。
