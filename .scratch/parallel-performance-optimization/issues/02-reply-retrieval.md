# 02：回复依据范围内批量读取与复验
Triage: ready-for-agent
State: claimed

## What to build
小批依据只读取所需ID，减少同一发送边界的重复复验，同时保持删除、纠错及版本失效。

## Blocked by
None (can start immediately)。

## Acceptance criteria
- [ ] 联系人/本人记忆、消息和待确认候选保持原范围、有效期、状态与来源合同。
- [ ] 按明确ID集合读取，不再为每条依据取全量记忆；合成大记忆池取回行数随依据规模。
- [ ] 生成前后不同时间边界仍复验，来源/修订/授权变化和迟到结果均拒绝旧依据。
- [ ] 同一发送边界只做必要复验；内容、排序、引用与原基线一致。

## Comments
用户已授权此拆分。遵循同目录规格；执行会话独占本任务文件与其责任代码，主会话负责集成和真实桌面。
