## What to build
小批依据只读取所需ID，减少同一发送边界的重复复验，同时保持删除、纠错及版本失效。

## Blocked by
None (can start immediately)。

## Acceptance criteria
- [x] 联系人/本人记忆、消息和待确认候选保持原范围、有效期、状态与来源合同。
- [x] 按明确ID集合读取，不再为每条依据取全量记忆；合成大记忆池取回行数随依据规模。
- [x] 生成前后不同时间边界仍复验，来源/修订/授权变化和迟到结果均拒绝旧依据。
- [x] 同一发送边界只做必要复验；内容、排序、引用与原基线一致。

## Answer

实现提交：`4e7fa994`。联系人／本人记忆、待确认候选的 ID 集合下推到 SQL；历史导航只读所选实际版本，保留完整来源检查及历史输入顺序。消息复验集合与既有消息授权集合取交集。每次 `validate_current` 内按证据轨、历史权限分批读取并复用结果，不跨阶段缓存。
