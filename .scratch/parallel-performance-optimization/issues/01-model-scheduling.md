Triage: ready-for-agent
State: resolved

## What to build
模型退避和工具轮间让位于前台，同时保留实际在途互斥、期限、来源核验及计费。

## Blocked by
None (can start immediately)。

## Acceptance criteria

- [x] 实际在途请求仍互斥，调用方超时不冒充SDK取消；停止和来源撤销阻止下一请求。
- [x] 绝对期限、完整追踪、逐物理请求台账、核验预留与重试上限不变。
- [x] 合成慢模型和退避案例提供前后等待证据；相关回归、两类裁决和整理路径通过。

## Comments

## Answer
Direct 通过显式逐请求接缝领取许可，重试退避在许可外以停止事件及来源／租约复验中断；旧合成及旧维度运行时保留整次单请求兜底。场景／画像 SDK 每轮请求领取许可，`_call` 仅为声明能力的 Adapter 开启该路径，避免新旧包装重复领取。前台仍持有整次生成许可。

已开始的 SDK 请求直到返回／抛错才释放，外层超时仅放弃结果；排队、轮间和传输仍共用原绝对期限。未改变重试、五轮工具上限、实际传输计费及核验预留。补齐 Direct 重试前的最小台账结算，成功不再遗漏早先失败请求，沿用完整追踪及来源删除链。
