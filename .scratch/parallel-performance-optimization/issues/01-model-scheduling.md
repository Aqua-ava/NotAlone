## What to build

## Blocked by
None (can start immediately)。

## Acceptance criteria
- [ ] 退避期间前台可开始；工具物理请求之间有前台需求时先执行前台。
- [ ] 实际在途请求仍互斥，调用方超时不冒充SDK取消；停止和来源撤销阻止下一请求。
- [ ] 绝对期限、完整追踪、逐物理请求台账、核验预留与重试上限不变。
- [ ] 合成慢模型和退避案例提供前后等待证据；相关回归、两类裁决和整理路径通过。
