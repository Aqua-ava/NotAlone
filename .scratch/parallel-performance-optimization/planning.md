# 并行执行与集成
Triage: ready-for-agent
State: open

- 用户授权：三个会话并行实现，主会话统筹、合并与验证。
- 共同基线：创建会话前最新 main 的规划提交；不得从原工作区旧分支派生。
- 01 模型调度：无阻塞；独占模型许可、提取重试和整理物理请求调度。
- 02 回复检索：无阻塞；独占回复上下文、发送前复验和检索仓储。
- 03 桌面交互：无阻塞；独占 desktop 输入状态、IPC 和 Skill 刷新。
- 集成：Blocked by 01, 02, 03；由主会话串行合入 main，执行组合验证和 Standards/Spec 两轴审查。
- 共享文件：规格、planning、architecture/current/ADR 由主会话维护；执行者只在自己的任务单记录结果，必要修订先报告。
- 桌面占用：当前原工作区 npm run dev 运行中，三个执行会话不得另起真实 App 或操作微信；主会话负责协调验收。
- 数据边界：只用合成数据与随机_test库，禁止读取真实聊天/.env、业务库迁移、真实模型外发、打包及 push。
