# 本机 App 首用与资料生命周期

Triage: ready-for-agent
State: open

> 2026-10-23 用户确认 Q1–Q14、完整方案及文档发布。本轮仅整理规格和票据，不写代码；设计已确认，实施及完整验收未完成。

## 问题与目标

下载 App 后通过界面完成本机准备、微信授权与模型配置；用户无需安装 PostgreSQL、Conda、填写运行路径或执行终端命令。保留本地数据库方向，打通新安装、原库升级、重开与恢复，不把建库成功当作产品交付。

## 已确认行为

1. 保留 PostgreSQL，App 自带引擎和可信迁移规则，不携带开发者资料。确认为首次安装且不存在既有配置／资料时创建空库，后续沿用原库。
2. App 检测环境并准备经验证的微信组件，引导必要授权。不把工具准备等同账号确认、会话可读或读取授权；安全可行接入路径先核实，不重复此前被中止的特权路线。
3. 默认仅用户选中的会话，列表不预选；保留显式授权全部现有及未来私聊的路径。稳定账号和联系人身份必须核验，授权前不读正文，不凭昵称猜归属。
4. 首次历史仅指本机微信可读取的私聊文字，不承诺恢复其他设备缺失消息。非文字沿用占位，不新增媒体正文读取。
5. 授权后进入主界面，按联系人显示进度、覆盖状态和不完整原因；当前联系人优先但不能饿死其他联系人。历史未完成阻止生成，明确不完整后经用户确认可用已有部分，警告保留在界面、后端与请求依据。
6. 消息同步与关系提取分层。模型使用用户自己的 API Key，界面配置和检查连接；未配置模型可先授权同步，但不能发起模型提取／生成。必要文本出站仍须明确用途与授权，本机存储不代表完全离线。
7. 退出 App 或关闭总开关停止读取，重开仅在有效授权与开关允许时继续；撤销／删除排除不恢复。旧增量授权不等于历史授权，按 ADR-100 另行确认，拒绝仍保留原增量。
8. 普通升级在原库逐版本应用缺失可信迁移，成功版本不重放、不改写历史 SQL 或账本。中断后核验并继续；未就绪时阻止业务同步和生成。
9. 临时失败提供安全重试；漂移、无可信基线、损坏或版本不兼容时保留资料并停止写入，提供脱敏诊断及支持入口，不换空库、不自动降级、不承诺万能修复。
10. 删除程序不等于删除资料；重装复用仍在本机的原资料。彻底删除须明确范围及二次确认，沿用来源、联系人、账号及历史副本删除规则，不用删目录绕过归属核验。
11. 同机重开、系统重启、更新和重装属于范围。普通启动不强制备份、不搬库；历史副本的清理责任保留。

## Implementation Decisions

- 决策见 [ADR-101](../../architecture/adr/101-local-app-first-use-lifecycle.md)。保留 ADR-061 来源／权限要求、ADR-066 原库更新和 ADR-100 历史契约；局部修订 ADR-065 的交付范围并补齐 ADR-095 的默认单会话首用分支。
- 复用现有 `desktop/src/main/startup/managed-runtime.ts`、`startup/diagnostics.ts`、`setup/controller.ts`、`setup/wechat-controller.ts` 与后端迁移／同步／回复服务，不重复建设业务库或同步引擎。
- 分别表示运行时、数据结构、工具、账号证据、授权、历史覆盖、模型及关系提取状态，不能以一个 ready 替代其他状态。
- 组件获取／校验、只读账号探测、列表枚举、授权提交和正文读取分别设边界。上游列表可能夹带摘要：取得必要列表访问同意后才枚举，摘要丢弃，不保存、不外发；单会话选择不得预存全部正文读取授权。技术上无法满足时记录阻碍，不自行放宽。
- 固定组件来源、版本、摘要、完整许可和无开发环境依赖清单。票01先核实可行路线；新的高风险选择返回决策，不因产品目标获得任意提权、重签或重启微信的权限。
- 诊断导出采用字段白名单，不含正文、联系人身份、密钥、原始截图和可识别路径，不自动上传。

## Testing Decisions

- 使用独立合成 `_test` 库检查首次建库、原资料升级、中断、重复启动、并发、损坏、较新版本拒绝和重装复用，核对业务资料与既有账本不被改写。
- 页面及后端检查两种范围、取消、账号变化、授权幂等、权限拒绝、不兼容工具、模型缺失、覆盖警告、二次删除和诊断脱敏。模型连接探测用合成最小输入，不用用户聊天试连。
- 真实微信沿用原票08及用户明确范围，不发送外部消息；合成、开发App、真实模型、真实微信分别记录。
- 最终以同一可追溯安装产物在无开发环境的受支持机器验证：新装到生成候选、旧资料升级、中断恢复、停读与重开、重装和旧版本拒绝。开发机隔离目录、构建、签名均不能代替。
- 日常只用 `npm run dev`，先 `dev:status` 复用实例。本轮不授权打包、运行安装包、修改发布门禁、公证或发布；最终票等待用户明确发布任务和目标机器。

## Out of Scope

云端资料与账号、多设备同步、换机迁移、模型代付计费、自动降级、通用自动修复、普通启动强制备份、媒体正文及外部自动发送。不承诺新增端侧加密，保留本机库未加密提示。
