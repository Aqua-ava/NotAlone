# 全部微信私聊的持续同步范围

> 决策：用户已明确批准；[ADR-089](../../architecture/adr/089-all-private-wechat-sync-scope.md)修订 ADR-030／087 的逐会话授权限制。
> 实现状态：已实现，相关自动验证及开发版桌面验收通过；已按用户明确授权开启实际全部私聊范围。全量测试的限制见下方记录。

## 用户行为

同步设置提供“仅所选会话”和“全部微信私聊（包括以后新增的会话）”。默认仅所选；用户明确开启全部后，同一微信账号现有未绑定私聊及以后新增私聊自动建立联系人与有效绑定，继而参与文字增量同步，无需逐个确认。总开关独立控制读取；切回仅所选保留已有绑定，仅停止自动纳入。顶部搜索仍是唯一联系人搜索入口。

全量范围指会话集合，不是全量历史。新绑定从 baseline 开始，已有绑定沿可靠游标恢复；不读取群聊或媒体正文，不新增外部发送能力，不扩大模型用途。

## 公开边界与实现职责

- API：`POST /api/sync/scope` 严格接收 `{mode: "selected" | "all_private", confirmed: true}`；owner 和账号来自可信运行上下文，不接受调用者注入。同步状态公开 `sync_scope` 与 `sync_scope_failure_code`，保存失败不能显示已启用。
- 持久化：按 `owner_id + channel + account_scope` 保存范围；无记录及升级默认 `selected`，重启保留明确授权，切换账号不继承。撤销／删除留下无正文排除记录，只有明确的单会话确认可以恢复。
- 后台引擎：总开关开启且范围为 `all_private` 时周期发现当前账号私聊。唯一有效稳定身份复用原联系人；无身份则创建独立联系人及绑定。同名不合并，冲突不改绑，重复发现及并发重试不重复创建。范围变更、停读与事务提交须协调，不能在关闭后继续自动纳入或读取。
- 桌面控制器／视图：显示并更新后端权威范围、失败和现有总开关状态；刷新与重启不默认发送授权请求，失败不乐观保留扩大范围。授权后刷新联系人列表，当前辅助对象不因批量加入而自动切换。
- 删除与来源：复用原来源、消息、记忆及删除链；排除记录不保留正文，避免后台自动复活被删除的联系人或资料。

## 必须验证的行为

1. 无记录／旧库升级默认仅所选，明确授权后持久保存，进程重建仍生效；不同 owner／账号隔离。
2. 当前未绑定私聊全部按稳定身份纳入；之后新增私聊无需人工操作也能被周期发现。
3. 唯一已有身份复用，同名不同身份独立，重复事件／发现幂等，稳定身份冲突明确失败且不串资料。
4. 总开关关闭与退出停读并停止自动纳入；重新开启恢复。切回仅所选停止新纳入，已有绑定和独立游标保留。
5. 撤销或删除后的会话不会被周期发现、重启或重复全部授权重新加入；重新单项确认可以恢复。
6. 新绑定 baseline、可靠游标与消息去重不回归；群聊、媒体正文、名称匹配与发送不成为授权旁路。
7. 桌面显示权威模式；错误请求和保存失败可见；顶部唯一搜索与主／小窗当前联系人保持。
