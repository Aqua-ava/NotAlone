# 03: Skill 读取失败时继续回复

Triage: ready-for-agent
State: resolved

**规格：** [DSH 回复 Skill 接入规格](../spec.md)

**Blocked by:** 02 自动选择并加载回复 Skill

## 要实现的行为

当模型选中的 Skill 暂时无法读取时，如果本次联系人资料和授权仍有效，回复助手不使用该 Skill 继续生成，并显示“回复策略暂不可用”。如果资料或授权失效，则停止生成。

## 验收标准

- [x] Skill 暂时缺失、读取失败或不可用时，在合法且安全的条件下继续生成不使用该 Skill 的候选，并显示“回复策略暂不可用”；未实际使用 Skill 时不显示其名称。
- [x] 后续模型请求、持久会话和结果不包含已失效 Skill 正文或失效工具结果；不能保证时拒绝使用失效内容，不靠提示词假装已清除。
- [x] 只有 Skill 不可用走此降级；联系人资料失效、授权撤销或其他阻止生成的错误仍停止，不借降级绕过业务边界。
- [x] 为继续生成所需的模型调用、取消、超时及用量保持有界并记录实际请求，不发生无界重试，也不在出站前跳过资格复验。
- [x] 通过正式回复入口与合成模型验证失败提示、无 Skill 候选、上下文和记录；覆盖读取前失败、部分读取后失效、联系人授权撤销、取消及持久会话恢复。
- [x] 用隔离数据在桌面热更新实例检查提示和回复交互，不读取真实用户聊天或发送外部消息。
