# 02: 自动选择并加载回复 Skill

Triage: ready-for-agent
State: resolved

**规格：** [DSH 回复 Skill 接入规格](../spec.md)

**Blocked by:** 01 受控发现与读取回复 Skill

## 要实现的行为

用户生成候选回复时，模型通过 DSH 官方 Skill 工具判断是否需要使用一个可用 Skill；界面显示实际使用的 Skill 名称，不再要求用户手动选择。没有合适的 Skill 时仍可正常回复，用户继续自行查看、编辑和发送候选。

## 验收标准

- [x] 正常回复入口无需手选 Skill；模型在当前范围内自动选择零或一个有效版本，没有适用 Skill 时可生成回复。
- [x] 使用正式 DSH registry、作用域及 `dsh-tool-skill`，只把业务层允许的候选提供给模型；直接使用的依赖、插件及其生命周期按锁定版本核验。
- [x] 同一回复最多实际读取一个 Skill；明确区分选择、正文读取和发送给模型的事实，结果仅在实际使用时显示正确名称，未使用不显示。
- [x] 保留显式版本接口的既有兼容或管理用途，并与自动选择共享资格校验；不得因 Skill 增加通用文件、代码执行、网络或外部消息发送能力。
- [x] 模型调用和工具步骤有明确次数、时间及输入输出预算，支持取消；每次物理出站和结果提交前复验联系人资料、授权、来源及有效 Skill 修订。授权撤销、来源删除或版本失效时拒绝迟到结果。
- [x] 追踪实际输入及来源，限制和清理持久会话／缓存中失效的目录、正文及工具结果；会话恢复不能重新使用失效内容。
- [x] 以正常业务入口、正式 profile 和合成模型验证自动选中、无需 Skill、单次上限、名称展示、联系人隔离、版本失效与取消；桌面热更新实例验证界面和可编辑候选，不发送外部消息。
- [x] 本任务中的 Skill 读取错误可先按受控错误结束；错误后的继续生成和提示由任务 03 交付。不得让失效内容进入模型或提交。
