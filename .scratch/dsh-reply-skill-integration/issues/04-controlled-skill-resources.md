# 04: 按需读取 Skill 辅助资料

Triage: ready-for-agent
State: resolved

**规格：** [DSH 回复 Skill 接入规格](../spec.md)

**Blocked by:** 02 自动选择并加载回复 Skill

## 要实现的行为

当已选 Skill 需要补充说明或静态模板时，回复助手可按需读取该 Skill 有效版本中的允许资料，并继续生成候选回复。辅助资料只提供策略文本，不给模型任意文件读取或执行权限。

## 验收标准

- [x] 只有当前已实际加载的 Skill 可以提供其版本清单内的 `references/` 或允许的静态 `assets/`；不读取其他 Skill、任意本地文件、脚本或外部 URL。
- [x] 每次资源读取复验账号、联系人、启停、来源、有效版本、路径、符号链接、大小和内容完整性；返回的实际内容绑定同一有效版本并纳入本轮模型预算。
- [x] 资源或来源在读取中发生替换、撤销或删除时拒绝失效结果；取消、迟到结果、目录缓存和恢复会话不得重新引入旧内容。
- [x] 实际读取的资源、版本与来源记录支持回看和删除；不得把资源的物理路径暴露为通用文件访问能力。
- [x] 正常回复入口使用合成 Skill 和合成模型验证正文后按需读取资源并生成候选；覆盖未加载正文、第二个 Skill、未列出路径、遍历、链接、内容替换、停用和跨联系人隔离。
- [x] 桌面热更新实例使用隔离数据检查含辅助资料的候选和实际 Skill 展示；不读取真实聊天或发送外部消息。辅助资源失败的处理遵守任务 03 最终形成的失败规则；在该任务尚未完成时，安全地结束本轮并保留清晰错误。
