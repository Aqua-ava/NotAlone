# 02：失败任务的业务恢复入口

Triage: ready-for-agent
State: open
Type: task
Blocked by: 01

**What to build:** 用户通过 HTTP 或 CLI 明确恢复指定联系人已失败的原任务，并能继续执行至完成。

- [ ] 自动重试耗尽的失败任务通过公开 HTTP 恢复，复用原任务、已成功步骤不重复执行。
- [ ] CLI 提供对应显式恢复入口，遵守现有预检查和全局串行规则。
- [ ] 跨用户、跨联系人、缺失、未失败的任务，以及来源已进入删除路径的导入任务不能被恢复；既有删除任务遵守自己的来源状态许可。
- [ ] 错误和状态只显示必要元数据，不复制正文；不新增自动重试预算或隐式重建任务。
- [ ] 公开接口先验证失败，再完成最小修复和相关回归，双轴审查并独立本地提交。
