# 01 — 记忆提取接缝与证据契约校验

**What to build:** 记忆提取模块的核心接缝：给定一个联系人的消息窗口，模型运行时（fake 驱动）返回结构化事实候选，确定性外壳校验证据契约——引用的消息 ID 必须在窗口内、事实文本非空、分类为五类之一、带置信度与风险标记——合法候选通过、非法候选拒绝，整体不可解析时报明确的提取失败。

**Triage:** ready-for-agent
**State:** open
**Blocked by:** None — can start immediately

- [ ] 提取模型运行时接缝定义（输入消息窗口，输出结构化候选列表），schema 采用强化模式（全字段 description、禁字符串数组）
- [ ] 证据契约校验：窗口外引用、空文本、非法分类、缺置信度的候选被拒且不进入结果
- [ ] 每条合法候选含事实文本、分类、消息引用、置信度、风险标记、可选有效期
- [ ] 输出整体不可解析时返回明确的失败结果（可重试语义），不静默
- [ ] fake model 单元测试覆盖合法、逐类非法、整体失败路径，只用合成数据
- [ ] 模型经既有 DeepSeek 构造入口注入（本片不调真实 API）
