# 01 — 提取接缝、证据契约与主体标注

**What to build:** 记忆提取核心接缝：消息窗口经模型运行时（fake 驱动）返回结构化事实候选，确定性外壳逐条校验证据契约——引用消息必须在窗口内、文本非空、五类分类/三值主体/受控主题合法、置信度必填——合法候选通过、非法拒绝；prompt 含上下文语气理解要求与负例示范；整体不可解析返回明确失败。

**Triage:** ready-for-agent
**State:** open
**Blocked by:** None — can start immediately

- [ ] 提取运行时接缝与强化 schema（全字段 description、禁字符串数组、低温、function calling 路径）
- [ ] 候选含事实文本、主体（self/contact/shared）、五类分类、消息引用、置信度、风险标记、受控主题（健康/工作/家庭/出行/财务/学习/情感/其他）、可选有效期
- [ ] prompt 含"结合上下文理解语气（反讽/玩笑/抱怨）"要求与负例示范（闲聊不产出记忆）
- [ ] 证据契约校验：窗口外引用、空文本、非法分类/主体/主题、缺置信度被拒且不进入结果
- [ ] 整体不可解析返回明确失败（可重试语义）
- [ ] fake model 单测覆盖合法、逐类非法、失败路径；不调真实 API；只用合成数据
