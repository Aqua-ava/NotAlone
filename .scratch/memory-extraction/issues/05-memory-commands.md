# 05 — 记忆命令族与台账接线

**What to build:** 命令行入口族：提取命令（自动判断全量/增量：联系人从未提取过→全量分批滚动，提取过→从水位只提新增；断点安全重跑）接出站台账；手动录入命令（manual 标记，支持联系人级与 owner 级）；列出记忆命令；删除记忆命令（软删除留指纹）。终端只输出统计与状态。

**Triage:** ready-for-agent
**State:** open
**Blocked by:** 04（写入裁决）

- [ ] 提取命令自动判断全量/增量并以水位断点续跑；已提取部分重跑自动跳过
- [ ] 单批消息窗口上限为显式常量；分批串行执行
- [ ] 提取与裁决的外部调用三态落台账，含 provider、模型名、token 与延迟
- [ ] 手动录入命令：文本+分类+主体+联系人（或 owner 级）经 MemoryPort 标 manual 入库
- [ ] 列出命令：按联系人或 owner 列出记忆（含状态、来源、采纳标记、版本历史），不打印正文以外的敏感信息格式与既有命令一致
- [ ] 删除命令：软删除留指纹，删除后检索不可见
- [ ] 终端输出只含统计与状态；更新 README 记录命令用法与边界
