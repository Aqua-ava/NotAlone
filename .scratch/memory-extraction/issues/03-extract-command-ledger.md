# 03 — 提取命令与台账接线

**What to build:** 独立命令行入口：按导入命令的环境变量与参数惯例指定已确认联系人，读取该联系人最近固定条数消息（时间正序、含媒体占位文本），执行一次提取并输出纯统计（提取、采纳、跳过、拒绝条数）；提取的外部模型调用接入出站台账三态记录与用量上报；终端不打印消息正文、事实文本或联系人标识。

**Triage:** ready-for-agent
**State:** open
**Blocked by:** 02（自动采纳与重复抑制）

- [ ] 命令入口对齐导入命令惯例（数据库连接串与 owner 经环境变量，联系人经参数）

- [ ] 外部调用成功、运行失败、校验拒绝三态落台账，含 provider、模型名、token 与延迟

- [ ] 更新 README 如实记录命令用法与能力边界
