# 01：单帧定位贯通现有入口

State: resolved
Triage: ready-for-agent
Blocked by: None

## 交付行为

用户通过现有助手入口进行一次定位时，原生探针、认证后端和助手展示共同使用一帧取得的名称证据。每轮只采集当前唯一前台微信窗口一帧，保留必要的质量与绑定检查；结果描述采集时点，不能被解释为返回时仍是该会话。

本票先完成现有单次入口的单帧链路；连续调度由 04 交付。

## 验收条件

- [x] 有效观察恰好采集一帧；顶部名称与选中会话名称来自该帧的两处局部裁剪，移除第二帧采集、布局检测及跨帧像素复查。
- [x] 移动、缩放后的新观察使用当次窗口布局，无需手填坐标或旧人工 profile；未知布局、多个选中候选、截断、不一致、非法置信度或低分继续失败关闭。
- [x] 保留不采图的前台进程、唯一窗口、几何和代际检查；采集或识别期间可检测的失焦、窗口变化、连接失效不交付有效旧结果。
- [x] 同窗会话切换不能导致补截第二帧；公共结果与助手状态明确保留采集时点语义，不宣称消除了同窗切换滞后。
- [x] 已验证且唯一的绑定通过认证观察链路映射到原联系人；首次、改名、重名、未绑定或低质量继续要求人工选择，外部会话定位标识不能替代 `contact_id`。
- [x] 无前台微信、不可见窗口、缺失权限或定位停止时零图像采集；原始帧和裁剪及时释放，仅端侧内存处理，不 OCR 正文或其他列表、不保存或上传画面。
- [x] 单次观察有明确超时与错误投影，不降低质量门槛或无界重试；匿名耗时证据与真实 App 性能通过结论分别记录。
- [x] 定位不读取 CLI 正文、不改变后台同步开关、不创建候选回复任务、不操作微信或发送消息。

## 测试与完成条件

沿用原生自动窗口观察的注入接缝，以合成像素及可控上下文检查采集次数、裁剪、移动/缩放、质量拒绝和失焦。再通过生产认证观察入口与桌面公开控制器验证有效绑定、人工选择和错误状态传递，只替换 OS/CLI 输入为合成适配器。

执行最小相关原生、后端前台定位及桌面协议验证，记录实际命令、通过/失败、数据影响和剩余风险。合成链路不代替真实 App、屏幕录制权限或微信版本验收；实机组合由 06 接续。完成后在 `## Answer` 记录证据，再将本票改为 `resolved`。

## Answer

### 交付与证据

- [原生观察](../../../native/macos/Sources/NotAloneSyncCore/AutomaticSessionCapture.swift)移除第二帧、第二次布局检测和跨帧名称像素复查；图像取得后立即记录 UTC `captured_at`，成功协议为 `automatic-window-v2`。保留采集前后及 OCR 结束的无图上下文校验，仍仅 OCR 同帧两处名称，质量门槛为 0.90。
- 新宿主传入显式 `--single-frame`；旧二进制在参数解析处拒绝，不进入旧双帧采集。后端保留旧协议诊断解析，但认证的新观察仅接受 v2 和有效 UTC 采集时间；现有八字段 HTTP 结果的 `observed_at` 传递采集时间，未增加数据库字段。
- [助手控制器及展示](../../../desktop/src/renderer/ForegroundPanel.tsx)保留采集时点，包括有编辑而要求确认的联系人建议，并提示同窗切换可能滞后。新的低质量/错误观察清除旧手选资格；正常助手生命周期取消在途观察使用暂停语义，保留手选资格并拒绝迟到结果。
- [原生合成测试](../../../native/macos/Tests/NotAloneSyncProbeTests/AutomaticSessionCaptureTests.swift)验证恰好一帧、同帧名称裁剪、移动/缩放、亮暗布局、质量拒绝、同窗变化不补截、采集后与 OCR 后失焦拒绝。权限预检、唯一可见窗口和停止门沿用现有实现及相关安全测试；本票未实测系统权限或真实窗口。
- [生产认证 HTTP/隔离 PG 回归](../../../desktop/tests/single-frame-foreground-http.test.mjs)使用合成探针/CLI，贯通唯一绑定到原 `contact_id`、采集时间和公开助手状态；覆盖旧协议、低分、名称不一致、无效/无时区时间、重名及改名拒绝，编辑建议显示时间，以及在途获焦和迟到响应。定位前后正文 tail 计数不变，候选回复请求为零。既有首次/未绑定与授权门继续由前台定位及 CLI/宿主测试覆盖。

### 数据影响、清理与剩余风险

实际改动仅减少每轮视觉采集数量并增加采集时间语义；原始帧/裁剪仍只在端侧内存，不持久化或上传，不 OCR 正文或其他联系人列表。观察只读取 CLI 会话元数据，不读正文、不改变后台同步、不调用模型、不生成或发送消息。仅使用合成联系人和隔离业务库；HTTP 夹具已认证停止自有后端、删除测试库，未确认资源列表为空。

未运行真实 App、微信或真实采集探针，未验证新版屏幕录制权限归属、真实 OCR、正式 App 绑定匹配及性能；这些必须由 06 在用户认可的有限时段完成。单帧结果仍允许同窗切换滞后，布局检测器的微信版本边界未扩大。没有 push、远端分支或 PR。
