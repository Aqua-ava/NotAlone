Type: task

## 交付行为

冻结同一实际安装产物，证明没有开发环境的新装和保留已有资料更新两条完整用户路径可用，给出可审查的安装与版本证据。

## 验收条件

- [ ] 无开发环境的目标机器从安装包完成首启、微信确认、生成与编辑候选；无预填路径或提前迁移的测试替代。
- [ ] 正式旧版结构在 App 内备份兼容更新后继续使用，资料、来源、绑定、开关和暂停状态保留。
- [ ] 覆盖移动 App、重复启动、权限拒绝、更新中断／失败与退出收尾的同版组合检查。
- [ ] 核验全部随包组件来源、许可、摘要、签名与平台范围；Developer ID／公证和外部发布在具体产物准备好后单独按授权执行。
- [ ] Standards 与 Spec 两轴独立审查完成，修复发现项，更新普通用户安装说明。
- [ ] 缺少实际环境、权限、凭据或版本证据时如实保留未完成项，不宣称独立可交付。
