## 交付行为

无开发环境的新安装从实际 App 包启动，向导准备受管后台与数据库，完成本人及模型设置并进入可用的联系人空目录，全程不填开发路径或运行终端。

## 验收条件

- [ ] 产物提供可重定位的后台、Python 及 PostgreSQL 运行环境，组件具有固定来源、版本、摘要和完整许可；不携带开发配置或私人资料。
- [ ] 从独立空用户目录通过公开 App 操作准备空数据库，运行生产迁移与后台；不用测试进程预填路径、迁移或借用开发环境。
- [ ] 本人及模型设置复用既有明确操作与受控凭据语义，进入联系人空目录时显示真实连接与状态。
- [ ] 取消、缺损组件、准备失败与重开提供对应动作；重复启动不创建多套环境或重复后端。
- [ ] App 搬动后仍可用，退出认证停读并回收本次数据库和后台，保留用户数据。
- [ ] 在最高公开 App 接缝先 red 后 green；构建、相关回归、签名、Computer Use 与真正无开发环境的结果分别记录，不互相代替。

## 工作边界

遵循 ADR-061、工程与领域规则；只使用独立合成资料。未受支持的既有资料交给任务04，不得静默改指空库。本任务不完成微信授权、不修改用户当前业务库或系统权限，不推送或发布远端。
