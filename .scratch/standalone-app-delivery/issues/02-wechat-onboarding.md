# 02：通过受控授权完成微信首次接入

Type: task
State: open
Triage: ready-for-agent
Blocked by: 01
Spec: ../spec.md

## 交付行为

使用者在首启向导看见影响后，亲自确认微信退出／重开和必要的一次性系统授权，完成读取工具初始化，并看到真实可用或失败结果。

## 验收条件

- [ ] 固定可取得源码与构建来源、版本、摘要、依赖清单及完整许可，重验与产品实际协议兼容性；不拿新源码补证旧黑盒产物。
- [ ] 解决 LLDB／系统 Python 等隐含开发依赖，在不安装开发环境的目标机器验证。
- [ ] 初始化先说明影响并取得本次明确确认，原微信保留，管理员认证由系统处理，App与子进程不保存管理员密码。
- [ ] 特权入口只执行本次固定初始化，不接受任意命令或执行路径，后台不能沿用权限再次提权、重签或重开微信。
- [ ] 拒绝、取消、过期和失败不继续，向导有真实状态与恢复动作。
- [ ] 公开 App、原生授权与真实微信分项验收；不可行时带证据回到设计，不放宽边界或把准备成功当作接入成功。

## 工作边界

用户已确认产品体验；实际新系统权限、管理员凭据输入等仍按桌面工具的行动时规则由用户完成。不得发送聊天消息或扩大联系人读取范围。
