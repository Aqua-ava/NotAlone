## 交付行为

空目录用户从实际 App 完成本机、本人和模型设置后，明确创建／选择联系人，粘贴当前聊天文字或确认单联系人资料导入，生成并编辑带依据的候选；全程不要求准备微信、运行路径或终端。

## 验收条件

- [x] 空联系人目录提供公开、明确的建联系人与选择入口，不伪造微信身份或绑定。
- [x] 用户手动输入可通过既有生成协议；无 CLI／探针不阻止此路径，未选择联系人仍禁止生成。
- [x] 单联系人导入保留预览、确认、来源与删除语义；混杂、损坏或归属不明时拒绝或要求拆分。
- [x] 候选依据可查看、可编辑；切换联系人不串资料，手动当前消息不静默成为长期记忆，最终消息由用户亲自发送。
- [x] 公开界面如实说明首版输入方式与未完成渠道，失败提供对应恢复动作；不启用未完成特权初始化。
- [x] 取得实际包公开行为 red→green、Computer Use首用与退出证据；合成模型、真实模型和无开发环境分别记录，不混作完成证明。
