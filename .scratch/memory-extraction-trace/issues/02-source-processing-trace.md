# 02：从新原始聊天到规范消息的完整来源处理链

Triage: ready-for-agent
State: claimed
Blocked by: 01

## What to build

用户导入历史或同步已确认会话后，可以从提取结果一路回查到当时原始文字记录、解析、说话人和时间转换、规范化、过滤与去重，知道哪些数据在进入模型前已经改变。处理时间以实际发生为准，旧来源不伪造回填。

## Acceptance criteria

- [ ] 历史导入保留所用原始 JSONL 记录原文与解析结果、定位、实际时间及规范化版本/转换结果。
- [ ] CLI 只在已确认文字会话范围捕获投影前文字事件，保存说话人、时间、正文及去重/过滤定位，不保存整段输出或视觉帧。
- [ ] 新输入的处理记录连接来源引用和规范消息，再连接提取追踪；消息已保存与模型曾读到明确区分。
- [ ] 解析失败、筛选、重复、来源引用增补和历史缺失有真实结果，不把后台记账时间当作原始解析时间。
- [ ] 来源删除、跨范围拒绝和处理记录写入故障通过公开入口验证，受影响快照不可恢复。
- [ ] 在已确认导入/同步及查询/删除接缝完成 red → green 和相关验证。
