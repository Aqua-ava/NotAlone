# 默认 L1 失败恢复

## 范围与行为
- 参考本地腾讯 MemoryCore 的有限重试与 JSON 修复，默认 L1 连接/超时、408/429/5xx、结构输出失败最多追加 5 次请求，间隔 30 秒。
- SDK 重试必须为零，避免与提取层次数相乘；鉴权、追踪写入及其他非暂态错误不重试。
- 只修复明确的语法问题；已知字段缺起始引号、结构尾逗号、控制字符及完整代码围栏可解析，修复路径拒绝重复键、非有限数字及截断正文。不改写记忆内容或来源。
- 默认 L1 外的核验、裁决和 L2/L3 调用不在本次修改范围。退役的升级运行时显式禁用内部重试，保持其按调用计预算的契约。
