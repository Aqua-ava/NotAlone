# 开发 App 延迟验收

Triage: ready-for-agent
State: open

Blocked by: 03

## Goal

复用 `pnpm run dev` 热更新实例，在相同联系人、相同合成输入和相同本地数据下比较修复前后的准备阶段，确认不再出现三十秒级等待。

## Acceptance

- [ ] 只操作实际开发 App和微信，不打包、不发送外部消息。
- [ ] 记录点击时间、本地阶段、模型阶段和总耗时，至少区分准备与模型。
- [ ] 使用合成测试对象和输入，不保存私人截图、正文或凭据。
- [ ] 报告实际样本量、前后耗时、数据影响、命令、剩余风险和清理情况。
- [ ] 只提交本任务变更，不包含现有用户未提交修改。
