# 02 — L2 联系人记忆目录与失效

**What to build:** 用户生成候选回复时，系统可以使用当前联系人有效关系记忆的精简场景/主题目录定位相关资料；当记忆更新、失效或删除时，旧目录和派生索引不会继续影响回复。

**Blocked by:** 01 — 关系记忆的采纳状态、来源和有效期规则必须先确定。

**Status:** ready-for-agent
**State:** open
**Triage:** ready-for-agent

- [ ] L2 只从有效的 L0/L1 及其来源生成，保存少量主题入口和有效记忆引用。
- [ ] L2 不复制全量聊天正文，不产生脱离权威记忆的新事实。
- [ ] 记忆新增、修改、分类变化、过期或删除后，目录 revision 发生变化，旧目录不能继续参与回复。
- [ ] 目录由可重试、幂等的后台任务增量更新或重建；重建完成前不会引用已失效资料。
- [ ] 用户的候选回复可以通过 L2 找到相关 L1，但 L2 本身不会被当作最终事实。
- [ ] 删除底层来源后，相关目录、全文索引、缓存和运行摘要均不可继续检索。
- [ ] 使用合成联系人验证版本不一致、删除、重建失败和重复任务行为。
