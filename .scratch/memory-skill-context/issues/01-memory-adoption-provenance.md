# 01 — 关系记忆采纳与来源证据

**What to build:** 用户在真实消息产生关系记忆候选后，可以看到候选的来源、可信度、风险和有效期；低风险且明确的资料按规则自动采纳并标记为 `auto`，敏感关系推断保持待确认状态。用户可以确认、修改、拒绝或撤销记忆，且旧版本和来源仍可追踪。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent
**State:** open
**Triage:** ready-for-agent

- [ ] 真实 Message 只在成功提交后进入异步提取，候选带有当前 Owner、联系人、来源消息、置信度、风险和有效期。
- [ ] 低风险且明确的候选可以按 allowlist 自动采纳为 `confirmed_memory`，记录 `auto`、来源和可撤销关系。
- [ ] 敏感关系推断在用户确认前保持候选状态，不进入默认回复上下文。
- [ ] 用户可以查看来源、接受、编辑、拒绝和撤销；更新创建新版本，旧版本标记失效而不是静默覆盖。
- [ ] 重复提取和重复任务幂等，不产生重复候选或确认记忆。
- [ ] 采纳规则与现有关系记忆架构决策完成明确复审，不能静默覆盖既有决定。
- [ ] 使用合成或匿名化数据覆盖来源缺失、冲突、过期、越权和删除后的行为。
