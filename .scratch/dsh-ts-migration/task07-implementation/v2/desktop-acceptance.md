# 根独占的 07 桌面验收

本文件是待执行步骤，不是 App 验收证据。必须记录最终合入源 SHA，先核验并复用 `npm run dev` 热更新实例；不得打包或运行打包版。

1. 在根已授权的合成测试库、临时用户目录和 loopback 模型配置下，核对 App → 正式 DSH host-plugin → Legacy 公开路由 → TS B/C 的进程链；不得使用直接挂载 runtime.handle 的服务夹具替代。
2. 统一工作区留空点击候选：直接进入 C，不插入伪方向或 B；输入本次想法再生成，编辑、保存、关闭重开，核对本次意愿和草稿保留。
3. 在可用目录中分别选择自动、指定版本与不用 Skill，检查实际版本名称、版本号、选择来历、候选依据；B 固定的 Skill/NoSkill 进入 C 后不能静默重选，自动来历不能显示为用户确认。
4. 方向探索出现澄清时回答，核对未自动确认意愿；明确选择或直填后才生成。换组不重复方向，不刷新原 15 分钟根时效，不增加无效重放的物理模型调用。
5. 在模型未结束时停止、切换到另一位合成联系人编辑草稿，再释放模型；原晚结果不得写入另一联系人或恢复原暂停状态。原 SDK 完全退出后才释放共享许可。
6. 查看带长正文的最近 50 条证据，核对消息标识、顺序、说话者与全文；B 的小窗口不得替代 C 的完整窗口。来源删除与目录撤权后晚结果应失效。
7. 核对旧探索入口兼容、回到同一会话后的选择和候选重放；不重新暴露已收敛的旧交互模式。检查根 23 用量与诊断入口仍可达。

每项记录实际观察、源 SHA、所属进程与结束状态、脱敏截图或 UI 证据、模型物理调用数、来源引用与自有资源清理。只用合成内容，不发送外部消息。未执行项保持待验，不能由公开适配器测试推断 App 已通过。
