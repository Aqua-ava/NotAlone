# 助手 generation 生命周期迁移清单
- 源码基点 a61a21407c9395c462e4e68bfeee4628e7e9b15c；根统一集成与提交。
- 独占 backend-ts/src/assistant-generation-*.ts 与 backend-ts/test/assistant-generation-*；未修改共享文件。
- Class：AssistantGenerationLifecycle({transaction,skillsRoot,replyService,environment?,resolveBinding?,runInScope?,onEvent?})。
- replyService 注入现成 ReplyHttpService，复用其 prepare/generate、供应商、预算、模型仲裁和候选 writer。
- handle({method,path,body,scope:VerifiedReplyScope,signal,respondAsync?}) → Promise<{status,payload}|null>。
- handleExploration(input,exploration:ExplorationHttpService) → 同返回合同；只接 confirm/answer/prepare-confirm/prepare-answer。
- prepare(scope,sessionId,body,signal)；generate(scope,sessionId,body,signal)。
- replace(scope,sessionId,body,signal,prepare=false)；retryInterrupted(...)；continue(...)。
- /replies[/prepare]、/replace[/prepare]、/retry-interrupted[/prepare]、/continue[/prepare]、/interrupt、/preparation-format。
- 同 owner 锁内核对联系人、授权、覆盖确认、输入 CAS、来源／候选／Skill 和原指纹，领取持久 A 锚点及输入。
- 准备失败的 no_generation 仅在回滚局部领取、确认零 A/C 并持久封键后返回。
- 同键异稿冲突；同键在途立即处理中；C 仍由现成 PostgresReplyStore 原子领取。
- 同事务替换旧键及租约；迟到写入仍经现成来源、版本、失效键与提交守卫。
- 持续要求核对完整展示组与版本、已选说法、当前意愿、累计要求与消歧。
- 新消息采用继承真实当前输入要求；探索中断重试使用既有 reconfirm writer 建新 B 执行身份。
- Prefer: respond-async；GET/DELETE /.../prepare/status/:id；4并行、64缓存、120秒截止、5分钟终态留存。
- job 是原合同的短期等待句柄；持久权威是 A 输入／锚点与 C 请求，不新增数据库表。
- 异步任务通过 runInScope 重新进入已核验范围，202 返回后的手动来历不会回落到桌面绑定。
- drain() 停止接纳、取消并等待本实例在途工作；recover(ownerId) 不调用模型。
- recover 对零 C 遗留 running A 封键标 app_quit；已完成 C 关联保存结果；仍 running C 拒绝猜测终态。
- 事件沿原公开合同；未增加未知 SSE type，onEvent 保留可选接缝。
- 原 Python、依赖、任务票和 schema 均保留；真实桌面／微信、配置和模型由根独占。
- 本次新增公开测试完全用 Node 迁移、随机 _test PG、本机假 provider 和官方 DSH profile。
- 旧来源／讨论回归单独运行，保留其隔离 Python 建库夹具，不计为零 Python 产品启动证据。
- 详细验证、数据影响、清理及限制见 validation.md；精确文件／摘要见 source-manifest.json。
