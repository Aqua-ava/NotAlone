# root 的合成实际 App 操作清单

1. 全程独占桌面、CUA 操作；先核对原项目 `cd desktop && npm run dev:status`，正常退出原实例后才启用本夹具。不得打包或运行打包版。
2. `NODE` 指向已有 Node 24+；`F=.scratch/dsh-ts-migration/final-native-basic-fixture/fixture.mjs`。需要本机 `/tmp:5432` PostgreSQL 和已有 npm；不安装依赖。
3. 在仓库根执行 `"$NODE" "$F" prepare`；私有输出给出 `sessionPath`、`directory`、`projectDirectory`、`startScript`、两份 `importFiles`。只在私有工具状态保存这些路径。
4. 令 `S`、`D`、`P` 分别为该 sessionPath、directory、projectDirectory；`"$NODE" "$F" inspect "$S"` 仅用于初始状态，确认迁移清单与种子归属。它显式跑一次合成 tail，CLI 日志基线不是空文件。
5. 源码快照与原文件逐项同 SHA，依赖是既有 node_modules 的符号链接；没有复制原 .env、用户配置、账本或资料。后续原仓修改不会热更新进该快照。
6. root 启动：`nohup "$D/start-dev.sh" >"$D/dev.private.log" 2>&1 &`。此脚本以干净环境执行快照的 `npm run dev -- --user-data-dir ...`；不启用 CDP。
7. 就绪后在 `$P/desktop` 再跑 `npm run dev:status`，核对唯一 `--notalone-dev` 宿主和监督器；服务就绪以 CUA 画面确认。若启动失败，保留私有日志，不能用 API 结果冒充 GUI。
8. CUA 在顶部选「合成验收甲」，确认记忆有「青色便签」auto 项、待确认有「折纸」；切到「合成验收乙」只应见乙的手动资料，甲的内容不出现。
9. 切回甲，打开「设置 → 从文件导入」或页面的「从文件导入」，在原生文件选择器选 `synthetic-import-a.jsonl`；预览应为 2 条，归属甲、本人及 talker 均为 synthetic。
10. 先切到乙，确认甲的预览与确认失效；重新选甲、选择甲文件并预览，勾选核对、确认本次预览，再点「取消本次确认」。这些取消不等同于生成中取消。
11. 再次确认并正式导入，确认新增 2 条及来源文件。关系提取受空模型 key 阻止或等待，不能声称自动提取质量通过；记忆页任务面若出现可停止任务，可点「停止任务」并核对终态。
12. 在来源管理选择刚导入的合成来源，先取消删除，再明确删除，观察真实任务完成；两条导入消息应随来源清除，乙的资料保持。
13. 甲「待确认」点「记住」审核折纸候选；在「对方」该项「⋯ → 编辑」先取消，再保存明确合成修正文，随后「移除 → 确认删除」。
14. 甲青色便签 auto 项「⋯ → 移除 → 确认撤销」；再次切乙，乙的独立手动资料应保留。这里验证撤销自动采纳，不宣称完整自动版本替代撤销矩阵。
15. 甲表达工作区展开「历史讨论」，刷新/读取既有讨论，展开「方向讨论」核对预置折纸活动合成文字；先取消删除会话，再确认删除，会话不再能恢复，关系/来源保持。
16. 「同步」默认总开关关闭、范围仅所选；如显示历史授权待确认，用实际按钮「允许读取历史」。开启总开关，观察两位合成联系人的历史覆盖与 CLI 2 条历史接续，不能称为真实微信覆盖。
17. `"$NODE" "$F" control "$S" on` 只改变自有合成事件源；CUA 检查增量及覆盖，重复检查不应重复入库。日志只在 `$D/cli-commands.jsonl`，按开启前后比对，不进入公开记录。
18. CUA 关闭总开关，检查日志不再出现新正文 tail；重新开启检查接续与去重。若状态尚未覆盖或不可达，原样记录缺口，不写通过。
19. 空模型 key 无法稳定创建真实生成作业，所以「停止本次生成」的在途取消不属于本夹具已覆盖范围；真实微信/前台 OCR、真实模型、完整语义矩阵与两项争议均不由本夹具认证。
20. CUA 正常菜单退出 App，核对开发监督器、后台与合成 CLI 已退出，再 `"$NODE" "$F" close "$S"`。退出前不能删目录或数据库。
21. close 只接受本夹具随机 `_test` 名、私有记录及数据库归属标记；有存活 PID、相关进程或数据库连接即失败保留现场，不强杀、不强制 DROP、不碰原库。
22. close 成功需返回 `databaseAbsent=true`、`directoryAbsent=true`、`liveOwnedProcesses=0`；原依赖链接的目标不在删除范围。失败修复占用后以同一 `S` 重试，不盲目新建夹具。
23. GUI 验收结果与截图/日志留私有目录；公开仅相对路径、非正文元数据和 SHA。先前自检不代表本轮实际 App 已验收，也不改变 25 claimed、26 未开始。
