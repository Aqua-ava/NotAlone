## Computer Use实际操作与观察

1. 管理后台显示合成甲友、已关联fixture-a、0条消息。点击“打开输入小窗”，显示“本次联系人已通过微信会话绑定确认”；小窗获得焦点后显示前台定位暂停，后台同步独立。
2. 给合成名单增加一个未绑定同名会话，隐藏并重新打开助手：出现“当前联系人未确认”，两个生成按钮均禁用，要求“确认本次联系人”。没有自动生成候选。
3. 点击确认后，用CUA paste输入合成验收草稿，并从AX核实其实际值。把同一稳定身份的合成显示名改为合成新名，保留数据库原绑定名；重新打开后再次要求确认、生成禁用，原草稿与合成甲友显示保留。
4. 再次手动确认后，将合成名称恢复、置信度设0.1；重新打开依然要求确认、生成禁用，草稿不变。
5. 在同步设置点击“关闭后台同步”，实际UI变为已关闭。此时把合成探针设为读取即写marker并挂起；公开观察返回sync_disabled且contact_id为空，probe-started marker不存在，证明关闭后没有读取该探针。
6. 恢复合成新鲜高分观察，用UI重新开启总开关再打开助手：既有人工确认门持续，未静默恢复生成。再次点击“确认本次联系人”后显示“本次联系人已由你确认”，生成按钮恢复可用；未点击生成。
