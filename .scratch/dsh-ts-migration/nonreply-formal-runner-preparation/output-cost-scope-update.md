# 输出与费用范围更新

2026-10-25，用户在状态汇总聊天明确要求：“输出和费用都先不要管 不要做限制，给这些会话通知一下吧”。该最新指示覆盖本轮此前的输出容量及费用限制。

- 正式runner、矩阵和后续交接不再以固定4096输出token、输出容量预算、1.10费用比或费用预算作为阻塞、停止或验收门槛。输出额度按实际任务需要配置，不继承本目录假provider的4096夹具值为正式上限。
- 费用和各类用量继续如实记录；历史实测、原失败和原报告保留。不为满足旧输出/费用门槛继续停工、重跑或专项优化。
- 物理请求次数/时限的既有授权、来源及联系人范围、取消、真实质量和人工发送、桌面开发及发布约束继续有效。发送端口中的根问题账本仍用于物理尝试记录及授权复验，不要求费用余额或输出容量额度。
- 本目录依然只支持离线/loopback假provider；此次更新不新增本会话的真实外呼、密钥、真实资料、App或微信操作范围。真实执行仍由根协调。

已冻结探针不重跑；其中的4096及 `waived_temporarily_by_user` 是原运行配置/政策记录，不代表更新后的限制。新政策以本文及当前交接为准，不改写冻结材料、oracle、语义质量阈值、失败或实际用量。
