# 2026-10-24 模型配置范围更正

用户明确要求：「ecnu这个废除不用这个，不需要兼容。」已从转达会话读取并核对人类原始消息；这项决定更新此前「所有模型配置保留」中的 ECNU 例外，其他 DSH／TS 直接替换任务与验收要求不变。

- 不再开发 ECNU／ecnu-max 的 Chat Completions 兼容，不为其新增 pi-ai 插件或依赖，不把缺少 ECNU 验收列为迁移阻塞。
- 已开始的 ECNU 专项在安装或修改文件前停止；没有新增相关依赖或产品实现。保留历史协议差异说明，避免以后误判只需更换 URL。
- 正式配置遇到 ECNU 时明确返回已退役、需重新配置的结果。不得自动改用官方 DeepSeek、覆盖原配置、读取真实凭据或逐请求回退旧生成器。
- 既有联系人、资料、UUID、历史模型调用及未知用量均保留；不因废除供应商配置删除业务数据。
- 官方 DeepSeek 的精确配置、输入预算、逐次物理许可、累计费用与调用次数、取消和恢复合同仍须实际验证。原 05、06 及后续任务的其他验收条件保持。

用户也说明愿意配合必要验收。先准备好实例，再提出具体、最少的配合步骤；这不扩大既有单个测试会话、仅新消息、本机验证的范围，也不授权 Agent 自行发送外部消息或读取历史。

决策已同步到 [ADR-102](../../architecture/adr/102-dsh-typescript-backend-migration.md)、[实施规格](spec.md)与[规划索引](planning.md)。旧 ADR-045／062 的 ECNU 配置决定由 ADR-102 这项更正替代，历史实现仍按实际状态描述，不能把范围变更冒充全部旧代码已退役。
