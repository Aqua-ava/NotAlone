# 本次参考：直观只读展示

状态：用户于本会话确认范围并授权实现。复用当前开发实例，仅 npm run dev，不打包、不推送。

## 用户可见要求

1. 一轮候选共用一个位于候选下方的「本次参考」入口，默认收起，换联系人、请求或历史会话后恢复收起。
2. 收起显示本轮实际材料分类与数量，加载中/失败/旧快照未知须明确，不假装没有材料。
3. 展开按聊天、关系资料、本人资料、表达参考、回复方法展示具体原文；本次输入独立显示。来源/时间可继续展开。
4. 只显示实际提供给模型的冻结材料。目录与已读正文区分；不从当前资料库补造历史；不能把提供给模型视为每项均被候选引用。
5. 不新增调整、排除、重新生成操作。已有生成前排除和候选编辑/复制等操作保留。
6. 普通用户主视图不显示 UUID、版本号、token、调用预算；技术详情折叠。未加载类别不占主列表。
7. 样本原文依附现有请求快照并沿既有删除链清理；旧快照未保存正文时说明未知。回复策略按已存名称显示，不编造策略解释。
