# 04 — 离线召回评测与 CI 门槛

**What to build:** 一套合成中文召回评测：用例描述维度、query、联系人范围、记忆集合（正文、分类、主题、采纳方式、置信度、有效期）、期望召回与排除、预算参数；runner 装配内存检索、真实评分器和真实回复上下文组装，不复制实现；七个维度各至少 15 条用例，门槛断言在常规 `unittest` 中运行，不需要模型凭据与数据库：直述命中 top-5 ≥ 90%、改写命中 ≥ 60%、无关拒绝误注入 0、跨联系人泄漏 0、失效或删除注入 0、预算超限 0 且双预算独立、排序优先级正确率 ≥ 90%。不达标先调整词法与阈值，不得放宽门槛。

**Triage:** ready-for-agent
**State:** open
**Blocked by:** 02 — 联系人记忆相关性召回；03 — 本人记忆独立召回

- [ ] 七个维度各至少 15 条合成用例，无真实聊天内容
- [ ] runner 复用真实评分器与真实上下文组装
- [ ] 门槛断言进常规测试，无凭据、无数据库环境可通过
- [ ] 失败输出可归因到具体维度与用例
- [ ] 无关拒绝、跨联系人、失效三类安全维度为 0
- [ ] 双预算独立性与排序优先级有独立用例覆盖
